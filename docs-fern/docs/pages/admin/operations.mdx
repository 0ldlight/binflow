# 制品操作与回收站

两个生命周期域，共用 pro 档功能槽：**制品操作族**（槽 `repo-operations`）与 **Trash can**（槽 `trashcan`）。community 实例对族内写动词答 403 + `X-Binflow-License-Required: <槽id>`；降级只关门不碰数据。

## 制品操作族（copy / move / zip / archive! / explode）

| 动作 | 端点 | 一句话 |
|---|---|---|
| copy | `POST /binflow/api/copy/{srcRepo}[/{srcPath}]?to=/…` | 树级复制（零拷贝，blob 引用复用） |
| move | `POST /binflow/api/move/{srcRepo}[/{srcPath}]?to=/…` | 树级搬移（copy + 源删除） |
| 目录/整仓打包下载 | `GET /binflow/api/archive/download/{repo}[/{path}]?archiveType=…` | 流式 zip / tar / tar.gz，不落盘 |
| 归档内成员读取 | `GET /binflow/{repo}/{archive}!/{entry}` | 不解包直读归档里的单个文件 |
| 解包部署（explode） | `PUT /binflow/{repo}/{path}` + `X-Explode-Archive: true` | 上传归档的同时原地展开 |

### copy / move

```bash
curl -su admin:$ADMIN_PW -X POST \
  "$BASE/binflow/api/copy/generic-local/acme/a.bin?to=/staging/a.bin" | jq .
# {"messages":[{"level":"INFO","message":"copying generic-local/acme/a.bin to staging/a.bin
#   completed successfully, 1 artifacts and 0 folders were copied"}]}

# 干跑（不落任何数据，消息带 "Dry run for " 前缀）
curl -su admin:$ADMIN_PW -X POST \
  "$BASE/binflow/api/copy/generic-local/acme?to=/staging/acme&dry=1"

# 搬移目录树（源目录搬空后自底向上剪除）
curl -su admin:$ADMIN_PW -X POST \
  "$BASE/binflow/api/move/generic-local/acme?to=/archive/acme"
```

- 响应 200 + `{"messages":[{"level","message"}]}`（Content-Type 为 Artifactory vendor 形）；HTTP 状态 = 最后一条 error 的码（无码 409 兜底）。
- 参数：`to`（必填，`/{targetRepo}[/{targetPath}]`）/ `dry`（0/1）；`failFast`、`suppressLayouts` 解析接受但行为等同默认。
- `/api/flat/copy|move` 不实现（404）。
- **校验链**（顺序即优先级）：目标 remote/virtual → 400；repo 不存在 → 400；源 == 目标 → 400；源读权限 → 403；目标模式 → 403；move 的源删除权限 → 403；目标已存在且无删权限 → **401**（override 特例）；目标写权限 → 403。目标仓配额逐项检查（超限逐文件 413 消息，不失败整请求）。
- **数据语义**：零拷贝（blob 引用复用）；属性全量随行；源仓型 local 直读、remote = 缓存行 + miss 回源、virtual = 首个持有成员（**move 源为 virtual → 400**）；审计 `artifact.copy` / `artifact.move`。

### 目录打包下载

```bash
curl -su admin:$ADMIN_PW \
  "$BASE/binflow/api/archive/download/generic-local/acme?archiveType=zip" -o acme.zip
# checksum 伴随文件：&includeChecksumFiles=true（从 blobs 台账生成 .sha1/.md5/.sha256 条目）
```

- `archiveType` 必填枚举：`zip` / `tar` / `tar.gz|tgz`——缺省或未知 400。
- 仅 **local 仓**（remote/virtual 404）；无读权限 403；流式打包不落盘。
- **默认关**（`folder_download.enabled=false`）。配置段（重启生效，`GET /api/v1/system/settings` 回显核对）：

```yaml
folder_download:
  enabled: true                     # 总开关；BINFLOW_FOLDER_DOWNLOAD__ENABLED
  enabled_for_anonymous: false      # 匿名打包下载
  max_download_size_mb: 1024        # 0 = 不限
  max_files: 5000                   # 0 = 不限
  max_concurrent_requests: 10
  enabled_empty_directories: false
```

（camelCase 拼写被 strict schema 拒绝——用 snake_case。）关 `enabled` → 403 `Download Folder functionality is disabled.`；匿名腿未开 → 401 `You must be logged in to download a folder or repository.`。

### 归档内成员读取：archive!/

```bash
curl -s $BASE/binflow/generic-local/acme/bundle.zip!/README.md          # 读单个文件
curl -s $BASE/binflow/generic-local/acme/bundle.zip!/inner.jar!/META-INF/MANIFEST.MF   # 嵌套递归
curl -s $BASE/binflow/generic-local/acme/bundle.zip!/README.md.sha256   # 成员 checksum（裸 hex）
```

按**首个 `!/`** 切分；成员名**逐字匹配**（`./x` 只匹配 `./x`，折叠形 404）；非 GET → 405。可读归档集：zip 家族（zip/jar/war/ear/nupkg/conda/apk）+ tar 家族（tar/tar.gz/tgz）；**bz2/xz/7z 不支持**（400）。权限骑归档路径本身的读门；无开关（恒可用）。

### 解包部署：explode

```bash
curl -su admin:$ADMIN_PW -T bundle.zip \
  -H 'X-Explode-Archive: true' \
  $BASE/binflow/generic-local/acme/bundle.zip -i | head -3
# HTTP/1.1 201 Created
# X-Binflow-Exploded-Files: 7        ← 条目计数头
# （body 为空；归档原件不落库）
```

- 白名单闭集：`zip` / `tar` / `tar.gz` / `tgz`（白名单外 / 无扩展名 400）；PUT 路径尾斜杠 → 400 `Explode archive deployment failed, Missing file name.`。
- 默认 accumulate-then-answer（条目失败记录后继续，部分落地保留）；`X-Explode-Archive-Atomic: true` = 补偿式回滚已落地条目。
- 排除项：首段 `.jfrog` 系统文件、`maven-metadata.xml`（静默跳过）；**zip-slip 防御**：`../`/绝对路径条目 → 整单 400。
- 目标父目录无 `w` → 403；匿名 401；remote 目标 405。

## Trash can（回收站）

local 仓的删除不再一去不返：**删除前先把节点捕获进内置仓 `auto-trashcan`**（布局 `auto-trashcan/<原仓key>/<原节点path>`），可浏览、可恢复、可永久清除；保留期（默认 14 天）到点由小时级 cron 自动清。

### 捕获语义

- 捕获点：权限门之后、任何源行删除之前——**捕获失败即中止删除**（fail-closed：宁可留活）。逐节点打属性五元组：

| 属性 | 值 |
|---|---|
| `trash.time` | 捕获时刻 epoch 毫秒 |
| `trash.deletedBy` | 执行删除的主体 |
| `trash.originalRepository` / `trash.originalRepositoryType` | 原仓 key / 恒 `local` |
| `trash.originalPath` | 本节点的原路径（子树任一节点可独立恢复） |

- **跳过集**（本地生成物不入站）：`.jfrog/**`、`dists/**`、`repodata` 段、`_tmp_*` 首段、`maven-metadata.xml` 及其 checksum 族。
- **不捕获面**：remote 缓存失效、`DELETE /api/repositories/{key}?deleteContent` 仓拆除、docker manifest/tag 删除。
- `auto-trashcan` 是系统仓：建/改/删仓拒该 key；virtual 成员校验拒绝；无 permission target 能点名它——只有 admin / readonly_admin 可见。
- community 实例**不捕获**（删除仍是硬删）。

### 浏览（骑既有 storage 面）

```bash
curl -su admin:$ADMIN_PW $BASE/binflow/api/storage/auto-trashcan | jq .
curl -su admin:$ADMIN_PW \
  "$BASE/binflow/api/storage/auto-trashcan/vlibs/com/acme/v.jar?properties" | jq .
# {"properties":{"trash.time":["..."],"trash.deletedBy":["admin"],
#   "trash.originalRepository":["vlibs"],"trash.originalRepositoryType":["local"],
#   "trash.originalPath":["com/acme/v.jar"],"license":["apache-2.0"]}}   ← 原属性随行保留
```

### 恢复 / 清空 / 永久清除

```bash
# 恢复（to 覆盖 > 属性五元组 > 路径结构首段；响应 = copy/move 的 messages 同构）
curl -su admin:$ADMIN_PW -X POST \
  "$BASE/binflow/api/trash/restore/vlibs/com/acme/v.jar?transaction-size=100"

# 清空 / 单条（子树）永久清除
curl -su admin:$ADMIN_PW -X POST $BASE/binflow/api/trash/empty | jq .
# {"removed":2,"files":1,"folders":1,"bytes":3}
curl -su admin:$ADMIN_PW -X DELETE $BASE/binflow/api/trash/clean/vlibs/com | jq .
```

trash REST 族的门是 `system:write`（**仅全量 admin**）。恢复后落地树剥除 `trash.*` 标记（原属性保留）；`to` 指向已存在同名文件 → 覆盖。审计 `trash.restore`。

### 保留期

默认 **14 天**；小时级 cron 按 `trash.time` 判龄。**可配**（重启生效，`GET /api/v1/system/settings` 回显核对）：

```yaml
trashcan:
  retention_days: 7        # 0 = 默认 14；负值拒启
```

**GC / cleanup 免疫**：trash 内容 = 引用内容——GC 的 mark 集包含 can 的节点行；cleanup 的 policy 腿只走 remote 仓。`trashcan.enabled` **不是配置键**（strict schema 拒绝）——捕获开关走 license 槽。

## 常见报错对照

| 症状 | 原因 | 处置 |
|---|---|---|
| 403 + `X-Binflow-License-Required: repo-operations` / `trashcan` | community 档 / license 过期 | 装 pro license；读面不受影响 |
| 400 `…only be performed on local repositories` | copy/move 目标是 remote/virtual | copy/move 只落 local |
| 401（override 消息） | copy 目标已存在且无删权限 | 授 delete 或换目标路径 |
| 400（zip-slip） | 归档条目含 `../`/绝对路径 | 修归档内容 |
| 404 `Unable to find zip resource: ...` | `archive!/` 成员名不逐字 | 用归档工具核对成员名 |
| 打包下载 403（已认证有读权限） | `folder_download.enabled` 默认 false | 配置段置 true 重启；临时用 `!/` 成员读取 |
| 删除后 can 里没有（community 实例） | 捕获侧同槽门控——不捕获即硬删 | 装 license；物理移除后不可恢复 |
| restore 400 / 404 | `to` 指向 can 自身或目标仓非 local / 目标仓已删除 | 换 local 目标仓 / 先重建 |
| 建/删名为 `auto-trashcan` 的仓 400 | 系统仓守卫 | 不要用这个 key |
