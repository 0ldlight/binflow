# BinFlow 简介

BinFlow 是一个用 Go 从零实现的**云原生制品仓库**，架构与概念模型对标 JFrog Artifactory——仓库、存储、权限、REST 语义一一对应，Artifactory 用户迁移过来不用重学词汇。单静态二进制、零外部依赖，内嵌 Web 控制台。

本文档适用于 **BinFlow v1.0.0**。

## 包型矩阵（含档位）

| 档位 | 包型 | 说明 |
|---|---|---|
| **community**（地板——不装 license 也有） | generic、docker、maven、npm、pypi | 五核心包型 + 属性系统 |
| **pro** | go、nuget、cargo、conan、helm、rpm、debian、helmoci，及制品操作族、回收站、webhook 三个功能槽 | 建仓/上传需 pro 及以上 license |
| **enterprise** | ha、xray-integration 功能槽 | 槽位占位 |

档位语义一句话：**读永不劫持**——license 缺失/过期只关闭建仓（400）与写动词（403 + `X-Binflow-License-Required: <addon>` 头）；`GET /binflow/api/v1/addons` 返回逐槽位实时判定。详见 [License 与 Add-ons](/admin/license)。

每种包型都支持 **local / remote（pull-through 代理缓存）/ virtual（聚合）** 三种仓型（docker 的 virtual 聚合暂不支持）。

## URL 拓扑

所有 URL 使用统一的 `/binflow` 前缀：

| 面 | 前缀 | 说明 |
|---|---|---|
| 管理/兼容 API | `/binflow/api/...` | 仓库 CRUD、用户/权限、审计、GC、token |
| 制品内容路径 | `/binflow/<repoKey>/<path>` | 上传、下载、删除制品 |
| Docker Registry v2 | `/v2/...`（根级例外） | docker/podman/crane/skopeo 客户端 |
| Prometheus 指标 | `/metrics`（根级例外） | 匿名可读（默认） |
| Web 控制台 | `/binflow/ui/` | 浏览器登录入口 |

## 安全基线

- BinFlow 只提供**明文 HTTP**——TLS 终结交给前置反向代理；compose 产物默认绑定 `127.0.0.1`。
- **匿名读默认开启**（内容路径 GET/HEAD 免凭据）；写操作与 `/binflow/api/**` 永远要求认证。关闭：`BINFLOW_SECURITY_ANONYMOUS_ACCESS=false`。
- 默认管理员 `admin` / `password` **仅限评估**——首次启动前设 `BINFLOW_ADMIN_PASSWORD`（环境变量，绝不写 YAML）。
