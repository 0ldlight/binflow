# License 与 Add-ons

BinFlow 的功能分级由**一份 license 文档 + 一张编译期 addon 槽位矩阵**决定：

- **不装 license 也能跑**：实例按 community 地板运行，五核心包型 + 属性系统全部可用。
- **装 license 解锁档位**：`pro` 解锁八个门控包型与 repo-operations / trashcan / webhook 三个功能槽；`enterprise` 追加 HA / Xray 集成槽位。
- **矩阵是代码不是数据**：槽位的最低档位（MinTier）是代码常量——不存在运行时可篡改的许可面。

## 三档语义与降级行为

| 档位 | 解锁面 |
|---|---|
| `community`（地板） | generic / docker / maven / npm / pypi + properties |
| `pro` | + go / nuget / cargo / conan / helm / rpm / debian / helmoci + repo-operations / trashcan / webhook |
| `enterprise` | + ha / xray-integration（槽位占位） |

未装 / 过期 / 验签失败 / 档位不足一律降级到 community。降级行为要点（排障先想这五条）：

| 形态 | 行为 |
|---|---|
| **读不劫持** | 门控包型的内容 GET/HEAD 恒 200——卸载/过期后既有制品照常可拉；remote pull-through 的内部落盘同样豁免 |
| **写动词 403** | push/PUT/DELETE → 403 信封 `license required: addon '<id>' needs tier '<t>' (current: <tier\|none>)` + 响应头 **`X-Binflow-License-Required: <addonID>`**（CI 可按此头分支） |
| **建仓 400** | 建仓/改仓/删仓/virtual 成员涉及未解锁包型 → 400 点名包型与档位 |
| **到期即降级** | **无宽限期**：每日检测到过期即降回，无需重启；`daysToExpiry` 负值 = 已过期 N 天 |
| **装失败不动现状** | 安装被拒后当前 license 原样保留 |

license 文档的 **addons 白名单**可收窄授权：`--addons "go"` 的 pro 文档只解锁 go——被收窄的包型报 `not named in the license addon allowlist`。

## 安装与卸载

**控制台**：管理模式 → License & Add-ons（`/admin/general/license`）——admin 粘贴 license 文档全文 → 「装载」；验签通过即刻生效（进程内原子切换）；卸载需输入 `UNINSTALL` 强确认。

**REST**（装/卸是 POST/DELETE，无 PUT；复数路径 `/api/system/licenses` 有意不做，404）：

```bash
curl -su admin:$ADMIN_PW -X POST $BASE/binflow/api/system/license \
  --data-binary @pro.lic -o /dev/null -w '%{http_code}\n'    # 201

curl -su admin:$ADMIN_PW -X DELETE $BASE/binflow/api/system/license
# 200 纯文本：License removed successfully.（幂等：未装同样 200）
```

GET 挂 system:read（admin / readonly_admin）；POST/DELETE 挂 system:write（仅全量 admin）。验签拒 400（wire 码 `LICENSE_EXPIRED` / `LICENSE_INVALID`，现证不动）。

## 状态查询

```bash
curl -su admin:$ADMIN_PW $BASE/binflow/api/system/license | jq
# {"licensed":true,"tier":"pro","licensee":"Acme Corp","expiresAt":"...","daysToExpiry":364,
#  "perpetual":false,"addons":null,"limits":null,...}
```

| 字段 | 说明 |
|---|---|
| `tier` | 生效档位；未装 = `community` |
| `daysToExpiry` | 剩余整天数；**负值 = 已过期 N 天**（已降级，读不劫持）；永久/未装 = `null` |
| `addons` | 文档的显式白名单（`null` = 按档位全量解锁） |

GET 与 POST 成功体**永不回显文档原文**——载荷与签名不出现在任何响应或日志。

## addon 槽位矩阵

`GET /binflow/api/v1/addons` 返回全部槽位的**实时求值**（与门控执行同源；无写面——其余动词 404）：

| addon id | 类型 | 最低档位 | 说明 |
|---|---|---|---|
| `generic` / `docker` / `maven` / `npm` / `pypi` | package-type | community | 五核心 |
| `properties` | feature | community | 矩阵参数 + 节点属性读写 |
| `go` / `nuget` / `cargo` | package-type | **pro** | [Go](/integrations/go) · [NuGet](/integrations/nuget) · [Cargo](/integrations/cargo) |
| `conan` / `helm` / `rpm` / `debian` | package-type | **pro** | [Conan](/integrations/conan) · [Helm](/integrations/helm) · [RPM](/integrations/rpm) · [Debian](/integrations/debian) |
| `helmoci` | package-type | **pro** | OCI 形态 chart 仓 |
| `repo-operations` | feature | **pro** | copy/move/zip/`archive!`/explode 整族（见[制品操作](/admin/operations)） |
| `trashcan` | feature | **pro**（暂行） | 删除捕获/恢复/保留期（见[回收站](/admin/operations)） |
| `webhook` | feature | **pro** | 订阅七端点 + 签名投递（见 [Webhooks](/admin/webhooks)） |
| `ha` / `xray-integration` | feature | enterprise | 槽位占位 |

行内 `reason` 的三种锁定原因：`license tier community < pro`（档位不足）；`not named in the license addon allowlist`（白名单收窄）；`disabled by configuration`（配置熔断，装 license 救不了）。

## `addons.disabled` 熔断配置

运维的全局断路器（排障旋钮，如上游故障期临时关掉某包型）：

```yaml
# binflow.yaml
addons:
  disabled: "go,nuget"     # CSV；addon id 大小写敏感；空 = 不熔断
```

```bash
BINFLOW_ADDONS__DISABLED=go,nuget    # env 等价
```

- **重启生效**；删条目 + 重启即恢复；熔断**永不删除任何数据**。
- 拒绝面 = 写动词 403（文案点名旋钮与恢复路径）+ 建仓/改仓 400；内容 GET/HEAD 恒 200。
- 熔断态的 403 **不带** `X-Binflow-License-Required` 头——装 license 解决不了配置熔断。
- 五核心 id（如 `docker`）也可熔断（降级旋钮，WARN 提示）；`properties` 槽位同样可熔断。

## 离线签发工具：bf license

签发是**纯离线**行为（不联系任何服务器）：私钥永远只活在 keygen 写它的那台机器上，经 `--key`/`$BINFLOW_LICENSE_KEY` 注入，**绝不进配置文件、不进服务器**。

```bash
# 1. 生成 ed25519 密钥对（私钥 0600 落 ./binflow-license-private.pem，已存在则拒绝覆写）
bf license keygen --as-go-const --pub-out pub.hex

# 2. 签发（pro 必须带 --days；community 缺省 = 永久）
bf license issue --licensee "Acme Corp" --tier pro --days 365 -o pro.lic
# 常用旗标：--addons "go"（白名单）、--not-before（RFC3339）、--kid

# 3. 本地验视（退出码跟随主判定；inspect 永不接触私钥）
bf license inspect pro.lic --key pub.hex
```

## 审计事件

`license.install`（装载成功）/ `license.delete`（卸载）/ `license.invalid`（装载被拒，detail 只含 reason 分类）/ `license.addon.denied`（门控写拒绝）。

## 常见问题速查

| 症状 | 原因 | 处置 |
|---|---|---|
| 建仓 400 `package type 'go' is not available (license tier 'community' < 'pro')` | 档位不足 | 装 pro/enterprise license，或换核心五型仓 |
| push 403 + `X-Binflow-License-Required: go` | 写动词门控 | 装 license；**读不受影响** |
| push 403 但**无**该头，文案点名 `addons.disabled` | 配置熔断（非许可问题） | 从 `addons.disabled` 移除条目并重启 |
| 装 license 400 `LICENSE_INVALID` | 验签失败 | 用 `bf license inspect` 本地复核 |
| 到期后读变 403？ | 不会 | 读恒放行，仅写/建仓面关闭；装新 license 即恢复 |
