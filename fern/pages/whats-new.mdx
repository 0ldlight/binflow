# 用户可见变化公告

本页面向**已在使用 BinFlow 的读者**：把最近的交付批次中你会直接看到或需要动手适配的变化逐一列明——包括若干**推翻此前既定裁定的翻案项**（每项注明「此前 → 现在」）。

## 控制台视觉刷新：设计系统落地（BinFlow 品牌面）

控制台完成设计系统迁移（零 API/协议面变化，纯视觉与交互皮肤）：侧栏 240px / 顶栏 64px 的固定壳与内容最大宽度对齐；界面字体切换为本地打包的 Inter（中文自动回退系统 PingFang，无外联请求）；表格与审计计数采用等宽数字（tabular-nums）对齐；图标徽章、抽屉/弹窗/Toast 过渡动效统一走设计令牌，并完整支持系统「减弱动态效果」（prefers-reduced-motion）。亮暗双主题全量可及性扫描（WCAG 2.x A/AA）零严重违规。控制台功能、路由与操作流不变，无需任何适配。

## 破坏性变更：仓库配置动词语义收紧（PUT 只建仓，更新只有 POST）

**此前**：`PUT /api/repositories/{key}` 对已存在 key = 替换更新（200）。**现在**：**PUT 只建仓**——已存在 key 一律 **400**（`error when validating repository name: <key> : Repository key already exists`），零副作用。**唯一更新拼写是 POST**，合并语义三列：**省略字段=保留存量**、**`null`/空串=清空**（数组空值保留、对象 `{}` 整族复位）、**显式值=覆盖**（含 `0`）；未知 key 404。对齐 参考仓库（参照更新拼写只有 POST）。

**影响面**：repeat-PUT 更新脚本（「先 PUT 建仓、每轮 PUT 刷配置」的脚本 / CI / IaC）从第二个 PUT 起 400。**迁移 = 更新调用 PUT 改 POST**（body 省略字段保留，无需补全）：

```bash
# 此前（现在 400）：
curl -u admin:*** -X PUT "$BASE/binflow/api/repositories/libs-release" \
  -H 'Content-Type: application/json' \
  -d '{"rclass":"local","packageType":"generic","description":"新描述"}'
# 迁移后（更新走 POST）：
curl -u admin:*** -X POST "$BASE/binflow/api/repositories/libs-release" \
  -H 'Content-Type: application/json' \
  -d '{"description":"新描述"}'
```

upsert 脚本改两步：`GET` 探测（404 → `PUT` 建；200 → `POST` 改）。动词语义表见[仓库管理](/admin/repositories)。

## 协议语义对齐批次：客户端可见面

六个协议域（npm / PyPI / Conan / Docker / Go / Helm）客户端可见语义逐项对齐 参考仓库 口径，Maven 与存储管理面同步收敛（经真实客户端在隔离实例或双端对照验证）：

- **Maven**：SNAPSHOT 缺省 `unique`（时间戳版本落盘 + buildNumber 跨趟递增）；版本目录 metadata 的 **pom 前置**（目录含 `.pom` 直接子文件才生成）；`deploy-file` 免 `generatePom` 404 面。见 [Maven 接入](/integrations/maven)。
- **PyPI**：`Requires-Python` 三源管线（twine 表单 / wheel METADATA / sdist PKG-INFO）——pip 版本过滤直接可见；坏元数据**存而不索引**。见 [PyPI 接入](/integrations/pypi)。
- **npm**：dist-tags 族——`latest` 删不掉（读时重算为最高已发布版本）；bulk 面 405；GET 带 60s 缓存头；重发同版本按 **tarball 路径占用**判 403（版本不可变，ghost 不入索引）。见 [npm 接入](/integrations/npm)。
- **Conan**：v1/v2 双协议（ghost 删除分叉、错误信封族、`q` 查询门）。见 [Conan 接入](/integrations/conan)。
- **Docker / Go / Helm**：token 流与 `/v2` 面、sumdb 校验链、chart `index.yaml` 计算面与 digest 口径对齐。
- **存储管理面**：`?list` 七参族全量（`deep`/`depth`/`listFolders`/`includeRootPath` + 元数据三参 `mdTimestamps`/`statsTimestamps`/`includePropertiesMd5`；非整数值 400 `For input string: "<v>"`）；递归属性写只对真实变更移动属性 mtime；下载计数只计内容 GET。见 [API 参考](/api-参考/binflow-api)。

## 界面语言：中英双语可切换

**此前**：控制台为中文单语。**现在**：内置中英双语资源包，一步切换。

- **切换器**在侧栏底部脚注（「语言」caption + `中文` / `English` 两档单选，两侧栏同脚注常驻），点选即生效。
- 切换 = **localStorage 持久化 + 整页重载**；**中文默认不变**；英文为全量覆盖（全部页面域与对话框）。
- **术语两包保真**：repo key、node、checksum、Deploy、Set Me Up、cron 等英文术语两语言下原样。
- **日期与数字随语言**：英文 `MMM d, yyyy h:mm:ss AM/PM` 12 小时形态；中文维持 `dd-MM-yy HH:mm:ss` 24 小时形态。

详见[控制台 · 界面语言](/admin/console#界面语言中英双语切换)。

## 计划任务（cron 调度）落地

**此前**：曾终裁**不引入**用户级 cron 计划任务（复制纯事件驱动、备份靠外部 crontab、GC 仅手动）。**现在**：该裁定**正式推翻**——调度域全面落地，与既有事件驱动轨并存：

- **维护**：GC 与缓存清理到点自动执行（三槽）。
- **定时备份**：实例内配置到点 export，免外部 crontab；恢复仍是带外 import CLI。
- **复制**：配置可挂调度轨（到点全量对账），与事件轨 / Replicate Now 并存且目标侧幂等。
- 表达式为 **Quartz 六域子集**（秒开头 6/7 域；`L`/`nL` 收录，`W`/`#` 拒收）。

见 **[计划任务（cron 调度）与定时备份](/admin/cron-scheduling)**。

## 监控面重组：服务状态 / 系统日志 / 系统信息归位

管理侧栏监控组扩为**服务节点组六页**——存储、**服务状态**（新页：总体徽标 + 三子系统 + 计划任务调度节；Uptime 无端点如实缺位）、**系统日志**（新页：7s 尾随刷新 + 过滤 + 导出 `.log`；**日志源为审计跟踪**——服务进程日志无在线端点，走部署层日志面）、系统信息、维护（GC）、备份 / 恢复（三页归位迁址）；Webhooks 移入「常规」。

## 远端浏览可选档：remote 仓的未缓存目录可见

**此前**：remote 仓在制品树里只显示已缓存制品。**现在**：**Helm / Debian / RPM** 三型 remote 可开启「列出远端目录条目」（`listRemoteFolderItems`，默认关——不开则行为与此前一致）：

- 树展开可见未缓存远端目录与文件（「远端」标记 + `—` 占位）；点击回源落地缓存。
- **上游降级不塌树**：已缓存条目始终可用，目录顶部给降级注记（`FolderInfo` 可选 `remoteDegraded` 字段）。
- 其它包型不做远端目录抓取——控件不出现，服务端按名 400。

详见[仓库管理 · 远端浏览可选档](/admin/repositories#远端浏览可选档listremotefolderitems)。

## 交互形态对齐与既定裁定的翻案

### 分页：页码控件全面替换「加载更多」（翻案）

全站列表与结果表统一**页码控件**（页码序列 + 首/末四钮 + 每页行数档 [20/50/100/200/1000]，缺省 100）；搜索两模式、审计、仓库/用户/组/权限/token 列表全部迁移。分治例外：制品树大目录「加载更多」维持（树增量 + 表页码双轨）。AQL 模式页码重写 `.offset()`、档位重写 `.limit()`——查询文本仍是唯一事实源。

### 用户与组：路由整页表单 + Retype Password 双录（翻案）

**此前**：列表页内联展开卡创建，创建态无二次口令输入。**现在**：创建与编辑均为**路由整页表单**（`/admin/security/users/new`、`/admin/security/groups/new`、`/groups/:name/edit` 深链直达）；内联卡退役；用户创建页补 **Retype Password 双录**；页脚 `Cancel | Reset | Save` 双初始禁置。能力位三开关（Can Update Profile / Disable UI Access / Disable Internal Password）为恒禁用预留位（服务端未承接，零提交）。

### 删除动作收敛（范围修正）

制品树 children 表的行内详情/下载/删除三钮退役——**删除统一走详情面板或右键菜单**（均过危险确认，回收站语义不变）。管理面实体列表删除维持详情危险区形态。

### 帮助菜单与 About（新面）

顶栏 `?` 帮助下拉四项：**Documentation**（本帮助文档）/ **Online Training**（无对应服务——禁用占位如实标注）/ **Release Notes**（升级与版本说明）/ **About**（版本弹窗）。编辑档案页新增 Identity Token 自助生成（一次性明文 + 即用 curl 样例）；SSH 公钥管理因服务端无端点如实缺位。

### 其他可见变化（简列）

- **树头工具带**：过滤仓库 / 包类型 facet / 仓型复选 / Sort-by / Compacted / **My Favorites 收藏仓**。
- **建仓三段步进** Basic → Advanced → Replications（`?section=` 深链）+ 924px 包类型网格（13 型全量、档位门服务端终裁）。
- **搜索统一结果网格**（选择列 + 批量复制路径 + 快滤 + 列选器）；顶栏输入即查询。
- **详情下载统计族**（Downloads / Last Downloaded By / Last Downloaded / Remote Downloads——「被访问次数」口径）；下载钮收为单图标钮 + 伴随菜单。
- **权限动作域五值** `read / deploy-cache / annotate / delete / manage`（`write` 为兼容别名；`annotate` 单控属性写门；迁移自动回填零提权）。
- **docker virtual 仓开闸**（`rclass × packageType` 组合门全量退役，剩余门只有 license 档位）。
- **AQL 统计域 + 闲置检索**（`stat.*` 与 `GET /api/search/usage`）。

## 兼容性影响

- **本批唯一破坏臂**：仓库配置动词语义（PUT 只建仓）——repeat-PUT 脚本按上文迁移；协议语义批其余条目为行为对齐，标准客户端无需改动。
- **旧路径自动折入**：本轮迁址的四条旧深链（系统信息、维护 GC、备份恢复、Webhooks）打开时一次性 replace 到新址，不落 404；书签建议尽早更新。
- **默认行为不变**：远端浏览默认关、界面默认中文、事件驱动复制轨不变。
- **控制台批次 API 面纯增量**：新端点族（维护/备份/调度投影）与 `cron_exp` 字段均为新增，既有端点行为零变化。
