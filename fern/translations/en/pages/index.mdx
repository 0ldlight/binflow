# BinFlow introduction

BinFlow is a **cloud-native artifact repository** written in Go from scratch. Its architecture and conceptual model align with JFrog Artifactory—repositories, storage, permissions, and REST semantics correspond directly, so Artifactory users can migrate without learning a new vocabulary. BinFlow ships as one static binary with no external runtime dependencies and an embedded web console.

This documentation applies to **BinFlow v1.0.0**.

## Package matrix and editions

| Edition | Package types | Notes |
|---|---|---|
| **community** (available without a license) | generic, docker, maven, npm, pypi | Five core package types plus the property system |
| **pro** | go, nuget, cargo, conan, helm, rpm, debian, helmoci, artifact operations, trashcan, and the webhook feature slots | Repository creation and uploads require a pro-or-higher license |
| **enterprise** | ha and the xray-integration feature slot | Reserved capability slots |

The licensing rule is simple: **reads are never hijacked**. A missing or expired license only blocks repository creation (400) and write verbs (403 plus an `X-Binflow-License-Required: <addon>` response header). `GET /binflow/api/v1/addons` reports the current status of every slot. See [License and add-ons](/admin/license).

Every package type supports the three repository classes: **local**, **remote** (pull-through proxy cache), and **virtual** (aggregation). Docker virtual aggregation is not yet supported.

## URL topology

Every application URL shares the `/binflow` prefix:

| Surface | Prefix | Notes |
|---|---|---|
| Management and compatibility APIs | `/binflow/api/...` | Repository CRUD, users, permissions, audit, GC, tokens |
| Artifact content paths | `/binflow/<repoKey>/<path>` | Upload, download, and delete artifacts |
| Docker Registry v2 | `/v2/...` (root-level exception) | docker, podman, crane, and skopeo clients |
| Prometheus metrics | `/metrics` (root-level exception) | Anonymous reads by default |
| Web console | `/binflow/ui/` | Browser sign-in entry point |

## Security baseline

- BinFlow serves **plain HTTP only**; terminate TLS at a reverse proxy. Compose artifacts bind to `127.0.0.1` by default.
- **Anonymous reads are enabled by default** for `GET` and `HEAD` content requests. Writes and `/binflow/api/**` always require authentication. Disable anonymous access with `BINFLOW_SECURITY_ANONYMOUS_ACCESS=false`.
- The default administrator, `admin` / `password`, is for evaluation only. Set `BINFLOW_ADMIN_PASSWORD` before first startup; this environment variable is never written to YAML.
