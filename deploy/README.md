# deploy/ — 多元部署矩阵

release-engineer 维护（基线见 DECISIONS.md ADR-0004）。目标：GA 时交付以下全部部署方式，每种都有 tech-writer 对应的安装指南 + 部署烟测。

| # | 方式 | 产物位置 | 说明 |
|---|---|---|---|
| 1 | 单二进制 | goreleaser → dist/ | linux/darwin/windows × amd64/arm64 + 校验和 |
| 2 | Docker 镜像 | 根 Dockerfile | multi-arch，distroless / alpine 双变体 |
| 3 | docker-compose | deploy/compose/ | 含卷持久化、健康检查、Postgres 可选；`--profile nginx` TLS 反代；`--profile s3` 内置 MinIO（桶自动初始化，BinFlow 等 MinIO ready 后起服）；M11：`.env` 承载实例主密钥 `BINFLOW_REMOTE_CREDENTIALS_KEY`，可选挂载 `binstore.yaml` 存储链（`BINFLOW_HOME=/etc/binflow` 发现；文件拥有链期间 chain-scoped env 忽略+WARN，S3 secret env 始终生效）；M13：env 块新增 `BINFLOW_WEBHOOK__ALLOW_PRIVATE_TARGET`（SSRF 拒绝缺省）+ `BINFLOW_FOLDER_DOWNLOAD__*` 六键 + `BINFLOW_TRASHCAN__RETENTION_DAYS`（默认=规格列=M12 as-built，`GET /binflow/api/v1/system/settings` 回显） |
| 4 | Helm Chart | charts/binflow/ | values：镜像/PVC/ingress/资源/探针/HPA；`config.s3`/`config.oidc`/`config.ldap`/`config.addons`（M10 断路器）/`config.replication`/`config.storage`/`config.auth` 配置段，托管键显式渲染进 ConfigMap（T-183 教训）；密钥一律 existingSecret 引用，ADR-0009；M11（Chart 1.2.0）：`config.binstore`（独立 binstore.yaml 链——与 `config.s3` 互斥，Q5 分歧在渲染期拒绝；非法链形/缺 migration mode 渲染期拒绝）+ `masterKey.existingSecret`（`BINFLOW_REMOTE_CREDENTIALS_KEY`）；M13（Chart 1.3.0）：`config.webhook`/`config.folderDownload`/`config.trashcan` 三键族显式渲染 + **Deployment 补 `strategy: Recreate`**（RollingUpdate 双 pod 争 serve.lock——升级必挂，实测发现）+ **`checksum/config` 注解**（仅改配置的 `helm upgrade` 原先不触发滚动）；M14（Chart 1.4.0）：PVC `helm.sh/resource-policy: keep` 恒注解（T-394——`helm uninstall` **有意保留数据卷**；用户注解经 `persistence.annotations` merge、键冲突时 keep 单键胜；NOTES.txt 记手动清卷双路〔按名/按标签 `kubectl delete pvc`〕） |
| 5 | 原生 K8s 清单 | deploy/k8s/ | Deployment/PVC/Service/Ingress/Secret 模板；M11：`binstore-configmap.yaml.example`（三处注释块启用：BINFLOW_HOME env + mount + volume，默认不入 kustomization） |
| 6 | systemd | contrib/systemd/ | unit 文件 + install.sh（建用户/目录/自启；配置 `/etc/binflow/binflow.yaml`，env 覆盖走 `/etc/binflow/env`，可承载 `BINFLOW_ADDONS__DISABLED`；M11：`/etc/binflow/binstore.yaml` 拥有链时自动发现、env 文件承载主密钥——unit 头注释有优先级说明；M13：`/etc/binflow/env` 同样承载三族旋钮 env 拼写，unit 头注释 + install.sh 完成输出有键名清单） |
| 7 | 离线安装包 | deploy/offline/ | 镜像 tar + Chart + 脚本 + 校验和（air-gapped）；M11 面见 README-offline.md「M11 配置面」节；M13 面见「M13 配置面」节（三族旋钮键随三模式自然可用，包结构零变化）；install-offline.sh 三修：探针随 `BINFLOW_BIND_PORT`、chart 包名自动发现（`helm package` 命名 ≠ 镜像版本）、helm 模式钉捆绑镜像（原拉 ghcr.io 在 air-gap 必失败）+ bash 3.2 空数组守卫 |
