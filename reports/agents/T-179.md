## 做了什么（对照 AC）

1. **AC① config 段**：`internal/config` 新增 `auth.oidc`（enabled/issuer_url/client_id/redirect_url/scopes/user_claim/group_claim/admin_group）
   与 `auth.ldap`（enabled/url/base_dn/bind_dn/user_filter/user_id_attr/group_filter/group_name_attr/admin_group/pool_size/start_tls）
   两段，键名逐字对齐 charts/binflow T-170 渲染的 snake_case（configmap.yaml）。raw 指针结构体 → build 映射 → defaults
   （两段 enabled=false、LDAP pool_size=5）→ 严格解码器放行。密钥 env-only：
   `BINFLOW_AUTH_OIDC_CLIENT_SECRET` / `BINFLOW_AUTH_LDAP_BIND_PASSWORD` 走 envSecret（splitEnvKey 显式登记，
   大小写不敏感，空值=未设）；rejectSecrets 递归扫 auth.oidc/auth.ldap，`client_secret`/`bind_password`
   （含 clientsecret/bindpassword 拼写）加入 isSecretYAMLKey 全局拒绝，secretYAMLErr 的逃生舱提示按
   段名/拼写指向正确的 env 名。Validate：enabled=true 时 OIDC 必填 issuer/client_id/redirect（http(s) 绝对 URL）、
   LDAP 必填 url（ldap(s) scheme + host）/base_dn/pool_size>0；client_secret 刻意不强制（PKCE 公共 client 合法）。
2. **AC②+③(auth) userCreator 导出**：`internal/auth` 新增 `UserCreator` 别名 + `NewUserCreator(metadata.UserStore)`
   （T-157 遗留②——包外拿不到 creator、`WithOIDC(prov, nil)` 会覆盖 NewFromStore 已设值）；另补
   `NewOIDCResolver`（与 NewLDAPResolver 对称）。cmd 以 `WithOIDC(prov, auth.NewUserCreator(md.Users()))` 注入，
   自动建用户链路用真实 store 适配器端到端验证。WithOIDC 的 nil=禁用自动建用户语义保持不变（测试钉死）。
3. **AC④ whoami/authenticateSession source**：`internal/auth/session.go` authenticateSession 的
   `Source: ProviderLocal` 硬编码改为 `u.Provider`（用户行的 owner provider；adaptUser 归一未知值→local）；
   `internal/httpapi/session.go` whoami body（GET /api/v1/session 与 POST 登录响应）新增 `"source"` 字段。
   **⚠ 范围偏离申报**：conductor 指示 httpapi 只准新增 auth methods 文件与 router 挂载行，但 whoami body 的
   序列化点（sessionWhoami）物理上就在 session.go——本次改动为最小增量（结构体+1 字段、两处赋值、
   principalSource 辅助函数放在新文件 auth_methods.go），未重构 T-157 任何逻辑；既有测试全部零回归。
4. **AC⑤ auth/methods**：新文件 `internal/httpapi/auth_methods.go`——`GET /binflow/api/v1/auth/methods` →
   `{"password":true,"oidc":bool,"ldap":bool}`。匿名可访问（routeAuth{}；anonymous_access=false 实例同样 200，
   测试钉死）；oidc 位以 `Deps.OIDC != nil` 为准（与 /oidc 路由 404 姿态同一事实源），ldap 位经消费侧
   facet 类型断言（`auth.Service.LDAPWired()`，新增于 identity.go；fake 无 facet 读 false）。
   router.go 仅追加一条挂载 case + 注释。非 GET 落 E-26 404。
5. **AC② cmd 装配**：`openStack` 在 metadata 之后构造 provider（`wireAuthProviders`：OIDC 构造含 discovery
   网络往返——不可达 issuer fail-fast 拒启；LDAP 池懒连接不拨号）；enabled → `WithOIDC/WithLDAP` 注入
   Authenticator；`oidcLoginSeam` 单点持有 typed-nil 守卫（nil provider 必须产生 nil interface，否则
   /oidc 路由从 404 翻成 500）注入 `Deps.OIDC`；stack 持有两 provider，close() 先排空 LDAP 池（7.4 序）。
   启动日志各打一行 active 姿态（issuer / url+base_dn）。密钥 belt-and-braces 直读 env（对齐 openS3Engine 先例）。
