## 2. 实现要点（对照 goproxy.md 十节）

1. **local 三件套**：GET 逐字节回读 + `X-Checksum-Sha256/-Sha1/-Md5` 实测头；
   `.info` 缺失→由 zip 节点时间合成 `{"Version","Time"}` 并尽力回写（触发主体权限骑行，
   匿名读不回写但每次合成同体）；`.mod` 404 + `+incompatible`→合成 `module <path>\n`；
   `@v/list` 只聚合 `.zip`（S8）＋纯版本列（S7）＋零版本 404（S13）；`@latest`
   官方候选序（release > pre-release > 最新 pseudo）；HEAD `.mod` 命中 200+Content-Length /
   未命中 **410**（S9）。PUT 校验链：版本文法（§5.1 正则族）→ major 一致性（`/vN`、
   gopkg.in `.vN`）→ `.info` JSON（Version canonical+一致、Time RFC3339）→ `.mod`
   module 指令一致 → checksum（malformed 400 / 不符 409，走既有 svc.Put）→ 201+Location
   （wire 再转义拼写）。幂等/覆写沿用 svc.Put 语义。
2. **`!lower` 三态**：wire→存储在 Layout（`!x`→Upper(x) 任意字符、`!!`/尾随 `!`→400）；
   存储→wire 在 Location 与 UpstreamPath（大写→`!`+小写）；存储路径保持解码态。
3. **remote**：版本文件 GET 走 svc.Get→internal/remote 引擎（上游 hop 由 provider 的
   `UpstreamPath` 再转义；标记路径 `.versionList`→`list`、`<mod>@latest.latest`→`@latest`）；
   上游 list/@latest 原文透传缓存（metadata TTL 短周期=§3.2 可过期集合）；上游
   404/离线一律 404 不 5xx；`+incompatible .mod` 不回源直接合成；PUT→既有 RE-05 405。
   **BinFlow 分歧保持**：允许 `GOPROXY=$BASE/binflow/go-remote` 直连（不采纳 Artifactory
   remote 直连 400）。sumdb/* 按未知路径 404（§9）。
4. **virtual**：三件套 GET 复用 svc.Get first-found（本地优先=成员序，带
   X-BinFlow-Resolved-From）；list=跨成员并集（成员序去重+字典序稳定输出）；
   @latest=全局最优取该成员原始响应体；PUT 走既有 defaultDeploymentRepo 路由；
   `+incompatible .mod` 只探本地成员（§6.2 不回源规则穿过聚合面）。
5. **门控集成**：D3 建仓 400（community，点名 addon+tier）；D2 写 403 +
   `X-Binflow-License-Required: go`；D1 读放行；**内部写豁免**（T-283 风险位）：DENIED
   门下 remote GET 触发的 pull-through 落盘成功且二次命中缓存（单测 + 真二进制双验）。

### 2.1 规格勘误登记（供 T-278 增补）

- **§7.1/L11 的 `GOPRIVATE='*'` 字面不可用**（go1.26.6 实测）：GOPRIVATE 是 GONOPROXY
  的默认值，会使全部模块绕过 GOPROXY 走 VCS（`unrecognized import path … ?go-get=1`）。
  「私有全走 BinFlow」的可操作形态 = `GOPROXY=<binflow> + GOSUMDB=off`（同表 air-gapped
  行）。已写进 client_e2e_test.go 注释与 go-pilot.spec.ts 头注；规格表自身的该行口径
  需 reverse-engineer 增补（非本票 area，不动 docs/reverse）。
