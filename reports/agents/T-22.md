## 四处回写点

1. **R3 匿名读键名统一（§8 / §3.4 / §7.1 / §7.2）**
   - §8 配置示例改为 `security.anonymous_access: true`（env `BINFLOW_SECURITY_ANONYMOUS_ACCESS`）为用户可见主键名；`auth.anonymous_read` 降为兼容别名，注释说明 config 包双键等价 + 两键同给不一致启动报错（与 T-8 实现一致）。
   - §3.4 Authorizer 注释、§7.1 认证分层、§7.2 中间件说明中 `anonymous_read` 引用全部同步改 `security.anonymous_access`。
   - ADR-0009 后果条目追加「后经 T-22 回写」句，记录键名统一与双键等价实现。

2. **R4 permissions 表重写（§6 DDL / §3.2 / §3.4 / §10）**
   - 废除扁平 `permissions` 表（username×repo_key×path_prefix 单前缀），改为 PRD E-24 命名 permission target：`permission_targets`（name 唯一、repos[]、includes/excludes pattern JSON 数组）+ `permission_principals`（target×principal×actions，principal_type 预留 groups [M4]）两张表。
   - DDL 内注释列三点与原扁平行的差异（name 可 CRUD 引用、多 repo + 双 pattern、principals 独立成表），与 T-10 迁移文件同款注释。
   - §3.2 Store 子接口列表补 `PermissionStore`；§3.4 Authorizer 判定规则改写为 target 命中语义（include/exclude `**`/`*` 通配、exclude 优先、无命中=拒绝）；§10 对齐表同步表名。

3. **R5 repo key 长度（§6 DDL 注释）**
   - `[a-z][a-z0-9-]{1,31}` → `[a-z][a-z0-9-]{1,62}`（PRD FR-3-AC4 为准），注释标明「原架构 {1,31} 作废，后经 T-22 回写」。ADR-0008 后果条目追加对应回写句。（正文 §3.3 未写具体长度，无需改。）

4. **R6 错误信封（§7.3）**
   - 占位单对象形 `{"error":{status,message,detail}}` 改为数组形 `{"errors":[{status,message}]}`，适用范围明确为全部端点含内容路径；标注依据 docs/reverse/rest-api.md §0 高置信度定案 + 后经 T-22 回写。原「待逆向规格确认」标记随之解除（规格已产出且定案）。
