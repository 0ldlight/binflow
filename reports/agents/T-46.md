| # | 链 | 命令要点 | 结果 |
|---|---|---|---|
| R1 | docker login | 对口令 `--password-stdin`；错口令对照 | `Login Succeeded` exit 0；错口令 `unauthorized: authentication required` **exit 1**（FR-11-AC4 口径保持） |
| R2 | build+push | Dockerfile（FROM alpine:3.20）→ build -t `<REG>/docker-local/acme/app:v1` → push | exit 0，`v1: digest: sha256:dafe594c…` |
| R3 | rmi→pull→run | `docker run --rm …/app:v1` | 输出 `ok`，exit 0 |
| R4 | curl token 流 | `GET /v2/token`（Basic）→ Bearer 打 `_catalog`；匿名 token；logout 后匿名 pull | `expires_in=2592000`（=720h）且 `token==access_token`；Bearer catalog 200；匿名 token 签发 + `docker logout` 后 pull exit 0；ping 401 + `Www-Authenticate: Bearer realm="…/v2/token",service="binflow"` + `Docker-Distribution-Api-Version: registry/2.0` |
| R5 | oras（FR-12） | login/push（--config helm.config + layer chart.content 双类型）/pull/tags/cmp | `ORAS_CMP_IDENTICAL`，tags `1.0.0`，整链 exit 0；踩点：oras v1.2 拒绝绝对路径（改相对路径过，已写入文档注记） |

| R7 | buildx 多架构 | `buildkitd.toml`（`[registry."…"] http=true`）+ `buildx create --buildkitd-config` + `--platform linux/amd64,linux/arm64 --push` | 登录态直推 `pushing manifest …@sha256:4db02f1f… done`；index 4 平台项（amd64/arm64+2 attestation）；pull→run `multi-ok` exit 0；反证两坑：登出态 push `unauthorized`、无 buildkitd 配置不通（已写入文档） |
| R8 | crane | digest/ls（匿名可用）/auth login/copy 实例内两 repo/manifest | copy 后 digest 逐一致（sha256:dafe594c…），manifest 合法 OCI index JSON，exit 0 |
