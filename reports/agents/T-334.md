## 4. T-337 消费要点（FR-103 实现票直接可取）

1. **路由全集**：§2 表 18 端点一次挂齐（挂既有 plane-aware rewrite，escaped 拼写保留）；`Search` 与 `Search()` 等价路由（括号可选）；`Packages()` 空括号=全包 feed、带 Id/Version=单条目；`Packages(Id='x')/Id` 投影别漏。
2. **门序**：401（forceAuth，Basic realm 头）先于 403（无授权仓）；例外两处——根 service document 的匿名豁免、`{filename}.nupkg` 直通免门（§3 表）。
3. **易踩错误码**：FindPackagesById **缺 id 参数 → 404**（非 400）；Packages 单条目未命中 → 404；feed 构建为空 → 404。
4. **publish 重复臂**（§5.1，T-304 §7 新发现）：已存在且无 d 权限 → **409** `Package already exist: <deployPath>`；有 d 权限 → 覆盖；缺 `package` 字段 → 400 精确文案；remote → 400 `This operation can only be performed on local repositories.`；virtual → defaultDeploymentRepo 路由 + 路径 pattern 不合法 **409 `Unacceptable path.`**。**与 cargo 形态不同（包型间不一致是 Artifactory 自身事实），勿互相看齐**。
5. **DELETE**：硬删 200 `Successfully removed '<path>'` / 404 / 403 文案照 §2 #16。
6. **$batch**：202 Accepted + `multipart/mixed;boundary=batchresponse_<guid>` + DataServiceVersion 2.0；七形态子请求分发；不支持形态整批 **400 `Unsupported batch entry.`**；part 查询串覆盖搜索参数。
7. **路径解析**：三级链（§6）——缓存→`<id>.<version>.nupkg` 扁平默认→属性（nuget.id+nuget.version）检索兜底；带前缀上传的包靠属性找到。
8. **v2 search 代理**（§7，T-337 范围内含 v2 面）：上游 URL = `<repo.url>/<feedContextPath 默认 api/v2>/<resourcePrefix>?<全参数>`；offline+storeArtifactsLocally 回落缓存事实；virtual 九步合并（**id 级去重**、GetUpdates 无 $orderby 注入 `$orderby=Version`、IsLatest legacy 聚合默认、include/exclude pattern 终滤）。
9. **semVerLevel**：官方语义照 §4（默认滤 SemVer2；>=2.0.0 且 <3 包含；>=3 回落 2.0.0；忽略大小写；不可解析=缺省）。
10. **不做面**：curated-feed 变体与 v2 autocomplete（官方有、Artifactory 反编译路由全集无）。
11. **回归护栏**：nuget.org 族源上前缀常量与动态解析观测等价（§9.2）——T-341 翻转时的既有绿灯不能丢。

T-341（FR-104）消费点已写入 §11（SearchQueryService 层阶、FeedUtils 回落、`.nuGetV3/` 布局、400→take=100 重试、virtual 合并、registration 改写），票面 dep 链 T-334+T-337 满足后可直取。
