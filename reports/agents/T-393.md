### 2.1 公开规范取证（客户端源码即规范）

本机 npm 10.9.8 实物源码逐文件读（node 22.23.2，`/usr/local/Cellar/node@22/.../npm/`）+ 官方仓库 latest 源码 webReader 对照：

| 文件 | 关键事实 |
|---|---|
| npm-profile `lib/index.js` | loginCouch：PUT body 七字段（`_id/name/password/type/roles/date`）、**无认证头**；E400 → 客户端改写文案「no user with the username」；E409 → GET `?write=true` + PUT `/-rev/<_rev>`（带 forceAuth Basic）；loginWeb：POST `/-/v1/login` → `{loginUrl,doneUrl}`，任意 4xx/500 → ENYI 回落 couch |
| npm CLI `lib/utils/auth.js` | 默认 auth-type=web 先试、ENYI 回落；成功后 `newCreds={token}` → `setCredentialsByURI` 写 `.npmrc` `_authToken` |
| npm-registry-fetch `lib/index.js`/`auth.js` | 头形态（Bearer token / Basic auth）；forceAuth → Basic 头；`.npmrc` 凭据键按 URI host:port:path 逐级最长匹配 |
| npm CLI `lib/utils/get-identity.js` | whoami：`.npmrc` 有 username 零 HTTP；token → GET `/-/whoami` 读 `.username`；失败一律 ENEEDAUTH |
