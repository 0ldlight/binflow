## 7. 遗留 / 观察

1. **排序字段须在查询输出集内**：默认输出九字段含 repo/path/size/modified 但**不含 sha256**——
   无 include 的裸查询点 sha256 表头会吃服务端 400「Only the result fields are allowed…」（表头
   title 已提示，错误内联呈现是诚实面——与 Artifactory 同语义，不做前端伪裁剪）。
2. **尾缀重写器的病态输入边角**：include 值内含括号（如 `include("a(b)")`）时该段与其前段拆不出，
   重写退化为整段追加 → 若与既有段重复即 400 内联呈现（诚实失败不吞查询）——代码注释在案。
3. AQL 查询草稿不持久（会话态；不入 URL 的理由见 §10.5 变更注记）——若 QA/用户反馈想要「最近
   AQL 查询」面，可沿 recentSearches 同款 localStorage 键扩一票。
4. 净实例 :8080（/tmp/bf-t419）留验在跑：`kill $(lsof -ti :8080) && rm -rf /tmp/bf-t419`（按端口
   精确杀）。注：本轮占的是**默认端口**（启动时端口空闲）——conductor 复验免 BASE 直跑，收尾请杀。
5. 观察项（非本票）：MUI ToggleButton 未选中态的 54% 黑是首个 ToggleButtonGroup 落点撞上的组件
   默认值坑——若后续页再引入该组件，同款 `:not(.Mui-selected)` 钉色应随首用页各自落（不抽共享层）。
