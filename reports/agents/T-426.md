## 2. 实测命令（净实例，2026-09-02）

实例：HEAD 工作树自建二进制（`go build ./cmd/binflow-server`）双 scratch 实例——A=127.0.0.1:18501（`anonymous_access:false`，`BINFLOW_REMOTE_CREDENTIALS_KEY` 已设）、B=127.0.0.1:18502（默认开匿名，兼作复制目标）；避开审计 workflow 占用的 18091/18099/18432。种子：maven-local/maven2-local（真 maven 布局上传）/team-local（generic+M10 属性）/maven-virtual（virtual 成员展开）/empty-local（空仓空跑）。

**腿① AQL + 老搜索（全部跑通，输出摘录进文档）**：

- 基础/envelope 逐字节（默认输出九字段、ISO8601 毫秒 UTC、空集 `[  ]`）；include+sort+offset+limit 链（range 窗口回显 + **用户 limit 触发截断标记的边角如实入册**）。
- 属性条件 `{"@stage":"prod"}`（嵌套 properties 输出）；$match/$nmatch；**$msp 典范形**（property.key+property.value 同实例命中 1 行；两个不同 @key 放进 $msp 空集=语义正确，文档明示）；$or；$gt 数字。
- **相对时间发现（登记分歧）**：BinFlow 要求 count 与 unit 空格分隔——`"1 day"`/`"1 d"` 可用，`"1d"`/`"1w"`/`"1mo"` 400 `Invalid relative date format for: 1d`（lexer parsePeriod 注释自证为按规格示例形态的裁定）→ 迁移对照表「高频改写」第一行 + FAQ。
- virtual 展开（行 repo=成员 key + `virtual_repos` 隐式输出，双成员 6 行）；未知 repo 200 空集。
- 错误族逐字：`builds`/`statistics`/`properties` 域点名 400；`stat.downloads`/`modified_by` 字段点名 400；`$not` 操作符点名 400；链序错 E1 逐字；sort 字段不在输出集 400；>6000 E4 逐字；双空 E2 `Bad Request`。
- 传输臂：`?compact=true`（行/range 单行、外层包裹不变）；`?query=` 回退 200；匿名 A 401（闭环）/ B 403（开实例）两臂逐字；GET 动词 404。
- 权限：非 admin（jane + read 授权）——全域查询行级过滤（只见 team-local 行）+ `created_by:"unknown"` 脱敏（admin 对照回显真名）。
- 老搜索：gavc（g+a+v 三行/c=sources 单行/miss 200 []/零坐标 400/非法坐标 400 逐字）；prop（props=k=v / 任意参数形 / 键存在性 2 行 / 未知键 200 [] / 无约束 400）；pattern（树命中 3 行/跨仓通配 `*-local:`/miss 200 []/无冒号 400/**virtual key 空集边界**）；artifact `name=BUILD-REP` 大写命中小写制品（K64 翻转实测）。
- 截断头：用户 limit 下 `X-Binflow-Search-Truncated: true` 实测（1000 硬上限值核对 `search.ResultCap`，gate 并发 4/超时 10s 核对 engine.go）。

**腿② 复制包 B（单实例可测面全跑通）**：

- `GET /api/v1/system/replications` 官方键形（初始 false/false；封后 push+pull 双 true）。
- `POST /api/v1/replications`（201）→ `/{id}/test` 正确凭据 **200 ok:true**（锚定文案含探测地址全路径）；草稿面错误凭据 **400 ok:false status_code:401**（内联目标 errors[]）；自实例 **400**（`Cannot replicate to the same instance…`）；`-cache` 目标 **400**（官方文案逐字）。
- `POST /{id}/run` → 200 `{scheduled:5}`；B 侧 AQL 验证 5 路径全落；**status 面实测 4 success + 1 failed**——failed = 目标仓自己生成的 `maven-metadata.xml` 与源副本 sha 不一致 → first-write-wins 终态（last_error 含 Q7 interim 文案）——**该冲突预期已写进治理指南**；重复 run 200 再种不去重；停用 → 409（文案点名配置+指路）；block 后 run → 409（锚文+解锁指路）；空仓 config run → `scheduled:0`；未知 id 404。
- block/unblock 全变体：`block?push=true` 双向+官方文案；`block?push=false` 仅 pull 变体文案；`unblock` 文案；双不动 `No action taken.`；审计词 `replication.run`/`replication.config.update`/`replication.block.update`/`replication.config.test` 台账实测在列。

**顺带发现并修复的存量文档 bug**：`governance.md`/`api-reference.md` 复制配置示例的 `target_url` 带 `/binflow` 后缀——引擎自 M6 起推送地址为 `{target_url}/binflow/{repo}/{path}`（engine.go:753），照示例配置会拼出 `/binflow/binflow/…`（实测 Test 404 证实）；两处示例已改裸 origin 并加注。
