### 关键设计决策（含实证过程）

1. **ServeMux 彻底不用在产品路径上**。票据预告「mux 会把 `..` 归一成 3xx」。动手前先
   用裸 TCP 探针实证（Go 1.26.5）：`GET /binflow/r/a/../b` 即使 mux 只注册唯一
   catch-all 模式 `/`，仍返回 `307 -> /binflow/r/b`——cleanPath 归一在
   ServeMux.findHandler 内，与模式数量无关。结论：**任何** ServeMux 挂法都会吃掉
   adapter Layout 的 400 防线。最终形态：`Server.route()` 只对 `/healthz` `/readyz`
   两个精确段用 mux（探针路径不可能含点段，归一无害），其余全部走手写 dispatcher，
   基于 `r.URL.EscapedPath()` 分发，RawPath 原样透传给 adapter（FR-4-AC10）。
   测试用裸 TCP 重放点段请求行断言「非 3xx 且 400」（Go client 拒绝发送未归一请求行，
   只能裸 TCP）。

2. **principal 的两道 context 缝**。middleware 链内层用本包 `principalBox`；分发给
   adapter 时在 `withStrippedPrefix` 里再塞进 `adapter.WithPrincipal` 的缝（架构 §5.1
   「adapter 从 PrincipalFrom 读、自己不认证」）。实测发现缺第二道缝时 admin PUT 变
   401「Authentication is required to deploy artifacts」——adapter 读不到
   principal，已修。

3. **RepoLookup 缝取 `metadata.RepoStore.Get` 而非 `repo.Service.GetRepo`**。后者要
   求已认证 principal，但路由必须先解析 repo key 才能挂 adapter，而匿名 GET 也要走
   这条路（ADR-0009：匿名读在 adapter 前就放行）。只读 PackageType 一列，config 字
   段不过缝——repo 存在性对能匿名下载的人本就不是秘密，受保护的是内容与写面。
   （决策记录在此，review 若不认可可改回 Service + 专设匿名查询。）

4. **accessLog 在链第 2 层、authenticate 在第 5 层，但日志要记 user**。context 只能
   向内传，深层解析出的 principal 无法向外流向 accessLog——这是实现中发现的真实缺
   陷（首版 `user=anonymous` 即使带了有效凭据）。修法：`logFields` 可变 holder 经
   context 向内传、authenticate 写入、accessLog 在内层返回后读取（单槽
   atomic.Value，写一次读一次）。测试断言 `user=admin` 与 `user=anonymous` 两态。

5. **adapters 注入而非进程注册表**。`Deps.Adapters []adapter.Handler` 由 cmd 传
   `adapter.All()`；测试传各自的实例。避免并行测试共享 `adapter.Register` 全局表
   （重名 panic 是启动期设计，但会耦合测试）。`Server` 内建 packageType→handler 映
   射，语义与 registry 的 byType 键一致。

### 交付面

- **envelope.go**：`{"errors":[{status,message}]}`（rest-api §0 高置信度，T-22 回写
  取代单对象形）；`notImplemented`（message 含 "not implemented in BinFlow"，E-26②）
  与 `notFoundPrefixHint`（/artifactory 提示 /binflow，E-26①）。
- **middleware.go**：链固定 `requestID → accessLog → recover → CORS → authenticator
  → authorizer → handler`（§7.2）。authorizer 的路由需求（required/action）在
  dispatch 分支内按路由决定后经 `enforce` 包在 terminal handler 前——等价于「链顺序
  固定」且每路由 action 可变。recover 对 `http.ErrAbortHandler` 重抛（流式响应的静
  默断连不吞）；CORS 空 origin 列表=同源姿态、`*` 或白名单显式开；访问日志字段
  method/path/status/duration_ms/remote_addr/user/bytes_in/out/request_id，绝不记
  头（NFR-S3，测试断言 Authorization 与 base64 凭据值都不出现）。
- **router.go**：dispatch 树 = 非 /binflow 前缀→E-26① 404；`/binflow` 与
  `/binflow/`→console；`/binflow/api/...`→dispatchAPI（本票 4 端点 + 其余 E-26②）；
  `/binflow/v2/**`→E-26 404（M2 预留）；其余→内容路径（内容动词→action 映射：
  GET/HEAD=r、PUT/POST=w、DELETE=d；repo 行查 metadata→packageType→adapter；未知
  repo→404 spec 文案；无 adapter→记日志+E-26 形 404 而非 500）。
- **server.go**：`New(Deps, *slog.Logger)`、`Handler()`、`Run(ctx)`（ctx 取消=
  Shutdown(GracefulTimeout)）、`Shutdown(timeout)`（幂等）。SIGTERM 信号捕获归
  cmd/T-16——Run 的契约是 ctx 取消即优雅排空，§7.4 的「关 storage→关 metadata」顺
  序也留在 cmd 单点。
- **system.go**：ping（200 text `OK` 免认证）、version（`{version,revision,
  product:"BinFlow"}` 如实，Q4）、v1/health（storage 可写探测 + metadata Ping，
  `{status,storage:{status},metadata:{status}}`，E-22）、v1/storage/stats（blob 数/
  logical=Σnode.size/physical=blobs/ 目录字节，E-23，C12 去重观测）。
- **console**：`Handler()` 返回 `{service:"binflow",console:"M4"}`，M4 换 go:embed
  实现不动路由缝。
