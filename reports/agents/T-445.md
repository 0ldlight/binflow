## 4. 契约漂移（conductor 请过目）

1. **「普通面 FileInfo 非敏感字段」不存在（派单 vs T-438 as-built）**：派单
   摘要说 Downloads 族「admin 面 ?stats，普通面 FileInfo 非敏感字段」——
   但 T-438 按 ADR K69.4（DECISIONS.md:1135 + architecture §25.5「基础
   FileInfo 零变化」）落成 **?stats 唯一面**：FileInfo 不带任何下载字段，
   计数面（downloadCount/lastDownloaded/remoteDownloadCount）对全档可见
   （路由 = item-info 读门，匿名随开关），仅 lastDownloadedBy 挂
   CapSystemRead。本票 FE 按 as-built 消费：**所有档位统一走 ?stats**
   （普通用户也拿得到计数），lastDownloadedBy 随服务端 omitempty 呈 '—'。
   效果与派单意图等价（普通用户可见非敏感计数、不可见下载者），但承载面
   不同——若 conductor 意欲混合形（FileInfo 冗余投影），是后端 5 行追加 +
   FE 零改（getNodeStats 换面即可），请示下。
2. **GET /api/repositories/{key} 的 url 字段缺内容面前缀**（`repositories.go`
   repoConfigOf：`requestBase + "/" + RepoKey` → `http://host/<key>`，缺
   `/binflow`）——仓视图 File URL 行如实回显该后端值（不 FE 端拼改），链接
   形态不可达。**非本票引入**（M1 起既有），登记为后端 repositories 面
   勘误候选（一处 `requestBase + prefix` 的事）。
3. **FileInfo.downloadUri = api/storage URI 非 Artifactory 语义的下载 URL**
   （storage.go fileInfoOf：uri 与 downloadUri 同值）——本票 File URL 未
   采用该字段，客户端构造内容面 URL（与「直接下载」钮同构、e2e 剪贴板
   断言实证可用）。wire 勘误候选，登记不阻塞。
