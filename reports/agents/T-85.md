## 关键产品决策（PM 裁定，均可溯源）

1. 控制台挂 `/binflow/ui/**`（避免与内容路径 `/binflow/<repo>/<path>` 冲突），repo key 保留字增补 `ui`（ADR-0008 输入）；`GET /binflow/` 301。
2. session cookie 与 Basic/Token 为等价认证凭据（控制台上传/删除靠它），CSRF 暂行 = SameSite=Lax + cookie 认证写请求 Origin 同源校验（CI 的 Basic/Token 零感知）。
3. 组模型极简：`{name, description}`，组无 admin 位（与 Artifactory 组 admin 有意不兼容，SE-07 行内标注）；有效权限 = user ∪ groups 并集、逐请求即时生效。
4. 组删除被 permission target 引用 → 409（BinFlow 从严，K3 暂行待校准）。
5. 配额：repo 级 quotaBytes（0=不限）、413 原子拒绝、remote pull-through 不计量、秒传/mount/写路由全堵（NFR-S23）。
6. GC 在线化走 `/api/v1/system/gc`（语义等同但路径不同；Artifactory prune 异步语义不做），与 export 共用 data 目录级锁（互斥 409 可观察）。
7. export = 在线（SQLite backup API 快照先行 → blobs 拷贝保 mtime → manifest 引用完整性）；import = 停机 + 空 data dir + fail-fast 无半恢复。
8. 治理范围收窄：maxUniqueSnapshots/immutable tag/virtual 穿透删除等「M4 预告项」推迟 M5+（§2.2 逐条给出理由，防范围蔓延）。
