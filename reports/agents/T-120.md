# T-120 — 懒 chunk 运行时资产路径修复（D-104-1，P1）

- 状态：done（自测全绿，待 qa）
- 角色：devops-engineer；area：`web/scripts/`（最终未动 vite.config / package.json / Makefile）
- 变更：`web/scripts/relink-assets.mjs` 一个文件（扩展 + 自检门禁）

## 1. 根因复核（比 QA 报告更进一步的事实）

vite 6.3（`base=/binflow/ui/`）把 base 烧进**三个面**，T-89 的 relink 只盖住前两个：

| 面 | 形态 | 修前值 |
|---|---|---|
| 1 | `dist/index.html` 里 `<script>/<link>` 完整 URL | `/binflow/ui/assets/index-*.js` 等 2 处 |
| 2 | `dist/assets/*.css` 里 `url(...)` 完整 URL | （本项目无命中，防御性保留） |
| 3 | **JS chunk 内的运行时拼接函数**：preload helper 的 `assetsURL` | `zv=function(i){return"/binflow/ui/"+i}`，dep 为 outDir 相对名 `"assets/<hash>.<ext>"` |

关键点：懒 chunk 的死引用**不是** chunk 内的 `/binflow/ui/assets/` 完整字面量（所以对 dist grep 该串是 0 命中——曾误导排查），而是 `"/binflow/ui/" + dep` 拼接在**运行时**求值。整棵 dist 里 `"/binflow/ui/"`（带尾斜杠、带引号）恰好只出现 1 次，就是该拼接函数；路由 basename 是无尾斜杠的 `"/binflow/ui"`（minify 后 `basename:"/binflow/ui"`），字形不同、不可误伤。

浏览器侧机制（与 QA §3 证据闭环）：每个懒路由经 `vitePreload` → `zv(dep)` 生成 `/binflow/ui/assets/tree-*.css` → SPA fallback 应答 497B shell（text/html）→ WebKit/Firefox 严格 MIME 拒绝 stylesheet → helper 抛 `Unable to preload CSS for …`（serve 日志与 QA pageerror 一致）→ dynamic import 被 reject → 整路由空白；Chromium 宽容 CSS 失败但同样丢局部样式 + 每导航 ~20 个死预取。

## 2. 路线选择（评估了两条，取 relink 扩展）

- **② relink 扩展（采纳）**：JS 面的修法是把拼接前缀 `"/binflow/ui/"` 改写为 `"/binflow/"`（dep 自带 `assets/`，拼接结果恰落共享挂载 `/binflow/assets/<file>`）。单文件改动、命中面经全量枚举验证唯一、对 dev 流与既有 ADR-0014/T-108 架构零扰动；并新增**自检门禁**（见 §3），把「grep 验证」变成每次 `npm run build` 的硬失败条件。
- **③ vite base 直接配对（不采纳）**：`base='/binflow/'` 能让三面原生正确，但 (a) 与 `src/main.tsx` 的 router basename `"/binflow/ui"`（产品代码，不在本票 area）解耦后，**dev server** 应用路径变为 `/binflow/` 而 basename 仍是 `/binflow/ui` → `npm run dev` 白屏回归；(b) 若用 mode 条件 base（dev 保 `/binflow/ui/`、build 用 `/binflow/`）再删 relink，任何 `--mode development` 构建将静默退回死 URL——正是 D-104-1 得以存活的那类静默漂移；(c) `experimental.renderBuiltUrl` 属实验 API 且对 modulePreload dep 的覆盖面不确定。爆炸半径大于收益。
- **① console handler 双段服务（不在 area）**：internal/ 产品代码，且违背 T-108 errata「fallback 永不做文件特判」的立意，排除。

## 3. 变更内容（web/scripts/relink-assets.mjs）

1. 改写目标从 `{index.html} ∪ assets/*.css` 扩为 `{index.html} ∪ assets/*.{css,js}`；
2. JS 面改写用正则 `/(["'`])\/binflow\/ui\/\1/g → '$1/binflow/$1'（引号风格是 minifier 的选择，三种引号都认、保留原引号）；
3. **自检门禁**：改写后全量扫描 `dist/` 每个文件，残留 `/binflow/ui/assets/` 字面量或 `"/binflow/ui/"` 拼接前缀 → 打印 LEFTOVER 并 `exit 1`。今后 vite 升级若改发射形态，构建直接失败逼人更新本脚本，而不是把死 URL 发进二进制。
4. 头注更新：三面清单、D-104-1 机制、basename 不可触碰说明。
