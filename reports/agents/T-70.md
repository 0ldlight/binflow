## 2. AC 覆盖（PE-01~PE-03 / FR-19）

**PE-01 simple index**
- PEP 503 归一化三态同页：`Demo_Pkg`/`demo_pkg`/`demo-pkg`（+`Demo.Pkg`/`demo__pkg` 变体）同一 index 页、同一 ETag（TestSimpleNormalizationMatrix；索引查找用归一化键，node 遍历按 `normalizePackageName(firstSeg)` 过滤）。
- 文档头固定 `<meta name="api-version" value="2" />`（PEP 629，规格 §3.2 逐字，仓级/包级同头）；仅 sha256 fragment（`#sha256=`，无 `#md5=`）；无 Artifactory 私有 `rel="internal|external"`；条目按文件名排序（并列按全路径，保证 ETag 稳定）；href=`../../packages/<repo内路径>#sha256=<hex>`，值经 HTML 转义（注入用文件名实测转义）。
- 无尾斜杠 302：Location 为**相对**形式（`demo-pkg/`）——T-63 缝把 URL 重写到内容面后处理器看不到 api 拼写，绝对路径 Location 会逃出协议挂载；相对目标对 api 挂载与裸内容两入口都正确解析（curl redirect_url 实证）。`/simple`（无斜杠）同规则 302 → `simple/`。
- ETag=渲染体的 sha256（带引号不透明串）+ If-None-Match（弱比较/W前缀/*）→ 304；内容变化 → ETag 变化 → 旧 tag 200。
- 未知名 404（envelope，消息含归一化名）；`simple/` 根索引（P2）已实现：归一化项目名排序锚点。
- `/simple/<name>/<version>`（含更深、带/不带尾斜杠）恒 404（规格 §3.1 保留端点）。
- PEP 691 JSON（P2/PE-05）已实现：Accept 显式含 `application/vnd.pypi.simple.v1+json` 才出 JSON（`{"meta":{"api-version":"2.0"},"name":...,"files":[{filename,url,hashes,size}]}`），其余（缺省/`*/*`/`text/html`）保持 HTML——对齐 Artifactory 默认关（PRD 定案）。
- gzip 预压缩（P2）：不做（PE-01 行内 P2；pip 对 identity 完全兼容），已注明。

**PE-02 upload**
- `:action` 严格 `file_upload`：错值 400 `unknown action '<action>'`（定案文案）；缺失 400 `missing ':action' field (expected 'file_upload')`（缺失分支规格未定案，文案自定已注明）。
- `md5_digest` 可缺失（twine ≥6.2 形态）：服务端自算（下载头 X-Checksum-Md5 回显实证）；提供且正确（大小写不敏感）→ 200；提供且不一致 → 走 client-checksums 链 409（received/actual 文案，session.Commit 阶段拒绝，**不落任何 node**）；宽度错 → 400。`sha256_digest`（twine 同发）同链校验。
- 缺 name/version/content → 400。
- 同 filename 重复 → 400，消息含 "already exists"（M33 grep 目标；重复检查在 Commit 前的 svc.Get 探测完成，读被拒时不抢占 PutLandedBlob 的写门裁决）。
- 响应统一 200 空 body。
- 存储路径 `<name>/<version>/<filename>` 用元数据**原始名**不归一化（C7）；归一化仅用于索引查找。
- 上传字节流直灌 storage session（multipart 字段序不契约化——content 先于字段到达同样成功，TestUploadContentFirstOrder），最终 `svc.PutLandedBlob` 落 ledger+node（T-64 为此上传形态建的用例）。
- multipart 边界：非 multipart CT → 400；boundary 错/残体 → 400；非 content 字段带文件 → 400；重复 content 字段 → 400；值字段 1MiB/128 字段上限。
- 穿越变体（NFR-S18）：name/version 的 `../`、`.`、`/`、控制字节 → 400 且零残留；文件名侧双层防御——mime/multipart 自身剥目录成分（RFC 7578 §4.2，`../x`、`/etc/x`、`sub/dir/x` 落 basename），穿透解析的反斜杠名被适配器段校验 400；全量断言所有 node 保持 `<name>/<version>/<filename>` 三段形态。表单字段是原始数据不是 URL 编码（字面 `%2f` 名是一段，实证）。
- remote 仓 POST → 405 `Allow: GET`（RE-04）；virtual 仓 POST → 405 + C5 定案文案（T-71 落地路由引擎前的诚实拒绝，文案即 PRD 定案值）；均在读 body 之前由 ClassReader 缝裁决。

**PE-03 下载**
- href 目标 `/binflow/api/pypi/<repo>/packages/<name>/<version>/<filename>` 与裸内容路径 `/binflow/<repo>/<name>/<version>/<filename>` 同 node 双入口（同 bytes 同头集实证）。
- 复用 M1 下载链：X-Checksum-Sha256/Sha1/Md5（sha1/md5 取 blobs 台账）、ETag=未引号 sha1、Last-Modified、Accept-Ranges、单区间 206/不可满足 416（`bytes */total`）/多区间忽略 200、If-None-Match(弱)/If-Modified-Since 304、HEAD 等价。
- `packages/` 与裸内容路径只读（PUT/DELETE → 405 `Allow: GET, HEAD`；PyPI 上传只走根 POST，文档注明）。

**PE-04/PE-06（M58）**：`/pypi/<name>/json` 与更深形态任何方法 → E-26 族 "not implemented" 404；`/api/pypi-ui/**` 永久 404（挂载真 handler 后复测）。

**MetadataProvider（pypi）**：Classify（`simple/`→metadata，其余→content）、PackageName（存储形/包 packages/ 挂载形/索引形 → 归一化名；保留端点与 legacy JSON → ok=false）、Versions()=nil（M3 无 PEP 440 序，SPI 回落首命中）。`Register` 单调用同时入 adapter.Register 与 adapter.RegisterMetadata（同字面量，N2 收口；重复注册 panic 即注册表自身契约）。

**AC③ 匿名边界（M35 等价）**：匿名 GET simple/文件 200（anonymous_access 默认开）；匿名 POST 401 + Basic challenge（路由写门，NFR-S17）；anonymous_access=false 时 GET 亦 401。
