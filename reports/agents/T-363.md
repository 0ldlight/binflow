## 1. 设计摘要

### 1.1 分层（上游会话 / 缓存落盘分置）

- **上游会话**（internal/adapter/docker/remote.go）：OCI Distribution 会话（Accept 透传协商、401→WWW-Authenticate Bearer→realm 交换→Bearer 重试→token 按 scope 缓存）由 docker 适配器持有，出站链路复用 internal/remote 的**导出 client**（NFR-S13 SSRF 链/逐跳复查/超时/重试/禁压缩，与引擎同源）。每仓双 client：带凭据（首试+交换）与无凭据（Bearer 重试——applyBasicAuth 不覆写自定义 Authorization）。
- **缓存落盘**（internal/repo/dockerremote.go）：repo.Service 新增 **RemoteV2Plane** 能力缝（RemoteFetcher 先例：适配器侧类型断言，不扩 Service 主体接口、不破测试 fake）——RemoteUpstream（上游事实+解密口令+TTL/超时解析，顺序镜像引擎 effective*）、ProbeRemoteCache（步骤 3+4 只读：负缓存/TTL 副本）、LandRemoteBlob（engine.land 同不变量：session commit **强制 expect digest**、blob-first、checksum 寻址、首见溯源、content TTL 行、GC hold 后置释放）、CacheRemoteMiss（负缓存）、RecordRemoteManifest（manifest 行+tag 指针+best-effort ref 边，缓存填充非部署，无写面门）。
- **读面准入**：loadV2ReadRepo（local+remote；virtual 留 T-365 并在拒绝文案点名）替换 ResolveManifest/ResolveTag/ListTags/ListImages 四处。写面（PutManifest/DeleteManifest/uploads）不动。
- **路由分支**：serveNameRoute 在 authorizeRoute 后按 row.Class()==remote 分流 serveRemoteRoute；非 GET/HEAD 一律 405+Allow:GET（RE-05，镜像 refuseNonLocalWrite 文案，先于 upload session 发放）。RepoRow 增 Class()（static lookup 返回 ""，行为同旧）。
- **降级矩阵照引擎口径**：5xx/传输故障/token 交换失败→过期副本 STALE+X-Binflow-Upstream-Error，无副本→404 unfound 族（零裸 5xx）；上游 404→digest 键路径负缓存+过期副本续serve；401/403（舞步穷尽）→404+摘要不写负缓存；SSRF 拒绝→400；blob 落盘 digest 不符→502 不落盘。

### 1.2 上游 URL 约定（helm.md §8.3 定案）

`url` = 上游 registry 的 **distribution API 根（含 /v2）**：Docker Hub 形态 `https://registry-1.docker.io/v2`；BinFlow 自指上游 `http://host:port/v2/<上游仓key>`。仓内相对路径直拼（`<image>/manifests/<ref>`、`<image>/blobs/sha256:<hex>`，tag 原样/digest 补 sha256: 前缀）。

## 6. 登记与遗留

- **D-1（会话分置）**：v2 家族上游会话由 docker 适配器持有——internal/remote 的 path-joined 取数无法表达 Accept/Bearer/tag 解析（internal/remote 为 T-367 area，本票零改动）；落盘经 RemoteV2Plane 缝与 engine.land 同不变量。singleflight 与 assumed-offline 冷却窗不在此面（并发同拉幂等落盘无害；T-367 引擎缝可评估收编）。
- **D-2（tags 面）**：tags/list 与 _catalog 服务已缓存行（tag 随 manifest 落地），不代理上游 tags/list——无缓存镜像的 tag 集不可见；helm 带 --version 不受影响。上游 tags/list 代理滚后续票（helm.md §8.3 已登记）。
- **D-3（tag 负缓存）**：tag 404 无存储键不写负缓存（digest 键路径照写）。
- 断言反转：t342_helmoci_family_test.go（remote 读面 ListImages）；virtual 臂/写面拒绝/异类型拒绝三处维持原断言。
