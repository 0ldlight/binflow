## 做了什么

在治理组「存储 & GC」页（`/governance/gc`）新增「存储迁移（本地 → S3）」面板：

- 数据源 `GET /binflow/api/v1/storage/migration`（T-164，admin 门），每 **5s** 轮询（`MIGRATION_POLL_MS`），挂载即取一次。
- 进度呈现：water-bar 水位条（复用既有 `.water-bar/.water-line` 基元，零新增 CSS）+ mono 百分比；计数行全部 mono。
- 字段以 `internal/storage.MigrationStatusView` 实存契约为准：`running / done / total / migrated / skipped / failed / error / started_at / finished_at`。语义映射：完成度 = `(migrated + skipped) / total`（skipped = S3 已存在的幂等跳过，同样计入完成）。
- 交互四态收敛：
  - loading → Skeleton（仅首帧；轮询刷新不清屏）；
  - **403 → 整面板隐藏**（console-ux §3.6.3 L3，非 admin 直链兜底）；
  - **501 → 降级为「未配置 S3 迁移」提示**，不渲染进度条（AC 的优雅降级）；
  - 其它错误 → 无数据时 ErrorCard + 重试；已有数据时**保留旧进度 + 行内「上次刷新失败」**（观察进行中迁移时单次掉线不清屏），轮询自动续命。
- e2e：`web/e2e/storage_migration.spec.ts`（5 用例，hermetic 全 mock，见下）。
