# T-149: M6 架构增量设计（architecture delta）

**Role**: architect
**Date**: 2026-08-21
**Status**: done

## 产出摘要

为 BinFlow M6 里程碑（S3 后端、OIDC/LDAP、复制/联邦、Prometheus 指标、bf CLI、Artifactory 迁移）完成架构设计，产出 7 个新 ADR 并更新 architecture.md 的 1-12 章节。

## ADR 产出

| ADR | 标题 | 关键决策 |
|-----|------|---------|
| ADR-0018 | S3 存储后端 SDK 选型 | 标准库 net/http + AWS Signature V4 自实现（零 CGO、零新增依赖）；对比 aws-sdk-go-v2（被排除：依赖树 200+ 包、与 ADR-0005 冲突） |
| ADR-0019 | 存储引擎扩展缝 | 引入包内 `Backend` 接口（Put/Get/Delete/Exists/List）；`Engine.Open` 返回类型从 `io.ReadSeekCloser` 变更为 `io.ReadCloser`；disk 实现仍可 Seek（类型断言） |
| ADR-0020 | OIDC/LDAP 认证扩展 | Authenticator 增加第 4 个 Bearer arm（OIDC ID Token 验证）；新 `IdentityProvider` 接口；LDAP 仅走 POST /api/v1/session（不与 per-request auth 混） |
| ADR-0021 | 复制/联邦 | push 复制（异步，制品 Put 后触发）+ pull 复制（复用 remote 机制）；双向同步 defer 到 M7+ |
| ADR-0022 | Prometheus 指标 | stdlib expvar + 自写 Prometheus text format 序列化器（零新增依赖）；8 个核心指标（blob/node/repo counts、HTTP metrics、upload sessions、go memstats） |
| ADR-0023 | bf CLI 工具 | 独立二进制；`internal/client` 包封装 HTTP 客户端；子命令：login/logout/repo/user/token/upload/download/search |
| ADR-0024 | Artifactory 迁移工具 | `bf migrate` 子命令；3 阶段：discover → transfer → verify；间歇性迁移（resumable） |

## 接口契约摘要

| 模块 | 接口 | 变更 |
|------|------|------|
| storage | `Engine.Open` 返回 `io.ReadCloser` | 签名变更（M6+） |
| storage | `Backend` (Put/Get/Delete/Exists/List) | 新增（包内） |
| auth | `Authenticator` 4th Bearer arm | 新增 arm |
| auth | `IdentityProvider` (ProviderName/Authenticate/Resolve) | 新增接口 |
| metadata | `replications` + `replication_tasks` 表 | 新增 DDL |
| metadata | `users.provider` + `users.provider_id` 列 | 新增列 |

## 风险与合规

- **clean-room 合规**（ADR-0001）：所有设计基于 docs/reverse/ 的规格与官方协议文档，未参考 reverse-src/
- **ADR-0005 零 CGo 依赖**：S3 SDK 自实现 AWS Signature V4（零新增依赖）；Prometheus 指标自写 text format 序列化器；OIDC JWT 验证使用既有 `golang-jwt/jwt/v5`
- **安全**：OIDC/LDAP 密码不入 YAML（env-only）；复制目标密码 AES-256-GCM 加密存储；S3 凭证通过 K8s Secret 注入
- **多副本实验性**：S3 后端 + SQLite 的多副本场景存在元数据不一致风险（§11.24），M6 推荐单副本
