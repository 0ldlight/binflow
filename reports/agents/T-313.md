## 2. S8 URL 改写算法落点（urlrewrite.go，纯函数 + 表驱动 16 分支）

remote 成员条目（chartsBase = 仓 URL，见 D-2）：
- charts-base 前缀命中（**边界规则**：`/stable` 不认领 `/stable2/...`）→ 成员相对路径（客户端经虚仓取数 → 成员 engine 路径对齐回源）；
- 命中且余部以 `_external/` 开头 → `_transitive/<...>`（上游自身的 _external 面）；
- 基外 http/https + 允许清单命中 → `_external/<scheme>/<host>/<path>`（`://` 折叠为 `/`；query 串尾段 verbatim 保留，fold↔parse roundtrip 已测）；
- 清单未命中 → 保留原 URL（客户端直连）；非 http(s) scheme → 保留；
- `oci://` → 保留原样（D-5）。
local 成员条目：相对路径 verbatim（BinFlow 生成面即相对）；绝对 URL 指向本实例内容面（`<base>/binflow/<member>/`）→ 折回仓内路径；其余走外部分支。
合并序：成员两桶序内 (name, version) **first-wins**（S13——先成员即解析会服务的成员，digest 与下载面一致）；chart 内版本 SemVer 降序重排；空 entries 成员计为「有贡献」→ 200 空文档（区别于无 index 的 404，表驱动钉死）。
