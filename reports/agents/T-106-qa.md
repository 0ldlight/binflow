## 3. 缺陷与观察

### 3.1 D-106-1 [P1 · 产品侧 · 转主会话] 显式目录节点使 export 整体拒绝

- **症状**：`binflow-server export` 退出码 1：`export: snapshot references blob 0000…0000 but the filestore … does not carry it (dangling reference in the source instance)`；compose 容器内与宿主裸进程**双形态复现**。
- **根因**：C16 `mkdir` 建的目录节点 `nodes` 行 sha256 存 64 个 `0` 的占位值（实测 `('generic-local','acme/','00000000…0',0)`）；`internal/metadata/snapshot.go` `SnapshotChecksums` 的 `SELECT DISTINCT sha256 FROM nodes WHERE sha256 != ''` 过滤不掉该占位值 → `cmd/binflow-server/backup.go` Step 3 把它当被引用 blob 强求在拷贝树中存在 → 拒绝出包。
- **因果实证**：含目录节点 → export 失败；删除该目录节点（`DELETE …/t106/` 204）→ 同实例 export 立即 exit 0。
- **影响**：任何用过 mkdir（或未来任何产生目录节点的路径）的真实库**整体无法备份**（FR-32 不可用）；fail-closed，无数据损坏、无半包。
- **修复建议**（1 行级）：`SnapshotChecksums` 排除目录占位（`AND sha256 != '0000…0'` 或按 `path LIKE '%/'` 排除目录行）；import 侧同查。回归锚：建目录 → export/import 全链（本票序列即可作 QA 剧本）；建议随修复补 T-96 表驱动用例（"目录节点不是 blob 引用"）。
- 归属：dev-go-core（backup.go/snapshot.go 非本票 area，**未改产品代码**）。

### 3.2 D-106-2 [P2 · deploy 产物 · 本票已修复] 反代片段缺 `/binflow` 无斜杠直通

nginx 片段只配 `location /binflow/`，入口 URL `/binflow`（无斜杠）不命中 → nginx 自造绝对化 301（剥端口，非标准端口部署死链）。**修复**（`deploy/dev/README.md`）：nginx 加 `location = /binflow` 直通（BinFlow 自身 301 接管）；traefik 规则改 `Path(`/binflow`) || PathPrefix(`/binflow/`)`；均已实证（§2.3）。
