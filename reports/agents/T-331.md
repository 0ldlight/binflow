## 规格依据与差异登记

- **高置信直实现**：docs/reverse/auth-integration.md v2 §3.2 端点表（GET/PUT `…/saml/config/key/public[/regenerate]`，text/plain）、§3.3 保存流程（useEncryptedAssertion=true → createStoreAndGetKeyPair(false) 生成/复用；失败统一折叠不落库）。
- **D-1 路径归一**：票面速记 `saml/public`、`saml/regenerate` 落地为规格 §3.2 原路径（FE T-307 遗留 #1 的两按钮即调此路径）；票面第三端点 `POST /api/v1/admin/security/saml/key` 为 BinFlow 原生生成/替换面——Artifactory 无显式生成 REST（隐式挂在保存流），沿用 GPG 面 D-1 姿态。两写动词同机（force 一对一替换），审计动作分立（操作者意图有别）。
- **D-2 存储**（上述 C 级保留行决策）。
- **D-3 证书剖面（规格静默，C 级）**：RSA-2048（SAML xml-encryption 互操作默认）、CN=binflow-saml-sp / O=BinFlow、~10 年效期 + 1h 回拨、KeyUsage=keyEncipherment|digitalSignature|keyAgreement、不设 EKU（IdP 接受面最宽的无限制姿态）。
- **D-4 空态 404 文案**：Artifactory 失败文案无锚（规格无失败行），BinFlow 措辞，tests 已钉。
- **D-5 regenerate 响应体**：返回新公钥证书 text/plain——由 §6 UI 流（下载/再生成动作）推断（中置信），测试固化。
- **license 门控**：规格 §3.2 称 config 族挂 `@Entitlement(SAML)`；T-305 已裁定 BinFlow SAML 配置面不 license 门控，本票随族一致（如需门控应整族补，非三端点单列）。
- **未跑 L-A 实时取证**：手头无 Artifactory 实例，行为锚定规格 v2 双出处行；若后续取得实例，regenerate 的状态码/响应体可复核（唯一中置信点）。
