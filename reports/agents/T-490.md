## 二、行为联动：blackedOut=true 拒写（AC1 后半）

- **状态码/文案**：404 + `The repository '<key>' is blacked out and cannot serve artifact '<key>/<path>'.`（rest-api.md §1.2 步 6 / repo-semantics.md §2 步 2——**均中置信度，按纪律实现并以测试固化**；repoPath 用 BinFlow 全库既有 `<key>/<path>` 拼写约定）。StatusError verbatim 走 T-66/T-111 缝：内容面 errors[] 信封、docker 面 registry 信封（envelope code=UNKNOWN——verbatim 契约=状态+消息，T-111 specCodeOfVerbatim 既有映射）。
- **实测输出**（TestBlackedOutWriteRefusalWire / TestBlackedOutRefusesEveryDeployFace）：
  - 内容 PUT `/binflow/lib/a/b.txt` → **404** `{"errors":[{"status":404,"message":"The repository 'lib' is blacked out and cannot serve artifact 'lib/a/b.txt'."}]}`；
  - docker blob 单 POST 上传 → **404** registry 信封含同文案；docker manifest PUT → **404** 同文案；
  - folder deploy / checksum-deploy（PutFromBlob 链）/ PutLandedBlob（finalize+mount 链）/ ExplodeArchive / virtual 路由写（消息点名 **member**）全部 404；
  - **步序钉**：无授权 principal（alice 零 grant）写 blackedOut 仓 → 得到的是 blackout 404 而非 403（assertValidPath 先于权限对，repo-semantics §2）；
  - **翻回**：PUT `blackedOut:false` → 内容 PUT 201 / blob 上传 201（活开关，非粘性拒绝）；
  - **读/删面不动**（as-built 边界钉：blackout 期 Get 照常、Delete 照常——读侧 listing-404 是规格「中」置信注记，**未实现、登记待验证**）。

## 三、Stage 域 wire 键定案（AC2）

- **canonical = `environments`**（JFrog 官方 REST 文档记载的仓配置字段——clean-room 铁律「有公开规范的协议以官方文档为准」）；**`stages` = 7.161 时代输入别名**。
- 对拍留痕：本地参照实例 :8082（7.161.20）**当日离线**（lsof 无监听）——活体对拍不可用，改以两证据链定案：① 官方 REST 参考文档（公开规范，clean-room 准许面）；② docs/reverse/webhook.md（7.161.16 反编译规格）同期 **双拼写并存**佐证（app_trust 用 `stages`、release-bundle v2 promotion 用 `selectedEnvironments`）——7.161 产品线 wire 面本就双拼写生态，UI 更名（T-439 实测 Basic 步标签 Stage）不必然换 REST 键。**低置信度处理**：仓配置面官方文档只证 `environments`，`stages` 为别名推断（中置信）——以「双拼写全收 + verbatim 回显 + 分歧 400」的形态兜住两个方向，任一为真均零迁移成本；登记：若后续实例窗口活体证伪，删别名收窄为单键即可（validateStageNames 单点）。
- 往返一致：verbatim 透传（不归一化）——PUT `stages:["BOX"]` → GET `configuration.stages:["BOX"]`，逐键一致（表见上）。

## 四、K73 repoLayoutRef 落定（AC2）

- **裁定：出口②「钉协议默认值」**（T-439 报告推荐项）：字段 local 臂全量承接（转发+落库+回显 verbatim）、**不接线布局引擎**——路径解析恒由协议 adapter 固定布局（maven 即 maven-2 形，K70 grep 零消费方的实态），存储值是**呈现性元数据**（presentation-only），不构成解析开关。
- **值域不设门**的理由：PRD scenario D 迁移容忍（Artifactory 组织可携自定义布局名，按名拒收=破迁移脚本整包投递）；field-only 先例（remote 的 `unusedArtifactsCleanupPeriodHours`/`statisticsEnabled` 均为「承接入库+回显、引擎另票」登记态）。maxUniqueSnapshots（快照清理引擎）与 archiveBrowsingEnabled（Content-Disposition/archive 门）同此 posture——行为化留待对应引擎票，本票登记为 seam。
- 留痕：ADR-0003 勘误行（DECISIONS.md 追加式）+ PRD milestone-16 §5.6 K73 行回填注记（T-519 对账入口）。
