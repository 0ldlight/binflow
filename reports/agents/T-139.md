### 架构决策

- **安装脚本三模式**: compose（默认，最简单） / kind（K8s-in-Docker） / helm（已有 K8s 集群），均支持 `--dry-run` 预览
- **Idempotent**: 已加载镜像跳过 reload；已有 compose 栈不重复创建；已有 helm release 走 upgrade；已有 kind 集群复用
- **Fail-clean**: trap EXIT 捕获失败，回滚已加载的 docker 镜像、停止 compose 栈、卸载 helm release
- **Checksum gate**: 安装前强制验证 `SHA256SUMS`，验证失败立即退出
- **Bundle 构建**: `make offline-bundle` 阶段内依次执行 docker save × 2 / helm package / 复制 K8s 清单 / 复制 linux 二进制 + checksums / 生成 SHA256SUMS / tar 打包 / 记录外层 tar sha256
- **安全基线**: 容器镜像非 root（UID 10001 alpine / 65532 distroless）；Secret 不在 YAML 中硬编码；安装脚本 `set -euo pipefail`
