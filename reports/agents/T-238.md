### 1.2 存储概要新页（`/admin/monitoring/storage` 落真身，§6.18）

新组件 `web/src/pages/monitoring/StorageSummaryPage.tsx`（占位页退场）：

- **Artifactory Storage Summary 形态三件套**（reverse §3.11 骨架）：刷新行
  （「数据最近刷新于 \<ts\>」+ [刷新]）→ 汇总卡行（blob 计数/逻辑容量/物理占用/
  去重率）→ 仓库表（**TOTAL 首行**，占比 100%）。
- **数据面（契约冻结，零新端点）**：`GET /api/v1/storage/stats` + `GET /api/repositories`
  + 逐仓 `GET /api/v1/storage/usage/{key}`；usage **串行拉取 + 进度提示**
  （`storage-progress` done/total），>50 仓或单仓失败给「部分数据」标注
  （`storage-partial`）；virtual 仓不请求 usage（不伪造 0，沿配额页约定）。
- **列收窄**：Artifactory 的 Files/Folders/Items 计数列不在契约（usage 仅
  usedBytes/quotaBytes）——不渲染不伪造；配额列是 BinFlow 自有增强
  （quotaBytes 0=不限）。页脚 hint 明示两口径（stats 全局面 vs repo_usage 逐仓面）。
- **四态**：loading 骨架；空实例 0 值 + 建仓引导（`storage-empty`）；stats 403 →
  汇总卡 L3 隐藏 / repos 403 → 整页 L2 无权限卡；Refresh 即时重取（tick 重驱
  stats/repos/usage 三链）。
- 样式：`pages.css` 追加 `.storage-refresh-row` / `.storage-total`（token-only，
  assert-tokens 通过）。
