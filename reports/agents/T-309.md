## 2. index.yaml 生成（§5.1 逐条）

- `apiVersion: v1` + `entries.<name>[]` + `generated`（每次写出取当前时刻）；chart 名排序、无文档起始标记、无 serverInfo。
- 版本条目 = Chart.yaml 全字段（yaml.Node 原样拷贝，未知字段随行）+ `digest`（tgz sha256 裸 hex）+ `created`（索引时刻）+ `urls`（HL-2 终裁：**relative 恒为默认**，`Options.AbsoluteURLs` 配置位留而不暴露，绝对模式取 `server.base_url`——TL-1）。
- 同 chart 版本条目 SemVer 降序（不可解析回退字符串降序）；同 name+version 上传=remove+add 覆盖。
- S4：`version`/`appVersion` 恒双引号（`created` 亦引号——helm 自身输出同形）；最小化引号；单条目 roundtrip 校验失败→整 chart 剔除仅日志。
- read-modify-write 整文件回写，per-repo 引用计数互斥（cargo B1 姿态）；yaml.v3 嵌套 `*yaml.Node` 解码坑（零值节点重编码为 `null`）以整树手工遍历规避——已固化单测。

## 3. 存储面（§3/§4.2）

- 布局：仓根 `index.yaml`（系统生成）、`<chart>-<ver>.tgz` 任意子目录、`.tgz.prov` 并置普通文件。
- `.tgz` 判定=扩展名；gzip→tar→**归档根** Chart.yaml + requirements.yaml（+ Chart.yaml 内嵌 dependencies 合并）；无 Chart.yaml/非法 tar→跳过索引不拒 PUT（§4.1.3）。
- `chart.*` 属性：13 项按 §4.2（`created`=索引时刻、`chart.isDeprecated` 仅 true 写、sources/maintainers/dependencies 多值；>1KiB/空值被共享属性规则滤除）。
- 上传链 checksum 头：malformed 400 / 不符 409（共享契约）。

## 4. enforce layout（§4.3/S5，403 逐字）

- 开关读仓 config JSON：`forceMetadataNameVersion` / `forceNonDuplicateChart`（默认关；仅 .tgz 上传入库钩子，字节落库前判定）。
- 文案逐字（规格省略号按语义插值 `<repo>/<base>` 与 `<n>-<v>`）：
  - `This action is prevented due to the Enforce Layout Policy, the metadata of the package <repo>/<file> could not be read or is malformed.`
  - `This action is prevented due to the Enforce Layout Policy, a package with the same name and version <n>-<v> already exists in the repository.`
- 查重：默认 chart.name+chart.version 属性搜索；两开关齐开按文件名搜索（§4.3）。文件名=``<name>-<version>.tgz``、version 合法 SemVer2、Chart.yaml 缺 name/version → 403。

## 5. 真实客户端验证（helm 4.2.4 + gpg 2.5.21 + kind 集群）

`BINFLOW_T309_CLIENT_E2E=1`（`BINFLOW_T309_KIND=1` 加 install 腿）：

| 腿 | 命令 | 结果 |
|---|---|---|
| L-h1 | `helm create`/`package` → PUT tgz+prov → GET index.yaml | digest==shasum -a 256 对账 ✓；urls relative ✓ |
| L-h2 | `helm repo add binflow $BASE/binflow/helm-local` → `repo update` → `search repo` → `show chart` → `pull --version` → `template` | 全绿；pull 后字节 sha256 对账 ✓ |
| L-h3 | `gpg --clearsign` prov → PUT → `helm pull --verify --keyring` | `Signed by: T309 Signer / Chart Hash Verified: sha256:…` ✓ |
| L-h4 | `POST /binflow/api/helm/helm-local/reindex` → `repo update` | 200 + 客户端重新消费 ✓ |
| install | `helm install t309-rel binflow/mychart --verify --keyring --wait`（kind-bf-ga 集群） | `STATUS: deployed` ✓ → uninstall ✓ |
| 别名 | `helm repo add binflow-alias $BASE/binflow/api/helm/helm-local` → `search` | 200/search 命中 ✓（HL-1） |

**重要发现（差异登记 D-1）**：helm.md §9 L-h3 的 `gpg --armor --detach-sign` 配方产出的 prov **被 helm 实际拒绝**（`signature block not found`）。helm 的验证器（pkg/provenance）要求 prov 是 **clearsign 文档**（`-----BEGIN PGP SIGNED MESSAGE-----`）且正文含 `\n...\n` 分隔的两段：Chart.yaml 元数据 + `files:\n  <name>.tgz: sha256:<hex>` 校验块。正确手工配方：`gpg --clearsign` 上述 payload。服务端不受影响（.prov 纯透传）。已按验证源码（helm v4.2.4 pkg/provenance/sign.go clearsign.Decode + ParseMessageBlock）实证，建议 reverse-engineer 随规格修订合入（R-3 建议）。

真实二进制门控链（`binflow-server serve`，community 实例）：`PUT /api/repositories/helm-t309` → **400** `package type 'helm' is not available (license tier 'community' < 'pro')`（错误体含 helm/pro ✓；票据写"建仓 403"，实测为 ADR-0033 D3 定案的配置面 400——门控链语义一致，措辞登记于 D-2）。
