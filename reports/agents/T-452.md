## 做了什么

### AC1 — QRL 全量（FR-148.2 / aql.md §14.4）

- `internal/search/qrl.go`（新）：QueryRateLimiter 域——三态
  （disabled 出厂纯旁路 / enabled 延迟放行 / simulation 只记录不阻塞）、
  DEFAULT+LOW_PRIORITY 双桶（许可桶 + 充电时间配额双闸）、窗口指标计数族
  （totalQueries / totalPermits / slowedDownMillis / slowedDownByTimeMillis /
  chargedQueryTime，Sample 采样即归零）。
- **K72 定案（票内裁定）**：默认桶参数 ECHO K63 三元组——permits=4（并发）、
  frame=10000ms（超时）、quota=1000（行上限的数字）；`search.K63Gate()` 导出
  K63 常量快照，测试断言 REST 读数 == 门值，两面不可漂移。
- `internal/httpapi/system_qrl.go`（新）+ router 三行：
  `GET/POST/DELETE /binflow/api/v1/system/query_rate_limiter/config`——
  GET 200 `{"rlSettings":[DEFAULT…,LOW_PRIORITY…]}`；POST 合并写答
  纯文本 `Query rate limiter configuration was updated successfully`；DELETE
  复位答 `…deleted successfully`；disabled 态三操作一律 400 纯文本
  `Query rate limiter is disabled`（逐字）。门 = GET CapSystemRead /
  POST·DELETE CapSystemWrite（license/settings 家族姿态；plain user 三操作 403）。
- **两项登记的 BinFlow 映射**（§14.4 明示归 T-452 票内定案）：
  1. **enable 载体**：Artifactory 走 system.properties（重启生效）；BinFlow 无
     properties 面、本票 area 不加 config 键 → 三态随 REST 文档走（POST 可带
     `"mode"` 字段）；无 mode 的 POST 在 disabled 态维持锚的 400 臂。唯一有意
     wire 扩展，其余逐字。
  2. **admin 门**：RolesAllowed(admin) 映到 v1-system 能力族（readonly_admin
     可读——BinFlow 原生角色，登记偏差）。
- 引擎织入（engine.go runAST）：QRL 槽位于 K63 门**之后**、10s deadline**之内**
  ——429 拒绝不占速率预算；QRL 等待耗尽 deadline → 408 族（不漏 500）。
  disabled 引擎零记账零行为（K63 门原样，正交性有专测）。
- 指标（metrics.go）：`binflow_qrl_mode`（0/1/2）+ 五个窗口计数 gauge（label
  type=DEFAULT/LOW_PRIORITY），**scrape-time 采样**（锚的 60s 指标 job 映射为
  抓取驱动——cleanup/replay gauge 先例；60s 抓取间隔即锚的 60s 窗）；窗口出现
  限流时打锚的逐字 INFO 文案（占位符填实）。

### AC2 — UI 搜索族四端点 + dates/creation（FR-148.3 / §14.5 + §14.3）

- **UI 族**（`internal/httpapi/search_ui.go` 新，挂 `/binflow/api/<注册子路径>`，
  SAML key 家族的 re-home 先例；§14.5 的 /ui/api 前缀本身 V-m 待验证）：
  - artifactsearch：quick/gavc/checksum/trash（复用既有服务内核，答
    {"results":[FileInfo]} E-09 超集行——家族既有姿态）；pkg/{type} GET=该包型
    local 仓清单（「选项集」的 BinFlow 读法）、POST=检索条件数组在该包型仓内
    名字搜索；pkg/tonative=条件→AQL 文本转换（只回字符串不执行，JSON 转义防
    逃逸）；**deleteArtifact 不路由**（锚自注的删除动词缺位登记，E-26 404）。
  - stashResults：十操作全部答 404 逐字 `Stash search results endpoint is
    disabled`（出厂 false + BinFlow 无 enable 载体——Smart Searches pro 档不
    做的 PRD 口径互证）；该 404 与 E-26 措辞可区分（专测）。
  - packagesSearch：leadFile/artifacts 按 repo+path 解析（BinFlow 无 packages
    索引——per-协议 lead-file 语义为登记缺口）；未命中 404 **空体**（锚逐字）。
  - syntax-search：POST AQL 文本（text/plain body + ?query= 回退，aql 入口同

    400 errors[] envelope（锚的 ErrorResponse）。族门 required:true（匿名 401）。
- **dates/creation**（`internal/search/dates_query.go` 新模板 + `internal/httpapi/
  search_dates.go` 新端点）：
  - 引擎固定模板（RunCreation/RunDates 走 runAST——与手写 AQL 同门/同 deadline/
    同 cap/同 ACL 织入，K63 零豁免姿态）：区间 `> from AND <= to`；to 缺省=
    now（**V-j 双源冲突按官方口径裁**）；maven-metadata.xml 恒排除；creation=

    modified 值）；匿名 401；epoch-ms 参数；共享截断头。
- **ACL 同源探针**：dates/creation 双门专测（scoped 用户只见授权仓、raw body
