### AC3 详情字段族与统计

```bash
# 下载 3 次 → ?stats（downloadCount=3 / lastDownloadedBy=admin / remoteDownloadCount=0）
curl -su admin:*** "$BASE/binflow/api/storage/generic-local/acme/app.bin?stats"
# {"uri":".../app.bin","downloadCount":3,"lastDownloaded":"2026-09-04T09:51:36.000Z",
#  "lastDownloadedBy":"admin","remoteDownloadCount":0}
# 从未下载 → {"uri":".../legacy-installer.bin","downloadCount":0,"remoteDownloadCount":0}（无 lastDownloaded 键）

# usage 主例（90 天未下载；legacy-installer 创建时间经库回拨 120 天、零下载）
CUTOFF=$(python3 -c "import time; print(int((time.time()-90*86400)*1000))")
curl -su admin:*** "$BASE/binflow/api/search/usage?notUsedSince=$CUTOFF"        # 200，单行：
# {"uri":".../legacy-installer.bin","downloadCount":0,"lastDownloaded":"1970-01-01T00:00:00.000Z",
#  "remoteDownloadCount":0,"remoteLastDownloaded":"1970-01-01T00:00:00.000Z"}
curl -su admin:*** "$BASE/binflow/api/search/usage"                             # 404 "No results found."（缺参同空集）
curl -su admin:*** "$BASE/binflow/api/search/usage?notUsedSince=abc"            # 400（实测文案入文档）
curl -su            "$BASE/binflow/api/search/usage?notUsedSince=0"             # 401 Authentication is required
curl -su admin:*** -X POST "$BASE/binflow/api/search/usage?notUsedSince=0"      # 404（GET 专用）

# AQL statistics：include/条件/排序/null 字面量/stub/内部 id 拒绝——七连全 200/400 如文档所引
#   include 三字段 → "stats":[{"downloads":3,"downloaded":"...","downloaded_by":"admin"}]（never 行 null）
#   {"stat.downloads":{"$gte":3}} / .sort({"$desc":["stat.downloads"]}) → 200
#   {"stat.downloaded":{"$eq":null}} → 仅 legacy-installer.bin
#   stat.remote_downloads → 恒 0；stat.id → 400 "internal field, not exposed"
# 非 admin（archie）查 downloaded_by → "unknown"（脱敏实测）
```
