# T-133: FR-45 token 签发/吊销落审计 (DM-03, D-104-2 修复)

## Changes

### `internal/auth/token.go`
- Added `TokenFingerprint(plaintext string) string` — returns first 8 hex chars of `sha256(plaintext)`, used in audit events so the plaintext token never appears in stored detail (NFR-S3).

### `internal/httpapi/security.go`
- Added `"github.com/lzwzzy/binflow/internal/audit"` import.
- `handleTokenCreate`: after successful `Issue()`, records `token.issue` audit event with `fingerprint` and `ttl_seconds` in detail. Placed before response serialization so the plaintext AccessToken is available for fingerprint computation.
- `handleTokenRevoke`: added `p := principalFrom(r.Context())`. Two audit paths:
  - By-value: records `token.revoke` with `fingerprint` (computed BEFORE `Revoke()` which deletes the row).
  - By-id: records `token.revoke` with `token_id` (no plaintext token available for this path).
- Idempotent revoke ("Token not found") deliberately does NOT produce audit events.

### `internal/httpapi/t93_audit_test.go` (W23 vocabulary regression)
- Extended the test fixture with `token.issue` and `token.revoke` seed events.
- Added both actions to the assertion loop, confirming they are queryable through the audit endpoint.

## Verification

### Docker isolation (G31c)
Confirmed: `internal/adapter/docker/token.go` does not import `audit` package at all — structural isolation, not relying on caller discipline.

- `audit.Redact()` in `internal/audit/api.go` has `credentialKeys` map covering "token", "access_token", "refresh_token", "authorization" etc. — values are replaced with `[REDACTED]`.
- All token audit events use `fingerprint` (sha256[:8]) instead of the plaintext.
- `TestTokenPlaintextNeverInAudit` explicitly verifies no audit detail contains the minted plaintext token.
