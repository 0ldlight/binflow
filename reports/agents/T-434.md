## 过程缺陷（本票自抓自修）

1. **confirmDelete 闭包依赖钉死**（终验探针抓出）：新增的 wasSelected 回跳引用 dir/focusFile/goTo 但未入 useCallback 依赖——回调钉死在挂载初值，删除选中文件后 URL 永不回跳、右侧落「路径不存在」误导卡。补依赖 + 404 幂等分支同款回跳；修复后探针验证 URL 回跳父目录。
2. **checksum-badge 对比度**（潜伏债，新 axe 腿首扫出）：裸 `--bf-success`/`--bf-warning` 文本在 15% 底上亮色主题不足 4.5:1——「文件选中 + originalChecksums 在场」的详情形态此前从未被 axe 扫到。对齐 base.css 徽章族配方（token 78% + text）。
3. **根层文件 focusPath 前导斜杠**（编码期自检）：`${dir}/${file}` 在 dir='' 时拼出 '/name' 与 ChildNode.path 不同构——scroll 定位与叶行选中态会失配。改条件拼接。

## 契约漂移：无

零 API 变更（FE only）。两条设计定形注记（FR-142.3 授权「BinFlow 路由形态归实现票」）：

1. **URL 模型取「TAB 省略 = general」规范形**：对位 Artifactory `/ui/repos/tree/<TAB>/…` 的语义（页签即段、文件即路径），但默认档不占段——全部既有仓/目录深链保持规范形零重定向（书签与 30+ 既有 spec 断言面不猝死），仅 `?focus=` 旧形与多段旧形一次性折入。非默认页签（properties/permissions）恒占段，四态（页签/仓库/路径/文件）URL 完整承载。
2. **rclass 组按 BinFlow 实有三态** local/remote/virtual：Artifactory 的 Cache 位是其 remote 缓存子集视图，BinFlow remote 浏览面本就是缓存落地行——不伪造第四态（K67 冻结候选注记，锚册 + reverse §3.2 回填均照此口径）。
