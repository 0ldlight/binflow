## 契约决定（供 reviewer 与下游票确认）

1. **分发缝 = 路径重写而非平行分发**：`/binflow/api/<proto>/X` → `/binflow/X` → 标准 dispatchContent。理由：ACL 键、repo 行解析、adapter 请求形状全部复用既有单一路径，无第二套分发语义；等价性有 TestT63SeamEqualsContentPlane 钉死。副作用（有意）：`/binflow/api/pypi/<npm 仓>/x` 会路由到 npm handler（分发跟 repo 行 package type，不跟 URL 拼写）——跨协议误挂不额外 400，行为与裸内容路径一致；若 T-69/T-70 要求 Artifactory 式严格拒绝（如「repo 非 npm → 404」），在协议票内 adapter 首段判定即可，无需改缝。
2. **ClassReader 放行整行 `*metadata.Repo` 但契约只许读 Type**（与 httpapi RepoLookup 同款纪律——metadata.RepoStore 结构性满足，零接线代码）。若 reviewer 认为应窄化为 `RepoClass(ctx, key) (string, error)`，需在 internal/repo 加包装类型（本票 area 限 api.go，未做）。
3. **MetadataProvider 的 Versions() 返回 nil = 无序**（generic），消费方回落首命中（ADR-0013）——比「不实现比较器的协议不允许注册」更宽容，T-69 npm（semver 简单序）可自行决定是否提供。
