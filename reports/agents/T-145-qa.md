## 缺陷

### D-145-01: secret.yaml 占位符导致 kustomize 部署覆盖密码（文档缺口）

- **优先级**: P2
- **位置**: `deploy/k8s/secret.yaml`
- **现象**: `kubectl apply -k` 重新应用 `secret.yaml`，将 `BINFLOW_ADMIN_PASSWORD` 覆盖为 `<replace-with-a-strong-password>`。由于 `seedAdmin()` 在 admin 行已存在时跳过引导，密码变更无法通过 env var 生效。
- **期望**: README 或 NOTES 中明确说明操作者必须在首次 `kubectl apply -k` 前编辑 `secret.yaml`（或使用 `kubectl create secret` 独立管理）。
- **分类**: 文档缺口，非代码缺陷。`secret.yaml` 顶部已有注释，但部署流程中应强调此步骤。

### D-145-02: nginx compose profile 需要 SSL 证书（已知限制）
