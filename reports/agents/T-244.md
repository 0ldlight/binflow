## 1. 键盘全链（FR-75 / console-m8 §3.4 + §9）

**共享件**（新 `lib/keys.ts`）：

- `onTablistKeys`：role=tablist 容器 ←/→ 切换（选中 + rAF 落焦）——接入 `node-tabs`（NodeDetail）、`repo-tabs`（RepoDetailPage）、`repos-tabs`（RepositoriesPage，nav 形态 Tab 只加方向键不改语义）；smu-tabs 自有实现维持。
- `onTableRowKeys`：数据表行 Enter 激活 + ↑/↓ 同 tbody 行间移动——接入 repos/users/perms 三列表行（行补 `tabIndex={0}`）；树页 tree-list 行原有实现维持。

**对话框复核**：ConfirmDialog / SetMeUpDialog / DeployDialog 三处焦点陷阱的 FOCUSABLE 选择器加 `:not([disabled])`——禁用钮（强确认前置未满足 / 空队列的部署钮 / 空口令的提交钮）此前会让陷阱首尾落在不可聚焦节点上破口。SetMeUpDialog 包类型网格（radiogroup）补 ←↑→↓ 焦点移动。

**批量选择 Space**：无承载面——console-m8 §3.5 定案「无批量选择」（无复选框列、无批量端点），不造批量 UI；`lib/keys.ts` 头注钉死口径。

**spec**（新 `e2e/m8/keyboard.spec.ts`，6 腿）：① 登录全键盘 + 侧栏 Tab 落点 + nav-mode-switch 双向 Enter（aria-current 同步断言）；② 树方向键全语义（↓ sibling → 展开加载 → 子节点 Enter 进路径 → 切仓后 ← 收起）+ 表格行 ↑↓/Enter（目录进路径、文件进 ?focus=）+ Shift+F10 菜单 + Esc；③ 管理表行（repos + users 双页实证共享件）；④ tablist 方向键（repo 三 Tab + node 两 Tab）；⑤ 对话框陷阱（Tab 首尾循环跳过禁用钮、连打 10 次 Tab 不漏、Esc、ConfirmDialog 初始聚焦取消）+ quick-set-me-up 接线；⑥ axe 双主题（明示 localStorage 落主题）× 4 个 badge 密集页（树/仓库列表/用户/仪表盘）= 8 扫描 serious/critical=0。

**坑与修法**（spec 编写期）：

1. 跨仓根（repoKey=''）时树的懒加载效果早退——手动展开只翻视觉态不拉子层；展开断言须在任一仓内路由做。
2. `page.goto` 是整页装载（组件重挂载、expanded 归零）——「收起」断言前须重新展开。
3. 选中仓钉住展开态（`isOpen = expanded.has || selectedRepo===key`）——收起断言须先切到别的仓。
4. 相邻行断言不可假设唯一（实例上累积多轮测试的仓）——改为「焦点移到同族另一行」的序无关断言。
5. nav-mode-switch 连击 Enter 会用旧 mode 闭包重导航同址——第二次 Enter 前断言 aria-current（等 React 提交）。
