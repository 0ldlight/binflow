## 做了什么（对照 AC）

1. **AC① 最小补丁**：`charts/binflow/templates/configmap.yaml` oidc 块首行补
   `enabled: {{ .Values.config.oidc.enabled }}`（+1 行，净改动仅此一行）。写法逐字对齐 ldap 块
   现状（`enabled: {{ .Values.config.ldap.enabled }}`）；外层 `{{- if .Values.config.oidc.enabled }}`
   门保持不动，故渲染值恒 `true`。修复 T-179 遗留①：此前 Helm 开 `config.oidc.enabled=true`
   渲染出的 binflow.yaml 缺 `auth.oidc.enabled` 键 → strict decoder 按默认 false → OIDC 静默失效。
2. **AC② 验证三连**：见下"自测"，全过。
3. **AC③ ldap 侧确认**：ldap 块 `enabled: {{ .Values.config.ldap.enabled }}` 行在位
   （configmap.yaml 原第 77 行，本票未触碰）；渲染输出实证 `ldap: enabled: true`。

## 自测（实际运行，全部通过）

1. `helm lint charts/binflow` → `1 chart(s) linted, 0 chart(s) failed`（helm v4.2.4）。
2. `helm template charts/binflow --set config.oidc.enabled=true --set config.oidc.issuerUrl=http://idp
   --set config.oidc.clientId=bf | grep -A 8 'oidc:'` → **AC 字面命令无输出**：deployment.yaml:67 的
   `required` 门先挡（enabled 而 existingSecret 缺失 → render fail 并输出 kubectl create secret 指引）。
   这是 T-170 有意的防呆（密钥 env-only 铁律），非缺陷。补 `--set config.oidc.existingSecret=binflow-oidc`
   后 grep 输出：
   ```yaml
   oidc:
     enabled: true
     issuer_url: "http://idp"
     client_id: "bf"
     redirect_url: ""
   ```
3. **真实 config.Load 回灌探针**（T-170/T-179 先例，跑完即删）：
   - 渲染落盘：oidc 全字段 + ldap 同启（baseDn 逗号需 `--set` 转义），`--show-only templates/configmap.yaml`
     抽出 data.binflow.yaml 块 → /tmp/t183/binflow.yaml；dataDir 指向临时可写目录（Load 会做写探针）。
   - 临时探针 `t183probe/main.go`（模块内，import 真实 `internal/config`，验后 rm -rf）调 `config.Load`：
     ```
     OK config.Load: strict decoder + validate passed; oidc.enabled=true issuer="http://idp.example.com"
     client="bf" redirect="http://binflow.example.com/..." ldap.enabled=true base_dn="dc=example,dc=com"
     ```
     strict decoder（KnownFields+rejectSecrets+单文档断言）放行，`OIDCConfig.Enabled=true`，LDAP 臂同样 enabled。
   - **负面对照**（删掉 `enabled: true` 行模拟补丁前渲染）：
     ```
     OK config.Load: strict decoder + validate passed; oidc.enabled=false … ldap.enabled=false
     FAIL: strict decoder passed but OIDCConfig.Enabled=false — the silent-disable defect
     ```
     完整复现缺陷链：enabled 键缺席 → 解码不报错、其余字段全解码 → Enabled 落默认 false。静默失效实锤。
4. 清理：`t183probe/` 与 `/tmp/t183` 已删；`git status` 净改动仅 configmap.yaml +1 行。
