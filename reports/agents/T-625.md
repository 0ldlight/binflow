## 三、族三：helm empty-index（裁定建议：BUG 对齐 A）+ 新发现

场景定义（按台账 surface 文义）：空仓 = 新建 helm local 仓、未推任何 chart；缺 index = chart 全删后的仓态。腿集（NS=difftest-t625-f3-）：空仓 GET/HEAD ×（alias /api/helm/<r>/index.yaml + 内容路径 <r>/index.yaml）×（GET×2 同轮 + HEAD）→ PUT 最小合法 chart → populated GET ×2 → DELETE chart → post-delete GET ×2。真实 helm CLI 腿（v4.2.4）：add/update/search/pull 全生命周期 ×2 轮 + populated-first 补充流 ×2 轮。

**A 形定形（双轮）**：「index 恒存在可为空」——空仓/删空后均 200 CT=text/plain，体 69B `apiVersion: v1\nentries: {}\ngenerated: <RFC3339Nano 未引号>\n`；头集=全 validator（Etag/三键/LM/AR）+ Cache-Control: no-store + CD + X-Artifactory-Filename=index.yaml；CD 形态随面：alias=单参 `attachment; filename="index.yaml"`，内容路径=双参（filename*=UTF-8''index.yaml）；同轮双 GET 逐字节同（生成后缓存，非逐请求再生）；chart 删除触发空 index 再生（新 generated 戳）。

**B 形定形（干净基线双轮）**：三态——空仓=404 text/plain; charset=utf-8 `'difftest-t625-f3-helm/index.yaml' not found`（45B）；populated=200 CT=text/yaml（B 自钉类型）317B（urls=相对文件名、ts 引号形、4/6 空格缩进）；**删空后=200 text/yaml 61B `entries: {}`（非 404）**——B 并无统一「无索引即 404」契约，never-populated 404 是存储节点生命周期缺口。

**真实 helm CLI 行为差（台账 review_gate 所问）**：空仓 `helm repo add`：A rc=0 → update/search 全绿；**B rc=1 `…is not a valid chart repository or cannot be reached: failed to fetch …/index.yaml : 404 Not Found`**（repo 无法注册，后续 update/search/pull 连锁全败；×2 轮 ×2 cycle 确定性）。populated-first 流：双端 add/search 均 rc=0。

**建议分类：BUG 对齐 A**（空仓 GET index.yaml → 200 空 index）。理由：①真实客户端证据——`helm repo add` 是客户端对新生仓的第一个操作，B 上确定性失败；②B 内部不一致——删空态已能渲染 200 空 entries index；③A 语义为 helm 生态惯例。范围注记：仅 local 仓类有证据，remote/virtual 面 NOT_RUN；对齐时空 index 体形建议逐字对 A（未引号 RFC3339Nano、entries: {}）。

**邻接新发现（独立记账候选，不入本裁定）**：①populated index 体形族——A `urls: local://demo-0.1.0.tgz`（未引号纳秒 ts、2/4 缩进、CT text/plain）vs B `urls: demo-0.1.0.tgz`（引号秒级 ts、4/6 缩进、CT text/yaml）；且 **A 自身 local:// 令 helm pull 报 `scheme "local" not supported`**（A 侧亦不可 pull），B 相对名 pull 亦失败但根因未隔离（双拼写 chart GET 均 200 已证）——该族对齐方向需独立评估（甚至 B 反向更客户端友好）②chart PUT 201 面：A ItemCreated JSON 704B（CT=vnd…ItemCreated+json;charset=UTF-8）vs B 裸 Location+CL:0 无 CT ③index 200 头集：A 全 validator+no-store+CD/Filename vs B 裸 CT/CL——T-608 头集族未延伸至 helm index 面（B serveNode 未接 SetDownloadDisposition）。
