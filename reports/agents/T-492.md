## 1. B-3.2 初始态形态（parity §12 B-3.2 翻正——M16 候裁挂起项收口）

**as-built**（web/src/pages/artifacts/ArtifactsBrowser.tsx，新增 effect + `hadSelectionRef`）：

- **触发**：跨仓根（URL 无仓段）+ 仓库清单 `status === 'ok'` + 本挂载周期从未有过选中
  （`hadSelectionRef`）→ 自动选中 `filteredRepos[0]`（当前 Sort-by 序第一行，默认名称序
  ——与树呈现序同源），右侧 item view（NodeDetail 仓库形态 + children 表）即刻呈现。
- **URL**：`navigate(buildTreeUrl(tab, first, []), { replace: true })`——replace 规范化，
  不占历史栈（回退回到进入前位置）；跨仓根页签段保留（/artifacts/properties →
  /artifacts/properties/<first>）。
- **边界/让位五条**（注释同款落档在代码内）：
  1. 空实例（0 仓）：不选——空实例引导卡（emptyInstance 分支）承载；
  2. 普通用户清单 403：不选（status ≠ ok）——L2 无权限卡承载，URL 原地；
  3. **用户接管让位**：过滤词 / 包型·rclass facet / My Favorites 任一在场 → 不选——
     过滤中的首行不是「实例首仓库」，且选中会连带清掉过滤词（跨仓复位语义）与用户
     意图相抵。该守卫同时消除了「清单在途时用户已敲过滤词、就绪后自动选中把词清掉」
     的竞态（console-fr82 过滤腿双向时序均安全，回归实证绿）；
  4. legacy 规范形重定向在途（目标 ≠ 当前路径）：先等重定向落定；同路径 ?focus= 残参
     （无承载面）不阻塞——选中导航顺带清掉；
  5. **回根让位**：曾选中过仓库后 SPA 内导航回跨仓根（侧栏「制品」再点）→ 不重复
     自动选中——根态（静态引导卡 + 工具带跨仓过滤语境）是用户主动回到的视图；
     全新挂载（登录落点 / 模块进入 / 模式切换）则正常自动选中。
- **首仓空内容**（「空仓」边界）：item view 照常 + children 表真实空态
  （tree-empty-dir）——不因自动选中伪造内容（e2e 腿 2 实证）。

**锚/断言面**：零新增锚（复用 tree-page / node-detail / tree-empty-dir /
tree-root-denied）；URL 即形态证据。既有落点断言翻新见 §5。

## 2. Users Last Login 列 + 列选器形态

**wire 消费**（web/src/pages/security/api.ts）：`UserListItem.lastLoggedIn?: string`
——T-454（FR-146.3）投影，RFC3339 UTC，**omitempty：从未登录整键缺席**（与
userDetail.lastLoggedIn 同拼写；pre-M16 消费方字节兼容超集）。

**列形态**（web/src/pages/security/UsersPage.tsx）：

- 列集 admin 视角七列闭集：用户名 | Email | 组 | 角色 | Status | **最近登录** | 操作
  ——新列插在 Status 之后、操作之前（对位 Artifactory 列序 Name/Email/Realm/Groups/
  Admin/Status/**Last Login**，reverse/console-ui.md §3.6）。
- 呈现：有值 = `YYYY-MM-DD HH:mm:ss`（截断到秒，mono，title = 原始 RFC3339 全值）；
  **缺席 = 「—（尚未登录）」**（text-muted——复用详情页同键，如实呈现「从未登录」，
  不伪造 Never 以外语义）。
- 排序：`UserSortKey += 'lastLogin'`——前端列头排序族（RFC3339 UTC 字典序 = 时间序；
  缺席 '' 沉首/沉底与 email 空值同口径）。服务端排序臂维持 T-454 登记的 out-of-scope。
- **列选器接入**（columnPrefs 共享层 T-387 形态，T-414 已备——本票把新列收进闭集）：
  COLUMNS 增 `{ id: 'lastLogin', label: 最近登录, anchor: users-columns-item-lastlogin }`；
  显隐与表头/单元格同步、per-page localStorage（binflow-console-cols-users）持久
  reload 保持、全选复位（存储回 []）——e2e 腿 6 实证 + t414 spec 计数翻新（6→7）。
- 新锚 2 枚：`users-columns-item-lastlogin` / `users-sort-lastlogin`（**锚册待回写——
  conductor 收口**）。
