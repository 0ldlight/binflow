## 3. 差异登记（需 architect/PM/conductor 过目）

1. **两字段落 canonical JSON，未走 remote_configs 扩列**（architecture §15.4 规划钩子字面是「remote_configs 扩列、003 同款」）。理由：布尔缺省 false=产品默认，JSON 无损；fetcher repoPolicy 本就读 canonical JSON（hardFail 先例）；零迁移面、存量行自动读「关」。§15.4.1 as-built 回写归 architect 触点。
2. **statisticsEnabled / sourceOrigin 接受+回显+落库但无行为**：BinFlow 无下载统计基座（`?stats` 为 E-09 未实现臂），入站统计上报协议无公开规格（replication.md 待验证清单）。按「低置信不擅自定行为」处理，AC1 的 K37 统计断言形态 = 默认 false + 不随复制传输（单测断言属性携带外无额外目标请求）。**待 stats 面立项后承接。**
3. **属性携带仅 generic 平面**（generic/maven）：docker/npm/pypi 协议面的目标节点经协议端面落盘，其属性语义归各适配器——协议面属性携带登记遗留。
4. **属性变更不触发再入队**（replication.md §4.1 properties-change 事件，中置信）：属性写路径不经 repo.Service（httpapi→metadata 直写），挂事件需新 httpapi seam + cmd 装配（cmd/main.go 与 T-319 共享文件风险）；收敛路径 = 幂等重传再推送（已测）。事件复制词表启用另立票更干净。
5. **K37 无需 ADR-0037**：子字段集锚 artifactory.xsd（inv-4 F5）+公开文档；统计语义锚 replication.md §2.2 默认 false。未超既有锚点，不新增 ADR（PRD「如需」条件未触发）。
