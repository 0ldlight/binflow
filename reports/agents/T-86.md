## 关键裁决

### ADR-0014 console 包基线

1. **挂载**：SPA 挂 `/binflow/console/**` **保留段**（与 `/binflow/docs` 同模式；`/binflow/` 根 302 → console）；repo key 保留字 {api,v2} → {api,v2,docs,console}。否决「SPA 占 /binflow/ 根」——SPA fallback 与内容路径空间互相侵蚀。
2. **认证 = server-side session**（vs JWT：登出/吊销需黑名单即回到服务端状态 + localStorage XSS 面；vs 复用 API token：永久性与会话语义错配）：004 新表 `web_sessions`（sha256 摘要存储，与 tokens 同规）、Cookie `bf_session`（HttpOnly/Secure/SameSite=Lax/Path=/binflow）、绝对 TTL 12h + 滑动续期、登出 revoke。`auth.Authenticator` 第三臂。**CSRF 三层**：SameSite + 前端自定义头 `X-BinFlow-Console: 1` + 服务端强制（Cookie 认证的变更请求无该头 → 403）。
3. **SPA/REST 边界 = 无 console 专属 API 树**：前端直接消费通用 `/api/v1/**`（CLI/curl/前端同面，权限单源）——不采纳 OSS web/rest-ui 的专属后端模式（那是 UI/后端版本解耦的历史结构）。
4. **构建链 = vite + React + TS**（与 Docusaurus 同栈）；**ADR-0005 边界澄清：白名单管辖 Go 依赖树，前端 devDependencies 属构建期不进二进制**——放宽但守 lockfile 锁定 / 零运行时 CDN（断网可用）/ CI npm audit / 直接依赖变更过 architect 四条。

### ADR-0015 治理面基线

1. **GC 在线触发**：`POST /api/v1/system/gc`（默认 dry_run；apply 需 `{"dry_run":false,"confirm":true}` 双字段）+ 状态查询 + 进程内互斥（409）；admin-only + 审计 + **grace 不变**（在线触发不是紧急删除通道）；定时 GC 不做（M5+ 留缝）。
2. **配额 = repo_usage 计数器**：配额值在 repositories.config JSON（quota_bytes）；计数行与 node 增删同事务；enforcement 在 `repo.Service.Put` 全族（已知 size 预检 / 流式落盘后判——超限回滚登记 blob 留 GC）；**口径 = 逻辑字节**（物理占用走既有 stats 面）。
3. **备份顺序硬规则：先 DB 快照（VACUUM INTO）后 blobs tar（保 mtime）**——多余 blob 无害、反向悬空引用不可接受；import 仅空实例 + 仅 CLI（高危写面不走 REST）+ 幂等。
4. **export 双入口**：CLI `binflow-server export` + admin REST 异步；import 仅 CLI。
