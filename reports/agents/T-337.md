**重复臂（§5.1，T-334 §4-4 消费点）**：已存在且无 d 权限 → **409 `Package already exist: <deployPath>`**；有 d 权限 → 覆盖 201；同字节 → 幂等 201；remote/未路由 virtual → 400 `This operation can only be performed on local repositories.`。实现路径：预探测存在性 + 以实测 sha256 为声明摘要走 svc.Put 的权限对（同字节幂等 / 异字节需 d）——409 映射只在「已证实存在」时成立。**未向 cargo 形态看齐**（T-334 §4-4 警示遵守）。

**鉴权两道门（§3）**：401→403 门序由 httpapi dispatchContent 的共享中间件链承担（GET/HEAD=read 门、写动词=required+write/delete 门，`WWW-Authenticate: Basic realm="BinFlow Realm"`）——spec §3 自己的「BinFlow 实现建议：与 BinFlow 匿名读策略合并表达」；适配器不再自建门。已由 noAnonymous 栈测试固化（401 challenge / 授权 200 / 无授权 403）。

**三级路径解析（§6）BinFlow 等价链**：canonical flatcontainer 目录（「默认扁平路径」级）∪ 全仓 listing 按文件名身份 `<id>.<version>.nupkg`（「属性索引」级——从最左 `.` 起取最长合法版本尾，`pfx.pkg.2.0.0` 判为 (pfx.pkg, 2.0.0)）。**并集语义**（canonical 命中不再短路——live 矩阵发现的 bug，见 §3）。

**remote 代理（§7.1）**：上游 URL = `<repo.url>/api/v2/<资源拼写>?<verbatim 查询串>`（feedContextPath 取 xsd 默认 `api/v2`，不新增配置键）；响应经 `.nuget-v2/<hex>.xml` marker 落缓存（cargo search-marker 同款可逆编码，引擎 TTL/负缓存/stale 全链生效），解析后经本包渲染器重锚（下载链接 → 本仓 v2 Download 面）；上游异常 → 回落落地事实（离线臂）；`$count` 非数字体 → **-1 哨兵**。

**virtual 九步（§7.2）**：两桶顺序成员解析→fan-out（local=深层事实链，remote=marker 代理）→$select 全程重置→GetUpdates 无 $orderby 按 Version 排（注入等价）→**跨桶 id 级去重**（桶内版本级）→链接重锚本 virtual Download→id 小写升序+版本升序→IsLatest legacy 聚合（过滤后可见集上重算）→pattern 终滤降级（BinFlow virtual 无 include/exclude——差异登记）。

## 5. 差异登记（BinFlow 侧有意/受限偏离）

1. **401/403 门载体**：共享中间件（JSON 信封）而非 Artifactory 的纯文本+`realm="Artifactory Realm"`——realm 用 BinFlow 全局值，body 信封是 BinFlow 全局面。状态码与门序一致。
2. **计数端 content-type**：规格（DE）`text/plain;charset=utf-8`（照实现）；nuget.org 活体为 `application/xml`——取规格（Artifactory 对齐）。
3. **root publish 落点**：Artifactory 落 `<id>.<version>.nupkg`（仓根扁平）；BinFlow 落 canonical flatcontainer 三件套（§6 推论明文许可，M10 v2/v3 同存储契约），201 文案中的 path 随之。`#18` 前缀形仍按规格字面落 `<前缀>/<id>.<version>.nupkg`。
4. **virtual include/exclude 终滤（§7.2-9）**：BinFlow virtual 无该配置面 → no-op。
5. **离线回落臂（§7.1-1）**：`svc.List` 仅支持 local 仓——remote 仓「从未缓存过搜索响应且上游故障」时无法枚举落地包 → 404（引擎 stale 副本照常服务上次成功响应，已由 marker 缓存断言覆盖）。
6. **virtual DELETE 路由（§5.2）**：svc.Delete 全局拒 virtual（RE-08）；适配器显式路由到 defaultDeploymentRepo（成员上评估 d 权限，语义等价 Artifactory）；仅对 virtual 自身的授权不延伸到成员的 BinFlow 授权模型细微差异存在。
7. **M10 两处断言翻转（spec 承载，非回归）**：FindPackagesById 缺 id 400→**404**（§2 #5）；feed content-type application/xml→**application/atom+xml**（§2 #3/#5 + nuget.org 实抓）。
8. **`Packages(Id='x')/Id` 投影体**：取 OData 属性元素形（`<d:Id m:type="Edm.String">`）——DE 未给字面 body，属实现裁量（中置信，测试固化）。
