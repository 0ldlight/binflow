## 修复

**服务端**（`internal/repo/service.go`，Artifactory parity——rest-api.md §3 的 remote-cache FileInfo/FolderInfo 证据）：
1. `List`：remote 仓列**缓存**（pull-through 落地即普通 node 行；`remote_cache` 只存校验元数据）——列表面**永不回源**；virtual 拒绝维持（FR-21-AC8 P2）。
2. `Get` remote 臂 folder 面：缓存 marker 行直答 `ErrIsFolder`；**读侧材料化**（复用 `putFolderRow`）——fetcher 落地只写文件行不材料化祖先（fetcher.go:831），pre-T-406 存量缓存由此治愈；childless folder 探测 = 诚实 404，零上游往返。

**Console**（`ArtifactsBrowser.tsx`）：
1. virtual：内容面不发注定 400 的调用（D-396-1 同款 gate）→ `tree-empty-virtual` 成员感知空态（成员读自 `configuration.repositories`）；RepoBranch virtual 静态化（twisty 占位、无子级区——消除「选中即骨架屏」次生问题）。
2. remote 空态文案分支：「远程仓库：仅展示已缓存的制品（浏览不回源）」。

**锚册**：console-ux.md v1.26——`tree-empty-virtual` 入册 + remote 空态文案分支留痕。
