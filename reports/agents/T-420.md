## 3. 票内裁决与规格置信度

1. **enabled:false → 409（中置信，规格锚缺位推导）**：§9.2-A 错误表无「停用配置触发」逐字锚（executeall 的对位形态是 200 warn「No active push replications are configured forthis repo.」——但那是**仓级全量面**的「无启用配置」态，非逐配置触发面）。取 409 的推理：停用位的任务行 drain 永不认领（engine.drain/Enqueue 双处 !Enabled skip，T-405 已钉），排程即制造死行 = **资源状态与动作冲突**，族内 409 先例 = POST create 的名称冲突；400 会被误读为请求畸形。测试钉死（`TestReplicationsRunDisabledFlip` 全翻转链 + `TestTriggerFullSyncRefusals` 引擎哨兵）。若 QA/规格复核判 400 或 warn-200，翻转点在 handler 一个 case + 测试两处。
2. **重复触发 → 200 再种（照锚，中置信）**：AC「在途重复触发幂等（200/409 照锚）」按 §9.2-A-7 落 200-不去重；「在途」确定性用 parked PUT 目标钉死（`TestTriggerRepeatWhileInFlight`：worker 悬在首趟 push 内，第二次 trigger 照样 200+追加，收敛后 6 行全 success）。
3. **200 响应体**：官方 A 面无体定义（§9.1），UI 面 info 串中高置信——BinFlow 族形态带锚定 info + 结构化计数，供 FE toast 与 capped 提示（§9.3 留的「族惯例 envelope——T-420 定形」即此：**对象体 + errors[] 错误族**，T-422 Test 端点沿此定形）。
4. **审计词入册**：`replication.run` emit site 为 httpapi 字面量（族先例，测试钉住）；**internal/audit 常量块登记归 §9.4 批次（T-422 腿 + audit owner）**——internal/audit 非本票 area，未越界。
