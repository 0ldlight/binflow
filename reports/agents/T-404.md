## 0. 票内定案（规格留痕——勘误条款的落地裁定）

1. **R1 形态**：复制配置 = 仓库编辑页 `form-section-replications` **内嵌节**（T-383 `form-section-*` 族第七名，Paper 分区照仓编辑页既有节形态；无 modal/drawer——R9）。条件呈现 = **编辑态 × local**（push 源是本仓；建仓态仓不存在，POST 的 source_repo 前置校验必 400，不提供假入口）。Artifactory 的 387px 步条是其整页表单的分步形态，BinFlow 仓编辑页为单页分区制（T-240 定案、T-383 锚定）——照 conductor「照仓编辑页既有节形态」执行，不引入步条重构。
2. **字段族两档（R3 双源勘误）**：
   - BinFlow 实字段（全量进 payload）：name / source_repo（锁定=本仓）/ target_url / target_repo / target_username / target_password（只写）/ max_bandwidth_bytes_per_sec / max_items_per_push（BinFlow 超集，Artifactory 无——保留呈现）/ enabled。
   - Artifactory 六字段 = **预留位组**（`repl-form-reserved`）：cronExp / enableEventReplication / pathPrefix / syncDeletes / syncProperties / syncStatistics——控件**恒禁用**、hint 如实标注（cron：引擎事件驱动 + ≤1min sweep，R4 勘误——无用户级 cron；event：语义恒真；其余：引擎尚不支持）、**绝不进 payload**（spec 网络层对账：POST body 键集 = wire 闭集）。不伪造语义。
3. **编辑语义**：REST 无字段级 PUT（T-405 仅启停）→ 编辑保存 = **删除 + 重建**（DELETE+POST；与 repo 编辑「全量替换」同为能跑通的唯一路径）。后果如实呈现：`repl-recreate-note` 明示「未决任务级联清空 + 配置 id 变化 + 原密码不回显需重输（留空=匿名目标）」；重建失败（旧已删新未建）时表单保持打开并明示状态。

5. **R5 列/Run 映射**：仓列表 local Tab 增 `Replications` 列（列选项第 8 名，端点背书）。0 条 = 纯文本「0」（OSS 未启用分支同款 cell）；≥1 条 = 行级 **Run 动作**（▶ glyph IconButton + Tooltip 携条数/启用数）。R5 的 executeReplicationNow 在 BinFlow **无对位端点**（parity §7「后端 trigger 前置项，不挂 FE parity 旗」）——tooltip 如实标注事件驱动语义，点击 = 深链本仓编辑节（`?section=replications` scrollIntoView + data-active），不伪造触发。全局封锁三态中的 blocked 态不适用（R8 无 blockPush——如实省略）。

## 5. 契约漂移

- **PUT /v1/replications/{id}（T-405 在飞，形状假定）**：票面写「PUT /api/replications/{id}」——实际挂载面为 **/binflow/api/v1/replications/{id}**（v1 段；派单文案缺段，非漂移仅注记）。body 按 `{enabled: bool}`、响应按「更新后的配置行（POST 同形）」假定——T-405 落地后若形状不同（如 204 无体 / 按 name 寻址），`lib/replications.ts` 的 `putReplicationEnabled` 是唯一改动点；**联合腿归 conductor 合并后验证**（本票 spec 的 mock 200 腿即按此假定钉死成功路径，真栈分流腿合并前后皆绿）。
- **GET /api/v1/replications 无 per-repo 过滤参数**（全量清单）——仓级两消费面（编辑节/详情 Tab/列表列）客户端按 source_repo 过滤，操作员规模配置集无分页需求；契约文档（architecture §API）如补 `?source_repo=` 可换服务端过滤，非本票阻塞。
- POST 实测回 **201 + 创建后的配置行**（凭据密码无字段）——与 replication.go 注释一致，无漂移。
- R3/R4/R5/R6/R8 的引擎语义缺口（cron/事件开关/路径前缀/sync 三开关/手动 trigger/Test/全局封锁）——非漂移，规格在案的 BinFlow 语义边界（parity §7 矩阵「后端语义前置项」），本票以预留位/如实标注/deep-link 承载，未伪造。
