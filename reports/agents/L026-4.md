## 证据链（不猜测——#121/#122/#123 三 run 日志原文）

- **e2e job 无门控坐实**（本票对象）：ci.yml 改前 `on: push: branches:[main]` 且 e2e job 无 if——每次 main push 必跑。#123（35167497036，head 09d4f56a，PR #123 merge）e2e job 00:40:21→01:25:23 结论 **cancelled**（`timeout-minutes: 45` 顶死在 Playwright 步，日志尾 `##[error]The operation was canceled.`），最后失败腿 `e2e/m14/t383-newrepo-parity.spec.ts:202`——正是 L025-2 **A 桶**清单成员。#121/#122 同因（ci.yml 未变过）。
- **Test 步红两族分流**：#123 的 `TestRestByHashConfigDrivesIndexEngine / TestRestCompressionAndArchConfigDrivesIndexEngine / TestRestPolicyKeysDriveReindexBranches` 归属 `internal/adapter/deb/t327r_policy_test.go` 与 `internal/adapter/rpm/t327r_policy_test.go`（grep 定位）——**L026-3 域，本票零触碰**；metadata 族见下。
- **metadata 预算腿=三连红唯一/主导腿**：#121（94a24ae1）与 #122（6d2dc41b）全 run 日志里**唯一**失败测试即 `TestRBACMigration011HundredUsersUnderOneSecond`：1.759128373s / 1.770659619s（包时长 396.831s / 393.258s）；#123 同腿 1.438298439s（包 369.101s）。共居样本簇 1.44–1.77s，稳定越 1s 界——**确定性共居翻越，非尾部 flake**。
- **降速因子**（L025-2 + 既有 ci.yml 注释）：包级共居 2.2–2.9x（166.8s 隔离 vs 369–477s 共居）；runner host-steal ~1.35x（httpapi 独跑 772s on-runner vs 571s idle metal，run 33881407081）。→ 隔离估值 = 1.44–1.77s ÷ 2.2 ≈ 0.6–0.8s，×steal 尾部 ~1.1s——2s 界给 1.8–3.3x 余量，1s 界在共居下无解。
- **该腿是负载计**（决定纯 pad 不够）：本机 2026-09-17 09:51 load 14.3 下，`-race -count=3` 单腿隔离跑 2.79/3.56/4.84s 三连红——fsync+迁移的 wall-clock 在忙主机无界。故终方案=**拆独占串行段（治共居根因）+ pad 2s（吸收 runner 残余 steal）**双层，任一单独都不稳：纯 pad 3s 也压不住忙机（4.8s 实测）、纯拆段 1s 界只剩 ~1.1-1.7x 余量。

## 改动明细

### 1. ci.yml（e2e 门控——对齐 CircleCI 姿态）

- `on:` 增 `workflow_dispatch` + `run_e2e` boolean 输入（默认 false）：自动触发面不变（push-only 指令原样），dispatch 永不在 push 上触发；protocol-matrix.yml 已有同款 dispatch 面（先例）。
- e2e job：`if: github.event_name == 'workflow_dispatch' && inputs.run_e2e == true`；注释块写明重开条件（L026-2 绿 + A25+B8+C18 清零 + conductor 确认 → **删 if 行**即回 always-on；同刻 CircleCI 面翻 run_e2e 默认 true——其 parameters 注释同口径）。
- ci / release-dryrun job：`if: github.event_name == 'push'`——dispatch 跑 e2e 时不再重烧 40 分钟套件。

### 2. Makefile（test 配方——预算腿不再共居测量）

```make
BUDGET_PKGS := github.com/lzwzzy/binflow/internal/metadata
BUDGET_HERE := $(filter $(BUDGET_PKGS),$(PKG))
REST_PKGS   := $(filter-out $(BUDGET_PKGS),$(PKG))

test:
	$(if $(BUDGET_HERE),CGO_ENABLED=1 $(GO) test -race -count=1 -timeout $(TEST_TIMEOUT) $(BUDGET_HERE),@echo "...")
	$(if $(REST_PKGS),CGO_ENABLED=1 $(GO) test -race -count=1 -timeout $(TEST_TIMEOUT) $(REST_PKGS),@echo "...")
```

本地=CI 单一口径保持（同一 make test）；test-cov 不拆（覆盖 profile 跨调用合并无谓复杂化——非闸门面，登记于此）。

### 3. t212（pad 1s→2s）

AC 语义不动（"idle metal 上远低于一秒"仍是规格）；断言界按共居现实放宽一档，证据全链写进测试头注释（三 run 数据 + 降速因子 + 忙机协议）。
