# T-128: [P0] FR-44 BE: putNode 祖先 folder 行材料化 + 007 回填迁移 (ADR-0016)

**状态**: done

**角色**: dev-go-core（双 reviewer 票，标记待双 review）

## 做的什么

实现了 ADR-0016 的目录材料化不变式：putNode 在写入目标节点前，通过 `materializeAncestors` 确保每个祖先目录都存在对应的 folder 行，并写入 007 SQLite 回填迁移用于数据库升级。

### AC1 — putNode 中的 materializeAncestors

- 新增 `materializeAncestors(ctx, p, repoKey, path)` 方法，遍历 `ancestorDirs(path)` 并调用 `putFolderRow` 为每个祖先目录写入 folder 行
- `putFolderRow` 实现了幂等写入：
  - 若已有 folder 行且 sha256 为 `emptyFolderSHA`，执行幂等刷新（更新 mime/updated_at）
  - 若不存在，先调用 `ensureFolderLedger`（写入哨兵 blob 行），然后插入 folder 行
  - 若已有文件节点（非 folder），按现有逻辑走（不做覆盖）
- `ensureFolderLedger` 写入 `sha256=64×'0', size=0` 的哨兵 blob 行，满足 FK 约束
- `ancestorDirs`（validate.go）枚举祖先路径，最外层优先，不包括自身
- `putNode`（~735 行）现在在写入目标前先调用 `materializeAncestors`，无权限检查、无治理、无审计、usage=0

### AC2 — 007 回填迁移

- `internal/metadata/migrations/sqlite/007_folder_rows_backfill.sql`
- 两步：
  1. `INSERT OR IGNORE` 哨兵 blob 行（FK 前置，由 EXISTS guard 保护）
  2. 递归 CTE 遍历节点路径，`INSERT OR IGNORE` 祖先文件夹节点行
- 幂等、确定性（created_at 取 MAX of descendant created_at）
