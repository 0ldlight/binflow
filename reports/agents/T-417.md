## 0. 设计定案（先读这段）

**数据路径沿 architecture §24.6 的字面**：「老搜索三端点消费 match.go 内核 +
`search.ResultCap` 截断常量与截断头（形态同源单点）；数据路径维持 repo.Service
既有搜索方法（T-92 面零迁移）」——三端点不走 AQL 引擎（引擎行 `NodeQueryRow`
无 mime 列，E-09 FileInfo 复用会缺字段；且文本合成 AQL 有注入面），而是沿 T-92
的用例形态扩展：

```
httpapi(search_legacy.go) ──search.LikePattern() 单次翻译──► repo.LegacySearchService
   │  (consumer-side 断言，copyMoveRunner 先例)                  │ T-92 同款：校验→searchGate→
   │  cap = search.ResultCap+1 由端点单点传入                     │ NodeSearcher→filterVisible
   └─截断：len>cap → X-BinFlow-Search-Truncated                   ▼
                                                     metadata.NodeSearcher +3 方法（SQL 侧）
```

- **area 跨越留痕**：票面 area 为 internal/httpapi，但数据路径的架构裁定要求
  repo/metadata 两层各有增量。落地方式取零 fake blast radius 姿态：
  - `repo.LegacySearchService` 是 **CopyMoveService 式 capability face**（operations.go
    注释原文先例：「deliberately NOT part of the big Service interface」），大 Service
    接口零改动 → 全树 fake 零破坏（`go vet ./...` 全树绿已验证）；
  - `metadata.NodeSearcher` 接口 +3 方法（该缝全树仅 nodeStore 一个实现者，grep
    核过：repo/search_test 的 fake 只实现 NodeStore 面）；
  - httpapi 侧 consumer-side `legacySearcher` 断言（copyMoveRunner/archiveFamilyRunner
    同款）。Deps 零改动——T-415 姿态效仿达成。
- **K63 上限单点**：`search.ResultCap` 常量在 internal/search（该包 import repo，
  repo 无法反向 import）→ 由 **httpapi 端点**取 `ResultCap+1` 作 limit 入参下传，
  SQL LIMIT 截断，端点读「多一行」置 `search.TruncatedHeader`——与 AQL 同一常量、
  同一截断头，两平面不可能漂移（engine.go ResultCap 注释本就预告此共享）。
- **匹配内核单点**：pattern 端点在 httpapi 调 `search.LikePattern()`（repo 不能
  import search——cycle；aqlquery.go 的 IR `QueryLike` 本就以「已翻译模式」为通货，
  先例一致）。

## 3. K65 余量条款判定（票内留痕——不顺车，M16 登记）

**判定：dates/creation 不顺车，登记 M16。** 理由：
- T-407 判「trivial」针对的是**数据腿**（created_at 单列区间直查）——成立；
- 但 wire 腿不 trivial：属**另一空集族**（未命中 404 `No results found.`，aql.md
  §0-4/§8.2 v8l/v8n/v8o）+ **第三种行形态**（瘦行 uri+created/usage 统计字段，非
  E-09 FileInfo）+ epoch 毫秒参数解析/时区归一——与本票三端点的 envelope/空集族
  全不同构，塞进本票只会做成半吊子；
- 本票实际余量已被三端点 × 三层缝 + K64 翻转 + 两处断言反转 + 全树 vet 占满。
- M16 登记项：`GET /api/search/creation?from=&to=`（to 缺省 now）+
  `GET /api/search/dates?from=&to=&dateFields=`，404 空集族 + 瘦行 envelope +
  epoch-ms 解析；`usage` 本就 dep stats 基建维持 M16（aql.md §9 K65 行）。
