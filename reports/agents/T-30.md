## 关键裁决（ADR-0010，新增，不推翻 ADR-0008 而是例外化）

### 1. /v2 前缀冲突：选 a) 根级例外

- 三案评估：a) 根级例外（httpapi 为 `/v2/**` 开不剥前缀的路由特例）；b) 反代 rewrite（裸部署 docker 不可用——违背单二进制核心场景，出局）；c) 双挂载（`/v2` + `/binflow/v2` 双份 Location/Www-Authenticate/catalog 分页生成与双份 QA 面，纯成本，出局）。
- 裁决 a：`/v2/**` 与 `/healthz` 同属「客户端协议硬编码豁免类」，进同一 middleware 链（logging/recover/auth）但不剥 `/binflow` 前缀；repo key 保留字 `v2` 维持；`/binflow/v2` 不提供。ADR-0008 的「统一前缀」表述由本 ADR 修订为「统一前缀 + /v2 协议例外」。
- **决定性附带收益**：token 端点 `/v2/token`（自有，非 RFC 标准）realm 指向自身路径，`Www-Authenticate` 头无需重写——b 案在 rewrite 下必须重写该头，是隐藏的复杂度炸弹。

### 2. token 认证流：复用 TokenRegistry，不平行一套

- 流：匿名 `/v2/` → 401 + `Www-Authenticate: Bearer realm=<base_url>/v2/token,service=binflow` → Basic 凭据 GET realm（service/scope 参数）→ `{"token","expires_in"}`（附 access_token 同值兼容）→ Bearer 后续请求。
- docker token = 有限 TTL 的 BinFlow token + scope 声明；scope 映射：`pull`→`r`、`push`→`w`、manifest DELETE→`d`；scope subject 首段交 Authorizer 的 repoKey、余段并入 path。无 Bearer 时回退 Basic/匿名（与 §7.1 分层一致）。
