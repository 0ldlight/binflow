## 0. 两勘误定案留痕（AC1 二选一落笔）

### 勘误①（断言反转①——T-445 漂移登记①清偿）：`GET /api/repositories` 的 `.url` 补 `/binflow` 前缀

- **规格锚**：docs/reverse/rest-api.md §2（高置信）：列表条目 `url` = `<contextUrl>/<key>`；§0/§1.2 的 contextUrl 定义含 context path（Artifactory 例 `/artifactory`）——BinFlow 的 context = `/binflow`（ADR-0008）。M1 as-built 漏了前缀段（T-445 漂移登记①、T-466 §5 复核维持登记）。
- **实现**：`repoListItemOf`（列表）与 `repoConfigOf`（单仓 GET 回显）统一走新增的 `contextURL(r)` = `requestBase(r) + prefix`——与 `storageURI`/`downloadURI` 同族的唯一定义点（G33a 家族纪律）。
- **curl 验收**（L57 第一臂，real curl）：`curl -u admin:… "$BASE/api/repositories"` → `"url": "http://127.0.0.1:PORT/binflow/generic-local"`（curl_compat_test.go C05 断言钉死）。

### 勘误②（LC-107 票内二选一）：**定案 = ①下载语义 URI 归位**（不取「语义注记终裁」）

- **规格锚对拍**（rest-api.md §3）：§3 的 FileInfo 字段表将 `uri` 与 `downloadUri` 列为**两个独立字段**（若是同值冗余不会分列）；对拍组内双证——
  1. **官方 REST 文档语义**（FileInfo 示例）：`uri` = `…/api/storage/<repo>/<path>`（元数据视图），`downloadUri` = `…/<repo>/<path>`（直取下载地址）；
  2. **仓内 as-built 佐证**：generic/maven 适配器的上传 201 FileInfo 体（rest-api.md §1.2）一直说直取形（`internal/adapter/generic/iteminfo.go:64`、`internal/adapter/maven/put.go:421`）——同产品两 face 语义应当一致；
  3. 反向佐证：aql.md §9（buildArtifacts 搜索）以 `downloadUri` 为**唯一**键承载下载语义——键名即语义。
- **实现**：`storage.go` 新增 `downloadURI(base, repo, path)` = `<base>/binflow/<repo>/<path>`；`fileInfoOf` 的 `DownloadURI` 改走它（uri 维持 api/storage 形）——E-09 FileInfo 体与搜索 envelope 共享该定义，一次翻转全家对齐。
- **有意不动的面**：FolderInfo 维持无 `downloadUri` 的 as-built（官方 folder 示例同形）；`?permissions`/`?stats` 视图 uri 维持 api/storage 形（无 downloadUri 字段）。
- **越界登记（area 纪律）**：适配器上传 201 体的 `uri`/`downloadUri`/`Location` 头用 `requestBase` 直拼（**缺 /binflow 前缀**，且 uri 也是直取形）——internal/adapter 非 T-493 area，已登记遗留（§5）。

## 1. System Logs 进程日志端点真身（AC2 / 断言反转②——T-459 契约漂移解除）

### 1.1 端点形态（照既有 router 惯例）

```
GET /api/v1/system/logs?limit=N&filter=substr&download=1     （system:read 门）
```

- **形态裁**：BinFlow-native C 层拼写（v1 系统面家族——settings/schedules/backups 先例），不走 Artifactory 的 `/api/system/logs`（A 层别名）：其 live-logs 真身是中置信的**内部 UI 面**（inv-1-core.md「Live Logs」`system/logs/config|data` + `ui/.../systemlogs/v1/system/logs`），且 logger-levels 与 tail 是两个不同问题；别名挂载与带①（T-504）的行 17/18 同族候裁。rest-compat-matrix D06 行 13 已翻 ◐ 留痕。
- **三能力**：
  - **尾随** `?limit=`（1..1000，缺省 200——audit 族 limit 惯例；越界 400）：环形缓冲**匹配流**的最后 N 行，oldest→newest；
  - **过滤** `?filter=`：服务端大小写敏感**纯子串**（`strings.Contains`，无 regex——零病态输入面），≤256 字符（超长 400）；过滤先于窗口裁剪（尾随的是匹配流的尾部）；
  - **下载** `?download=1`：同一窗口 text/plain + `Content-Disposition: attachment; filename="binflow-service.log"` + nosniff——下载的即所见窗口。
- **响应体**（JSON 臂）：`{"lines":[…], "count":n, "held":m, "capacity":4096, "truncated":bool, "generatedAt":ISO}`——`held`/`truncated` 让查看器能如实区分「窗口」与「全史」（环驱逐过旧行时 truncated=true）。

### 1.2 进程日志来源与读面安全边界（票内核定）

- **来源定案**：**进程内环形缓冲**（stdout/文件二选一中的等价第三条路）：BinFlow 按 12-factor 写 stderr（cmd `newLogger`——默认无日志文件），文件读面无源可读；环从装配好的 logger 取流。`internal/console/logtail.go`：`LogRing`——4096 行 × 单行 4096B 硬上限（最坏 16MiB、常态 ~1MiB）、逐行截断带标记、部分行跨 Write 缓冲、RWMutex。
- **接线**（qrl/aql 自装配先例——cmd 的 Deps 布线零改动）：`httpapi.New` 内 `assembleServiceLog` 把传入 logger 包进 `serviceLogFanout`（slog.Handler 扇出：原目的地 + 喂环的 TextHandler 视图——环内渲染为**稳定 text 形**，不随 logging.format 切换）；`Deps.ServiceLog` seam 允许测试注入/未来 cmd 侧扩面。
- **边界留痕**：环覆盖**装配之后**的服务运行时流（每条 access 行 + 全部 handler 日志）；cmd 侧装配前的 boot 行只进 stderr（cmd 侧 wiring 可后续扩，非本票 area）。
- **安全边界**：
  - 门 = **CapSystemRead**（audit 读同门——readonly_admin 可读、普通 user 403、匿名 401 + Basic 挑战；t215 守卫计数 75→76 随表更新）；
  - 环内容 = 进程 logger 的镜像——access 行只记 method/path/status/actor/duration，auth 面只记失败原因，**永不落凭据**；
  - 参数界：limit 1..1000、filter ≤256 字符、无 regex；
  - E-26 家族姿态：POST/PUT/DELETE 与任意子路径 → not-implemented 404。

## 2. `?properties` 分号矩阵语法注记（AC2 后半——wire 行为不变断言）

- **断言钉死**（`TestStoragePropertiesRESTSemicolonIsContent`，properties_test.go）：
  1. `%3B`（编码分号）在值内 = **值内容**：PUT `?properties=k=v1%3Bv2` → 204，读回 `{k:["v1;v2"]}` 单值逐字；
  2. 对照臂：**逗号**才是 REST 配对分隔——`k=a,b` → 两值；
  3. 混合：`k=v1%3Bv2,k2=x` → `{k:["v1;v2"], k2:["x"]}`——k2 由逗号而生，分号永不生键；
  4. **raw 分号臂（as-built 钉死）**：raw `;` 使整对从 net/url 的 query 解析中脱落（Go 拒 `;` 作分隔符）——GET 落 plain item 体（200，非 properties 视图），PUT/DELETE 落家族未知拼写 E-26 404。分号在任何拼写下都不构成配对分隔。
- 代码面注记同步落 properties.go 文件头（T-447 契约注记 + T-493 wire 定案）；**文档面归 T-518**（wire 零变化——本票未动 properties.go 任何解析逻辑）。
