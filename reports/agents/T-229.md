## 权威契约

- ADR-0028（DECISIONS.md，Accepted）：`Engine.Close` **保留**未过期上传会话（`upload_sessions` 行 + `uploads/<id>/` 数据文件），不删除、不做过期清理；**sweep + TTL 是唯一回收路径**；Close 打一条保留清单 INFO（计数 + id 清单，截断）。

## 可靠性故障场景覆盖

- 并发：`-race` 全绿三包；Close 与 BeginSession 竞态分支（e.mu 下 double-check）保留；`logPreservedSessions` 在锁外调用。
- 中断/停机三径对称：SIGTERM 探针绿 + kill -9 探针绿 + 单测 `TestClosePreservesUnexpiredSessions`（干净 Close → 重开 resume → 续传 Commit 摘要正确）。
- 校验失败：既有 `TestCommitChecksumMismatchRejected` 等不受影响（本票未触 Commit 协议）；续传后摘要逐位验证在探针 + `TestClosePreservesUnexpiredSessions` 双钉。
- GC/回收：sweep+TTL 唯一回收路径由 `TestClosePreservesThenSweepReclaimsAfterTTL`、`TestCloseRefusesNewSessionsAndPreserves`（nil-store 孤儿臂）、`TestPoisonedSessionOnEngineClose`、httpapi `TestV2BlobSessionSweepResidue`（过期行+目录 sweep 回收）四路钉死；GC CLI 路径（main.go:1083）带 Sessions seam，不会误删保留目录。
- 资源泄漏：detach 关 fd、句柄终结（复用后 Append/Commit 干净报错、Abort 无害）。
