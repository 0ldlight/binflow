## 一、做了什么

实现 `internal/config`：`Load(path)` 读 YAML → `BINFLOW_` 前缀环境变量覆盖 → 默认值填充 → fail-fast 校验，产出不可变 `Config` 值树。解析用 `go.yaml.in/yaml/v3 v3.0.5`（ADR-0005 白名单，gopkg.in 已归档禁用）。

设计要点：

1. **YAML strict 解析**：`KnownFields(true)` 拒绝未知键（顶层与嵌套均报错，错误含行号与字段名）；非 mapping 文档、tab、未闭合引号、重复键均报错。raw 结构体全字段用指针，区分「未给（走默认）」与「显式给 false/0」。
2. **双键等价匿名读**（R3 冲突的兜底实现）：`security.anonymous_access`（PRD 主键）≡ `auth.anonymous_read`（架构 §8 别名）；单独给任一键生效，两键同给且一致生效，**不一致 → 启动报错**（错误信息点名两键并建议只留主键）。
3. **env 覆盖**：`BINFLOW_` 前缀 + `__` 表层级（如 `BINFLOW_METADATA__DRIVER=postgres`），变量名大小写不敏感，枚举值归一化小写。已知例外：
   - `BINFLOW_ADMIN_PASSWORD`：秘密只走 env（ADR-0009），Load 填入 `Config.AdminPassword`；YAML 里出现 `admin_password`/`password`/`master_key` 等秘密形状键（顶层或 security/auth 内）→ 报错并指向该 env 变量。
   - `BINFLOW_SECURITY_ANONYMOUS_ACCESS`：主键的无 `__` 拼写（PRD C27 原文），`BINFLOW_AUTH__ANONYMOUS_READ` 别名同样可用。
   - `BINFLOW_HOME`：忽略（cmd/T-16 的保留名，避免本票误报未知变量）。
   - **未知 `BINFLOW_` 变量报错**（防拼写静默失效），错误列出全部未知变量并给命名规则示例；列表值（`server.cors_origins`）env 不可覆盖，尝试即报错。
4. **fail-fast 校验**（`Validate()`，纯值检查在前、文件系统探测放最后，避免校验失败还留下目录）：
   - listen 端口可解析（host:port、数值型、0-65535；拒绝 scheme、缺端口）
   - `base_url` 非空时必须 http(s) 绝对 URL、无 query/fragment
   - `data_dir` MkdirAll + 写探针（`.config-write-probe` 写后即删，不留残渣）
   - driver 枚举 sqlite|postgres（postgres 仅枚举透传，启动拒绝归 T-16/FR-3-AC10）
   - DSN 形状：sqlite 拒绝 `:memory:`（多连接各得私有库）与带 query 的 DSN；postgres 必须 `postgres://`/`postgresql://` URL
   - 所有时长/内存参数必须为正
   - logging.level/format 枚举
5. **默认值**：listen `:8080`、data_dir `./data`、driver sqlite、anonymous_access true、session_ttl/gc_grace 24h、graceful_timeout 30s、argon2 64MB、token TTL 720h、audit on、info/json。`Defaults()` 导出为活文档。
6. 接口面（architecture §2 契约）：`Load(path string) (*Config, error)`、`Config.Validate() error`、`Defaults() *Config`、`SecretEnvVar` 常量。

## 六、Review 修复记录（REQUEST_CHANGES → 已修复，2026-08-17）

依据 /Users/lzw/dev-center/reports/agents/T-8-review.md，4 项 blocking/major 全部修复，每项附新增测试用例名；reviewer 的原始探针输入已逐一复验。

### B1 多文档 YAML 静默丢弃 doc2+（load.go decodeRaw）

- 修法：strict 解码成功后再 `dec.Decode(&extra)`，非 `io.EOF` 即报 `config file must contain exactly one YAML document`；`---` 后的秘密/未知键/覆盖不再逃逸。顺带落实 review n2：null 文档（`---`/`null`）按空文件处理（走默认值）。
- 新用例：`TestLoadRejectsMultiDocumentYAML/{secret_in_doc_2, override_in_doc_2, unknown_key_in_doc_2, top-level_secret_in_doc_2}`、`TestLoadNullDocumentActsAsEmpty`。
- 探针复验（真实进程）：4 个多文档输入全部 `ERR: config file must contain exactly one YAML document`，exit 1。

### B2 sqlite `file::memory:` 绕过（validate.go validateDSN）

- 修法：改为白名单语义——sqlite DSN 只允许「空或纯路径」，含 `:` 或 `?` 一律拒绝（`file::memory:`、`file:test.db`、`file::memory:?cache=shared`、`:memory:` 全落网），错误说明「内存库数据不落盘」。与旧注释「plain file path」的自相矛盾一并收口；下游 T-10 的 `file:` 放行不再被端到端击穿（config 层先行拒绝）。
- 新用例：`TestValidateRules/{sqlite_file::memory:_uri_(review_B2), sqlite_file:test.db_uri_(review_B2), sqlite_file::memory:?cache=shared_uri_(review_B2)}`。
- 探针复验：三种 URI 全部报 `sqlite DSN must be a plain file path…`，exit 1；合法纯路径回归通过。

### B3 `BINFLOW_ADMIN_PASSWORD` 大小写变体静默失效（load.go）

- 修法：删除 `build` 里对 `env[SecretEnvVar]` 的精确大小写读取，赋值移入 `setEnvValue` 的 `case envSecret`（与其他所有变量同一大小写归一路径；空值=未设）；多变体并存时按 `applyEnv` 的 C-locale 排序遍历后写胜出（确定性语义，注释已写明——注意大写排前，故小写变体后写胜出）。
- 新用例：`TestLoadAdminPasswordCaseVariants/{lowercase_spelling_works, mixed-case_spelling_works, empty_value_counts_as_unset, several_variants:_sorted_walk,_last_one_wins}`。
- 探针复验：`binflow_admin_password=T0pSecret` 与 `Binflow_Admin_Password=MiXeD` 均 `admin_pw_set=true`；空值 `admin_pw_set=false`。

### M1 postgres DSN 错误回显口令（validate.go validateDSN）

- 修法：新增 `redactDSN`（剥 userinfo，保留用户名去口令）用于两处错误回显；`url.Parse` 失败时不再回显原始错误（其文本可能引用含凭据的原文），改报 `unparseable postgres URL`。
- 新用例：`TestPostgresDSNErrorDoesNotLeakPassword/{missing_host, wrong_scheme}`（断言错误不含口令子串与 `user:pass` 形态）。
- 探针复验：`postgres://admin:SuperSecret@/binflow` → 错误回显为 `postgres://admin@/binflow`，口令不出现。

### 顺手项（non-blocking）

- m2：`ensureDataDir` 补 TOCTOU 注释（probe 是 fail-fast 尽力而为，非安全边界；并发删写无害的说明）。

- m4：新增 `TestValidateFailureLeavesNoDataDir` 钉住「纯值检查在前、fs 探测在后」的顺序契约。
- m5：新增 `TestLoadExplicitZeroValues` 钉住 `graceful_timeout_seconds`/`argon2_memory_mb`（YAML 0 值）与 `BINFLOW_SERVER__GRACEFUL_TIMEOUT_SECONDS`/`BINFLOW_AUTH__TOKEN_DEFAULT_TTL_HOURS`（env 0 值）的 raw 指针→Duration/int→校验全链，含正值通过例。
