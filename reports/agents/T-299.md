## 做了什么（组件级清单）

BOARD 2026-08-26 指令「前端 UI 框架使用 MUI，交互逻辑按 Artifactory」的批次一：
Login / 壳层 / 仓库域三页面组，**只换组件层**——路由、键盘导航、数据流、
权限姿态、console-ux 册锚全部不动。

### LoginPage（web/src/pages/LoginPage.tsx）

- `input#login-username / #login-password` → MUI `TextField`（outlined small，
  无浮动 label——上方原生 `<label htmlFor>` 保持，32px 密度带 + surface-3
  底/border 边框/accent 聚焦经 sx 复刻，`mono` 类保留在 input 上）
- 提交/SSO 按钮 → MUI `Button`（contained / outlined，**显式 type="submit"**
  ——MUI Button 默认 type="button"，不覆写会断 Enter 隐式提交链路）
- 行内 401 错误 / SSO 错误 → MUI `Alert severity="error"`（role=alert 保留，
  testid 不变；`.login-divider` 保留原生 div——login.spec 以类选择器断言）
- 卡片仍为原生 `<form className="login-card">`（表单语义 + CSS 类承载面）
- 不动：SSO 探测/复核状态机、return 安全校验、LDAP 零分支

### AppShell（web/src/components/AppShell.tsx）

- 顶栏搜索输入 → MUI `InputBase`（无边框原语，嵌在 .search-entry 容器内；
  `inputRef` 直指 input——⌘K focus+select、Esc 两段、↑↓/Enter 键盘链路零变化）
- 主题切换 → MUI `IconButton`（32px 密度带 + text-2→text 悬停经 token；
  title 原生 tooltip 与 aria-label 保留）
- **刻意不迁**（见「批次边界」）：侧栏 NavLink 条、nav-mode-switch、
  session 菜单（自定义 role=menu + ↑/↓/点击外关/Esc）、面包屑 nav、
  最近词下拉、帮助链接

### RepositoriesPage（web/src/pages/repositories/RepositoriesPage.tsx）

- `<table>` → MUI `Table/TableHead/TableBody/TableRow/TableCell`（`.table`
  类续挂根上——base.css 表格密度按特异性压过 MUI 默认，双主题观感不变）
- 列头排序 `SortTh` → `TableCell component="th"`（aria-sort 三态、点击
  承载在 th 本体、内部 .th-sort 键盘按钮原样）
- 行 = `TableRow`（onClick + onTableRowKeys + tabIndex，↑↓/Enter 行导航）
- key 过滤输入 → MUI `TextField`（repos-filter-key 锚在 input 上）
- 添加仓库 / 创建第一个仓库 → `Button component={Link}`（contained）
- 行内 Set Me Up / 部署 → `Button`（outlined small，`rowBtnSx`——文字/边框
  走 text/border token：MUI outline 主色在 hover 行 surface-2 上 4.48:1，
  axe color-contrast serious，repositories.css 里 .row-link 同款坑）
- 行内删除 / 用量失败重试 → `Button`（text + `quietBtnSx` = .row-del/
  .usage-failed 同形复刻：text-2 常态、danger 悬停；**repositories.css 的
  .row-del/.usage-failed 死样式已清**）

  details/summary，spec 类钩子）、badge 家族、CopyButton、EmptyState

### RepositoryFormPage（web/src/pages/repositories/RepositoryFormPage.tsx）

## 批次边界（刻意不迁清单，供 conductor 拍板后续批次）

- **session 菜单 / 侧栏 nav / 面包屑 / 最近词下拉**：保留自定义 DOM。理由：
  MUI Menu/Drawer 会改变焦点语义（开菜单即夺焦、backdrop 点击关闭与
  toggle-close 冲突）、NavLink 是 react-router 锚（`.nav-item` 类选择器被
  shell.spec 计数断言钩住）、面包屑 children ≤4 时 MUI Breadcrumbs 无折叠
  但引入新 DOM 层。零交互变化红线下取保守面。
- **badge 家族（.badge.*）**：控制台全站徽章体系（users/groups/perms/
  storage 30+ 落点，批次二以外页面），单页换 MUI Chip 会分叉视觉语言；
  且 axe 对比度族刚在 T-244/T-250 收口。
- **member-pop（details/summary）与 pkg-grid 网格项**：spec 类选择器钩子
  （`.member-pop summary`/`.pop`）+ radiogroup 语义。
