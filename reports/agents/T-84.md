## 做了什么

newAssembledServer 原只挂 generic/docker/maven。补齐（照 maven 形态，两包各自的"单调用装配钩子"契约优先）：

1. **npm**：`npm.New(stack.svc, stack.md.Repos(), npm.Options{BaseURL: cfg.Server.BaseURL})` → `.WithAuth(stack.authSvc, stack.md.Users(), stack.authSvc)`（NE-06 登录三件：TokenRegistry + 用户目录 + 早期写权限门）→ `.WithLedger(stack.md.Blobs())`（packument ETag/sha1 头）→ **`npm.Register(npmHandler)`**（adapter.Register + RegisterMetadata 一次入两注册表——T-63 review N2 的单字面量契约）。
2. **pypi**：**`pypi.Register(stack.svc, stack.md.Repos(), stack.md.Blobs(), stack.st)`**（构建 + 双注册表一次完成，storage engine 缝供上传面走 PutLandedBlob 形态）。
3. 两者入 `Deps.Adapters`（httpapi 的 /binflow/<repo> 内容分发与 /binflow/api/npm|pypi 挂载缝都查这张表——router.go dispatchAPIProtocolMount）。
4. **maven.RegisterMetadata() 确认已在**（main.go 原有，T-68 计算器消费；handler 经 Deps.Adapters 挂载）。

装配语义注意（已核实）：全局 adapter registry 的重复注册会 panic（registry.go 契约——装配 bug 必须启动期暴露）；newAssembledServer 每进程一次（serve 一次 / cmd 测试一处调用），无重入面。
