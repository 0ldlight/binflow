## 1. B-1 修复：`bf-migrate --skip-users`（FR-77 AC2）

**语义**（依据 T-228 R-1 实腿 + T-226-qa B-1 建议原文「降级 warning 或 --skip-users」）：

- 旗标语义 = **用户面可选**（degrade，不是无条件跳过）：带 `--skip-users` 时仍尝试 ListUsers——
  - **403/400**（非 admin 凭据 / Artifactory OSS license 门"available only in Artifactory Pro"，即 T-228 两种真实形态）→ 跳过用户面，`Summary.UserPhaseWarn` 记显式降级告警，**继续 tokens/artifacts**（此前硬 abort 令这两阶段永不可达）；
  - 清单可读 → 用户照常全量迁移（旗标不吞用户）；
  - 其他错误（网络/5xx/解码）→ 仍然硬 abort（对意外形态 fail-closed）。
- **无旗标零回归**：任何清单错误仍 `user phase aborted before any write` 硬中止（负例腿钉死）。
- 降级发生在密码策略解析**之前**：被拒源上运行无需 `--password-env/--passwords-out`（T-228 OSS 场景操作员本就无从迁用户）。
- 告警三面落地：`Summary.UserPhaseWarn`（结构体）→ `Print` 的 `warning:` 行 → 报告 JSON `users.warnings[]`（T-196 持久化契约，abort 路径照旧落报告）。

**改动**：`internal/migrate/migrate.go`（Options.SkipUsers godoc + runUserPhase 降级分支 + Summary/Print）、`report.go`（userWarnings 投影）、`doc.go`（Semantics 补一条）、`cmd/bf-migrate/main.go`（旗标 + phases/flags/example 三处 usage + 包文档 Semantics）。

**测试**（table-driven，全部实跑绿）：
- `internal/migrate` TestRunTable 新增 5 腿：403→告警+继续（深断言：users 全零/无用户写/无密码文件/tokens found=2/artifacts migrated=8/progress users 空/报告 warnings 持久化）、400→license-gate 告警+继续、可读清单→全量迁移（found=4 migrated=2）、**无旗标 403→仍硬中止**（repos 先行/artifacts 不可达/报告无 warnings 负例）、500+旗标→仍中止（fail-closed）。
- `cmd/bf-migrate` 新增 TestMigrateSkipUsers（CLI 缝三腿：无旗标 abort / 400 源+旗标降级（stdout 含 `users: found=0`+`warning: users phase skipped via --skip-users`+`license gate`+`artifacts: found=3 migrated=3`，报告持久化）/可读源+旗标照常迁 alice）；cliArtMock 增 userStatus 注入臂（400 体即 "available only in Artifactory Pro"）；TestMigrateHelp 增 `--skip-users`。
