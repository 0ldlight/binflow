- **reader.go**：Artifactory REST 读取面（形状依 docs/reverse/rest-api.md §2 + auth-model.md §1/§3.3）：`/api/repositories`、`/api/repositories/{key}`、`/api/security/users`、`/api/security/users/{name}`、`/api/security/token`。APIError 携带状态码+截断 body；`IsStatus` 分类（token 列表 401/403 → 警告非失败）。URL 校验拒绝空/无 scheme/host 为空（`host:8081/x` 会被 net/url 吞进 scheme，显式拒）。
- **converter.go**：repo 映射 —— rclass local/remote/virtual 1:1；federated 跳过；packageType generic/docker/maven/npm/pypi 1:1、gradle→maven（带 warning）、其余（nuget 等）跳过；local 携带 includesPattern/excludesPattern；remote 携带 url/username、**上游密码不可导出**（Artifactory 从不回显）→ 迁移 + 警告；virtual 携带成员表、无成员跳过。user 映射 —— 跳过 anonymous/_system_/非 internal realm（IdP 供给）/无 email；名字小写化（Artifactory 建号即小写、BinFlow 拒绝混合大小写）；groups 透传（目标须预建组，未知组 → 该用户 400 记为 item failure）。

- **progress.go**：JSON 进度文件（version/source_url/target_url/repos/users/tokens_listed/updated_at），逐项标记后原子落盘（temp+rename，0600）。resume 时端点不匹配拒载（防两场迁移混用一个检查点）；损坏 JSON 报错；文件缺失视为从头开始。
- **migrate.go**：三阶段编排 repos → users → tokens（**保序**：真实源按 type 再 key 排序，virtual 殿后，成员先于聚合仓就位）。item 级失败不中断：记录、不标记（下次 --resume 重试）、结束时聚合报错 exit 1。跳过项也落进度（resume 不重评估）。dry-run 只读不改任何文件。tokens 阶段按现实约束只记账：`TokenPolicyNote` 每次总结都声明「token 值不可导出——列出统计、全部跳过、目标侧重发再分发」。
- **migrate_test.go**：mock 双端 + table-driven（详见验证节）。

## 关键设计决策（如实记录）

1. **token 面策略**（派单写 auth-model.md §4；现文档该约束实际落在 §3.3，§4 是权限概览）：`GET /api/security/token` 仅回元数据（token_id/subject/expiry），**值只在创建时返回一次**——不可导出是 Artifactory 的硬约束。故第三阶段不伪造迁移：列出 → 计数 → 全部标 skipped → 提示在目标重建。非 admin 凭据（403）或端点失败记为阶段警告、不标进度（resume 会重试），不判 run 失败。
2. **用户密码同约束**：Artifactory 任何响应不含口令。策略二选一 fail-fast（共享 env 或 0600 生成文件，追加写保证 resume 只新增本轮用户）。
3. **失败与进度解耦**：成功/跳过才标记；失败项留空 → `--resume` 即重试杠杆。级联失败（成员仓未建 → virtual 400）同样可恢复，冒烟已验证。
4. **Q9（验收环境）条件腿**：按 mock 双端实现（形状全部锚定逆向规格与真服务端行为）；真实 Artifactory 实例验收待用户定案环境后补跑——reader 面无 Artifactory 专属魔改，届时只需端点可达 + admin 凭据。

| migrate 要传的 | client.RepoCreateRequest json tag | internal/httpapi repoConfig json tag | 后果 |
|---|---|---|---|
| virtual 成员 | `members` | `repositories` | 真服务端静默丢弃成员 → 建出空 virtual |
| includes | `includes` | `includesPattern` | 真服务端丢弃 local 仓 patterns |
