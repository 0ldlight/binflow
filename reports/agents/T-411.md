### 关键实现决策（含规格依据）

1. **path = 父目录**（非 nodes.path 全路径）：aql.md §2.2「父目录路径」/§10「余段 = path」+ t407 活体 v01/v09 双证
   （`"path":"com/example/t228/t228-lib"` + `"name":"maven-metadata.xml"`）。**这是 ADR-0043 映射表之外的第三处分歧**
   （ADR 写 path→nodes.path 直取）——按票面纪律从 aql.md，登记待 ADR 勘误回填（与已知两处同批）。
   派生式：`substr(path, 1, length(rtrim(path, replace(path,'/',''))) - 1)`（父）/ `substr(path, length(...)+1)`（名）。
   未用 ADR 的 replace 形——replace 全量替换在中段重复出现时有理论错位面，substr 前缀截取无此险（机制轴 A 不变，表达式更稳，已在代码注释留痕）。
2. **depth = 段数（根子项 = 1）**：aql.md §2.2「根 folder 起」+ v05 活体 `"depth":2`（1 斜杠文件）定标——
   `length(path)-length(replace(path,'/','')) + (CASE WHEN path LIKE '%/' THEN 0 ELSE 1 END)`（folder 行 = 斜杠数，file 行 = 斜杠数+1）。
   ADR 原式（纯斜杠计数）在根级文件上与活体冲突，属表达层口径，从 aql.md。
3. **默认 file 谓词**：无 type 条件的查询补 `path NOT LIKE '%/'`（aql.md §2.2 活体 v09 + §10「查询侧补 type=file 谓词」）；
   `{"type":"any"}` 视为已声明（禁默认），`{"type":{"$ne":"any"}}` → 1=0（诚实空）。
4. **时间双侧归一化**（ADR 轴：`julianday(x)`）：部分精度日期（YYYY/YYYY-MM/YYYY-MM-DD）在 planner 侧解析为周期边界
   （$eq/$ne = 整周期；$gt 离开周期、$gte 含周期头、$lt/$lte 对称）；完整精度即时比较、带偏移时区归一 UTC。
   实测拍死两处裸文本比较会错的点：小数秒（`.5` < `Z` 字典序倒置）与 `julianday('2026')`（SQLite 把裸 4 位数当儒略日数）。
5. **属性谓词三态编译**（性能腿抓出的真坑）：初始全走 ADR 的 EXISTS-子查询 hoist，EXPLAIN 实测 **两个 DISTINCT 子查询
   同语句时第二个被物化为无索引临时表、逐探针线性扫描**（12k 语料 1.9s，超 800ms 预算 2.4 倍）。重构为：
   - name 等值 + value 等值（四列 PK 精确寻址、行唯一）→ **node_props 直接 join**（EXPLAIN：`SEARCH np0 USING INDEX idx_node_props_name (name=? AND value=?)`）；
   - 其余带 name 条件者 → **至多一个** DISTINCT 子查询 join（键存在性形态的 idx 消费腿）；
   - 其余（值条件/嵌套 Or 位置）→ 关联 EXISTS（node_props PK covering 探针，实测 12k 全扫 46ms）。
   DISTINCT 上限一行注释留痕；LIMIT/OFFSET 语义不受 hoist 影响（直接 join 行唯一、DISTINCT 去重）。
6. **$msp 同实例**：全部条件落同一 node_props 行（直接 join 或 EXISTS 内联）——multi-value 属性上 any-of（两条件可由不同 value 行满足）
   vs $msp（同一行）有判别性用例钉死（env=[prod,dev]：and 两条件命中、$msp 零命中）。
7. **懒 blobs join**：WHERE 或投影引用 sha1/md5 才 `JOIN blobs b ON b.sha256 = nodes.sha256`（投影侧触发是行为链测试抓出的漏——已补）。
   EXPLAIN：sha1 键值过滤走 `idx_blobs_sha1`（T-73 缝顺带兑现）。
8. **virtual 展开**（aql.md §7-1/§197 归 T-411 编译器）：`VirtualResolver` 接口在消费侧（search 包）定义、`PlanOptions.Virtual` 注入
   （nil = 字面透传，快照测试形态）。$eq 替换为成员组 / 字面 $match 保留+OR / $ne·$nmatch 保留+AND 排除 / 带通配 pattern 与范围算子透传
   （范围枚举需 repo 侧缝，T-413 接线时定）。真实现归 T-413（T-412 落地 repo.Service 解析）。
9. **投影回显**：默认集 = aql.md §3.3 十字段 **minus modified_by**（无存储源，ADR-0043 pt 2 不伪造；T-415 需知悉默认行无此键）；
   `include("*")` = 13 存储字段 + virtual_repos 逻辑字段（v05 活体序）；modified_by/repo_path_checksum/id/original_* 不出（无源，诚实）。
   type 无 QueryField 键（低化为 FolderTest），投影走固定超集行（NodeQueryRow 全列，懒 join 两列除外）。
10. **双方言**：PG 仍被 Open 拒（M1 现状），分歧点单点化留痕——日期归一（julianday ↔ ::timestamptz）与 `LIMIT -1 OFFSET`（sqlite 无 LIMIT 不能 OFFSET）。

### AC2 注入红线证据

- 快照性质断言：同形查询，良性值与 8 个恶意值（`' OR '1'='1`、`'); DROP TABLE nodes; --`、`UNION SELECT ...`、`/* */ --`、
  `%`/`_`/`\`、unicode、`\n\t\0`、`*/';`）编译出的 SQL **文本逐字节相同**，恶意值只出现在 args（表驱动 7 形 × 8 值）。
- SQL 文本仅由包内常量片段拼装（`//nolint:gosec // G202` 注释与 nodeQuery 先例同款）；唯一动态量是 IN 占位符个数。
- `$match` 转义核验：`a?b%c\d` → `a_b\%c\\d`（match_test 14 形）；行为腿：`100%_done*` 不放大匹配（零命中）。
- `idx_node_props_name` 消费（M10 兑现）：EXPLAIN 断言直接 join 臂 `SEARCH np0 USING INDEX idx_node_props_name (name=? AND value=?)`、
  键存在性 DISTINCT 臂 `(name=?)`，且禁 `SCAN np0/np/node_props/b`。
