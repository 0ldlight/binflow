R10 行以「docker tags GET」作 session 凭据等价性示例，与 E4 定案相悖：session cookie `Path=/binflow` **结构性不达**根级 `/v2`，docker 客户端按 Registry spec 固定向 `/v2/...` 发请求、认证走 `/v2/token` Basic 面——浏览器 console 的 session 凭据永远送不到 `tags/list`，该例不成立。
