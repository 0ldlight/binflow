设计取舍记录：
- **`.env.example` 用 `BINFLOW_ADMIN_PASSWORD=change-me` 占位**，compose 对该变量用 `:?` 约束——未设置时 compose 直接报错并提示 `cp .env.example .env`，避免任何人"顺手"用缺省口令 `password` 起评估实例（比 PRD 更严一档，PRD 只要求文档明示；FR-6-AC1 命令本身仍是 `up -d --build`，配置是前置步骤第 0 步）。
- **compose 默认绑 `127.0.0.1`**（host 侧）：NFR-S6「M1 明文 HTTP 仅限内网/本机」的默认安全形态；需要暴露时改 `.env` 的 `BINFLOW_BIND_ADDR`。容器内仍监听 `:8080`。
- **选 alpine 而非 distroless**：M1 dev 镜像保留 `docker exec sh` 可调试性（deploy/README 的 GA 矩阵本就规划 distroless/alpine 双变体，M1 落 dev 用 alpine）；`wget` 来自 busybox，健康检查零额外依赖。
- 镜像内**不烤配置文件**：serve 无配置文件时按 defaults+env 启动（FR-6-AC5 路径），全部旋钮走 `BINFLOW_*` env，与 compose `.env` 单一事实源一致。

## 三、偏差与说明（如实记录）

1. **本机 8080 已被无关本地栈占用**（`arca-frontend` 容器绑 `0.0.0.0:8080`，非本仓库管理）。compose 验证用 `.env` 的 `BINFLOW_BIND_PORT=18080`（本票新增的文档化旋钮）完成；默认值仍是 AC 要求的 8080。README 已写"8080 被占时改 BINFLOW_BIND_PORT"一段。
2. **首次 build 因网络瞬断失败一次**：BuildKit 拉 `golang:1.26-alpine` 元数据时 `auth.docker.io` IPv6 超时（本机网络问题，非 Dockerfile 缺陷）；`docker pull golang:1.26-alpine` / `alpine:3.21` 预拉后（各 ~15s）build 一次通过。GOPROXY 镜像（goproxy.cn）在容器内 `go mod download` 实际生效，无代理超时。
3. **AC1 计时口径**：镜像缓存命中时 `up -d --build` → ping OK = 2.35s；全冷（含基础镜像拉取）会多 ~30-60s 拉取时间，属 Docker Hub 网络，不计入 30s 服务可用预算（30s 门以 up 完成后 ping 达 OK 计，实测 0.06s）。
4. **README 中 localhost 字面量在本机 IPv6 环境的注意**：本机另一进程曾占 `*:18080`（IPv6 wildcard），`curl http://localhost:18080` 命中过错误后端；README 示例保留 `localhost`（通用形态），验证以 `127.0.0.1` 显式 IPv4 执行，全部命令退出码 0。此为共享开发机的偶发端口碰撞，与交付物无关。
5. **`gc --help` 返回 rc=1**（flag 包把 --help 当解析错误路径打出 usage 后 exit 1）：T-16 已知 CLI 形态（gc 子命令未接 ErrHelp 分支），README 未承诺 `gc --help`，不改（跨 area，非本票面）。

## 四、遗留 / 建议

1. **镜像版本 stamping**：`--version` 报 `dev`（main.version 未注入）。Dockerfile 预留了注释位，M5 goreleaser/CI 落 `-ldflags "-X main.version=..."` 时在 build stage 加一行 ARG/ENV 即可（届时 README 版本示例同步）。
2. **distroless 变体**：GA 部署矩阵（deploy/README 第 2 项）要求 distroless/alpine 双变体——本票只落 dev 用 alpine；distroless 变体归 release-engineer 的 M5 票（无 wget，健康检查届时换 `busybox` sidecar 或 Go 静态探针二进制）。
3. **CI 未加镜像构建步骤**：票面 AC 只到本地 compose；`.github/workflows/ci.yml` 增加 `docker build`（不推送）建议随 M2 部署烟测票落地，避免 CI 时长翻倍。
4. **compose restart 的 stop_grace 生效前提**是 healthcheck 与 `unless-stopped` 已配置；K8s 侧对齐项（terminationGracePeriodSeconds ≥30s）已在 architecture §9，归 Helm 票。
