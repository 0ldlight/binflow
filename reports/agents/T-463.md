### 2.3 CI 断言（防回流）— `web/scripts/assert-i18n.mjs`

- **用法**：`node scripts/assert-i18n.mjs [--stats]`；退出码 1 = 违规。
- **三道闸**：① 硬编码闸——src 内（i18n/ 除外）任何 CJK 出现在 JSX 文本/字符串/模板字面量且非 `tr()` 绑定翻译器调用首参 → 违规（行尾 `// i18n-allow` 为显式豁免口，本票零使用）；② 键集闸——t() 键路由后与 en 目录包**双向同构**（missing = 运行时告警源；orphan = 已删文案残留）；③ 清单闸——zh 清单逐域一致。
- **挂点**：`package.json`——`build` 链（assert-tokens 之后、vite build 之前）+ `lint` 链尾（`eslint . && node scripts/assert-i18n.mjs`）+ 独立 `assert:i18n`。CI 路径：`make console`（`npm run build`，.circleci build job）自动携带；本票已负测（注入硬编码字符串 → 1 violation 精确定位行号 → 清除后复绿）。

### 2.4 一次性工具（scripts/t463/，考古留档，非 CI 依赖）

- `codemod.mjs` — AST（TypeScript compiler API）codemod：JSX 文本/字符串/模板 → t() 键引用；生成 en 骨架 + zh 清单。核心保真点：JSX 文本按**编译器实测语义**归一（含换行的空白 run → 单空格；纯空格 run 原样保真——`ts.transpile` 与 esbuild 双实测对齐）；模板 `${a} 项` → `t('{a} 项', { a })`（非标识符表达式命名 v1/v2…，内层 CJK 字面量递归键化、编辑吸收进复合替换防偏移二次移位）；危险位（case 子句/对象键/字面量类型）显式报错不静默（本票零命中）。
- `verify-extraction.mjs` — 零语义变化对账（§4）。
- `regen-catalogs.mjs` — 目录包/清单再生成（键集手工修正后免重跑 codemod——codemod 不可对已转换树重放）；`astral-keys.mjs` — 星面字符键巡检（§6.4 根因的常备探针）。

## 6. 特殊登记

1. **t/tt 双名**：27 文件因既有 `t` 绑定（如 `(t: string) =>` 形参）改用 `tt`（codemod 冲突检测顺延 t→tt→tti；全树零 tti）。`assert-i18n` 按绑定识别翻译器，双名等价。
2. **brace-in-key 5 条**（admin 4 / repositories 1）：原文案自带 `{0}`/`{baseUrl}`/`{id}` 字面花括号（LDAP 过滤器模板说明等）。运行时安全——插值只替换实传 vars 的占位符（无 vars 调用原样保留）；已登记防未来同名 var 误伤（T-464 填 en 时留意）。
3. **改前恢复事故（过程记录）**：codemod 前两版有注入位/复合模板偏移两缺陷，产出了语法损坏的 64 文件；经 CJK 字符守恒校验确认 diff 纯属本票损坏后 `git checkout -- web/src` 恢复重跑（含快照中 5 个 pre-modified 文件——逐一验证其 HEAD diff 仅有本票形状的变更后才恢复，无既有未提交工作受损；NavIcons/api.ts/两监控页在会话开始前已由 conductor 提交）。终版一次通过 tsc。
4. **UTF-16 代理对正则陷阱（根因留痕——emoji 误键）**：codemod 初跑的 CJK 判定正则以字面字符书写，其中 `豈-﫿` 段的 `豈` 实为 **U+8C48**（统一表形文字区）而非预期的 U+F900（兼容区）——无 `u` 标志的 JS 正则按 **UTF-16 码元**匹配，区间 8C48-FAFF 覆盖代理对区 D800-DFFF，导致一切星面字符（emoji）的高位代理命中「CJK」：7 处 emoji 独占 JSX 文本（🔒×2 / 🗑×2 / 👥×3，`aria-hidden` 装饰图标）被误键化为 `t('🔒')`。渲染零差异（zh-as-key 恒等回落）但属垃圾键——已全部拆除（还原字面 emoji）并再生成目录包/清单。三个常驻/工具脚本的正则统一为转义书写（`豈-﫿` 端点，无代理区覆盖）；教训：**跨平面字符类必须 `\u` 转义书写或加 `u` 标志**。emoji 并非可译文案，assert-i18n 的「CJK」判定不含 emoji——后续新增 emoji 图标无需走 t()。
5. **en DEV 态告警噪音**：`npm run dev` 下 en 引导会对全部未填键 console.warn（去重）——设计如此（驱动 T-464 补齐）；生产构建 `import.meta.env.DEV=false` 静默 + 回落 zh，e2e 已断言零告警。
6. e2e 新 spec 第 3 腿的一次性注入用 sessionStorage 旗标防 addInitScript 在 reload 时重放写回（spec 内注释说明）。
7. **emoji 拆除后复跑**（终态二进制 = 最终 console 嵌入）：auth-config（🔒 证书腿）+ artifacts（🗑 树删除）+ t455 权限五列（👥）+ t447 属性下载（🗑）+ t463 机制腿 → **24 passed / 3 skipped（条件）/ 0 failed**；全套门链复绿（tsc 0 / lint 0 / assert-i18n OK / verify 85 文件 2581 条相等 / build 0）。
