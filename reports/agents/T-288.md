## 1. 交付内容

### 1.1 License & Add-ons 管理页（`/admin/general/license`，「常规」分组第二页）

- **License 状态卡**：档位徽章三色（community=中性灰地板 / pro=蓝 `.badge.tier-pro` / enterprise=金 `.badge.tier-enterprise`，徽章文本 = 档位闭集 wire 值）；licensee / License ID / 签发时间（mono）；有效期（perpetual=永久）+ 倒计时（`daysToExpiry` 负值如实呈现「已过期 N 天——D6 无宽限已降级」）；未装 license = community 地板说明块（license-floor）。**GET 不回显文档原文**（NFR-S52）由服务端保证，前端无展示面。
- **POST 装载**：文本域贴文档 → `rawBody`（body 即文档全文，非 JSON——`lib/api.ts` 加 4 行 `rawBody` 纯增量缝）；400 验签拒绝**原文呈现**（mono + `LICENSE_EXPIRED/LICENSE_INVALID` wire 码，FR-84-AC3「不含内部细节」由服务端保证，UI 只如实转述）；拒装不动在装 license（AC 腿断言地板维持）。空文档禁用装载钮（表单零坏请求）。
- **DELETE 卸载**：仅 licensed 态渲染；强确认 = 输入 `UNINSTALL`（confirmDisabled 前置——删仓同款 P5 形态）+ 降级语义说明（门控面即刻关、读不劫持）。
- **Addons 矩阵表**：`GET /api/v1/addons` 装配序全槽位——Id（mono）/ DisplayName / Kind 徽章（wire 值 `package-type|feature`）/ 最低档位（地板 =「—」无徽章；pro/enterprise 徽章）/ **Enabled 只读态**（license 决定不可手动切：`已解锁`〔绿点〕/ `锁定·需要 N 档` / `⊘ 已禁用·addons.disabled 熔断`〔金〕）；锁定/禁用行灰显（`is-locked/is-disabled`）+ `⊘`；reason 作 title 呈现。空数组（pre-M10 单元栈）走缺省 `empty-state` + 自我说明（非错误）。
- **三角色门（FR-86-AC5）**：admin 全量；readonly_admin 页面/矩阵只读可见 + `license-readonly-note` 注记，写入口**不渲染**（L4 预收敛，服务端 403 兜底）；普通 user 导航不可达 + 直链页面级 L2（复用缺省 `empty-state` 锚）。

### 1.2 建仓对话框包型档位徽章（RepositoryFormPage）

- 进页包类型网格 + 表单 radio 行共享一份 `GET /api/v1/addons` 实时数据：**五核心无徽章=地板；门控型（go/nuget/cargo）pro 徽章；未解锁型禁用 + 提示「需要 N 档 license」**（D5 可见性口径：入口可见带徽章，不隐藏）；`addons.disabled` 熔断提示优先（对 admin 可行动）。
- 可选集 = 五核心静态元数据 ∪ 注册表 package-type 槽位（displayName/description 用注册表行，**前端不复制槽位清单**——FR-86-AC2 单源）。加载中/403/失败 = 仅五核心（地板恒合法、门控型不误放；服务端 D3 建仓门终裁）。
- `PackageType` 联合扩 `go|nuget|cargo`（`PACKAGE_TYPES` 常量仍 = 五核心，SetMeUpDialog 等既有消费方零变化）；顺带修复 prefill 的**潜在静默改写缺陷**：旧「五核心枚举守卫」会把门控仓编辑回显打回 `generic`，全量替换提交即错仓型——改为信任服务端已终裁的 wire 值。
- `commands.ts` 三函数补 `default` 臂（门控型给指路块兜底，不在 UI 发明接入命令——内容与 docs/user 同源，go/nuget/cargo 文档归 T-296 面）；否则旧穷尽 switch 在门控仓上返回 undefined 击穿 Set Me Up / 详情页渲染。
