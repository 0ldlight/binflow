- **open_questions**:
  1. normalize 注册制的粒度：v2 按域注册（域内规则整组生效）；normalize.yaml 现结构是描述性 prose 非可执行规则表——按域注册还是按规则注册，请 compatibility-engineer 定
  2. normalize.yaml 至今无 status 字段是「尚未引入注册标记」还是「有意全不注册」？影响首批真实批次是否需要先提金/登记才能出非 raw 结论
  3. v2 内置规则词汇表（drop-volatile-headers / base-url-placeholder）语义是否与未来登记的域规则对齐，待首批真批次对表
- **decisions_made**:
  1. 用例格式定为 .py（声明式 CASE dict + 编程式 run(ctx) 双轨），放弃 YAML——stdlib 无 YAML 解析器，自写解析器不值（README 已写明格式）
  2. normalize 注册制按域粒度实现（票面只要求「status: registered 才应用」，域粒度是最小忠实实现）；未注册 → mode=raw + note，绝不私自归一
  3. runner 退出码与用例状态解耦：跑完即 0（FAIL 也 0），2 仅表示用法/发现层错误；CI 门走 score.sh JSON——「状态走 JSON 不走退出码」对 runner 同样成立
  4. 超时默认 30s 写死于 runner.py（DEFAULT_TIMEOUT_S），用例 timeout_s / --timeout 显式覆盖，永不自动放宽
  5. NOT_RUN 的两个确定来源：--dry-run 与 --case 过滤（未选用例入 results.json 记 NOT_RUN，防静默漏跑）；HTTP 4xx/5xx 是合法响应参与比对，只有 transport 层失败才 BLOCKED
  6. run/ 产物目录 gitignore（evidence 含实例 host，不进库）
- **deferred**:
  1. golden-only（B 单边）模式：本票 dual 框架，B-only 断供降级待首批真批次需要时加 `sides: ["b"]`
