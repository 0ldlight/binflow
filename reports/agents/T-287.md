## 2. 交付面

### 2.1 v3 主面（`/binflow/api/nuget/v3/<repo>/…`）
- **index.json**：version 3.0.0 + 资源族（SearchQueryService{,/3.5.0,/3.0.0-beta}、
  RegistrationsBaseUrl{,/3.4.0,/3.6.0}、PackageBaseAddress/3.0.0、PackagePublish/2.0.0、
  LegacyGallery{,/2.0.0}），绝对 URL 回指本实例（BaseURL 或请求派生，X-Forwarded-Proto 认可）。
- **flatcontainer**：`<id>/index.json` 版本清单（local=事实生成 / remote=透传 / virtual=并集）、
  `<id>/<ver>/<id>.<ver>.{nupkg,nupkg.sha512,nuspec}` 三件套 GET、PUT push、DELETE。
- **registration**：local 单页内联生成（catalogEntry 全字段 + dependencyGroups + packageHash）；
  remote 代理+重写（§2.3）；virtual 成员合并（版本并集、local-first、leaf 锚定成员自身 base）。
- **query**：q/take/skip/prerelease 最小集，事实源检索（§6-L3 限制）。

### 2.2 push 链（真实客户端实测修正过两轮）
- **双 URL 形态**：`flatcontainer/<id>/<version>`（PRD 载体/curl 面）与 **publish base 直推**
  （dotnet 8 实测 PUT 到 PackagePublish @id 本身、无 id/version——身份取自包内 nuspec）。
- **multipart 解包**：dotnet 8 实测 push 体为单 part multipart/form-data（name=package，
  filename=package.nupkg）——与 Artifactory 的 FormDataMultiPart 路由互证；裸流照收。
- 流式 spool（临时文件 + 边读边算 SHA-512，包不整驻内存，512MiB 上限）→ zip/nuspec 校验
  （id/version 与 URL 或自身一致性，400 家族）→ 落 nupkg + 服务端生成 `.nuspec`/`.nupkg.sha512`
  两 sidecar（regenerable 豁免）→ 201 + Location。
- `.sha512` 有合成回退：bare-content 上传或缺 sidecar 时对存储 blob 现算（remote 除外——
  上游 404 如实透传）。

### 2.3 remote pull-through
- 存储布局 = 官方 flatcontainer 拼写 ⇒ **包文件 identity 映射**；provider.UpstreamPath 把
  `{id}/index.json`、`{id}/.registration`、`{id}/.page/<f>` 译到上游 `v3-flatcontainer/` 与
  `v3/registration5-gz-semver2/`（nuget.org 当前拼写，2026-08 实测；常量单点，登记 §6-L5）。
- **registration 代理必重写**：上游文档内嵌绝对 URL（packageContent/itemsUrl/@id）按 URL
  路径形状（非主机名——nuget.org 文档在镜像下发仍引用 api.nuget.org）改写到本仓 base，
  JSON token 级替换（非 URL 字节零扰动）；分页保留（page 路由同链处理）。
- **强制 gzip**：registration5-gz-* 端点无协商也回 Content-Encoding: gzip（实测）——
  serve 时 gunzip-on-magic。
- 门控内部写豁免实证（gate_test）：GET 触发的落地不问 verb 门。

### 2.4 v2 最小面（`/binflow/api/nuget/v2/<repo>/…`）
- `FindPackagesById()?id='X'`（OData Atom feed：V2FeedPackage 属性族、Dependencies
  `id:range:tfm|…` 串、IsLatestVersion=最新稳定 / IsAbsoluteLatestVersion=最新含预发布、
  未知 id=空 feed 收集语义）；`$metadata`（EDMX 实体集 + FunctionImport）；v2 push
  `{id}/{version}` 与官方 `/package/` 前缀拼写。Search()/Packages()Id=/$count 未做（K28
  裁定归 T-280/T-293，代码注释已标）。

### 2.5 挂载与门控
- router：`apiProtocolMounts` + nuget 的 **plane-aware rewrite**——
  `/binflow/api/nuget/{v3|v2}/<repo>/<rest>` → `/binflow/<repo>/{plane}/<rest>`（escaped
  拼写逐字保留），复用 dispatchContent 的 RBAC + repo 查找 + addon 门 + adapter 分发，
  全链单次。
- 门控全链（gate_test，T-285 形态）：community D3 建仓 400（含 nuget/pro token）→
  pro 装载后建仓 200 + push 201 → 卸载后 push 403 + `X-Binflow-License-Required: nuget`
  + 读维持（D1）+ 建仓回 D3。真实二进制上 `make test-m10-invariant` 的 T05（nuget 建仓
  =400）同步绿。

## 5. 发现与勘误（登记）

1. **dotnet 8 push 直推 publish base**（无 id/version）——PRD 88.1 只写了 flatcontainer PUT
   的寻址形态；两形态均已实现，dotnet 实测走 direct。
2. **dotnet 8 push 体为 multipart/form-data 单 part**——官方 push 文档未明示；与 Artifactory
   反编译路由（FormDataMultiPart）互证。
3. **add package 无版本号走 SearchQueryService**、带 `--version` 走 flatcontainer versions
   index——search 面（remote=缓存事实）成为 remote 上无版本 add 的已知边界（§6-L3）。
4. **T-280 规格缺失**——§1；建议 conductor 补规格票或并入 T-293 as-built 收口。

## 6. T-287 rulings（待 T-280/T-293 复核，代码内均有注释锚）

- **L1** DELETE=硬删版本目录（无 listed 位）；relist 405。
- **L2** v2 $metadata/service 文档随最小面提供（老客户端可发现性）；$count/Packages()Id=/
  Search() 不做（404），K28 边界留裁。
- **L3** search=存储事实（local 全量 / remote 已落地缓存 / virtual 的 local 成员）；上游
  azuresearch 异主机异 query 面，引擎 path-join 不可达。
- **L4** 上游前缀常量 `v3-flatcontainer` / `v3/registration5-gz-semver2`（nuget.org 当前
  拼写，单点常量）；上游重写按 URL 路径形状匹配（容忍镜像主机拼写漂移）。
- **L5** push 大小上限 512MiB（nuget.org 250MB 的宽松上界）；nuspec 提取上限 4MiB。
- **L6** 版本键=官方归一化（补零到三段、第四段保留、prerelease/build 小写）；id 键=小写折叠，
  展示 id 保留 nuspec 原大小写（v2 d:Id/registration catalogEntry.id）。
- **L7** virtual 的 remote 成员 search/v2 贡献=local 成员 + 该 remote 已落地缓存（经成员
  seam 不可枚举远端全量——记录在案）。
