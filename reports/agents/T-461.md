## 1. 做了什么

### 1.1 可选档开关（AC1）

- **表单**（RepositoryFormPage Advanced 步）：`form-list-remote-folder-items`
  复选「列出远端目录条目（listRemoteFolderItems）」+ hint（TTL 缓存/点击
  回源语义）；**仅批 1 型 helm/debian/rpm 呈现**（`REMOTE_BROWSE_PKG_TYPES`
  = 引擎 BrowseSupported 同集；true 于其它包型服务端按名 400——generic/
  maven 的 HTML 目录抓取 BinFlow 明确不做〔remote-browsing.md §6〕，不建
  禁用占位不伪造「将支持」）；off 默认（diff=0）；**显式 false 恒提交**
  （POINTER 语义，flip-off 过 round trip——forceConanAuthentication 同款）。
- **详情回显**（RepoDetailPage repo-remote-card）：`repo-remote-browse`
  kv 行双态（开启/关闭 + 语义注记）。
- **编辑回显 + dirty-gating 交互零回归**（spec ①腿钉死：零改动 Save
  disabled → check → enabled → 保存 → 详情「开启」→ 编辑回显 on →
  uncheck → 保存 → 「关闭」）。

### 1.2 树消费双态（AC2，web/src/pages/artifacts）

- **off（默认）**：零代码路径变化——spec ②腿断言仅缓存行（charts/ 派生
  臂缺席）+ off 口径注记文案；既有树断言全绿（§3 回归面）。
- **on**：
  - **树展开含未缓存远端目录**：BE listing 并入派生行，FE 懒展开链零新
    请求面（folder-face 快照应答）；helm 全树臂（charts/ + index.yaml +
    tgz 派生行）/ rpm 元数据臂（repodata + RPMS/x86_64/）/ deb 元数据臂
    （dists + pool/main/——枚举基座 = 缓存内 suite 集，spec 先拉 Release
    落缓存）。
  - **派生行标记**：children 表 `tree-row-uncached` Chip「远端」+ title；
    派生行 size/mtime/sha256 列呈现 '—'（wire 的 0/epoch 是占位非事实）；
    根层无 ?list 合并不标记（误标比漏标差——留痕 lib.ts 注）。
  - **点击未缓存路径触发回源**：item-info GET 即 pull-through，详情自纠
    真实值；刷新后行不再带「远端」标记（落地成缓存行）。
  - **下载计数联动**：?stats 面 T-438 单源——spec 断言动作后 >0（不绝对
    值：NodeDetail useAsync 的 deps 数组恒新引用 → item GET 随父渲染重复
    发射、计数非确定——**既有怪癖，见 §6-3 登记**）。
  - **virtual 含 remote 成员行（§8.5 扩面消费）**：virtual 树 charts/ +
    文件行来自 flag-on remote 成员（spec ③腿）。
- **仓头注记双态**：`tree-remote-note`（原 T-406 期无锚 warn-box 升锚）
  ——off「已缓存内容…」/on「远端浏览已开启…点击未缓存条目会回源拉取并
  落地缓存」；403（普通 user 深链，repoMeta 不可得）按 off 口径呈现，
  行为仍由服务端单源决定。空目录 hint 同步双态。

### 1.3 上游停机降级（AC3）

- **缓存行可用**：listing 不整树塌（BE §4-1）——spec ⑤腿换 url 死端口后
  断言 index.yaml 缓存行在场、charts/ 派生臂消失。
- **已渲染派生行点击错误态**：`node-remote-error`（NodeDetail）——同 url
  杀上游后点击仍渲染的派生行，item GET 失败给远端专属文案（REMOTE_COPY.
  fetchFailed——上游不可达/已不在上游索引 + 缓存仍可用）；普通行通用
  错误文案零回归。
- **wire note 消费（契约形）**：listChildren → `listFolder` 双返回
  `{nodes, remoteDegraded}`（FolderInfo 可选字段）；ArtifactsBrowser
  DirStatus.ok 携 note → `tree-remote-degraded` 横幅（children 表上方，
  「已缓存条目仍可用」+ 原文 mono）。**字段缺席零渲染**——BE 渲染腿合入
  即点亮（§4-1 契约缺口）。e2e 以 route 注入契约形验证 FE 消费逻辑。

## 4. 契约漂移（conductor 请过目）

1. **降级 note 无 wire 面（缺口——T-448 §5-2 预告缝的实证）**：
   `repo.RemoteBrowsePlane.ListWithRemote` 已 compile-pin 携
   `RemoteDegraded`，但 httpapi 三处 `ReposSvc.List` 调用点（storage.go
   serveRootFolder / writeFolderInfo / handleStorageList）丢弃 note——
   **FolderInfo/?list 体无该字段**（curl 实证：死上游 listing 体无
   remoteDegraded）。FE 已按**假定字段名 `remoteDegraded`**（Go 结构体
   字段 JSON 名直译）消费（可选字段缺席零渲染），route 注入契约形验证
   消费逻辑。**建议 30min spot 或并入 BE 支撑**：storage.go 三个 List
   调用点各一行 + fileInfoBody/listResponse 一字段（T-448 报告 §5-2 原
   方案）；合入后 FE 即点亮、注入腿退役为 live 断言。**字段名若 BE 另定
   请回写本条**。
2. **`?list` 派生行的占位值语义**：派生文件行 `size:0` /
   `lastModified:"0001-01-01T00:00:00.000Z"`（Go 零时）——非事实值。

   （如 `remote:true`），FE 判别式可简化（现判别式对「落库文件恒带
   digest」不变式有依赖——browseDisplayNode 注同源）。
