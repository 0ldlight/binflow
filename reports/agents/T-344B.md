## 3. 实施中修复的四项回归（均有根因链与复现证据）

1. **axe color-contrast（scrim 合成）**：/admin/repositories/new「进页即弹」的包型网格 modal 的 scrim（--bf-scrim 45%）下，旧壳顶栏因**不透明背景**（axe 取祖先实底、忽略重叠层）达标；新 AppBar color=transparent 全透明链 → axe 做视觉重叠合成（bg #8a8d91）→ 顶栏文字假性炸裂。修复：AppBar sx backgroundColor 'background.default'（同旧值不透明）+ zIndex 恢复 var(--bf-z-nav-sticky)=70（MUI AppBar 默认 1100 会浮在 scrim 上破坏模态全屏遮罩——同时修正了一个交互回归）。
2. **MUI v7 `slots={{root:'span'}}` 丢样式**（SSR 实证）：slots.root 字符串替换 elementType 绕过 styled 包装 → Chip 全部默认样式缺失（无 css-hash 类、radius 0）。AppShell 会话 Chip 改 component="span"（保留 styled + phrasing content 合法性）。全仓 grep 仅 AppShell 两处使用该形态。
3. **permanent Drawer 布局**：MUI 要求 Drawer root sx 提供宽度占位（demo 必需项）——漏配时 root 0 宽 + paper fixed，主区从 x=0 起被 224px 盖住，树页交互点击被拦截（e2e 大面积「超时」的实质根因之一）。修复：Drawer sx width 224 flexShrink 0。
4. **行内 outlined 按钮主色对比度**：cellBtnSx 初版纯布局项 → outlined primary 文字在 hover 行 surface-2 上 4.48:1（T-299 登记过的坑回归，repositories-admin:98 axe 腿实证）。修复：cellBtnSx 钉 color 'text.primary' + borderColor 'divider'（palette 快捷合法）。
5. **aria-progressbar-name**：RouteFallback/boot 的 CircularProgress（role=progressbar）无 accessible name，懒加载窗口被 axe 扫中。修复：aria-label「页面加载中」/「会话验证中」。

另：m9/console-fr82.spec.ts:244 的 axe include 钩子 `.app-topbar` 依赖壳类——AppBar 续挂 app-topbar 类保名（§3.8 漏登项，登记 §4-D5）。
