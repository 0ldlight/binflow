## 裁决：**A（service 写路径材料化）**，ADR-0016

理由（按权重序）：

1. **模型不变量优于读路径补丁**。BinFlow 已全面承诺 folder 行为目录模型——哨兵 blob、mkdir 建行（E-15）、prune 删行、Delete folder 分支、§3.4 ACL folder 契约（尾斜杠=folder）。隐式目录洞不是模型二义，是**写路径未维持自家不变量**。A 一次修复所有消费方；B 要求每个目录解析点永久维护第二套投影语义（合成节点拼写、零值时间戳、与行行为的对齐负担），且不修复模型——export 快照里依然没有这些目录。
2. **取证站在 A 一边**。参考实现 nodes DDL 有 node_type=0=folder（storage-layout §3，高）——目录是实体行；repo-semantics §4（高）「删除后自动 prune 空父目录」只有当上传材料化过父目录行才可能成立。BinFlow 自己的 pruneEmptyParents 在纯隐式树上今天就是死代码——这正是不变量缺失的症状，而非设计。
3. **B 的性能优势经量化不成立**。显式 folder 的 FolderInfo 今天已付全子树 List（writeFolderInfo → List → childInfos 首段投影，B 所谓「前缀扫」的代价显式分支已在付）；B 唯一省的是写，却给每个真实 404 加一次前缀探测。A 稳态写成本 = 深度次 PK 读 + 新目录才有的 insert。
4. **B 作为常设机制有害**：读写双机制会让「忘了材料化」的缺陷被读 fallback 静默兜住（测试照样绿）——不变量失去检验面。B 也因此**不作为 A 的过渡桥**：007 回填 + 写路径材料化已覆盖历史与增量，崩溃窗口按「祖先先落」只剩良性空 folder 行。
5. **C 已被实测证伪**：NB① 的 404 语义丢失、搜索面全后代载荷、mkdir 窄授权静默失败都是运行过的真实代价，且 console 之外的 REST 兼容面（ADR-0003 对标面）不被兜底覆盖。

## 关键设计裁定（ADR-0016 五要点）

1. **缝 = putNode**：五个落库变体的唯一汇点；file 与 folder 目标均材料化祖先（空仓 mkdir 链 `a/b/c/` 的 `a/`、`a/b/` 服务端建——FE 逐段循环可删）。
2. **顺序 = 祖先先于目标行**（blob-first 同构）：崩溃窗口至多残留空 folder 行（良性、可删、prune 收），绝不出现文件行无父目录行。
3. **祖先是派生状态不单独过门**：不判权、不过 governance pattern、不记审计；quota/usage delta 0（size 0）。
4. **007 回填**：先 `INSERT OR IGNORE` 哨兵 blob 行（`nodes.sha256` FK 前置——backfill 直接插 folder 行必撞 FK，这是实现票最大坑），再递归 CTE 推祖先集；双方言、幂等。
5. **remote engine 不跟随**（fetcher 直写 `Nodes().Put`）：M4 无 remote 目录浏览面不可观察，§11.20 登记；M5+ 开 remote 浏览/聚合（repo-semantics §8.5）时随 §4.5 增量票评估。

行为变更面（conductor 需知）：隐式目录 GET/`?list` 404→200（向 rest-api.md §3 参考行为靠拢）；pruneEmptyParents 生效（删文件后空祖先链自动清除——含显式 mkdir 过的空目录，repo-semantics §4 参考实现同款，无 explicit/implicit 之分）；docker 仓 image 目录成为可浏览实体行（全套件回归确认无断言依赖现状）。

### 票 1（BE）：putNode 祖先 folder 行材料化 + 007 回填迁移

- `role:dev-go-core` `area:internal/repo、internal/metadata/migrations` `ref:ADR-0016`
- 实现：putNode 内抽 `materializeAncestors(ctx, p, repoKey, path)`——对 path 每个祖先段调 folder 臂写（复用现有 folder 语义：ensureFolderLedger + 新行/幂等刷 UpdatedAt，经 `Usage().PutNodeWithUsage` size 0）；目标行写入之前执行。**不新增审计事件、不单独判权、不过 governance 门**。
- 迁移 `007_folder_rows_backfill.{sqlite,postgres}.sql`：① 哨兵 blob 行（sha256=64×'0'，size 0）INSERT OR IGNORE；② 递归 CTE 拆既有 node path → 祖先目录集 → folder 行 INSERT OR IGNORE（created_by=''；created_at/updated_at 建议取该目录最年轻子代的 created_at，票内定并测试确定性）。文件体内无事务语句（迁移器已包）。
- 测试面：深层单上传（≥4 段）全祖先逐级 GET 200；既有目录重复上传零新行 + 祖先 mtime 刷新、created/createdBy 保留；空仓 mkdir 链服务端材料化；删文件 → 空祖先链 prune、有兄弟子代不剪、**显式 mkdir 的空目录同样被剪**（§4 参考语义）；同名 file+folder 共存回归；docker push 后 image 目录可浏览 + docker 套件全绿；governance 拒绝上传**零祖先残留**（门在 putNode 前）；并发同新目录上传无 unique violation；`?list`/childInfos/搜索对 folder 行投影回归（现有逻辑已容忍 mkdir 行）；export/import 往返含 folder 行与哨兵 blob；007 幂等重跑。
