## 做了什么

### AC① web/ 工程 + console.Handler + go:embed

- **web/ 工程**：vite 6 + React 19 + TS 5（strict），`base=/binflow/ui/`（R1 裁决值）；`src/main.tsx` BrowserRouter `basename=/binflow/ui`（与 base 同步注释互指）+ **React.lazy 路由缝**（每屏独立指纹 chunk，后续票加屏不动构建形态）；直接依赖仅 react/react-dom/react-router-dom（变更过 architect——ADR-0014 决策 4 第三条，README 注明）；**零运行时 CDN**（全量打包）。lockfile（package-lock.json）提交，`npm ci` 锁定。
- **资产挂载 relink**（scripts/relink-assets.mjs）：vite 单 base 下产物引用 /binflow/ui/assets/，构建后改写 index.html + CSS 到共享挂载 **/binflow/assets/**（PRD FR-23/W02 定案路径，位于 ui 段外使段内 fallback 永不需文件特判）。已验证 chunk 间 import 为相对说明符（`"./home-*.js"`）自动跟随；JS 内嵌资产 URL 的升级路径（experimental.renderBuiltUrl）在脚本头注明。
- **internal/console/console.go**：`//go:embed dist` + Handler 三形态路由——`GET /binflow(|/) → 301 /binflow/ui/`（CE-01）；`/binflow/ui/**` → SPA shell `no-cache`（段内 history fallback，任意深链回 shell）；`/binflow/assets/<hash>` → `public, max-age=31536000, immutable`（ServeContent，零 modtime 无条件请求舞步）；**其余一切 404——不越段吞 /binflow/<repo>/<path>**（含 path.Clean 反 `/binflow/ui/../<repo>` 逃逸背板）。GET/HEAD 405 门。`Dist()` 导出只读测试缝。
- **占位策略（二选一，选定并注明）**：**方案 A——占位文件常驻 dist**。`dist/placeholder.html` 提交（同 #root/同 title，e2e 对两种 shell 均可断言），`make console` 产物（index.html/assets/）gitignore；fresh clone 无 node 可 `make build`（实测 18.75MB、可启动、console 测试通过含 skip 分支）。
- **SPA gzip 体积**：`make console` 输出 `console SPA payload (gzip, js+css): 75013 bytes`（75KB，≤5MB 目标的 1.4%）。CI 构建日志即记录面。

## 决策点（5）

1. **占位策略选 A（提交占位文件 + 产物 gitignore）**：无 build tag、无嵌入空匹配风险、fresh clone 语义清晰；方案 B（构建标签双文件）成本高无增益。
2. **资产 URL 改写用构建后脚本**而非 experimental.renderBuiltUrl：vite 实验面不稳，改写面仅 index.html+CSS（chunk import 天然相对），升级路径已注明。
3. **e2e spec 条件 skip 探针**而非留红/删断言：基建今天就真实可跑（浏览器/配置/baseURL 全验证），T-91 后零改动转绿。
4. **httpapi 两处 seam 测试更新**（TestConsolePlaceholder→TestConsoleRootRedirect（301+no-follow client）、TestMiddlewareOrder 200→301）：这两处钉的是本票按 PRD 反转表（「GET /binflow/ 返回占位 JSON → 301」）终结的旧 seam 语义，属 AC③「占位测试同步更新」的题中之义；httpapi 路由代码零改动（/binflow/ui/** 挂载归 T-91）。
5. **Go 质量门排除 web/**（.golangci.yml paths + Makefile PKG 过滤 + vet 改用 PKG）：node_modules 内 vendor 了第三方 Go 文件（flatted 的 Go port），`go list ./...` 会将其纳入 build/vet/lint——web/ 是 npm 工具链自有域（eslint/tsc 同级门），README 与 Makefile 注明。PKG 定义序在 GO 之后（$(shell) 展开序坑，已注释）。
