## FE 四陷阱的实现（票面指令逐项）

1. **SAML noAutoUserCreation 反语义**：表单呈正语义复选「Auto Create Users（勾选 = 自动创建）」，wire 边界取反（`sections.ts` invert 位）；e2e CFG4 双向断言（勾选 → wire false，取消 → wire true）。
2. **哨兵语义**：GET 回显 20 星 → 表单留空 + placeholder「留空保持不变」+「已设置」提示行（authcfg-*-manager-set / oauth-secret-set）；**提交时空值自 payload 整个剔除**（绝不回传哨兵——CFG1 网络层断言 PUT body 无 managerPassword 键且全文不含 20 星）；CFG2 负向腿：直连 PUT 哨兵 → 400「refusing the masked placeholder」+ 拒绝不改动在用配置。
3. **SAML GET 空态 {}**：`authcfg-saml-empty` 引导块（保存后消失）；表单全默认（autocreate 未勾、verify-audience 勾）。
4. **OAuth persistUsers 摊平**：BinFlow 单段模型下即本段 `auto_create_users` 一位（T-305 漂移 1 的 FE 侧对齐——v2 的多 provider/defaultNpm/availableTypes 面无承载）。

其他要件：测试连接双形态（候选 = 当前表单值随体——LDAP 附 §1.6 testUsername/testPassword 两半齐备门；存量 = 空体探已保存配置）+ TestReport 呈现（成功/失败消息原文照 BE，phase/category mono 徽标）；PUT 全量替换语义 → 非 secret 字段逐字段回传（漏发会被服务端归一成默认值，FE 字段册保证全集）；启停开关（enabled 复选）+ 「保存即生效，无需重启」页内明示；readonly_admin 控件 disabled + 反断言 + REST PUT 403 终裁；普通 user 导航不可达 + 直链 L2 无权限卡。

## 差异登记（契约漂移）

1. **OAuth Tab 字段集 = BinFlow OIDC issuer 发现式单段 wire**（snake_case：issuer_url/client_id/client_secret/redirect_url/scopes/claims/组映射），非 v2 §2.1/§2.2 的多 provider 模型（providers/authUrl/tokenUrl/apiUrl/basicUrl/domain/pkce/useDefaultProxy/defaultNpm/availableTypes 无承载）——T-305 差异 1 的既登记漂移，FE 按契约实态渲染（能跑通的为准），本票不新增漂移。
2. **LDAP 单段模型**：v2 §1.4 的多设置列表/拖拽排序/POST reorder/独立 DELETE 无承载（T-305 差异 3）——key 锁定 "ldap" 只读展示，无排序面。
3. **SAML 证书动作缺口**：v2 §3.2 的 `GET/PUT …/saml/config/key/public[/regenerate]`（下载/再生成 SP 加密公钥）T-305 未落九端点之外的面——useEncryptedAssertion 字段已渲染，但无证书下载/再生成按钮。**建议 conductor 派 BE 补票**（或裁出 FR-92 范围）。

非漂移注记：① v2 §1.6 测试连接的「失败 = status 汇总 + 逐条 warn/info 列表」在 BinFlow 是 TestReport 单消息 {ok,phase,category,message}——FE 呈现消息原文 + phase/category（无列表可列，非 FE 缺陷）；② secret 清除（BE 支持 ""=清除）FE 不开口子——「留空=保持不变」是用户裁定的交互（清除走 REST），页内提示行已写明。
