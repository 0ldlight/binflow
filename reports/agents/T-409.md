## 3. 规格依据（docs/reverse/aql.md 逐节）

- §0-1 `$not` 不存在 → 不实现；查询中出现 → 400 点名拒绝（v03 证据文案在案）。
- §2.1 子集边界表：入口域仅 `items`；其余 12 个入口域全部注册提示语 → `ErrUnsupportedDomain`（C 层增强文案，aql.md 明文许可）。
- §2.2 item 域字段全集 17+2：全部注册。有存储源的 16 个可查/可投影；`modified_by`（无 updated_by 列）、`original_sha1/original_md5`（无双值）、`id`/`repo_path_checksum`（内部）注册为 **known-but-unsupported**（用即 400 带原因——注册表即诚实拒绝单点，ADR-0043 pt 2 的 canonical case）；`virtual_repos` include-only（criteria → output-only 拒绝）。
- §2.3 property 域：`@key` 短记法（含 `@*` catch-all、`@key:"*"` 键存在性）、`property.key/property.value` 展开形态、`$msp`（收录——票面 AC 点名 + aql.md 建议；inner 条件限 property 域，违规点名拒绝）。
- §2.4 操作符闭集：$eq/$ne/$gt/$gte/$lt/$lte + $match/$nmatch（string only）+ $last/$before（date only，周期 ms/millis/s/…/mo/y，`mills` 拼写以实现为准收 `millis`；`mi` 不收）+ $and/$or（逗号隐式 $and、任意深度）；$not/$contains/$eqic/$eqvic/$matchic → 点名 400。
- §2.5 尾缀链：include（"*"/跨域/`@key`，首次 item 域字段覆盖默认输出集）→ sort（`$asc|$desc` 数组；**两条 validator 文案逐字**：`Only the result fields are allowed to use in the sort section.` / `Duplicate fields, ...unique.`）→ offset → limit（非负整数，可带引号；0 合法，absent 用 HasOffset/HasLimit 区分——§3.2 range.limit 省略键语义）；链序违规 → E1（v1c 锚点）；`.distinct/.transitive/.delete/.update/.dryRun` → `ErrUnsupportedSuffix` 400（M15 只读面，§2.5/§7-5）。
- §4 错误面：E1 逐字（语法/链序）；E4 逐字（>6,000，`MaxQueryLen=6000` 常量，Parse 入口检查——资源门 T-413 无需重复）；`Invalid relative date format for: <v>` 逐字（§2.4）。
- §2.5 语法通则：字段名双引号（wire 实测全部带引号）与裸写法双收；数字可带可不带引号（`Value.Int` 双向填充）；`null` 字面量语法层可解析、语义层对 M15 全部字段诚实拒绝（null 语义官方只登记在 stat 域=M16）；通配 `*`/`?` 仅在 $match/$nmatch 字符串内按字面保留（翻译归 T-411 match.go 单一译者）。

## 4. ADR-0043 ↔ aql.md 分歧留痕（不擅改，上报 conductor/architect 裁勘误）

1. **$not**：ADR pt 2 EBNF `pair` 产生式含 `"$not" : object` 一行；aql.md §0-1 定案 $not 不存在于 AQL、BinFlow 不实现。实现按 aql.md（票面 AC 亦已校准为「$and·$or 任意复合 + $msp」）。**建议 ADR-0043 勘误段回填**。
2. **checksums 点路径形态**：ADR pt 3 映射表用 `checksums.sha256/sha1/md5` 点路径；aql.md §2.2 官方字段表为平名 `sha256/actual_sha1/actual_md5/...`。注册表收平名（aql.md 为字面契约权威——ADR 自身条款）；`checksums.*` 查询 → Unknown field。软缝对齐清单②就此闭合，**建议 ADR 勘误**。
3. **操作符闭集**：ADR EBNF op 仅 8 比较符；aql.md §2.4 另含 $msp/$last/$before（高置信）。实现收 aql.md 全集（软缝④闭合）。
4. **错误文案双轨**：语法错=E1 逐字；域/字段/操作符=C 层增强文案（aql.md §2.1 明文许可「码位一致、文案更明确」）。T-415 映射 E-01 时注意两类并存（全部 400）。

## 6. T-411 消费接口（定案）

`search.Parse(query string) (*Query, error)`（error 恒为 `*QueryError`，`errors.As` 解包）；

`Criteria` = And/Or/Compare/PropMatch/MSP 密封接口；`FieldRef{ID,Name,Domain}` 已注册表解析
（ID 即 ADR pt 3 的 FieldRepo…FieldMd5 闭集键；`modified/updated` 分立 ID、同列映射归 T-411）；
