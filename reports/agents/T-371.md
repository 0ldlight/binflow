## 1. 做了什么

### 1.1 修复（AC1 前半）

`internal/adapter/conan/v1.go` `channelFileName`：trim 前缀从复数 `segPackages`（"packages"，v2 wire 词汇）改为单数 `dirPackage`（"package"，通道自身语法——`parseV1Files` 组装 rt.path 与 `serveUploadURLs` 派发的都是这个拼写）。修复后 v1 通道包 PUT 落规格布局 `<coordinateRoot>/0/package/<pid>/0/<tail>`（conan.md §4）；PUT/GET 对称保持（GET 腿同一 trim）。recipe export 臂本就无病，不动。

### 1.2 repo.Service 窄原语（ADR-0042 决策 3，+1 接口方法）

`RewriteSubtreePrefix(ctx, repoKey, srcPrefix, dstPrefix) (*SubtreeRewrite, error)`（internal/repo/rewrite.go 实现 + api.go 接口段〔Adapter SPI face，PutWithOptions 后〕+ `SubtreeRewrite`/`RewriteConflict` 报告类型）：

- **子树前缀批改写**：srcPrefix 下全部节点行（文件与文件夹）映射到 dstPrefix 对应路径；逐行 `PutNodeWithUsage`/`DeleteNodeWithUsage` 配对（usage 净零，纯元数据改写）。
- **ADR 契约四点落位**：①同 blob link 平移——行字段全保（sha256/size/mime/created/createdBy），blob store 永不打开；②系统态无权限门（无 Principal 参数）；③零副作用——不触 copy/move observer、不发 webhook Emit、无逐节点审计（测试断言 rewrite 全程审计零行）、无 trash 捕获/复制入队/GC-hold；④错误显式分类——空源 `ErrNodeNotFound`、dst∈src `ErrInvalidPath`、非 local 仓 `ErrRepoTypeNotSupported`，目标占用（同 sha dedup / 异 sha 时间戳新者胜 + `Conflicts` 双摘要上报）为调用方可观测量而非静默损失。
- **随迁删除**（ADR 决策 2 细则，本票定形）：dst 是 src 祖先时，严格介于两者之间的脚手架文件夹行（D-F2 形下即 `…/<pRev>/package/` 一行）清空后删除（`intermediateFolders` + 空判）——谓词消耗完整性要求迁移后源形态零残留。
- 节点属性不随迁（契约注记：conan 包树不携带；需要者须在自己的面声明）。
- 耐久性：逐行写，无跨行事务——正确性由「监听器未起」结构性保证 + 谓词消耗断点续跑（ADR 决策 1/4 授权 T-371 定形）。

### 1.3 conan 域启动 sweep（ADR-0042 决策 1/2/4）

`internal/adapter/conan/sweep.go` `SweepV1FilesLayout(ctx, svc, logger)`：

- 仓库清单走 `svc.ListRepos(repo.SystemPrincipal())`（trash 捕获同款系统身份，admin 短路不触 Authorizer），过滤 `local + package_type=conan`；**零 conan local 仓 → 零扫描零成本**（AC4 冷启动无感）。
- 单仓一次全量 List + Go 内谓词匹配（O(节点数)，ADR 决策 2 成本界）。谓词 `doubleLayoutPrefix`：`<coordinateRoot>/0/package/<pid>/0/package/<pid>/<tail>`，coordinateRoot 四段过 `parseRef`、pid 过 `validPackageID`、双 `0` 字面 + pid 重复段三重约束；尾段恰为重复 pid 的**非文件夹**行（嵌套尾巴文件，规格合法形态）排除。
- 每个去重后的源前缀一次 `RewriteSubtreePrefix`；conflict 逐条 WARN（repo/path/kept/dropped）；每仓一行 INFO `conan v1 layout sweep: repo=<key> moved=<n> dedup=<n> conflicts=<n>`（ADR 决策 4 钉死文案；conflict>0 升 WARN）。
- 失败 fail-the-boot（返回错误）：写路径已修正，未迁移树会让通道 GET（规格寻址）404——先服务劣于先失败。

### 1.4 cmd 装配缝（**不自行动 cmd/，精确 diff 移交 conductor**）

插入点：`cmd/binflow-server/main.go` `runServe`，`newAssembledServer` 与信号 context 之间（监听器起前；`conan` import 已在文件内）：

```diff
 	srv := newAssembledServer(cfg, stack, logger)
 
+	// T-371 (ADR-0042 decision 1): the conan v1 files-channel layout sweep —
+	// bootstrap order, strictly before the listener below goes up (a
+	// half-applied tree is structurally unobservable; an interrupted pass
+	// resumes by predicate on the next boot). Idempotent and predicate-
+	// consuming: zero conan repositories scans nothing, a swept instance
+	// reports moved=0. A failure fails the boot — with the write path
+	// fixed, serving an unswept legacy tree would 404 the channel GET.
+	if err := conan.SweepV1FilesLayout(context.Background(), stack.svc, logger); err != nil {
+		return fmt.Errorf("conan v1 layout sweep: %w", err)
+	}
+
 	ctx, stop := signal.NotifyContext(context.Background(), os.Interrupt, syscall.SIGTERM)
 	defer stop()
```

（context.Background() 同 L299 `warnDefaultAdminPassword` 先例；不接信号 ctx——boot 阶段无可取消面。）
