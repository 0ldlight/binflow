## 1. 做了什么

### 1.1 适配器侧 reindex 入口（统一窄接口，consumer 接口在 cmd 侧定义）

| 包 | 入口 | 语义 |
|---|---|---|
| maven | `(*Handler).ReindexDirs(ctx, p, repoKey, dirs) error`（reindex.go 新建） | 每个候选目录 = 版本目录（<org>/<module>/<version>）→ 触发版本目录重算（SNAPSHOT 生成器；release 目录 = 无 pom 清扫臂，便宜空转）+ 父模块目录重算（版本组文档，跨目录去重）。<3 段目录无法拼写坐标 → 跳过 + debug 日志（不猜坐标）。同步执行（观察者本就脱离请求路径；calculator 进程级 exec 锁串行）。calc.go 微重构：抽出错误返回形的 `recalc`（recalcSync 的日志契约不变，ReindexDirs 消费错误面） |
| npm | `(*Handler).ReindexDirs`（reindex.go 新建） | maven calculator 同款「存储事实重算」姿态：候选目录 `<name>/-/`（tgz 父）或 `<name>`（packument 父）→ 包名去重 → `rebuildPackument`：列出 `<name>/-/` 全部 tgz，**逐 tgz 读全文**（测量 sha1/sha512 + 抽取 `package/package.json` manifest），版本取 manifest（缺失回退 C8 文件名拼写 + semver 校验），dist = {tarball: 相对路径, shasum, integrity: sha512-标准 base64}；旧 packument 的顶层字段/逐版本 time/目标存活的 dist-tags 随行保留，`recomputeLatestTag` 保证 latest 指向存活版本（**notarget 翻转的精确读点**）；docMu 下 savePackument（T-249 分类器照跑）。无可索引 tgz → 空转；tgz 无 manifest/非 gzip → 具名错误（拒绝猜测） |
| deb | `(*Handler).ReindexDirs`（reindex.go 增补） | deb 索引是**属性坐标驱动**（deb.*/dsc.* 笛卡尔积），路径形候选集无法指名 distribution → 诚实重算 = 全仓 `ReindexRepository`（管理面同引擎、同 per-repo index lock）；dirs 参数收下但有意不用（接口统一性） |
| conan | `(*ManagementHandler).ReindexDirs`（reindex.go 增补） | 每个候选目录作为 rebuild 前缀走（recipe 修订根 5 段 + packageId 7 段两类都在前缀枚举里）；**包含关系剪枝**：排序候选集中被更浅目录前缀覆盖的深层目录跳过（整配方 copy 一次走查而非逐文件） |

License 豁免（照 trash 先例）：四入口 godoc 钉死 D1 服务端内部写豁免（license_gate.go：门是 HTTP 动词面的，进程内重算不再自问——trash 链/remote 落地/metadata calculators 同姿态）；入口自身不设任何 license 检查；principal 由装配侧注入（SystemPrincipal）。
