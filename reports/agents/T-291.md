### 1. MUI 引入方式

- **依赖**（`web/package.json`，lockfile 钉版）：`@mui/material ^7.3.11` +
  `@emotion/react ^11.14.0` + `@emotion/styled ^11.14.1`。无 `@mui/icons-material`
  （图标用既有字形 ✓/✕/✎/🗑，bundle 纪律）、无 x-data-grid。
- **主题桥** `web/src/app/MuiProvider.tsx`（新文件）：`createTheme` 双模式
  具体色板**逐项对齐 `src/styles/tokens.css`**（文件头钉住「改 token 必须同步」
  的契约注释）。MUI 的 augmentColor 拒绝 `var()` 引用（实测
  `Unsupported var(--bf-accent) color` 异常），故 palette 用字面量复刻 token 值；
  亮/暗切换由既有 `ThemeContext` 驱动重建（不引入 MUI colorScheme 状态机，避免
  两套主题真值）。`CssBaseline` 基线与 `base.css` 同值（字体栈/13px/背景/文字）。
  typography.button 取消大写（控制台按钮从不大写）；shape.borderRadius=6
  （--bf-r-md）；fontSize=13（--bf-fs-body 密度主字号）。
- **挂载**：`main.tsx` 在 ThemeProvider 内包 `<MuiProvider>`（必须在内——消费
  useTheme）。存量页面零迁移零改动（MUI 样式 class 作用域隔离）。
- **体积**：index chunk 340KB（gzip 111KB，含 MUI 核心）；ArtifactsBrowser 懒块
  203KB（gzip 62KB）。`make console` 汇报 SPA 总 payload gzip 284KB（5MB 预算内）。

### 2. Properties 页签（`web/src/pages/artifacts/PropertiesTab.tsx`，新文件）

- **交互（Artifactory 对齐）**：key → 多值集合表格（值以逗号分隔呈现/编辑——
  wire 形态是 `map<string,string[]>`，如实逐值呈现）；**逐属性操作流**：行内
  编辑（键锁定不可改——PUT 按 key 合并，改键 = 删旧键 + 新增行两步，tooltip
  如实说明）+ 新增行（空行待填，`+ 新增属性` 开草稿行）+ 删除（无确认弹窗，
  Artifactory 轻交互）。Enter 保存 / Esc 取消。
- **保存语义可见**（票面要求）：页签常驻 caption——「保存 = PUT（该键值集
  整体替换，其他键保留）；删除 = DELETE 该键」；编辑行 helperText 复述。
  PUT 单键 merge（§11.40）与 Artifactory 逐属性 add/remove 效果面一致。
- **校验**（与服务端 `internal/metadata/props.go` 闭集同口径，即时反馈 +
  保存钮禁用）：键 `[A-Za-z][A-Za-z0-9_.-]{0,63}`；值非空/≤1024B/无控制字符；
  单键 ≤32 值；无重复值；节点 ≤64 键；新增重复键即时提示（「PUT 会原地替换
  值集，请直接编辑该行」）。
- **权限姿态**（沿树页 W12d 先例）：`canWriteProps={!readOnly}`——readonly_admin
  预收敛 disabled + tooltip；普通用户保留写入口，服务端 403 行内呈现（MUI Alert
  + 服务端 message + 授予指引）。GET 面走内容面读门（匿名随 anonymous_access）。
- **四态**：loading（既有 Skeleton）/ 空（`node-props-empty` 引导：矩阵参数/
  REST 写入提示）/ 错误（`node-props-error`：GET 失败重试面 + 写操作信封呈现）/
  数据（`node-props-table`）。
- **挂载**：仅节点形态（目录/文件——§15.3.2 folder 可载属性；仓库根无此 Tab）。
  `NodeDetail.tsx` Tab 组扩为 常规/属性/有效权限，键盘 ←/→ ids 数组同步（admin
  渲染三 Tab）；tab 状态沿用稳定键重置语义。

## 契约漂移

1. **POST `?properties=k=v` 不存在**：`docs/user/api-reference.md:35` 与本票
   任务书都写「PUT/POST/DELETE/GET 四动词（POST 增量）」，但 router.go:594-622
   的 properties 臂只挂 GET/PUT/DELETE——POST 落 E-26 notImplemented（T-286
   日志亦称「三动词」）。FE 全部走 PUT：merge 语义下单键写即「替换该键值集、
   保留他键」，与 Artifactory 逐属性 add/remove 效果面一致，无需 POST。**请
   architect 回写 api-reference.md**（删 POST 行或注明 M11+）。
2. GET 空命中 = **200 `{"properties":{}}`**（BinFlow §15.3.3 自有裁定）vs
   Artifactory 404——FE 空态面按 200 空表实现，与契约一致（仅登记，非漂移）。
