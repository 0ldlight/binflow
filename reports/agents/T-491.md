## 1. 语义定案（票内终裁留痕——AC1 的「or 终裁」出口取票内裁定）

**桶值拼写**（锚 docs/reverse/release-bundle.md §0⑧ + §5、build-info.md §7、ADR-0046 Errata ④ E8——Artifactory 内部常量，高置信）：

| 桶 | 桶值（wire/repos[] 字面） | 语义 |
|---|---|---|
| Any Local | `ANY LOCAL` | 覆盖 class=local 的**全部**仓库 |
| Any Remote | `ANY REMOTE` | 覆盖 class=remote 的**全部**仓库 |
| Any Distribution | `ANY DISTRIBUTION` | bundle 域伪键通道（ADR-0046 点 3）：调用方把桶值字面传进 `Can` 的 repoKey 位，path 位传 bundle 名；求值**纯精确匹配**（桶值永不展开——BinFlow 无 distribution rclass） |

- **桶值不可与真仓键冲突**：仓键字符集 `[a-z][a-z0-9-]{1,62}`（repo/validate.go）不含空格。
- **第四桶 `ANY`（Anything）不实现**：console-ui.md §3.8 两步弹窗预置恰三条；Artifactory 回退链的 ANY 行登记**规格待验证**（spec-pending）。wire 侧只收三个闭集字面——`"ANY"` 落普通 unknown-repository 400，杜绝「先存量后激活」的静默翻案面。
- **分类求值（每次 Can 时解析 class）**：新建仓即刻被通配覆盖（AC1 通配生效断言的机制本体）；virtual 无桶覆盖（ANY 家族按 class 键控，无预置名 virtual——fail-closed，票内留痕）；仓键无 repositories 行 → 无桶 → 仅精确匹配。
- **E8 对位**：ANY 家族**不隐式覆盖** bundle 域——`Can(p, "ANY DISTRIBUTION", …)` 只被显式点名该桶的 target 授予；`ANY LOCAL` 桶不授予伪键（测试断言在案）。一 target 同列 `["ANY LOCAL","ANY DISTRIBUTION"]` 合法，两字面各自生效。
- **组合语义零变化**：跨 target 并联合、target 内 exclude 优先、模式语义、动词五列独立性全部不动——桶**只放宽 repos 命中**这一个维度（AC2 零提权的构造性来源）。
- **ManageCoverage 维持字面键**（rbac.go T-491 注记）：桶字面进覆盖集（`coverage["ANY LOCAL"]`），不展开到仓库全集——family-4/E6 的子集判定保持字面键代数（fail-closed 方向；展开如裁另立票）。

## 3. 探针矩阵（测试输出摘要）

**auth 级**（`wildcard_bucket_test.go`，全绿）：

- `TestWildcardBucketClassCoverage`：ANY LOCAL r 授权 → 既有 local 仓 r=true；w=false；不存在键=无桶不覆盖；**授权后新建 local 仓即刻覆盖**；remote/virtual 不覆盖；未授权用户全 denied。
- `TestWildcardBucketRemoteMirror`：ANY REMOTE 覆盖 remote 仓、不覆盖 local 仓（两桶互不渗透）。
- `TestWildcardBucketPatternSemantics`：桶 target 的 include 命中/未命中、exclude 优先——路径面语义与精确 target 完全一致。
- `TestWildcardBucketVerbZeroExpansion`：**5×5 零提权矩阵**——五个单动词授权（r/w/d/m/a 各一经 ANY LOCAL），每授权只对自身动词 true、其余四动词 false（含 m 不隐含 r/w/d/a——ADR-0026 不变量在桶面复钉）。
- `TestWildcardBucketDistributionPseudoKey`：伪键通道 r 命中（bundle 名入 path 位、`rel-*` include 按名生效）；w 拒；未授权拒；**ANY LOCAL 不隐式授予伪键（E8）**；`["ANY LOCAL","ANY DISTRIBUTION"]` 双列 target 两字面各自生效（同场）。
- `TestWildcardBucketManagePlane`：manage-only 桶授权 → 任意 local 仓（含后建仓）CanManageRepo=true；r/w/d/a 全 false；ManageCoverage 含字面 `ANY LOCAL` 且**不含**任何仓键（字面语义留痕）；?permissions 视图出 Manage-only 位（视图与 Can 一致）。
- `TestWildcardBucketInertWithoutClassifier`：`WithRepoClass(nil)` → 桶退化为精确匹配（真仓不覆盖、桶字面作 repoKey 仍精确命中=伪键对称、精确授权不受影响）。
- `TestWildcardBucketFailsClosedOnBucketRead`：精确行健康、桶行查询失败 → 整体 deny（部分数据不构成真相子集——fail-closed 姿态延伸）。

**httpapi 级**（`permission_wire_buckets_test.go`，全绿）：

- `TestPermissionWirePresetBuckets`：三桶字面逐一 POST 201（pre-T-491 全是 400——B-2.16 漂移点）；桶+真仓混列 201；`["ANY LOCAL","no-such-repo"]` 对未知条目仍 400（桶不豁免其余条目的存在性检查）；`"ANY"` 400；小写拼法 `"any local"` 400（大小写敏感=闭集字面）；GET echo 逐字回显 `ANY LOCAL`。
- `TestWildcardBucketContentPlaneProbes`（AC1/AC2 HTTP 探针）：wire 勾 ANY LOCAL（r）→ 授权用户 GET 既有 local 仓制品 200；**GET 授权后新建仓制品 200**（自动纳入）；授权用户 PUT 403（r-only 零扩权）；无权限用户 GET/PUT 既有+新建仓全 403。

## 4. 零提权证明（AC2）

1. **构造性**：桶只作用于 `repoListed`（repos 命中谓词）；`rowAllows` 五动词开关零改动——动词列的求值路径与 pre-T-491 逐字节同源。
2. **探针性**：5×5 矩阵（auth 级）+ HTTP 写 403（wire 级）+ manage-only 无内容动词（m 面矩阵）。
3. **回退性**：伪键 w 拒、未授权全拒、桶行读失败整体拒。

## 7. 遗留 / 需上游确认

1. **SearchScope 通配展开缺位（跨包，非本票 area）**：`internal/repo/search.go` 的 AQL 一段式 `SearchScope` 直接读权限表（ADR-0043 3-C 已受的「同表双读」形态），桶字面会作为字面键进 covered 集——ANY LOCAL 读授权用户的 AQL 搜索范围**不**含各 local 仓（欠报，fail-closed 方向，非泄漏；内容面 filterVisible 走 Can 已正确覆盖）。建议 5 行小票：repo 包消费 `auth.BucketForClass`/`IsWildcardBucket` 把桶字面展开进 scope（T-511 AQL build 域票可顺路）。
2. **FE 面（B-2.16 解除腿）**：T-455 的「通配桶不建」注记文案（PermissionEditorPage.tsx + i18n security.ts 两处）与两步弹窗预置行（Any Local/Any Remote——Any Distribution 归 T-514）待 FE 小票翻新；本票 BE 契约已就绪（`repos[]` 收三字面、GET 回显逐字）。
3. **`ANY`（Anything）第四桶**：规格待验证登记（§1）；若裁进=wire 白名单加一字面 + BucketForClass 两 class 扩位，翻转面已隔离在 wildcard.go 单文件。
4. **虚拟仓桶覆盖**：本票 fail-closed（无预置名 virtual class）；若对位 Artifactory 需 ANY 覆盖 virtual，与遗留 3 同票裁。
5. **T-513 联测腿（dep 注记）**：bundle 端点票消费本通道时——`Can(p, auth.BucketAnyDistribution, bundleName, auth.ActionRead/Write)` 即完整调用面（path 位= bundle 名，includes/excludes 按名生效已测试固化）；管理面双门（CapSystemWrite/CapSystemRead ∨ 通道）照 ADR-0046 点 3。
6. **性能注记**：store-backed Can 对 local/remote 仓多一次桶行 PrincipalsFor + 一次 repositories PK 读（分类）。M17 规模（千行级权限表）在 14.1.9「不缓存」预算姿态内；若 NFR 压测翻红，缓存缝位已在 ManageCoverage doc 注记的同一议题上。
