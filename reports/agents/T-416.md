## 做了什么（AC 逐条）

FR-136.3：消费 T-412 的服务端聚合面（`GET /api/storage/<virtual>` folder 面
200 children = 成员并集），把 T-406 落下的 FE 受限面解除——

1. **`tree-empty-virtual` 空态锚翻转（AC1 前半，断言反转②）**：锚不退役、
   语义自「聚合浏览暂未支持（FR-21-AC8 P2 待补）」翻转为「成员并集为空」。
   有成员内容时不再空态（走正常 children 表 = 成员并集）；无成员/全空维持
   空态，文案按 dir 层区分（根 = 成员清单提示「成员 X、Y 当前均无内容…」；
   深层空目录 = 「此路径在成员仓库中无内容」）。成员清单仍读自
   configuration.repositories 规范回显（T-406 既有缝）。
2. **RepoBranch virtual 恢复动态展开（AC1 后半）**：T-406 的静态化（twisty
   降级占位、无子级区）整体退役——virtual 仓与非 virtual 仓同形（twisty
   按钮 + aria-expanded + 子级区）；内容面 gate 同步解除（loadDir effect
   不再以 isVirtual 拦截）。
3. **删除入口预收敛（票内新增语义，RE-08）**：virtual 仓行内删除钮 /
   NodeDetail 删除钮（canDelete）不渲染；右键菜单删除项 disabled + title
   「virtual 仓不经手删除（RE-08，服务端 405）」。依据 = 服务端真相
   `refuseVirtualDelete`（DELETE 一律 405 + Allow: GET，spec 内钉死）——
   不给注定失败的影子入口。右键判定按**目标** repoKey 查仓库清单（左树
   跨仓目标，非当前仓 rclass）；清单 403（普通 user 深链）时查不到 →
   不预收敛、交给服务端 405 原样呈现。
4. **loadDir effect 跨仓根展开收口（顺手修复，先于本票存在的缺口）**：原
   effect 以 `!repoKey` 早退——跨仓根（未选仓）手动展开任一仓的 twisty 会
   永远转骨架（对全部 rclass 同形，T-236 起即在；virtual twisty 恢复后该
   缺口从「 cosmetic」升级为「主路径不可用」，本地仓实测同样复现）。修复
   为「选中仓根 + 祖先链 ∪ 手动展开集」，行为只增不改。
5. **`.warn-box` 文本对比度清账**：virtual 浏览面常驻 warn-box（T-236 起）
   的裸 `--bf-warning` 文本色在亮色 8% 底上 <4.5:1（axe serious）——本票
   新增的 axe 腿首次扫描该面时暴露。对齐 base.css 徽章族既有配方
   `color-mix(in srgb, var(--bf-warning) 78%, var(--bf-text))`（同 token 对
   同比例；亮 ≈6.1:1 / 暗 ≈7.4:1）——T-391/T-414 color-mix 收口同款先例。

  成员列表」），若后续要真区分需 httpapi 面改 echo（另立小票，非本票面）。
