## 3. CG-2 失败分类出处锚定（T-316 硬前置——cargo 源在 reverse-src，无需降级）

取证范围：`batch2-protocol/org/jfrog/repomd/cargo/**`（LocalRepoHandler/ResponseUtils/publish model/SubResource）+ `batch3-addons/org/artifactory/addon/cargo/**`。逐类：

| 失败类 | Artifactory 响应 | 出处（类+行为） |
|---|---|---|
| 重复版本，principal **无** d 权限 | **401（匿名）/403（实名）** + errors 信封（`unauthorized user`/`forbidden`） | `CargoLocalRepoHandler.publish`：`isForbiddenOverwrite` 短路 → `CargoResponseUtils.forbidden(isAnonymous)`；`isForbiddenOverwrite`= `repoService.exists && !canDelete` |
| 重复版本，principal **有** d 权限 | **覆盖上传**（走正常链，无冲突臂、无 409） | 同上条件不成立即继续 → upload |
| 无写权限（canWrite=false） | 401（匿名）/403 + errors 信封 | `publish` canWrite 分支 → `forbidden`（匿名分支恒 `forbidden(true)`=401） |
| 解帧/元数据解析失败（畸形 JSON、连接中断——**IOException 族**） | **200** + `{"warnings":{"invalid…":[…],"other":["Failed to publish with error '<msg>'"]}}`——错误串入 `warnings.other`，**无顶层 errors 键** | `publish` 尾 `catch (IOException)` → `errors.add(...)` → `CargoResponseUtils.published(errors)`；`CargoPublishResponse` 模型仅 warnings 嵌套（三列表），`published()` 第三参即 `other` |
| 落盘/长元数据写失败（IOException） | 同上 200+`warnings.other` | 同一 catch 覆盖 `CargoUtil.writeLongMetadata`/`repoService.upload` 的 IOException |
| upload 返回非 201 | 401/403 forbidden（复用 forbidden 面） | `publish`：`res.getStatus()!=201` → `forbidden` |
| 帧长度前缀畸形（RuntimeException 族，如 4 字节前缀不足） | 未被 catch——穿透 Jersey 通用异常映射（500 形态；ExceptionMapper 细节未取证，降级声明） | catch 面仅 IOException；`readLittleEndianInt` 短读抛 RuntimeException |
| remote search 上游异常 | **409** + errors 信封 | `CargoRemoteRepoHandler.search` Exception 臂 → `CargoResponseUtils.conflict(msg)`；上游 RestException → 透传上游码（`error(status, msg)`） |
