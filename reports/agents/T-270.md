## 1. Q6 终裁实现：goreleaser 预编译双架构注入（全程零 qemu）

```
make release VER=v1.0.0-t270        # goreleaser 六平台原生交叉编译（CGO_ENABLED=0）
        │  dist/binflow_v1.0.0-t270_linux_{amd64,arm64}.tar.gz
        ▼
deploy/release/build-release.sh
  ① 解出双 arch binflow-server（amd64 18.9MB / arm64 17.8MB，Mac 基准）
  ② Dockerfile.assets 原生(amd64宿主)构建一次 → docker cp 拆出 CA/tzdata/passwd/group
  ③ 双架构基镜像按 digest 解析（alpine / distroless 各 amd64+arm64 manifest digest）
  ④ 每变体×每arch：plain docker build——运行时阶段 ZERO RUN，arch 由 FROM <ref>@<digest> 钉死
  ⑤ per-arch push → docker manifest create/annotate/push → BinFlow docker-local(:8080)
  ⑥ 验证：manifest 双 platform 断言 + registry config blob architecture 字段断言 + 冒烟
```

关键机制（使 2C VM 无 buildx/无 binfmt 也能产 arm64 镜像）：
- **运行时阶段零 RUN**：alpine/distroless 两个 prebuilt Dockerfile 的最终阶段只有 COPY —— arm64 构建不执行任何 arm64 指令（VM 实测：legacy builder + 空 binfmt_misc，alpine-arm64 4s / distroless-arm64 12s）。
- **digest 钉死基镜像**：`--build-arg ALPINE_BASE=<mirror-ref>@sha256:<arch-digest>` —— legacy builder 无 `--platform`，digest 引用即平台真值（两台主机实测产物 `Architecture=arm64`）。
- **assets 原生构建**：apk add 只在宿主原生平台跑一次，产出与 arch 无关（CA/tzdata/passwd 文本），per-arch 上下文复用。
- **healthcheck-probe 提源**：T-132 distroless Dockerfile 内联 heredoc 的探针提为 `deploy/release/healthcheck-probe/main.go`，脚本本机交叉编译（GOOS/GOARCH，无 qemu）。
- 基镜像走 daocloud 镜像（`docker.m.daocloud.io`/`gcr.m.daocloud.io`）——本环境 registry-1.docker.io / gcr.io 均不可达；可用 `ALPINE_SRC`/`DISTROLESS_SRC` 覆写回官方 ref。
- `docker manifest` 子命令是 CLI 侧直连 registry：对 BinFlow 的纯 HTTP 端口必须 `--insecure`（daemon 的 insecure-registries 不被它读取；`manifest rm` 无此 flag，勿传）。

## 5. 踩坑（后续复用）

1. `python3 - arg <<PY` 内再用 `json.load(sys.stdin)`——heredoc 已占 stdin（程序源），管道/重定向的 JSON 永远读不到；解析函数一律收文件路径参数。
2. GNU `mktemp -t name` 要求模板至少 6 个 `X`（BSD 任意后缀）——跨平台模板写 `name.XXXXXX`。
3. `docker manifest rm` 无 `--insecure` flag（create/push/inspect 有）；误传被 `|| true` 吞掉 → 旧本地 list 残留 → `manifest create` 拒绝 "refusing to amend"。
4. `ALSO_LATEST` 起初用 `latest-<variant>-<arch>` 当 children——per-arch 从未以该 tag 推过；latest list 应引用**版本化** per-arch children。
5. `docker build` 的 context 会整个 tar 上传：Dockerfile.assets 无 COPY，context 必须给空目录（repo 工作树 ~1GB docs-site 产物曾拖死 phase 2）。
6. `${REGISTRY:-default}` 会把显式空串变成默认值；"空=仅本地"语义必须用 `${REGISTRY-default}`。
7. push-jobs.sh 的 config.xml `<properties/>` 为空——job 推送后参数被清，首轮 `buildWithParameters` 400 "not parameterized"；跑一次 plain build 让 declarative `parameters{}` 物化后即恢复（T-248 已踩过同款，本轮又实证一遍）。
8. Jenkins agent 容器看不到宿主 `/home/lzw`——只读挂载只有 bare repo；中转文件放 `/srv/jenkins/`（= 容器 `/var/jenkins_home/`）。
9. daocloud 镜像 manifest inspect 时段性 >80s——digest 解析已加 3 次重试（失败样本与慢样本都实测过）。

## 6. Jenkinsfile 全文（binflow-release，内联 Pipeline script 归档）

```groovy
// binflow-release - T-248 tag release job, upgraded by T-270 (FR-83-AC2 /
// M9 Q6): multi-arch linux/amd64 + linux/arm64 images via PREBUILT injection.
//
// Chain: checkout bare repo -> T-270 overlay (release-chain files from the
// working tree until the conductor commits them) -> make console -> make
// release (goreleaser 6-platform archives) -> deploy/release/build-release.sh
// (per-arch zero-RUN image builds — NO qemu on this VM; per-arch push +
// manifest create/annotate/push into BinFlow docker-local) -> verification
// (docker manifest inspect platform entries + registry config architecture
// fields) -> smoke (amd64 run + arm64 qemu probe with graceful field
// fallback) -> dogfood (pull the multi-arch tag back from BinFlow, run,
// /readyz + version stamp).
pipeline {
  agent any
  options {
    timestamps()
    timeout(time: 90, unit: 'MINUTES')
    buildDiscarder(logRotator(numToKeepStr: '20'))
  }
  parameters {
    string(name: 'TAG', defaultValue: 'v1.0.0-t270', description: 'Release version (feeds make release VER=<TAG> and the image tags)')
    string(name: 'ARCHES', defaultValue: 'amd64 arm64', description: 'Target architectures, space-separated (default: amd64 arm64)')
    string(name: 'VARIANTS', defaultValue: 'alpine distroless', description: 'Image variants, space-separated (default: alpine distroless)')
    booleanParam(name: 'ALSO_LATEST', defaultValue: true, description: 'Also push the multi-arch manifest as latest-<variant>')
  }
  environment {
    GOPATH      = '/var/jenkins_home/go'
    GOCACHE     = '/var/jenkins_home/.cache/go-build'
    GOPROXY     = 'https://goproxy.cn,direct'
    GOTOOLCHAIN = 'local'
    npm_config_cache = '/var/jenkins_home/.npm'
    BF_REG      = '172.16.58.129:8080/docker-local'
    APK_MIRROR  = 'mirrors.tuna.tsinghua.edu.cn'
    // docker run -p publishes on the docker HOST; from inside this agent
    // container the published port answers at the host IP (T-248 pitfall 7).
    SMOKE_ADDR  = '172.16.58.129'
    SMOKE_PORT  = '18092'
    RELEASE_TAG      = "${params.TAG ?: 'v1.0.0-t270'}"
    RELEASE_ARCHES   = "${params.ARCHES ?: 'amd64 arm64'}"
    RELEASE_VARIANTS = "${params.VARIANTS ?: 'alpine distroless'}"
    PATH        = "/usr/local/go/bin:/usr/local/ci-bin:${env.PATH}"
  }
  stages {
    stage('checkout') {
      steps {
        checkout([$class: 'GitSCM',
                  branches: [[name: '*/main']],
                  userRemoteConfigs: [[url: '/home/lzw/binflow.git']],
                  extensions: [[$class: 'CleanBeforeCheckout']]])
        sh 'git log -1 --oneline && echo CHECKOUT_OK'
      }
    }
    stage('T-270 overlay (release chain, pre-commit)') {
      steps {
        sh '''#!/bin/bash
set -e
if [ -f /var/jenkins_home/t270/t270-overlay.tar.gz ]; then
  tar -xzf /var/jenkins_home/t270/t270-overlay.tar.gz -C .
  echo "OVERLAY_APPLIED"
  sha256sum deploy/release/build-release.sh .goreleaser.yaml
  ls -la deploy/release/
else
  echo "OVERLAY_MISSING — T-270 overlay no longer present; if the release chain is already committed, drop this stage"
  # not fatal once the files are committed: only fail if the script is also absent
  test -f deploy/release/build-release.sh || exit 1
fi
'''
      }
    }
    stage('console chain (embed real SPA)') {
      steps {
        sh '''#!/bin/bash
set -e
echo "CONSOLE_START $(date +%s)"
make console
echo "CONSOLE_END $(date +%s)"
'''
      }
    }
    stage('archives: 6 platforms + checksums (make release)') {
      steps {
        sh '''#!/bin/bash
set -e
echo "RELEASE_START $(date +%s)"
make release VER="$RELEASE_TAG"
echo "RELEASE_END $(date +%s)"
ls -la dist/ | sed -n "1,20p"
'''
      }
    }
    stage('multi-arch images + manifest (build-release.sh, no qemu)') {
      steps {
        withCredentials([usernamePassword(credentialsId: 'binflow-ci-bot', usernameVariable: 'BF_USER', passwordVariable: 'BF_PASS')]) {
          sh '''#!/bin/bash
set -e
export DOCKER_USER="$BF_USER" DOCKER_PASS="$BF_PASS"
export REGISTRY="$BF_REG" ARCHES="$RELEASE_ARCHES" VARIANTS="$RELEASE_VARIANTS"
export APK_MIRROR SMOKE_ADDR SMOKE_PORT
if [ "${ALSO_LATEST}" = "true" ]; then export ALSO_LATEST=1; else export ALSO_LATEST=0; fi
echo "MULTIARCH_START $(date +%s)"
./deploy/release/build-release.sh "$RELEASE_TAG"
echo "MULTIARCH_END $(date +%s)"
'''
        }
      }
    }
    stage('dogfood verify (pull multi-arch tag from BinFlow + run + readyz)') {
      steps {
        sh '''#!/bin/bash
set -e
IMG="$BF_REG/binflow"
docker rmi "$IMG:$RELEASE_TAG-alpine" 2>/dev/null || true
echo "--- pull the multi-arch manifest tag (daemon resolves linux/amd64 on this host)"
docker pull "$IMG:$RELEASE_TAG-alpine"
docker image inspect "$IMG:$RELEASE_TAG-alpine" --format "resolved platform: {{.Os}}/{{.Architecture}}"
docker rm -f t270-dogfood 2>/dev/null || true
docker run -d --name t270-dogfood -p 18094:8080 "$IMG:$RELEASE_TAG-alpine"
ok=0
for i in $(seq 1 30); do
  if curl -sf http://172.16.58.129:18094/readyz >/dev/null 2>&1; then ok=1; break; fi
  sleep 2
done
[ "$ok" -eq 1 ] || { docker logs t270-dogfood; exit 1; }
echo "readyz: $(curl -s http://172.16.58.129:18094/readyz)"
echo "version: $(curl -s http://172.16.58.129:18094/binflow/api/system/version)"
docker logs t270-dogfood 2>&1 | head -5 || true
docker rm -f t270-dogfood
'''
        withCredentials([usernamePassword(credentialsId: 'binflow-ci-bot', usernameVariable: 'BF_USER', passwordVariable: 'BF_PASS')]) {
          sh '''#!/bin/bash
set -e
curl -sf -u "$BF_USER":"$BF_PASS" "http://172.16.58.129:8080/v2/docker-local/binflow/tags/list"
echo
'''
        }
      }
    }
  }
  post {
    always {
      archiveArtifacts artifacts: 'dist/binflow_*.tar.gz,dist/binflow_*.zip,dist/binflow_*checksums.txt', allowEmptyArchive: true, fingerprint: true
      cleanWs(notFailBuild: true)
    }
  }
}
```
