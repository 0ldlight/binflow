## 1. AC1 — 翻转实现（403→409，四臂语义照 §5.1）

### 1.1 根因与修法（一行核心）

as-built 403 的根因 = `flat.go servePush` 把 `h.writeError` 共享映射套在包体 Put 上（服务层 overwrite 门
ErrForbidden → 403）；且该面还把客户端 `X-Checksum-*` 头透传服务层（`expect`），同字节+声明摘要==存量
时走幂等重传短路答 201——正是 T-378 在 v2 面摘除的同款分歧。修法照 T-378 手法：**存在探针 + 零值
BlobRef + 409 定点映射**。

### 1.2 变更明细（internal/adapter/nuget/flat.go）

| 位置 | 变更 |
|---|---|
| `servePush` | ① 包体 Put 声明摘要 `expect`（客户端 X-Checksum-\* 透传）→ **`storage.BlobRef{}` 零值**（D-10 同族同则——幂等重传短路被摘除，重复臂 byte-blind 由构造保证）；随之 `declaredDigests` 调用从本面移除（v2 面 T-378 同款姿态；该头族无 NuGet 客户端发送，bare content 面 `serveBareContent` 契约原样不动）。② Put 前 `duplicateArmProbe` 存在探针；错误映射新增 `existed && ErrForbidden` → **409**（其余错误照旧走 `writeError`）。③ 签名 `_ string` → `class string`（探针需要 rclass）。doc 注释补 §5.4/Q6 锚 |
| `msgPushDuplicate`（新 const） | **`A package with the provided ID and version already exists`** ——A1 官方逐字（Learn「Push and Delete, NuGet API」响应表原文，T-393 全文复核存档）。**规格文案非空 → AC1 的 v2 族 `Package already exist:` 回落形态未启用**（票内留痕：两 push 面各持各的锚，v2 面 DE 逐字文案不动） |
| `duplicateArmProbe`（新方法） | arm ② 的 exists 半边（!canDelete 半边 = 服务层 overwrite 拒绝）。**仅可写类探询**：local 直探；virtual 先查 `virtualDeployTarget` 路由（未路由不探，§5.1 virtual 行同款前置）；**remote 一律不探**——remote push 由服务层只读门（405）裁决，且探针读会触发 pull-through 上游接触（副作用零容忍，AC3 其他面零触碰） |

维持不动：③ d 权限覆盖 201（服务层 overwrite 门放行，sidecar `SkipOverwriteCheck` 原样）、④ 新包 201、
addressed/direct 两形态同面同臂、nuspec 身份冲突 400、multipart unwrap、addon 门。
