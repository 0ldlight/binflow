## 做了什么

httpapi 的 AQL 薄路由壳（架构 §24.2 的 handler 段）：

1. **路由**：`POST /binflow/api/search/aql`（router.go search 族新增 POST 成员，routeAuth{}——匿名两臂归 handler）；外异动词保持 E-26 404（search 族既有姿态）。
2. **参数解析**：text/plain body（不做 Content-Type 门——活体 curl 多种 CT 都过）→ body 空时回退 `?query=`（aql.md §1，v4c 实证）；body 经 `LimitReader(MaxQueryLen+1)` 硬上限读取，超限直接答 E4 文案（与 parser 单点文案有 parity 测试钉同步）；双空 → E2 `Bad Request` 逐字（v4a 现值；E3 新路径不实现，票面口径）。
3. **匿名门两臂**（E5/E6）：闭环实例 401 `Authentication is required` + Basic challenge；开实例匿名 403 `Only non-anonymous users are allowed to access AQL queries\n`（尾换行逐字，反编译单源，置信中——按票面 V-c 全集实现）。均先于 body 消费（垃圾请求不占资源位）。
4. **错误映射**（ADR-0043 pt6 + Errata ⑤）：`*search.QueryError` → 400（文案 = parser 单点组装，E1/E4 逐字样本有断言）；`ErrResourceBusy` → 429 + `Retry-After: 1` + body `too many requests` 小写逐字；`ErrQueryTimeout` → **408**（非 503/504）；`repo.ErrForbidden` → 401 臂（纵深防御，正常不可达）；其余 500 带日志。
5. **成功 envelope**（aql.md §3，t407 证据逐字节复刻）：前缀 `\n{\n"results" : [ `、行间 `},{`、行闭 `}` 列 0 + ` ],`、空集 `[  ]`、range 尾块、结尾 `\n}\n`；日期回显归一 ISO8601 毫秒 UTC（+08:00 偏移会归一到 Z）；`?compact=true` 只压行体与 range（外层包裹不变）；数字字段裸数字。
6. **投影渲染**：经 `Plan.Output` 回显序逐字段；默认输出无 `modified_by` 键（T-411 留给本票——无源不伪造，测试断言键缺席）；property 投影聚合为单一嵌套 `"properties" : [ {key,value} ]` 成员（stats 域嵌套先例 v16 形态；空集 `[ ]`）；`virtual_repos` 数组（空集 `[ ]`，v05 形态）。
7. **virtual 语义（133.5）**：`virtualIndex`（httpapi 内建，消费 metadata.RepoStore + Virtual().ListMembers）= 引擎的 `VirtualResolver`（§7-1 成员展开，编译期）+ 端点的 member→virtuals 反查投影（§7-3）。**查询目标是 virtual 时 `virtual_repos` 隐式入输出**：resolver 经 ctx 收集本请求展开过的 virtual key，Run 返回后据此补投影（range 比较符不触发展开的边角除外——已留痕）。
8. **引擎装配**：`httpapi.New` 内从既有 Deps 自建引擎（`Metadata.Nodes().(NodeQueryer)` + `ReposSvc` ACL 缝 + virtualIndex）——ADR-0043 §24.1「httpapi 唯一装配点」，**cmd 零改动、Deps 零新字段**（session/permView facet 先例）→ fake blast radius 为零。无引擎栈答诚实 503。
9. **metrics**（ADR-0043 pt8）：`binflow_search_queries_total{plane="aql"}`（含 400 在内每次执行计数）+ `binflow_search_query_duration_seconds`（histogram，无标签维度，照 ADR 字面）+ `binflow_search_rejections_total{reason="concurrency"|"timeout"}`（均预播种）；慢查询 >5s 单行 WARN（200 字符 query 摘要 + duration_ms；metrics-less 栈也照发日志）。T-92 两端点零改动零迁移（同包全量绿）。
10. **WriteTimeout**（ADR-0043 pt7/T-392）：维持不设全局 WriteTimeout（引擎 deadline 已治），新增 pin 测试（WriteTimeout==0 且 ReadHeaderTimeout==10s）。

## 遗留 / 需上游确认

1. **截断语义口径**：T-413 as-built——用户 `.limit(n)` 小于原始行数也置 Truncated（「原始行序仍有余量」的诚实上界），此时 notification 的官方文案「reached the search hard limit」读起来略错位（用户 limit ≠ 硬上限）。行为按引擎冻结语义钉死在测试；文案口径可随 K63/Q2 回写再裁。
2. 429/408 的 e2e 腿用 stub runner 验证映射（真门 4 并发在 SQLite 小语料下无法确定性饱和——aql.md V-a 同口径）；真实并发饱和腿归 T-413 的 8 路混合。
3. `virtual_repos` 隐式输出的判定 = 本请求编译期确有 virtual 展开发生；repo 上的 range 比较符（`$gt` 等）不触发展开（planner 限定 value-exact 展开）→ 该边角无隐式输出，与 §7-3「查询目标是 virtual」的极狭义解释有差，留痕。
4. 慢查询 WARN 的 >5s 阈值无法 e2e 触发（10s 引擎 deadline 内的确定性慢查不可造）；阈值+摘要逻辑以单元钉住。
5. T-417 落地时 metrics `plane` 标签扩值（老三端点）——本票已预播种 `plane="aql"`。
