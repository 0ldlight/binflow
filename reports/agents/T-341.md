## 5. 差异登记（BinFlow 侧有意/受限偏离）

1. **search 出站不带上游凭据**：RemoteConfig 密文 cipher 在引擎内（适配器无解密缝）；helm external-egress 同款姿态。公开源（nuget.org/BaGet/MyGet）匿名可用；带凭据源（Azure Artifacts）搜索回落落地事实/空集。**需上游（conductor/architect）裁量的候选缝：引擎暴露凭据化的出站客户端接口**。
2. **remote 搜索回落=200 空集**：svc.List 仅 local 仓（T-337 已登记的同款限制），remote 仓上游故障时无法枚举落地包；§8.1-6「贡献空」的 v3 读法（200 JSON，非 v2 面的 404 家族）。
3. **PackagePublish/2.0.0 @id 维持 flatcontainer 基**（T-287 dotnet 实证落点），不取 §9.1 表的 v2 行——切到 v2 根会破 dotnet 8 raw-body push（v2 publish 根期望 multipart `package` 字段）。
4. **virtual 合并的 remote leaves 锚定成员自身基**（flatcontainer-of-member，T-287 首中解析语义），§9.4 的 v2-Download 臂只落在单 remote 仓面（规格直接语境）。
5. **feed join 固定为 `<repo.url>/v3/index.json`**（xsd 默认 v3FeedUrl 的相对拼写）——不新增 per-repo 配置键；异构挂载点的源以 index 内 @id 自适配，唯 index 自身路径是约定（登记：如需精确对齐 Artifactory 的 v3FeedUrl 全 URL 覆盖，需 metadata 加列，跨包）。
6. **层阶单向性**（版本化→plain，§9.2）：仅含 `/3.6.0` 的退化 index 在 plain 形上取 nuget.org 族回落常量（真实 index 均含 plain 型；TestV3Ladders 冻结）。
7. **M10 断言翻转（spec 承载，非回归）**：remote registration 的 packageContent 改写目标 flatcontainer → **v2 Download**（§9.4），TestRemotePullThrough 断言随之翻转；TestGateInternalWriteExemption 的落地 marker 断言与接触计数（1→2：index+registration）同属规格驱动。
8. **旧 T-287 marker 布局孤儿化**（`<id>/.registration`、`<id>/.page/…`、remote canonical `<id>/index.json`）：新代码不再寻址，随 TTL 自然过期（纯缓存，无数据丢失）；`.page` wire 拼写保留兼容路由一个发布期。
9. **virtual 成员下载的服务层缝**：svc.Get 的成员首中解析仍 canonical join（引擎无绝对 URL 取数 facet——helm remote.go 同款登记）；适配器在其未中后补动态 marker 走查补齐（live 矩阵验证），彻底解需引擎 facet（跨包，遗留）。
