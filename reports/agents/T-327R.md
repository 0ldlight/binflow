## 1. 实现（internal/httpapi/repositories.go）

**方案选型：平铺类型化字段，不建子对象。** 依据三证：①适配器 probe 平铺读 config blob（deb/reindex.go RepoConfig、rpm/reindex.go RepoConfig 均 `json.Unmarshal(blob, &probe)`）——子对象会迫使读侧改动（越界）；②configJSON local 臂既有惯例就是平铺 setter 族（maven policy family 同形）；③Artifactory REST 仓配置这些键即平铺字段名（docs/reverse/debian.md §5 / rpm.md §2.4、§3.2、§4 的拼写逐字）。

- `repoConfig` 传输结构体新增 10 个字段（deb 6 + rpm 4，含 D-B 未点名但同族的 `optionalIndexCompressionFormats`），**指针类型**（`*bool`/`*int64`）保 explicit false/0 与 absent 可区分——load-bearing：`calculateYumMetadata` 产品默认即 false，关掉自动重算的更新必须活过往返，否则 409 分支开得起关不掉。
- `configJSON` local 臂补 10 个 setter 调用 + 新 `setStrSlice`（`optionalIndexCompressionFormats` 显式空数组 `[]` 要落库，与指针语义一致）。
- **只挂 local 臂**：deb/rpm 索引引擎只服务 local（reindex 家族拒 remote、virtual 读成员自身树），与 QuotaBytes 的臂位注释同口径。
- 键在 local 臂**不分 packageType**（maven family 同款姿态：debian 键落在 rpm 仓 = 存而忽略，caller-owned blob 契约）。
- GET 回显零改动：local 行本来就照搬 config blob（`repoConfigOf`/`repoListItemOf`），PUT 落进去 GET 自然带出来——D-B 的「GET 无该键」纯粹是 PUT 从未写入。
- 路由面核对：票面写 `PUT /api/v1/admin/repositories`，实际仓配置面是 `PUT|POST /binflow/api/repositories/{key}`（router.go 638-674；`/api/v1/admin/*` 只承载 security/auth-config 族），两动词共用 `repoConfig.configJSON` 单一咽喉——本修即全覆盖。

## 2. 行为对齐与差异登记

1. **票面 `byHash=strong` 非法**：规格枚举为 `ALL`/`SHA256`/`NONE`（debian.md §5，高置信——代码枚举 + inv-3 双证）。真测按 `SHA256` 驱动（顺带钉住 Release 裁剪联动 §4.1）；`strong` 等未知值走适配器 `normalized()` 落 NONE。
2. **mistyped 键从静默丢弃变 400**：键成为传输契约面后，类型错（`"byHash":123`）在 body decode 即败、字段名进错误文案——与 D-B 之前「200 后丢键」相反。测试钉住该 400；**真正未知键维持 scenario-D 容忍**（200 + 不落库），测试同样钉住边界。
3. **值域校验缺口（登记，不在本票修）**：`byHash` 任意字符串照存 verbatim、行为按 NONE——local blob 是 caller-owned、校验按架构归 repo.Service（`validateLocalConfig` 只查自家 cross-cutting 字段）。若要 Artifactory 式配置期枚举拒绝，需 repo 侧小票（transport 纪律不动它）。

## 4. 新发现（引擎侧，建议开小票）

**by-hash 保留桶混族裁剪**（deb reindex.go sweepDist）：保留按 `by-hash/<ALGO>` 目录计 newest `historyCycles`，而该桶混装同一索引族的 plain + .gz + 可选压缩拼写（本次 3 个文件/代）。`historyCycles < 每代拼写数` 时（如 cycles=2 + xz 伴生），当代文件按 UpdatedAt 全并列 → 保序任意/字典序，**当前代的 by-hash 拷贝可被裁掉**——违反规格「当前版必须可取」（debian.md §5，官方地板）。此前被默认值掩护（cycles=3 ≥ plain+gz 的 2），REST 解锁 `historyCycles` 后暴露。归 deb 引擎侧（本票纪律不动适配器），建议小票：按「索引文件 × 算法」分桶或显式保护当代。本票测试已按拆仓规避（byHash 键与压缩族键分仓断言）。
