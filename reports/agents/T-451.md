## 1. 做了什么

### 1.1 共享 Pager（AC1——§11.2 冻结形态逐项）

- **web/src/components/Pager.tsx（新建）**：页码序列（MUI Pagination，
  当前页 aria-current 高亮）+ 首/上一页/下一页/末页钮（showFirst/Last）+
  每页行数选择器（档位冻结见 §0）；**边界态**：首页 first/prev 禁置、
  末页 next/last 禁置、单页全量全链禁置——禁置不隐藏（P7）；锚族
  pager-range / pager-size / pager-size-\<n\> / pager-first / pager-prev /
  pager-next / pager-last / pager-page-\<n\>（固定名跨面复用，一面同刻唯一；
  renderItem 赋值形态落锚——对账器 src 提取口径）。
- **useClientPager 钩子**：全量已取回面的窗口化（epoch 派生回零——
  结果集标识变了即回落第 1 页，无 effect 回零；缩水夹取末页；换页大小
  回第 1 页）。调用方 epoch 走**字符串键**（数据形态 × 过滤 × 排序——
  同形刷新不丢页位；吊销翻态不丢页位）。
- **流式末页语义（语义 C 注的呈现层）**：total 未知面（audit keyset /
  AQL 流式 total=本页行数）range 行如实「（末页未知）」+ 页数 = 前沿+1
  逐页揭示 + 末页钮 title 注记——呈现对齐、语义自有。

### 1.2 消费点 ×8 迁移（AC1）

- **搜索基本模式**（ResultsTable）：slice/「加载更多」→ useClientPager
  页窗（pageSize prop = 初始档；search-pager 根锚维持挂 Pager；快滤注记
  续挂；选择列全选语义 = 当前页窗）。
- **AQL 模式**（AqlPanel）：页码 N → `.offset((N-1)×limit)` 尾缀重写、
  每页行数 → `.limit(n)` 重写**并清 .offset 回第 1 页**（旧 offset 在新
  页大小下指向错位窗口）——查询文本仍是唯一事实源；手写非档值 limit
  （如 .limit(2)）如实在选择器在场（不显示空白）；range 回显行
  （start_pos/limit/流式 total）原样保留。
- **审计**（AuditPage）：useAuditPages 窗口化改版——**keyset 游标链页窗**
  （cursors[k-1] = 取第 k 页游标；前沿逐跳推进〔每跳一次 keyset 取数，
  offset 扫描成本规避〕、向后直跳已缓存游标；过滤/页大小/刷新 = 链重建
  回第 1 页；alive 旗标晚到丢弃〔B1 竞态守卫语义保持〕）；path 过滤语义
  随窗口化改「仅作用于本页窗口」（audit-count 文案同步）；页脚根 =
  audit-pager（新锚）。
- **repos/users/groups/perms/tokens**：计数行升级为统一控件（根锚零改名；
  p → div〔p 内不得嵌 div——HTML 合法性〕）；tokens 保留「含已吊销 N」
  注记、perms 保留 m-holder「（管理范围内的权限 target）」注记、repos
  保留过滤注记。
- **退役 4 锚**：search-more / search-aql-prev / search-aql-next / audit-more
  （§10.6 退役总表 101 → 105 条）；**tree-load-more 维持增量**（分治豁免，
