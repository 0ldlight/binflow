## 关键决策

1. **对齐基准切换**：M1 兼容矩阵对齐「Artifactory 行为」，M2 对齐「distribution/OCI 官方 spec」——层级定义、错误体（spec `errors[]` 码表）、DE 矩阵列全部照此口径；错误体由此变为**四域并存**（E-01 / 用户管理纯文本 / OAuth / spec 错误体），在 §5.2 开头显式记分层，避免实现者混用（NFR-S10 验收）。
2. **Q1 路由冲突两案全量对比**（§7）：按 ADR-0008 预告展开反代 rewrite vs 根级例外两案的七个维度（客户端指向/裸机可用性/token realm/前缀纯度/E-26 回归口径/同域共存/行业先例），标注**待用户定案 → ADR-0010**；PRD 立场写明倾向方案 B 及理由，但 D 序列命令设计成「仅 REG 变量取值随方案变化，期望输出不变」，降低定案后的回写成本。
3. **M1 遗留逐条定界**（§6.4）：O1 纳入（P1，断开日志定界）、O2 纳入部署烟测（干净环境默认端口复跑留档）、O3 纳入（P2，gc -c 与 --grace-hours）、O4 维持现语义不改码（记为既定产品语义，M4 统一评审）、Content-Type 映射纳入（P2）、T-18 O2（409 vs replace）显式归档为自有语义并交 tech-writer 差异说明——无一条悬空。
4. **存储/认证零返工复用**：blob 与 generic 同池去重（跨协议去重 AC：D11 变体）、chunked 会话复用 `sessions/`（state.json 非 compat 承诺，bump version 即可，依据 ADR-0006 勘误）、token realm 复用 M1 `/binflow/api/security/token` 不新建 `/v2/token`（DE-13 混合层级标注）。
5. **跨 repo mount 纳入 M2**（FR-8-AC6/D13）：spec 明文且 crane/oras 高频路径，砍掉会直接伤 conformance；referrers API 显式不做（DE-15，404）。
6. **Non-goals 硬边界**：remote/virtual docker（M3）、manifest 级联 GC（M4，M2 靠 grace GC 语义够用）、blob DELETE 有意 405 UNSUPPORTED（DE-14，GC 唯一物理删除入口的 ADR-0006 安全底线）。
