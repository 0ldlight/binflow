## 1. 设计决策

1. **单源脚本 + 双 CI 引用**：`ci/protocol-matrix.sh` 是唯一协议逻辑载体；CircleCI job 与 GH workflow 只做「装工具链 → 调脚本」。两面对同一 UAT（52.79.109.153:8080）跑同一矩阵，不可能漂移。
2. **版本戳幂等**：每次运行 `VER=1.0.<UTC 时间戳>`（go 腿 `v` 前缀），推全新坐标——BinFlow 拒绝同版本覆盖（npm E403 / pypi 400 / nuget 409 是产品语义），时间戳使矩阵仓**保留即可复测**（票面裁定：不清理，历史随部署累积）。仓创建走 PUT upsert（实测二次 PUT 同 body → 200，幂等）。
3. **CircleCI 用 machine executor 而非 docker executor**：docker 腿需要可配 daemon（明文 HTTP UAT 需 `insecure-registries`；`setup_remote_docker` 的托管 daemon 无 daemon.json 入口）——docs/user/docker-registry.md「dind 启动旗标」同源姿势，VM 上 `systemctl restart docker` 生效；JVM/.NET/conan 工具链原生安装。
4. **每腿独立、失败不掩盖**：CircleCI = 十个 `when: always` step；GH = `strategy.matrix` 十腿并行 `fail-fast: false`。脚本层腿间亦独立（子shell `set -e`，`run_leg` 收集 rc，报告 TSV 累积到 `report.log`，末步 `--report` 汇总）。
5. **`--strict-tools`（CI）vs 默认 SKIP（本地）**：工具缺失/license 不足在 CI = FAIL（矩阵必须完整），本地干跑 = SKIP 并注明原因——本地 community 实例上 go/nuget/helm/conan 腿如实 SKIP（`license tier 'community' < 'pro'`），UAT（enterprise 19/19）上满编运行。
6. **`--docker-clients` 本地干跑模式**：宿主缺 mvn/java/dotnet 时用钉版本镜像（`maven:3.9-eclipse-temurin-17` / `eclipse-temurin:17-jdk`（跑 fixture 自带 gradlew 7.6.2）/ `mcr.microsoft.com/dotnet/sdk:8.0`），同路径挂载使宿主环境变量容器内有效。CI 不用此模式（真工具链）。`client_base` 按「该工具是否被容器化」选 URL：容器侧 `host.docker.internal`、宿主侧直连 `BINFLOW_BASE`（Docker Desktop 转发在容器扰动下偶发 502/ECONNRESET，本地实测两例后收窄到容器侧才走转发）。
7. **fixture 改造点全部就地留痕**（不复制进仓，仅改 workdir 副本）：maven 版本戳 + 2012 年代插件抬到 3.4.0（war 2.4 在 JDK17/mvn3.9 载入失败）；gradle 用 fixture 的 src + 我方 maven-publish driver build.gradle（原文件驱动 JFrog 插件）；npm/pypi 剥外部依赖（本地仓解析不到 send/PyYAML——测的是推拉协议不是依赖链，与 pypi `--no-deps` 同理）；nuget net7.0→net8.0 + 去 snappier 引用 + `<clear/>` 断外网源（restore 可证明走 BinFlow）；docker Dockerfile 补 CMD（fixture 的 echo 是 build 期）。**project-examples 无 conan 菜谱/无 chart 脚手架/其 golang-example 带外部依赖**——三处脚注明示改用客户端自生成 fixture（`conan new` / `helm create` / 合成无依赖 module zip，STORED 条目官方形态）。
8. **mvn 3.8+ HTTP blocker 解锁**：默认 mirror `maven-default-http-blocker` 拒一切外部明文 HTTP 仓——消费侧 settings.xml 加 exact-id mirror `blocked=false`（mirrorOf 精确匹配优先于 `external:http:*`）。CI 对 UAT（明文 HTTP）同样需要，已内建。
9. **helm 腿双面**：经典仓（curl PUT tgz + `helm repo add/update` + `helm pull` 逐字节对账）+ HelmOCI 仓（`helm registry login --plain-http` + `helm push oci://` + `helm pull oci://` 对账）——「helm push + pull」字面落在 OCI 面，经典面是 BinFlow 特有的 index 引擎回归。

### 4.5 本地干跑过程中发现并修复的缺陷（6 个，全部有复现）

1. BSD sed 无 `\?` —— REG/NPM_AUTH_HOST 的 scheme 剥离静默失败（npm ENEEDAUTH、REG 带 `http://`）→ 参数展开重写。
2. npm fixture 的 `dependencies: send` 令本地仓 install 404 → publish 前剥依赖（python json 改写）。
3. `pip show | grep -q` 在 pipefail 下被 SIGPIPE 误判 FAIL → 落盘后 grep 文件。
4. fixture Dockerfile 无 CMD，`docker run` 空输出 → 补 CMD。
5. `maven-war-plugin:2.4`（fixture 2012 钉版）JDK17/mvn3.9 载入失败 → pluginManagement 抬 3.4.0；mvn 3.8+ http-blocker → settings mirror `blocked=false`。
6. macOS `/usr/bin/java` stub 骗过 `command -v java` → `-version` 真探针；`cp -R` 二跑嵌套 → 腿前 `rm -rf`；Docker Desktop host.docker.internal 转发偶发 502 → `client_base` 仅容器侧走转发。
