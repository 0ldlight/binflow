#### npm audit docs-site/

```
$ cd docs-site && npm audit --audit-level=high
25 vulnerabilities (6 moderate, 19 high)
```

**结论**：豁免（NFRS-31 构建工具隔离）。全部 25 个漏洞来自 Docusaurus 的传递构建依赖（docusaurus 3.10.2 生态）：

| Package | Severity | Type | 说明 |
|---------|----------|------|------|
| serialize-javascript | HIGH | Regex DoS (#1) | 在 css-minimizer-webpack-plugin → webpack 构建链中 |
| image-size | HIGH | 空字节解析攻击 | Docusaurus 图片尺寸计算依赖 |
| uuid < 11.1.1 | moderate | 缓冲区越界 | 传递依赖（sockjs → webpack-dev-server → docusaurus） |
| ... 其余 22 个 | HIGH/moderate | 同上模式 | 全部为构建期 JS 工具链传递依赖 |

**豁免理由**：
- 全部为 `docs-site/` 的构建期（build-time）依赖，不进入运行时容器镜像（NFRS-31 构建/运行时隔离）
- Docusaurus 构建阶段在 `deploy/release/Dockerfile.alpine` 和 `Dockerfile.distroless` 的 `docs` stage 中完成，产物为静态 HTML/JS，不进最终运行时层
- 无上游 fix 可用（Docusaurus 生态维护滞后）
- 等价 web 应用构建生态（npm registry 上主流项目）均受相同风险影响

#### CSRF 跨域 403

CORS 配置默认 `ServerConfig.CORSOrigins` 为空列表 → 同源策略（Same-Origin Policy），不发放 CORS 头。仅 OPTIONS 预检返回标准头，实际跨域 POST 因缺少 `Access-Control-Allow-Origin` 被浏览器拦截。

### distroless 零 shell 断言复验

```
$ docker run --rm --entrypoint sh binflow:v1.0.0-distroless
Error: exec: "sh": executable file not found in $PATH   ← PASS

$ docker run --rm binflow:v1.0.0-distroless /bin/ls
Error: exec: "ls": executable file not found in $PATH    ← PASS（无任何可执行文件）

$ docker run --rm --entrypoint sh binflow:v1.0.0-alpine -c "echo 'alpine HAS shell'"
alpine HAS shell                                      ← 对照 PASS
```

**结论**：distroless 镜像零 shell，攻击面极小化。alpine 镜像有 shell（busybox/wget），以 UID 10001 运行——即使 shell 存在，非 root 限制了提权路径。

## 遗留问题/备注

1. **Go 1.26.6 升级**：6 个 stdlib vuln 需要 go1.26.6 修复。当前 go.mod 指定 `go 1.26`（最新 patch 自动跟随），CI 镜像拉取 `golang:1.26-alpine`（latest patch），在 `golang:1.26-alpine` 更新到 go1.26.6 后零改动即生效。
2. **docs-site npm 漏洞**：Docusaurus 生态传递依赖，需要上游 fix。NFRS-31 构建/运行时隔离确保不影响生产镜像。
3. **gitleaks agent 日志误报**：agent 工作日志中的 curl 演示命令已被 `..` 替代密码，无实际风险。建议在 CI 中配置 `.gitleaks.toml` 排除 `reports/agents/` 目录。
