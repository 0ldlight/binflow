# T-129 [P0] docs-site Docusaurus 脚手架

## 状态: done

## 做了什么

### 1. Docusaurus 主题配置修复
- **修复 `docVersionDropdown` -> `docsVersionDropdown`**：Docusaurus 3.10 的 navbar item type 是 `docsVersionDropdown`（带 `s`），之前的 `docVersionDropdown` 导致 build 失败（ValidationError）。详见 [Docusaurus navbar items](https://docusaurus.io/docs/api/themes/configuration#navbar-items)。

### 2. 搜索方案切换（T-130 K1 终裁影响）
- **已在 `docusaurus.config.js` 中使用 `@easyops-cn/docusaurus-search-local`**（T-130 终裁已应用）。配置：
  - `hashed: true` — 构建产物文件名带 content hash
  - `language: ['zh', 'en']` — 中文分词支持
  - `highlightSearchTermsOnTargetPage: true`
- `nodejieba` 作为 `@easyops-cn/docusaurus-search-local` 的传递依赖自动安装，无需显式加入 `package.json`。

### 3. baseUrl 确认
- `baseUrl: '/binflow/docs/'` — 已确认，零 CDN/第三方脚本/字体外链
- `favicon: 'img/favicon.svg'` — 内联 SVG，零外链
- CSS font stack 使用系统字体（`--ifm-font-family-base: -apple-system, ...`），零 webfont 网络请求

### 4. Makefile 目标
- **`make docs`**：构建 Docusaurus 站点并复制到 `internal/docs/dist/`：
  ```makefile
  docs:
      cd docs-site && npm ci && npm run build
      rm -rf internal/docs/dist/assets
      rm -rf internal/docs/dist/search
      cp -R docs-site/build/. internal/docs/dist/
      @$(MAKE) --no-print-directory docs-size
  ```
- **`make docs-size`**：报告站点原始大小（预算 <=15MB）：
  ```makefile
  docs-size:
      @bytes=0; for f in $$(find internal/docs/dist -type f); do ...
  ```

### 5. 占位策略 (T-89 复用)
- `internal/docs/dist/placeholder.html` 已提交（committed），保证 `go:embed` 无 node checkout 上仍然匹配
- `.gitignore` 已更新，排除构建产物但保留占位文件：
  ```
  !internal/docs/dist/
  internal/docs/dist/*
  !internal/docs/dist/placeholder.html
  ```

### 6. Go embed + Handler
- `internal/docs/docs.go` 已完成：`go:embed dist` + `Handler()` 返回 HTTP handler
- `New()` 中 `deps.Docs` 默认使用 `docs.Handler()`（零 nil 处理）
- `router.go` 中 `/binflow/docs/**` 路由已绑定，匿名只读，不经过认证门

### 7. CI 构建步骤
- `ci.yml` 中 `ci` 和 `release-dryrun` job 均已添加 `make docs` 步骤

### 8. 测试
- `internal/docs/docs_test.go` — 所有 handler 语义测试通过（301 重定向、405 方法门、dot-segment 安全、占位文件）

## 遗留问题

1. **已有内容的 broken links**：`docs/user/README.md` 引用了 `getting-started/`、`install/` 等尚未创建的文档（属于 T-141 内容矩阵），Docusaurus 已配置 `onBrokenLinks: 'warn'` 仅告警不阻断。内容矩阵就位后（T-141/T-142）可改为 `'throw'`。

2. **`@easyops-cn/docusaurus-search-local` 无 `nodejieba` 显式依赖**：nodejieba 是传递依赖。如果未来版本中断此传递关系，需在 `package.json` 显式添加 `"nodejieba": "^0.x"`。

3. **搜索功能端到端验证**：需要 Playwright 冒烟测试验证搜索可用（已有 Playwright 空白 exit code 27 问题待排查，属于另一 ticket）。

4. **版本化骨架**：`docusaurus.config.js` 中 `versions.current: { label: '开发中 (next)' }` 已配置。`npm run version v1.x` 需在有稳定发布版之后执行（M5 GA）。
