## 1. 实现清单

### 1.1 CG-2 确定臂（publish 失败面翻转，publish.go）

- **精确 wire = 200 + `warnings.other` 载荷**（T-304 精度注 1 逐字落实）：错误串 `Failed to publish with error '<msg>'` 入 `warnings.other`，**绝无顶层 errors 键**（R-1：cargo 1.98 见 errors 键即判失败）；成功 = 200 + warnings-only（`other:[]`）。
- **失败分类落地**（T-304 §3 全表 → docs/reverse/cargo.md §5.3）：
  - 类 4/5（IOException 族——帧体截断/元数据 JSON 畸形/名称与 SemVer 校验失败/属性校验失败/落盘失败/副作用面失败）→ **200 + warnings.other**；
  - 类 7（帧长度前缀畸形 + 形状违例：超限声明长度/空 crate 帧/尾随字节）→ **500 + errors 信封**（RuntimeException 族穿透的降级声明——`errFramingDefect` 哨兵取代 T-294 的 `errInvalidPackage`）；
  - 类 1/3/6（权限族）→ **401（匿名，带 WWW-Authenticate）/403（实名）+ errors 信封**；
  - 类 2（**D-3 翻转**）——**409 冲突臂删除**：重复版本由服务层 repo-semantics §3 闸门裁决（可删→覆盖上传；不可删→401/403）；
  - 副作用面（sidecar 写/索引重写）失败**不翻转 200**——错误串追加进 warnings.other（Artifactory publish 先答 200、索引是异步链〔D-4〕，派生面失败不可把已落地 crate 报成 HTTP 失败）。
- BinFlow 自有策略面（checksum 头 409/quota 413/路径与属性规则 400）保持原 4xx——部署策略面不入 CG-2 双轨（登记）。
- **索引唯一行收敛**（index.go）：D-3 覆盖臂可落同名版本多种 build-metadata 拼写（各自独立存储路径）；rewriteIndexLocked 按「忽略 build metadata」去重，取**最新节点拼写**（UpdatedAt 平局按 vers 字典序决胜，确定性）——官方唯一性 must 保住，被折叠拼写的 blob 仍可下载。

### 1.2 D-5 裸写接受 + 收敛链（handler.go）

- `index/{pkgPath}` PUT/DELETE：T-294 的 403 → **接受**（svc.Put 201 / svc.Delete 204）+ **convergeIndex**（CargoMetadataInterceptor 语义的 BinFlow 等价物：按派生路径归属 crate 重算整文件索引）；有存储事实的 crate 手写行立即被重算覆盖（cksum 对账闭环由重算保证），无事实的（外部导入形态）手写文件保留。
- `.cargo/**` 裸 PUT：403 删除 → 接受 + 收敛（sidecar 更新即进下一轮索引行）。
- `index/config.json` 写仍拒 403——合成面无落点，不入 D-5（config.json 不是存储节点，Artifactory 同为请求时合成）。

### 1.3 cargo remote（remote.go 新 + provider.go facet + handler.go 类门）

- **类门**：RepoTypes → {local, remote}（virtual 留 T-318 诚实 404）。
- **读面全走 FR-20 引擎**（svc.Get 于 remote 仓自动分发，conan T-312 同构）：index 文件/下载/裸内容 GET = pull-through（负缓存/双 TTL/守卫出站/MISS 落地/stale-while-error 全继承）；`serveIndexFile` 补 reader 的 ExtraHeaders 结构探测（X-BinFlow-Cache 随索引面透出，serveNode 同款）。
- **UpstreamPath facet**（provider.go，纯函数）：`crates/<n>/<n>-<v>.crate` → `v1/crates/<n>/<v>/download`；`config.original.json` → 上游 `index/config.json`；`.cargo/search/<hex>.json` → `api/v1/crates?<逐字 query>`（hex 可逆编码保存储键合法 + 出站跳带查询）；index 文件恒等。缓存键/落点/singleflight 全保持存储拼写。
- **config 翻译链**（S4/AC1）：对外 config.json 合成自指（dl/api 指回本 remote 仓——下载必经缓存）；上游 config.json 原文缓存为仓根 `config.original.json`（config.json 响应路径上**尽力同步**拉取，错误吞掉——上游不可达不断 config 面）。
- **search 代理 + 缓存**：查询串逐字（含未知参数/顺序/重复）键入 marker 路径，上游响应体逐字服务（上游 search 契约即响应）；引擎按查询独立 MISS→HIT；**硬错误类（hardFail/超限 502）→ 409 + 信封**（CG-2 类 8）；unfound 族保持诚实 404。
- **写拒绝**：publish/yank/unyank/索引面写 → 405 + Allow: GET + errors 信封（RE-05 措辞逐字，conan/deb 姿态，先于 body 读取）；裸 PUT → 服务层 405；DELETE（含索引文件面）→ **RE-06 缓存驱逐**（204/404，二次取 MISS）。
