## 2. 重建指南（给 L003-1/L003-2 —— 撞容器名 binflow-ga 时照此重建你的验证版）

```bash
# VER 命名：uat-l003<N>-<shortsha>（N=你的轨道号）
VER=uat-l0031-<your-shortsha>
make console && make docs && make release VER=$VER
REGISTRY= PUSH=0 SMOKE=0 ARCHES=amd64 VARIANTS=alpine ./deploy/release/build-release.sh $VER
docker tag binflow:${VER}-alpine-amd64 binflow:${VER}-alpine
# 换版本只需改 .env.uat 两行，然后同卷同端口重建（不要 --build，Dockerfile 源构建是断的，见 AUDIT-L000-D §5）：
sed -i '' "s/^BINFLOW_VER=.*/BINFLOW_VER=$VER/; s/^BINFLOW_REVISION=.*/BINFLOW_REVISION=<your-shortsha>/" deploy/compose/.env.uat
docker compose -p binflow-uat --env-file deploy/compose/.env.uat -f deploy/compose/docker-compose.yml up -d --force-recreate
# smoke：
curl -s http://localhost:8083/binflow/api/system/version   # version/revision 应为你 VER
curl -s http://localhost:8083/healthz
curl -s -o /dev/null -w '%{http_code}\n' http://localhost:8083/binflow/ui/   # 200
echo "$BINFLOW_ADMIN_PASSWORD" | docker login localhost:8083 -u admin --password-stdin
```

注意：① 容器名钉死 binflow-ga，三轨道互斥——**重建前 `docker ps` 确认现容器归属**，替换后尽快完成你的验证轮（数据卷共享，前轨 push 的仓/制品仍在）；② 密码读 deploy/compose/.env.uat 的 BINFLOW_ADMIN_PASSWORD。
