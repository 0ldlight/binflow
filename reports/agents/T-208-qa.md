## curl 腿明细（真实栈，全部实际执行）

Base `http://127.0.0.1:18410/binflow/api/security`，admin=basic（seed 口令），登录探针 = `POST /token`（`-u user:pw -d expires_in=3600`，非 admin 自签有限 TTL）：

| 腿 | 命令要点 | 期望 | 实际 |
|---|---|---|---|
| L1a | `PUT /users/ci-disabled` body `{"enabled":false,...}` | 201 | **201** |
| L1b | ci-disabled basic 登录 | 401 | **401** `errors[] invalid credentials`；sqlite `enabled=0` |
| L2a | `PUT /users/ci-active` 无 enabled | 201 + 默认 true | **201**，DB `enabled=1` |
| L2b | ci-active basic 登录 | 200 | **200**，access_token 64 字符 |
| L3a | 该 Bearer token 调 `POST /token` | 200 | **200**（禁用前基线） |
| L3b | admin `POST /users/ci-active` `{"enabled":false}` | 200 | **200**，DB `enabled=0` |
| L3c | **同一存量 token** 再调 `POST /token` | 401 | **401**（立即生效，无需等 TTL/重启） |
| L3d | ci-active basic 登录 | 401 | **401** |
| L4a | ci-keep 默认建→POST 禁用→登录 | 201/200/401 | 全符 |
| L4b | `PUT /users/ci-keep` 全量 body **无 enabled** | 保持 false | **登录仍 401**，DB `enabled=0`、email 已更新（替换确实发生） |
| L4c | `POST {"enabled":true}` → 登录 | 200/200 | 全符 |
| L4d | `POST {"email":...}` 缺省 enabled | 保持 true | **DB `enabled=1`，登录 200** |
