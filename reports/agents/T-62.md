## 做了什么

### AC ① — 003_remote_virtual.sql（sqlite 实装 + postgres 占位）

- `migrations/sqlite/003_remote_virtual.sql` 新增，严格按架构 §6 定稿 DDL：
  - `remote_cache` 表：etag/last_modified/fetched_at/expires_at/kind（DEFAULT 'content'），PK (repo_key, path)，FK → repositories ON DELETE CASCADE；`idx_remote_cache_expiry`。
  - `remote_configs` 扩列：`content_ttl_seconds`（DDL DEFAULT 86400）/ `metadata_ttl_seconds`（600）/ `allow_private_upstream`（0）/ `RENAME COLUMN unreachable_mask TO blocked_out`；001 的 cache_ttl_seconds 列保留但注释标注被双 TTL 取代、不出现在 RemoteConfig 结构面。
  - password 列语义变更以注释记录（明文 → `enc:v1:` AES-256-GCM，env `BINFLOW_REMOTE_CREDENTIALS_KEY`）：M1/M2 从未写过 remote_configs 行（全库 grep 证实），无存量可加密，故迁移内无数据改写；有行无钥 fail-fast 归 T-66。
  - `virtual_members.position` 语义注释升级——**按 T-79 勘误后的两桶口径**落注释（「桶内声明序」，优先桶 = priorityResolution 标记成员；旧「跨类 local-first 固定」表述已作废），无 DDL 变更。
  - 顺手缝：`idx_blobs_sha1`（T-73 sha1-only 秒传的 blobs 台账查询缝；查询方法归 T-73）。
  - 文件体内零 BEGIN/COMMIT（既有 `TestMigrationsHaveNoTransactionStatements` table-driven 守卫自动覆盖 003）。
- `migrations/postgres/README.md` 版本历史补 003 条目（同 002 占位策略：postgres 目录仍无 .sql）。

### AC ② — Store 增 Remote()/Virtual() 子接口

- `api.go`：`RemoteConfig`（URL/Username/Password/双 TTL/AllowPrivateUpstream/BlockedOut；Password 对 store 不透明）、`RemoteCacheEntry`（验证器 + 时钟 + kind）、kind 常量 `RemoteCacheKindContent/Metadata`、`VirtualMember`；哨兵 `ErrRemoteConfigNotFound`/`ErrRemoteCacheNotFound`；`Store` 接口增 `Remote() RemoteStore`、`Virtual() VirtualStore`（外部唯一的全接口实现是 sqliteStore；repo 测试的 hookDocker 以 embed 满足接口，扩展无破坏——编译验证）。
- `substores_remote_virtual.go`：
  - RemoteStore：`CreateConfig/UpdateConfig/GetConfig/DeleteConfig`（CRUD，缺行哨兵，FK 保护）；`PutCache`（(repo,path) upsert 刷新验证器与时钟）/`GetCache`/`DeleteCache`（单路径失效，RE-06 强刷消费）/`DeleteCacheByRepo`（teardown，返行数）/`ListExpiredCache(now, limit)`（`expires_at <= now` 按 expires_at 序，吃 idx_remote_cache_expiry；limit<=0 全量）。
  - VirtualStore：`SetMembers`（单事务 DELETE+按序 INSERT，position=切片序 0..n-1，原子替换；空切片清空）/`ListMembers`（ORDER BY position, member_repo）。
  - 沿用既有模式：wrapExec 忙检、boolToInt、limitOrDefault、ErrNoRows→哨兵。
- `store.go` 装配两个访问器；`doc.go` layout 补行。
