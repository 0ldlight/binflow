# T-336 — 空载 RSS 瘦身（M12，P0，裁定⑤ D-8R 承载）

- 角色：dev-go-core ｜ 日期：2026-08-28 ｜ 状态：**done**
- 任务：把空载 RSS 压到 ≤100MB（`make footprint EXPECT=1` 由红转绿），冷启动 <2s 维持，console/docs 服务面零回归。
- 基线：vmmap physical footprint **138.7MB**（预算 100MB 红）；冷启动达标。check-size 六平台 94.13MiB 与本票无关（纯运行时内存面）。

## 1. 归因（先复测 + 分段取证，非猜测）

### 1.1 vmmap 分段（修复前，实例@ready，PID 87774）

| REGION | RESIDENT | DIRTY | 计入 footprint？ |
|---|---|---|---|
| **VM_ALLOCATE（Go 堆）** | **135.8M** | **135.8M** | **是——footprint 138.6M 的绝对大头** |
| __TEXT | 114.2M | 0 | 否（file-backed，含系统库） |
| __OBJC_RO | 40.3M | 0 | 否（共享） |
| __DATA/__DATA_CONST 等 | ~22M | ~2.2M | 小头 |
| MALLOC zones / stack | <1M | <1M | 忽略 |

### 1.2 GODEBUG=gctrace=1,scavtrace=1 启动跟踪（无代码插桩）

```
gc 1 @0.008s: 3->4->2 MB        ← 启动常规装配，live ~2MB
gc 2 @0.068s: 68->68->66 MB     ← ① seedAdmin 的 HashPassword：argon2id m=64MiB 单次派生
gc 3 @0.102s: 130->130->66 MB   ← ② warnDefaultAdminPassword 的 Authenticate：又一次 m=64MiB 派生
scav: 60s idle 仅归还 6.4MB     ← 后台 scavenger 在窗口内远不足以归还 128MB
```

- 两次 64MiB argon2id 派生（internal/metadata/password.go，ADR-0009 t=1/m=64MiB/p=4）顺序脏化了 128MB 堆页，之后 live 仅 ~2MB，但脏页滞留 → footprint@ready 与 @idle+60s 都钉在 138.6/138.7MB。
- ① 是首次种子哈希（probe 永远 fresh boot，不可免）；② 是每次启动固定的「默认口令警告」校验（错口令也要先全量派生再比对——argon2 语义使然）。seedAdmin 本身已做存在性检查，持久化启动只付 ② 一次。
- **embed 无责**：console（1.0MB staged）+ docs（4.2MB staged）全部按需 ReadFile/Open，gctrace 证明启动 live 仅 ~2MB；license/addon/metadata 启动加载同样干净。票据嫌疑面 1/2 双双排除，实证落在大额 KDF 派生翻搅。

### 1.3 机制实验（/tmp/memtest，仓库外，已弃）

两段 64MB churn + `runtime.GC()` + `debug.FreeOSMemory()` → vmmap footprint **130.4M → 2.5M**（peak 仍记 130.4M；VM_ALLOCATE resident 不变但 dirty 129.7M→1.7M）：darwin 的 MADV_FREE_REUSABLE 页即刻退出 physical footprint 且可被内核零成本回收——归还语义真实成立，不是探针时序技巧。Linux 侧 Go 用 MADV_DONTNEED，ps RSS 真实下降。

## 5. 差异登记 / 遗留

1. **启动 peak 仍 ~139MB（瞬态 ~100ms）**：两次 64MiB 派生照旧发生，仅事后归还。判定指标为瞬时 footprint，非门控项；如需压 peak，可消 ②（warn 校验的免派生化——需引入「种子时记录默认口令标记 + API 改密时清除」的元数据标记，涉及 schema 与行为契约，本票不擅动，留待上游裁量）。
2. **darwin ps RSS@ready 仍读 ~146MB**：MADV_FREE_REUSABLE 页在内核回收前仍计 resident——D-8 方法论（T-147/T-297）判定指标在 darwin 是 vmmap footprint（探针原逻辑），不受影响；Linux 判定面 ps RSS 因 MADV_DONTNEED 真实下降。
3. **运行期每次登录（argon2 校验）仍会瞬态脏化 ~64MB**，靠后台 scavenger 慢速归还；单次峰值 ~70-90MB < 100MB 预算，NFR-P4 协议（零流量）不触及。若后续要求「任意时刻 footprint ≤100MB」，需上 GOMEMLIMIT 或每次派生后定点归还——另行立项。
