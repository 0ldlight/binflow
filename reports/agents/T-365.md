## 1. 设计摘要

### 1.1 分层（walk 驱动 / 服务事实分置，T-363 同型）

- **适配器 walk**（internal/adapter/docker/virtual.go）：/v2 路由在 authorizeRoute 后按 row.Class()==virtual 分流 serveVirtualRoute——manifest/blob GET/HEAD 沿两桶成员序逐成员：local 成员答既有节点（行在而节点缺 = 成员 miss 继续）；remote 成员先读缓存事实（HIT 服务/NEGATIVE 跳过/STALE+MISS 走该成员的上游会话），拉到后**落进该成员**缓存。**首见语义**：第一个能产出正文的成员胜出；响应带 `X-BinFlow-Resolved-From`。
- **服务缝**（internal/repo/dockervirtual.go 实现 api.go 的 `V2VirtualPlane`）：V2MemberOrder / V2MemberManifest / V2MemberBlob / V2MemberUpstream / V2LandMemberBlob / V2RecordMemberManifest / V2CacheMemberMiss / V2WriteRefusal——全部以**成员在序**为守卫、不重跑成员自身权限门（权限已在 virtual key 上由 /v2 路由门回答，ReadVirtualMember 口径）。T-363 的 probe/land/record/miss/upstream 五方法抽成无门核心（probeRemoteV2Core 等），直连面与虚仓面共用一套不变量。
- **四读用例 virtual 臂**（service.go + dockervirtual.go）：loadV2ReadRepo 自本票纳 virtual；ResolveManifest/ResolveTag = 成员序 first-rows-wins；ListTags = tag 并集（first-wins 去重 + 全局排序 + 官方分页；remote 成员只出**已缓存**行，D-2 口径）；ListImages = image 并集、以 **virtual key** 前缀渲染。
- **写面**：V2WriteRefusal 渲染——未配 defaultDeploymentRepo → C5 文案原样（405+Allow: GET）；已配 → 如实文案（v2 面 push-through 未实现，点名目标、不谎称未配置）。
- **降级矩阵**（FR-116.5 经聚合面，getVirtual R10 的 §8.3 方言）：成员 RESULT 即停（含 STALE+marker 续 serve）；UNFOUND（负缓存/无副本/上游 404/401/403/传输故障无副本）继续下一成员；分类性非 unfound（SSRF 400、body 上限 502）原样透传。walk 走完 → unfound 族（附最后上游摘要，零裸 5xx）。

### 1.2 断言反转与顺手修复（登记）

- **D-5 型翻转**：t342_helmoci_family_test.go 的 virtual 臂——ListImages 于 virtual 行由 ErrRepoTypeNotSupported 翻为空目录（memberless virtual 的诚实答案）；remote 臂/写面拒绝/异类型拒绝三处维持。
- **隐患修复**：T-363 后 pro 许可下 helmoci virtual 建仓已合法，但 serveCatalog 对 v2 家族全行调 ListImages → virtual 行答 ErrRepoTypeNotSupported → **/v2/_catalog 整面 500**。四读 virtual 臂落地后 catalog 自然恢复（live 断言）。
- **catalog 口径**：virtual 行的并集（virtual key 前缀）与成员行并列出现——成员本就独立可寻址，不做抑制（登记，非票面问题）。

## 6. 登记与遗留

- **断言反转**：t342_helmoci_family_test.go virtual 臂（ListImages → 空目录），D-5 型，PRD 预告位。
- **push-through 路由未实现**：/v2 写面对 virtual 一律 405（未配路由=C5 原样；已配=如实文案点名目标）。票面 AC 只要求读聚合；实现需 upload 会话寻址换轨，建议后续票（与 T-380 docker remote 顺车票可同批评估）。
- **docker↔helmoci 成员混仓**：validateHelmFamilyMix 只管 helm/helmoci；helmoci virtual 配 docker local 成员当前**不拒绝**（同走 /v2 族，机制上可用——live 14 号腿即 docker 客户端经 helmoci virtual）。JFrog 语义上 HelmOCI virtual 应只含 HelmOCI 仓；是否收紧归 conductor 裁（可并 T-380）。
- **tags 并集的 D-2 阴影**：remote 成员未缓存版本在 tags/list 不可见（上游 tags/list 代理仍是 §8.3 登记的后续票），helm `--version` 拉取不受影响（live 4/6 号腿即证）。
- **审计口径**：virtual 服务记一条 virtual 为址的 download 行（detail resolvedFrom），remote 落盘照记成员为址行——镜像 getVirtual+引擎双行口径。
- 无阻塞项。相邻票互扰：本票未动 internal/remote、internal/httpapi、cmd/（lint/test 全树绿证）。
