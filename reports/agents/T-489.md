## 1. ADR-0045 决策摘要（Accepted——七轴里裁五轴）

| 轴 | 决策 |
|---|---|
| ACL 模型（K74 核心命题） | **仓库级 allow() 同源**——build 行携 build_repo 逻辑键（缺省 artifactory-build-info），五动词经同一 auth.Authorizer.Can 求值；**path 位传 build_name**（target includes/excludes 模式对 build 名生效——Artifactory「按 build 名模式授权」语义零新面获得）；否决独立 build 权限面（表达力全在 A 内零新面可得，B 却造第二条权限通道＝双真相源泄漏面）与管理面能力门（CI 数据面误判，场景 A 落空） |
| 数据载体 | metadata 规范化表族（六表：builds/modules/artifacts/dependencies/promotions/properties）+ payload 归档——**不进 storage/nodes**（记录非制品；§11.51 差异留痕） |
| promote 权限门 | **w(targetRepo) ∧ r(buildRepo, build_name)**——deploy-cache 同权位（「能 push 的才能 promote」，零提权面）；m 不承载（配置权≠迁移权）；无新动词（r/w/d/m/a 闭集维持） |
| 织入面 | import 禁令式包边界（build 禁 import webhook/search/scheduler/bundle/insights/license/replication/httpapi）+ Emit facet 注入（ADR-0041 gate func 同款）+ search 单向 import BuildSearcher |
| promote 载体 | 复用 repo.Service CopyOrMove 族 + docker 面 manifest 重放（T-509「复用非重构」兑现；principal=调用者，不豁免） |
| 档位 | **无槽 community 地板**（inv-2 §103 OSS openapi + inv-4 D1~D5 在案）；T-488 档位核验翻案 → 勘误 + 预留 ID build-info 建槽 |
| REST 子集 | 上传/append（合并不覆盖）/单查/列表·最新/批删/promote/retention 七族进 M17；rename/diff/docker promote 独立端点/projectKey 不进（远期行） |

webhook：build 域三事件（uploaded/deleted/promoted）dormant→wired＝eventtypes 三常量行 + Emit facet（envelope schema 零变化——webhook.md §3.4 已冻结）。AQL：builds/modules/dependencies 三入口翻转（T-511），promotion/releasebundle/sensitive 维持 400 诚实拒绝（M18+ 翻转点留痕）；BuildScope 服务端可见集 + 行级复核（aql.md §6 锚）。audit +5 词（build.{upload,append,delete,promote,retention}）+ metrics 4 枚。

## 3. K75 会签结论（洞察聚合层——ADR-0046 决策 5~9 + architecture §26.3 详规）

- **insights 新包定名＝internal/insights**（M17-SPLIT「定名从会签」兑现；否决 analytics/reports——与 metrics/audit 语义混淆）。
- **指标集四族**：download_trend（nodes.download_count 日差分）/ storage_growth（**repo_usage 既有聚合——禁 nodes.size 裸和**，共享 blob 双计）/ top_repos / top_artifacts（每日 Top 100 物化）。表族 insights_repo_snapshots + insights_top_items（全局趋势＝per-repo 行聚合，无 '*' 汇总行）。
- **K69 单源对账面**：数据源白名单闭集（nodes 四列 + repo_usage/blobs）；快照任务**只读业务表、只写快照表**（零第二计数通道结构性保证）；对账断言＝夹具下载 N 次 → 快照 delta == ?stats downloads == FileInfo 口径（T-515 AC3）；今日活性值＝最后快照 + 现值差值拼接（现值唯一源＝K69 四列）。
- **与 T-505 storageinfo 预裁**：不共享快照载体（时序 vs 现值两语义）；唯二共享＝事实源 + scheduler 基建；合体窗口留 T-505 票内核定（倾向不合）＝§11.53。
- 查询面＝/api/v1/insights/*（C 层自有——Artifactory Insights 系独立商业产品无 OSS 对位）；门＝CapSystemRead（readonly_admin 可见），手动重算＝CapSystemWrite；NFR-P81 由「快照只读业务表」结构性承载。

## 4. B-1.7 增补评审留痕（Q11——ADR-0046 决策 10，K68 先例同款「ADR-0026 增补评审」形态）

- **决策：维持三值枚举**（Q11 出口②）。五条论证：① 双布尔表达不了 readonly_admin（rbac-model #1/#2 高置信：Artifactory 实例级无 read-only admin）且 (false,true) 组合在 BinFlow 无载体＝需第 4 角色（闭集变更级）；② Role(3)×能力(6) 全表是 M7~M16 QA 矩阵既有资产，布尔组合无界化；③ ADR-0030 E8 已拒组级 adminPrivileges（第二条提权路径同型风险）；④ wire 证据未核验（7.161 系表单呈现，access API 对位未活体核验）——低置信不进断言；⑤ readonly_admin 角色短路语义会被布尔叠加击穿。
- **tripwire 触发器机制登记**：① FE 已备（T-453：user-form-role-parity-note + 能力位 API 漂移钉）；② 触发器＝任一票在 users wire 承接 adminPlatform/manageResources 字段族 → 漂移钉翻红 → **转正＝PM FR + architect 新 ADR + 零提权等价迁移论证**（K68 同款），实现票内禁止顺手承接；③ parity 册 §12 B-1.7 行标注更新归 T-492/T-519 顺腿（本票不写 parity 册——area 纪律）。ADR-0026 决策 1/3/5 零翻动。
