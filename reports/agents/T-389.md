### 2.2 favicon/PWA 派生（AC2）

本机无 rsvg-convert/magick（README §3 方案 A 不可用）——`web/scripts/gen-brand-assets.mjs` 为等价管线（playwright chromium headless 画 canvas）：

- PNG = canvas toBlob；favicon.ico = canvas ImageData 的 RGBA 在 Node 侧合成 **32bit BMP-in-ICO（DIB）** 三档（全平台支持面最宽的 ICO 形态，不赌 PNG-in-ICO 嗅探）；
- PWA 180/512 = mark-dark 居中 + 8% 边距实底 #1b2430（README「直接渲染会顶格」条款）；
- 16px 两箭可辨：像素级验证 y=11 扫描线蓝色 run = 2（两箭分离可辨）；样张归档 `reports/agents/t389-samples/`（16px 原尺寸 + 8x 最近邻放大）；
- 可复跑（换母版后 `node scripts/gen-brand-assets.mjs`），`--favicon-stroke 4.5` 保留 README「16px 发糊」退路（本次未启用——run=2 已可辨）。

### 2.3 搬挂 + 指纹化（关键工程决策）

`/binflow/ui/**` 一切路径都是 SPA shell（internal/console serveShell 无文件特例）——vite public 原位 `/binflow/ui/brand/**` **永远取不到字节**。`web/scripts/wire-brand-assets.mjs`（挂 `npm run build` 尾步）把七件搬入共享挂载并按 sha1 指纹化（`favicon-16-32c281e0.png` 形态）：

- 为什么指纹化：serveAsset 对整个 `/binflow/assets` 一律 immutable——稳定名会把旧图标钉死一年；指纹化保 immutable 语义诚实且**零服务端改动**（AC3 diff=0 红线）。
- manifest：icons[].src 改写为指纹名后整体指纹化；`start_url: "../ui/"`（按 manifest URL 解析回 /binflow/ui/；scope 缺省 = start_url 父目录）。**不用绝对字面量**——relink-assets 自校验禁止 dist 下任何 `"/binflow/ui/"` 引号字面量（那是死资产 URL 闸；app 路由引用走相对形语义同）。
- 自校验：html 属性面零残留（注释里的管线说明合法提及路径形态，不拦）+ 目标文件在场 + dist/brand 清场，任一违例非零退出（relink-assets 同姿势）。
