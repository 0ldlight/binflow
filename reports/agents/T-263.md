## 2. 移除清单

### 2.1 web/src/main.tsx（票面 area）

- 删除 `type PathRewrite` / `prefix()` / `TREE_REWRITE` / `EDIT_REWRITE` /
  `LegacyRedirect` 组件（整个兼容窗口代码块）。
- 删除 8 条承载路由（`repositories`、`repositories/:key/tree/*`、
  `repositories/:key/settings`、`repositories/*`、`settings`、`security/*`、
  `audit`、`governance/*`）。
- `useLocation` import 随之退役（`Navigate` 保留——index 落点与
  `/admin`、`/admin/repositories` 两跳仍是现役路由，非兼容窗口）。
- 路由表头注释改写为终态说明；`*` 通配注释标明 T-263 起不再兜底旧路径。

### 2.2 web/e2e/m8/shell.spec.ts（票面 area——断言反转）

- redirect 腿（原 `LEGACY_ROUTES` 20 条表驱动「落新路由 + 页面锚到达」）
  反转为 **404 终态断言**：`LEGACY_PATHS` 19 条旧路径逐条断言
  ① URL 精确匹配未跳转（原地不动）② `not-found` 锚可见（壳内）
  ③ `not-found-path` 回显原始路径。
- 第 20 条 `/` 不在移除集：index → `/artifacts` 是 §1.1 登录落点语义
  （非兼容窗口），保留断言（`tree-page` 锚到达）。
- 原「查询串保真」腿反转：「查询串不复活重定向」——旧树路径
  `?focus=seed.txt` 同落 404。
- 新增「404 页深链回主页」腿（`not-found-home` → `/artifacts` + `tree-page`），
  消费 T-239 已备形态。
- 锚零改名（ADR-0029 决策 3/6）：全部沿用既有锚（not-found 族 T-239 落定）；
  URL 断言仍只在外部前缀与终态腿两处（e2e/m8/README §2.1 口径已同步）。
- 种子瘦身：redirect 目标页不再挂载，`seedRepos`/PUT fixture 腿删除
  （provisionRoles 保留——404 仍在壳内，需登录态）。

### 2.3 e2e 路径断言同票携带（决策 6；area 扩张登记见 §5）

移除 redirect 后，M1~M8 既有 spec 里 **~80 处 `goto` 走旧路径**的腿全部
落 404（它们此前靠兼容窗口兜着到达页面）。按 ADR-0029 决策 6
「e2e 路径断言随路由表改、同票携带」，机械改写为新路径（有序 perl，
最特异优先）：

- `/repositories` → `/admin/repositories/local`；`/repositories/new` →
  `/admin/repositories/new`；`/repositories/:key` → `/admin/repositories/:key`；
  `…/settings` → `…/edit`；`…/tree[/<path>]` → `/artifacts/:key[/<path>]`
- `/settings` → `/admin/general/settings`；`/security/*` → `/admin/security/*`；
  `/audit` → `/admin/governance/audit`；`/governance/*` → `/admin/governance/*`

涉及 17 个 spec 文件（git diff --stat 见 §6）；改写后 grep 验证：web/e2e
内 UI 路由旧路径残留 = 0（shell.spec 的 19+1 条 404 断言腿除外——它们
断言的就是旧路径终态）。

### 2.4 docs/user/console.md（票面 area——移除节改写）

