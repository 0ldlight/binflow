## 2. 规范要点（三条最重要的设计决策）

1. **「让 MUI 默认皮肤生效」= 删压制规则，不是调注入序**。T-300 §3 实证（emotion 注入序在 base.css 后：单类平手 MUI 赢、复合类旧 CSS 赢）推出终态正解——退役清单的靶心是 47 个删/换装块（.table 续挂、.badge tint 配方、denseInputSx、手写 32px 带），类名只保留两类合法残留：spec 断言钩子（保名去规，§3.8 十六族）与无 MUI 等价物的语义 DOM（§3.7 八组）。
2. **密度从「手写 32px 带」换「MUI small 档」、字级 13→14**。这是与 console-ux §7.2 的唯一实质冲突，规范内修订（P1 信息密度原则不变，实现档位换 MUI 原生档：Table small 行 ≈33px、控件 small、Chip small）；console-ux v1.14 回写登记 §7.1，本票不改正文（纪律）。
3. **类钩子「保名去规」是退役的安全边界**。grep 实证 e2e 全量的 16 族 CSS 类钩子（.nav-item 计数、.badge.warning 类组合 toHaveClass、.water-bar warn/full、.toast、.modal fallback、.empty-state、.transfer-item、.authcfg-group、.card.section 等）——类名留 DOM 作 inert 标记、CSS 规则退役；并实证 permissions.spec 的 computed 色值仅 attach 不断言（换 tint→filled 配方安全）、theme-smoke 断言 --bf-* token 存在性（tokens.css 不可收缩该组）。
