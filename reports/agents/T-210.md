# T-210 复制私网目标显式开关 (ADR-0025 决策 4)

- 角色: dev-go-core
- 状态: done
- area: internal/config + internal/replication

## 做什么

把复制引擎的隐式 SSRF 默认升级为显式可配：新增 config 键
`replication.allow_private_target`（默认 `true`），落地到 `EngineOptions.DenyPrivateTargets`
（`= !allow_private_target`）。这是桥接，不是行为变更——默认值必须与现状完全一致
（现状 `DenyPrivateTargets` 零值 = false = 私网放行）。

## 改了什么

- `internal/config/config.go`
  - 新增 `DefaultAllowPrivateTarget = true`，注释解释 SSRF 语义与"默认宽松是刻意的"。
  - `splitEnvKey` 顶层 switch 新增 `REPLICATION_ALLOW_PRIVATE_TARGET` 单下划线便捷拼写。
  - `splitEnvKey` 泛型 `__` switch 新增 `replication.allow_private_target`（双下划线拼写）。
- `internal/config/api.go`
  - `Config` 结构新增 `Replication ReplicationConfig` 字段。
  - 新增 `ReplicationConfig` 结构（`AllowPrivateTarget bool`），字段注释说明 SSRF 语义
    （guard 仍强制 scheme/host 校验、逐跳重检、DNS-rebinding pinning，本键只切换私网段）。
- `internal/config/load.go`
  - `raw` 结构新增 `Replication *struct { AllowPrivateTarget *bool }`。
  - `build()` 新增 assembly：`if r.Replication != nil && ... { c.Replication.AllowPrivateTarget = *... }`。
  - `defaults()` 新增 `Replication: ReplicationConfig{AllowPrivateTarget: DefaultAllowPrivateTarget}`。
  - `setEnvValue` 的 `envBool` 分支新增 `case "replication.allow_private_target"`。
- `internal/config/replication_test.go`（新增）
  - `TestReplicationAllowPrivateTargetResolution`：缺省/显式 true/显式 false/双下划线 env/
    单下划线 env false/单下划线 env on 六种解析。
  - `TestReplicationSectionStrictSchema`：replication 节内未知键被严格解码拒绝。
- `internal/replication/engine_privatetarget_test.go`（新增）
  - `TestPrivateTargetDeniedWhenExplicit`：`DenyPrivateTargets=true` 时 loopback 目标在
    CheckURL 被拒（0 次 HTTP 调用），任务 failed、attempts=6、LastError 含 "loopback"
    与 "not retryable"。
  - `TestPrivateTargetAllowedByDefault`：零值引擎（私网放行）照常 push 成功，1 HEAD + 1 PUT，
    证明默认姿态不变。

## 自测结论（对照 AC）

1. config 键 `replication.allow_private_target`（默认 true）——raw 指针字段 + build + defaults
   + Validate 旁路（bool 恒合法，语义在字段注释）+ 双 env 拼写（单下划线 AND 双下划线）均落地。
2. 默认 true → 私网放行（DenyPrivateTargets=false），`TestPrivateTargetAllowedByDefault` 固化无回归。
3. 显式 false → 私网拒绝（DenyPrivateTargets=true），`TestPrivateTargetDeniedWhenExplicit` 固化
   loopback 在连接前被拒；guard 的 scheme/host 校验、逐跳重检、DNS-rebinding pinning 未动。
4. 路由门与审计未动（未改 replication 路由与 audit 代码）。
5. 全仓 `-race` 绿 + golangci-lint 0（限本 area）。

## 遗留 / 需上游确认

1. **跨 area 组装点**：`cmd/binflow-server/main.go`（约 line 630）仍是
   `replication.NewEngine(..., replication.EngineOptions{...})`，未把
   `DenyPrivateTargets: !cfg.Replication.AllowPrivateTarget` 接上。`cmd/binflow-server` 不在本票
   area，按 area 纪律未越界修改。需 conductor 派一张 `cmd/binflow-server` 的组装票或纳入本票的
   收尾把键真正接到引擎。
2. **内部偶发失败（与本票无关）**：`internal/remote` 的
   `TestFetchConcurrent404SingleUpstreamContact`（miss stampede 计数 2 而不是 1）在全仓
   `go test -race ./...` 中偶发失败；单独 `-count=3` 全过，属既有 timing-sensitive 测试，
   area 在 `internal/remote`，不在本票范围。

## 规格依据

- `DECISIONS.md` ADR-0025 决策 4：`DenyPrivateTargets` 默认 `false` 为正式决议，
  `replication.allow_private_target`（默认 `true`）落为 P2 票 T-210，scheme/host 校验、
  逐跳重检、DNS-rebinding pinning 仍生效。
- 行为规格（`docs/reverse/`）：本票不引入新行为，只把既有默认显式化，无低置信度新行为。
