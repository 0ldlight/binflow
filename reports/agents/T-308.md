## 1. 做了什么

### 1.1 新包 `internal/adapter/conan`（local 全量）

- **v2 族 17 端点**（规格 §3.1 全表 + HEAD 臂）：`search` / `<ref>/latest` / `<ref>/revisions` / `<ref>/revisions/{rRev}/files`（清单+GET+HEAD+PUT）/ `<ref>/revisions/{rRev}`（DELETE）/ `<ref>/revisions/{rRev}/search` / `<ref>/revisions/{rRev}/packages`（DELETE，pinned 404 文案）/ `packages/{pid}/latest` / `packages/{pid}/revisions` / `packages/{pid}/revisions/{pRev}/files`（清单+GET+HEAD+PUT）/ `packages/{pid}/revisions/{pRev}`（DELETE）/ `<ref>/search` / `<ref>`（DELETE 全 recipe）。
- **v1 族全量 17 端点**（CN-1 终裁推翻 v1.1 收窄）：握手三端点（`ping` / `users/authenticate` / `users/check_credentials`）+ 数据面（`conans/search` / `<ref>` snapshot+DELETE / `<ref>/search` / digest×2 / download_urls×2 / upload_urls×2 / snapshot×2 / `packages/delete` / remove_files×2）+ **files 直传通道**（PUT/GET，`[0/]` 双拼写；修订段默认 `0`，latest 由索引层解析——PUT 落 `0/` 树并注册 `0` 进 index，GET 经 index 解析 latest 后服务该树）。
- **修订链机制**（§4/§5 + TL-3）：`index.json` = revisions 响应体同构（`{"reference","revisions":[{revision,time}]}`，time 降序、同 time 按 revision 降序）；`.timestamp` 毫秒纪元、**首写定终身后不覆盖**（TL-3 无阈值例外）；latest = index 首项。读-改-写环按（repo, 坐标根）/（repo, package 目录）互斥（cargo B1 同款 refcounted mutex，测试断言并发上传同 revision 无丢行、revision 恰出现一次）。
- **能力头三 rclass 逐字**（TL-2）：`X-Conan-Server-Version: 0.20.0` 恒报；`X-Conan-Server-Capabilities`：local = `complex_search,checksum_deploy,revisions,matrix_params`，remote/virtual 追加 `only_v2`；`X-Conan-Client-Version-Check` 四档（<0.16.0 deprecated / <0.20.0 outdated / =0.20.0 current / >0.20.0 server_outdated）。**每个 conan 响应（含错误臂）都带**（capWriter 包装实现）。
- **S6 逐字 400**：remote/virtual 上的 v1 族请求 → `Unsupported Conan v1 repository request for '<repoKey>'`；v2 族 → 本发布未搭载的诚实 404（T-312 票面）。
- **校验链**（§6）：PUT 走统一 `X-Checksum-*`（malformed 400 / 不符 409）；checksum-deploy 零 body 部署（sha256/sha1，miss → 404 C15 文案；v1 files 通道 miss → **显式透传 404 `Path not found`**，S8）；下载带实测 `X-Checksum-*` 头。真实 conan 2 客户端上传时序实测走 404（deploy 试探）→201（真实 body）两跳，正是该机制。
- **绝对 URL**（TL-1）：v1 digest/download_urls/upload_urls 一律 `{server.base_url}/binflow/<repoKey>/v1/files/<坐标序路径>/0/...`，空配置回退请求 scheme+host（X-Forwarded-Proto 认可）——npm/nuget/cargo 先例零新配置。
- **`<ref>` 语法与 S12**：`{name}/{version}/{user}/{channel}` 四段，`_` 占位字面存储字面匹配；大小写保留（percent-decode 防御后按原 case 落盘）；revision/pid 按 hex 字符集校验（路径防穿越，非内容校验——服务端不重算 RREV/PREV，§5）。
- **存储布局**（§4 逐字）：`<user>/<name>/<version>/<channel>/index.json` + `<rRev>/.timestamp` + `<rRev>/export/...` + `<rRev>/package/<pid>/index.json` + `<rRev>/package/<pid>/<pRev>/{.timestamp,conaninfo.txt,...}`。注意 **wire v2 族用复数 `packages`、存储与 v1 通道用单数 `package`**（§4 布局逐字），两套词汇不混用。
- **metadata provider**：index.json/.timestamp → KindMetadata（可再生）；export/package 文件 → KindContent（每 revision 不可变）——喂给 T-312 remote 引擎的 TTL 双分。
- **conan reindex 管理面**（§3.3 / ADR-0034 dispatchAPI 族）：`ManagementHandler` 业务体（`POST /binflow/api/conan/reindex`〔query+JSON body 两种入参〕与 `POST /binflow/api/conan/{repoPath}/reindex`），门 = 认证 + CanManageRepo(write)（内部自带，裸挂载不绕门）；仅 local（400）；从 .timestamp 事实重建全部 index.json。
