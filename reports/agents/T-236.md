## 6. 过程记录（坑与修法）

1. **make 在 web/ 下无 target**：`cd web && … && make build` 静默失败（grep 吞了报错），
   二进制陈旧导致「改了没生效」假象——用 `grep -ao index-*.js bin/binflow-server`
   对账嵌入 hash 后排除。二进制新鲜度纪律再 +1（embed 面同样适用）。
2. **Shift+F10 键形**：Chromium 实测 `e.key === 'F10' && shiftKey`（非字面
   'Shift+F10'）——键盘处理器三态兼容（F10+shift / ContextMenu）。
3. **菜单 scroll 捕获监听 vs Playwright 自动滚动**：`scroll` capture 关菜单会被
   Playwright click 前的 scrollIntoViewIfNeeded 触发 → 点击中途菜单消失。改为
   fixed 定位 + mousedown-outside + Esc 关闭（去 scroll 监听）。
4. **seed 助手语义**：`ensureReadGrant` 是 create-if-absent（名字固定 m8-e2e-read，
   只盖 m8-perf-local）——spec 给独立仓授权要 POST 独立命名 target。
5. **axe color-contrast（serious）**：共享 tree.css 的 `.on-chain` accent 文字在亮色
   主题 surface-2 上 4.47:1（差 0.03 不过门）。修法：browser.css 内 `.browser-page`
   作用域覆盖——文字回 `--bf-text` 全对比度，链语义改左侧 accent 指示条承载。
   （tree.css 本体未动——共享文件，同款样式若在其他页复现归 T-239/T-240。）
