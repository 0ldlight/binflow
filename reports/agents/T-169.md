### ② G15b — systemd 裸机部署收编（contrib/systemd/）

| 文件 | 变更 |
|---|---|
| `binflow.service` | T-168 优雅停机锚点：显式 `KillSignal=SIGTERM` + `TimeoutStopSec=30→45`（服务端 drain 上限 30s + teardown 余量，防 systemd 在 drain 完成瞬间 SIGKILL）+ 注释链到 journal 的 "shutting down gracefully"；`UMask=0027`（systemd-analyze security 唯一剩余建议；fresh db 0644→0640 实测生效） |
| `install.sh` | **修复 3 个真机 bug** + 3 项收编，全部 shellcheck 零告警 |

install.sh 修复明细（每条均在真 Linux systemd 容器上首跑复现后才修）：

1. **checksum 校验从未工作过**（G16 防线形同虚设）：`sha256sum -c` 按**当前工作目录**解析 checksums 行里的裸文件名，非按 checksums 文件所在目录——真机首跑必 `FAILED open or read` 中止。修复：`cd "$(dirname "$archive_file")"` 后再 `-c`。
2. **重装/升级路径 ETXTBSY**：运行中的服务持有二进制，`cp` 覆盖报 "Text file busy"。修复：替换二进制前 `systemctl stop`（首装无服务可停），结尾的 `enable --now` 负责拉起；配合 `rm -f`+`cp` 防半写二进制。
3. **全新安装必入 restart 循环**：goreleaser 归档只打包 binaries+README/LICENSE（无 config.yaml），而 `serve -c` 对显式缺失配置是硬错误 → 服务起不来 → `Restart=on-failure` 死循环。修复：无归档配置且无现存配置时生成最小配置（listen :8080、data_dir /var/lib/binflow，其余走内置默认；secrets 明示走 `/etc/binflow/env` 的 BINFLOW_ADMIN_PASSWORD，ADR-0009）。
4. **--dry-run 全链路可用**：原实现在校验/解压/二进制检查处必 die；现在非 root、非 Linux 工作站均可完整预览（download/verify/extract/service 动作全部打印跳过；平台探测降级为预览 linux 流程并告警）。
5. **装机后验证门（G15b 烟测内建）**：`enable --now` 后等 `is-active`（`BINFLOW_START_TIMEOUT`，默认 30s，超时 dump status+journal 后硬失败）+ readyz 探测（10×1s 重试窗口——unit active ≠ listener 已 bind，argon2 seed+migrations 先行约 1s；`BINFLOW_HEALTH_URL` 可覆盖，advisory 因 listen 是配置项）。
6. 依赖清单补 `tar/mktemp/grep`（原漏检，`ln` 从未使用已去掉）。
