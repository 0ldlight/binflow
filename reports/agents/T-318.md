### 1.2 virtual.go（新）——各面语义

- **index/{pkgPath} 归并（核心，规格 §12 裁决① 落地）**：按成员序经 `ReadVirtualMember`（remote 成员即 FR-20 引擎 pull-through，负缓存保留——文档读面的既定语义）读各成员索引文件全文，**行级去重键 = (name, 忽略 build metadata 的 vers)**（`normalizeVersionKey`，官方唯一性 must），**首见成员的原始行字节逐字保留**（不重排/不重编——上游行的自有字段集如 v/features2 原样存活；BinFlow 自产行的规范化由生成侧保证），再按 SemVer 排序输出（与 local 面写入序一致，确定性渲染）。裸拼接（Artifactory 反编译行为，重复行违反官方 must）不采纳——按规格登记的 BinFlow 建议执行，真机侧证见 §3。
- **合并文件校验器**：ETag = 渲染后合并体的 sha256（无单一 node 背书）、Last-Modified = 最新贡献成员节点时间，If-None-Match/If-Modified-Since → 304；`X-BinFlow-Resolved-From` = **首见贡献成员**（base——它赢下所有重复行平局，npm 合并 packument 同款姿态），base 成员 reader 的响应 hints（remote 成员的 X-BinFlow-Cache 族）随响应透出。
- **config.json**：合成自指 **virtual 仓**（dl/api 指回聚合面——下载必经 first-hit 成员解析；remote 面同款姿态上一层）；写仍 403。
- **download**：`svc.Get` 即服务层 getVirtual first-hit（local 成员节点 / remote 成员引擎链），`serveDownload` 原样复用，`serveNode` 结构化合并 Resolved-From + 缓存 hints。
- **search 跨成员归并**：local 成员 = 存储事实行（`ListVirtualMember` + **成员命名空间的 props**——yank 标志/描述在节点所在成员处；best 非 yank 版本、通配匹配、1000 扫描上限，均 local 面同款规则按成员执行）；remote 成员 = **查询键标记路径**（`.cargo/search/<hex>.json`）经 `ReadVirtualMember`——即该成员上游 search 端点的 pull-through 拉取（T-316 缓存形按查询独立 MISS→HIT）；行按 crate 名**首见胜**并集（与服务下载序一致），合并后再 per_page/排序。
- **publish 写路由**：`defaultDeploymentRepo`（三别名宽容读，npm/conan 同款本地复述）——**整条 local 发布链换址到目标成员**（帧解码→crate 落地→sidecar→`rewriteIndex(成员)`；npm loadPackumentForWrite 姿态：落在虚址的收敛会死于 svc.List 的虚仓拒绝，成员索引将滞留）；未配置 → **C5 405**（RE-08 钉死措辞本地复述，M52 逐字可比；body 排空前拒绝）。
- **yank/unyank first-hit**：解析出服务的成员（reader 的 Resolved-From hint）——local 持有者收属性 + 其自身索引重写（成员内语义原样）；**remote 持有者 405 只读措辞**（缓存副本非 BinFlow 可标记之物，上游拥有真相）；未知名/版本 → TL-6 404。
- **裸内容面**：GET first-hit；PUT 走写路由换址落地（收敛在成员）；DELETE = 服务层 refuseVirtualDelete（routed/unrouted 双措辞原样透传，405 + Allow: GET）。
- **成员失败策略**（npm/pypi/conan 聚合规则）：unfound 成员贡献空；分类失败（SSRF 400/hardFail 502）容忍跳过（WARN 日志）；**全体一无所获时浮现记住的失败**而非掩蔽成 404。

### 1.3 与 T-316 D-5/convergeIndex 的协调

- 虚址裸写（`index/**`/`.cargo/**`/普通路径 PUT）**先解析写路由、换址到部署成员再走 `serveDerivedWrite`**：落地与 `convergeIndex` 都在成员仓执行（成员可 List，收敛闭环成立）；未配置路由的虚仓经共享臂落到 `svc.Put` → 服务层 C5 405（换址无必要——收敛不可达）。
- 虚仓 DELETE（含索引文件面）不换址：服务层永不传播语义本身就是答案，措辞由 StatusError 原样渲染。
- `config.json` 写仍 403（合成面无落点，三类一致）。
