### 关键决策（reviewer 请重点看）

1. **隐式目录的浏览回退（本票最大契约发现，漂移 1）**：`putNode` 只落文件行、不落父目录行——制品路径推断出的目录（`acme/app.bin` 的 `acme`）在 `GET /api/storage/{repo}/{dir}` 是 404（folder 行只有 E-15 mkdir 建过才存在）。树对这类目录回退**搜索面前缀重构**（`name=<dir>/` 子串命中 + 客户端 startsWith 收窄 + 首段投影；搜索索引排除 folder 行，空的 mkdir 目录走 item-info 主路径可见）。副作用：搜索面回退返回全后代（非一层）——大数据量大目录与 R1 同族的代价，登记遗留 2。
2. **mkdir 逐段材料化祖先**：隐式目录下新建的空目录在搜索面重构里不可见（folder 行不进索引）——mkdir 把目标路径每一段都尾斜杠 PUT（已存在的 folder 行重放 = 幂等 redeploy 只刷 mtime），保证新目录在任何父目录下列表可见；祖先段失败不致命（窄授权），仅目标段失败上抛。与参考实现「目录是实体」的语义对齐。
3. **下载 sha 对账双路径**：详情面板「下载并校验」走 fetch → body.tee（一腿流式哈希、一腿 Blob 落盘），对账源 = item info `checksums.sha256`，徽标 ✓/✗（W13）；大文件给「直接下载」锚链接（不经浏览器哈希，内存友好——1GB RSS 腿归 T-104/T-105）。
4. **非 admin 的树页降级**：repo 元数据是 admin 面（路由门）→ 403 时按 generic 语义呈现（warn-box 说明），上传/删除按钮保留（内容面权限与 admin 无关），操作被拒时 403 原因行内呈现——W12d 的 read-only 腿即走此路径（E2E 全覆盖）。副作用：非 admin 打开 docker/npm/pypi 仓会看到 generic 形态上传入口，PUT 会被协议 adapter 拒并原样呈现（遗留 6）。
5. **上传错误三分支原样呈现**：E-01 message 逐字 mono 展示 + 语义提示行（403 → 权限指引 + admin 可见的权限页链接；413 → 「配额已满、原子拒绝零残留」；409 → pattern 或 checksum 双值说明）。UI 自算 checksum，409-mismatch 无法经 UI 自然构造——渲染路径与 pattern-409 同一管线（E2E 已盖 pattern 腿）。

## 契约漂移（与契约文档/派单信息不一致处，供 conductor 逼回写）

1. **隐式目录无 folder 行（最重要）**：`repo.putNode` 只落文件节点不落父目录行；`GET /api/storage/{repo}/{dir}` 对「制品路径推断出的目录」404（storage.go 的 storageNode 需要显式 folder 行）。`?list` 同样 404（先 storageNode）。FE 已按「搜索面前缀重构」回退 + mkdir 逐段材料化祖先消化（决策 1/2）。建议 architect 裁：service 在 Put 后材料化父目录行（对齐 Artifactory 目录实体语义），或 storage.go 对 item-info 的目录分支用 ListByPrefix 前缀列举——两者任一落地，FE 回退路径可删（主路径不变）。
2. **派单所述「children 列表/keyset 游标」与实际不符**：storage.go 的 children 无任何分页参数（console-ux §9-R1 的缺口原样）。FE 按 §6.5 兜底：客户端分页 100/页 + >2000 提示 + 行级 content-visibility（真窗口化见遗留 3）。
3. **folderChild 只有 uri('/name')+folder 两字段**：右表的 size/lastModified 不在 children 里——非根目录用 `?list&depth=1` 二请求合并（listFile 有 size/lastModified/sha1/sha2）；**根目录 `?list` 恒 400**（"Cannot list files of root."）→ 根层文件的 size/mtime 显示 `—`；createdBy 两处都无 → 仅详情面板（item info 有）。
4. **folder DELETE 必须携带尾斜杠**（实测）：`DELETE /binflow/r/d` → 404 "Could not locate artifact"（service.Delete 的 isFolderNode 分支键在尾斜杠）；带斜杠 → 204 递归删子树。与 rest-api 侧「目录地址可省尾斜杠」的直觉相反，建议回写 repo-semantics/storage 注释。
5. **建用户必须带合法 email**：`PUT /api/security/users/{name}` 对空 email 400 "Please provide a valid user email."（W12d 测试腿实测；SE-05 文档未强调必填）。
6. **搜索 SR-01 无分页参数、无类型化副行字段**（ux R2 的 P2 部分）：FE 客户端切片 + 副行从路径推导（maven GAV/metadata），不逐行二次请求。checksum 反查（SR-02）未接 UI（引导文案注明 CLI，遗留 5）。
7. **E4 知会核对（无缺陷）**：T-99 commands.ts 的 docker 例是 `docker login <origin>`——走 `/v2/token` Bearer 面（registry 平面），不经 `/binflow` 会话面，cookie Path=/binflow 排除 /v2 不影响它。本票树页 docker 命令卡复用同一块并在说明文案中注明「登录经 /v2/token（registry 面，与控制台会话无关）」。
8. `?permissions` 对 virtual/remote 400（P2 已知分支）：FE 只对 local 仓选中节点呈现该 facet（403/错误隐藏）。
