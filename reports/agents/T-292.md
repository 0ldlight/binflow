## 关键发现（对 M11 拆票有直接输入价值）

1. RPM 的自动重算默认关闭（calculateYumMetadata 默认 false）+ 增量索引默认关闭——BinFlow 全量重算即对齐 Artifactory 默认行为，实现面收敛。
2. RPM 索引只生成 .xml.gz 一种形态，sqlite 主动清除、zck 无代码路径——任务清单里「sqlite/xz/zck 形态」的答案是不做，规格 §9 已登记。
3. Helm 经典仓在 Artifactory 挂在 `/api/helm/<repoKey>` 而上传走存储内容面——BinFlow 建议内容面为主（helm 客户端只做相对 GET，两种挂载都兼容），`api/helm` 别名用现成 apiProtocolMounts 机制。
4. HelmOCI 与 docker v2 是**同一 REST 面**（isDockerGroup 三类型集 + config model 继承 OCI），BinFlow 增量只有：package_type=helmoci 分发接线 + helm media type 集合进 manifest Content-Type 映射；referrers 不做（helm push/pull 不依赖）。
5. Helm 虚仓缓存键含客户端上下文 URL 哈希 + 权限集哈希（不同对外 base/权限各一条 index 缓存）——BinFlow 实现时缓存键设计要带上这两维，否则权限过滤会串。
