## 4. 过程记录（坑与修法）

1. **Playwright fill 对已聚焦元素不重放 focus 事件**：recentSearches 腿里
   「Enter 应用后清空关键词再聚焦」拿不到 focus 事件 → 下拉不开。修法：
   先点页面标题失焦再 fill/focus（断言确定性）。
2. **axe include 在 lazy 分片到达前扫描**：profile 页 goto 后立即 analyze 报
   「No elements found for include」。修法：先断言页面根锚可见再扫
   （expectA11yClean 的使用纪律）。
3. **axe link-in-text-block（serious）**：登录常驻说明（muted 弱化色）里加
   文档链接后，链接与周围文字仅靠色彩区分不足。修法：链接带下划线
   （text-underline-offset 2）——非色彩信号，首轮全量唯一失败项，修复后绿。
4. **测试实例进程被环境回收（T-236 同款坑再证）**：nohup 后台起的
   binflow-server 数分钟后被 SIGTERM（「shutting down gracefully」），症状 =
   e2e 批次中途 ECONNREFUSED / beforeEach 秒失败 +「N did not run」。
   修法：非沙箱起服 + nohup + disown（90s 存活验证后再跑批次）。
5. **pkill 模式陷阱**：`pkill -f t239/binflow-server` 匹配不到 `./binflow-server
   serve -c /tmp/t239/binflow.yaml`（命令行里是 binflow.yaml 不是
   binflow-server）→ 旧实例存活导致 bind 冲突、新口令实例没起来（401 假象）。
   按 PID kill 后恢复。另：管道 `| tail` 会吞 playwright 退出码，终局腿改
   重定向到文件取真实 exit code。
6. 并行票 T-238 在共享工作树同窗落码（SystemInfoPage/StorageSummaryPage/
   main.tsx 挂载 + 他们也全量跑 e2e）：本票 main.tsx 编辑基于盘上最新态
   （/profile 挂 ProfilePage 与其 /admin/general/settings 挂 SystemInfoPage
   无缝冲突）；SettingsPage 的解散以「拆分终态」口径执行并在此登记。
   共享 node_modules 的并发 npm 活动会偶发 eslint formatter 加载失败——
   重试即绿（非本票产物问题）。
