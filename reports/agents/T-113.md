## 顺带核实：非 local 仓 ?permissions 是 404 还是 400 —— 结论 **400**（置信度：中，代码直读两层调用链）

调用链：`ArtifactResource#getStorageInfo` → `#prepareResponseAccordingToType`（`?permissions` 分派）→ `#preparePermissionsResponse` → `RestAddonImpl#getItemPermissions`。

- **资源层前置（可达分支）**：`#preparePermissionsResponse` 先做 `#isLocalRepo` 判定——非 local/cached 仓（virtual、remote 本体、不存在的仓）直接抛 **400**，文案 `This method can only be invoked on local/cached repositories.`。
- **addon 层 404（二道门，正常不可达）**：`RestAddonImpl#getItemPermissions` 里 `ItemNotFoundRuntimeException("Unable to find local repository '<key>'.")` → 404（显式 catch 转 `NotFoundException`，全局 `ItemNotFoundExceptionMapper` 亦 404）——判定条件与资源层同源，仅并发删仓等分叉窗口可触。review NB6「疑 404」不成立。
- **正常可达的 404** 是「repo 为 local + 路径不存在」：`Unable to find item '<repoPath>'.`。
- 校验次序：Accept 不兼容 406 → 非 local 仓 400 → 无 manage 权限 403 → item 不存在 404 → 200。
- 推论：**BinFlow 现行「非 local → 400」实现与真机规格一致，无需改码**；动态复现可选留给 T-103（真机 curl 一条即可复核文案）。
