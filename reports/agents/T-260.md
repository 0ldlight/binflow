### 1.1 lib/stepUpGrant.ts（新）——grant 消费面单点

- **fragment 消费**（§14.3-2）：`consumeStepUpFragment()` 在 **main.tsx 模块作用域**
  （早于 React 树渲染，严格早于「AppShell 挂载期」的契约下界）执行——`location.hash`
  前缀 `#step_up_grant=` → 提取 → **立即 `history.replaceState` 抹除**（保 pathname/
  search，不入历史、刷新不重放、地址栏不可见、不触发 popstate 路由零感知）→ 64hex
  形态校验（不符 = 孤儿：已抹除，静默丢弃）→ 有 pending 才激活内存 grant。
- **pending-mint**（§14.3-1）：sessionStorage 键 `bf.pendingMint`（契约指定拼写），
  值 = `{pkg, repo, startedAt}`——**grant 值绝不入此结构**；陈旧线 3600s+60s（grant
  TTL 上界）自动清理；sessionStorage 不可用（隐私模式）静默降级。
- **内存 grant store**：`useSyncExternalStore`（AppShell/SetMeUpDialog 消费）+
  `stepUpGrantValue()`（挂载 effect 取值）；`settleStepUpMinted/Invalid` 与
  `abandonStepUp` 三个结算口——invalid/成功/用户放弃即清 grant + pending。
- **日志卫生**：模块零 `console.*`（grep 证据 §2.3）；全 `web/src` 仅本模块一处
  `location.hash` 读取（唯一合法消费点）；step-up 路径零 localStorage。

### 1.2 SetMeUpDialog.tsx——OIDC 腿（T-242 过渡注记的真身，ADR-0027 决策 8 后半）

- **腿分流**（决策 3）：whoami `source=oidc` → 重认证腿；local/ldap/未知回退口令腿
  （T-242 形态逐字保留——旧行为零变化）。
- **发起流**：401 `step_up_required` 且 oidc → `need-reauth` 引导面板（说明文案含
  「将跳转身份提供方重新登录」）+「重新认证并继续」→ 存 pending-mint → 全页跳转
  `/binflow/api/v1/oidc/login?purpose=step_up`（busy 态防双发）。
- **回跳续铸**：`resume` prop 挂载即自动 `runMint({grant})`（body 携 `step_up_grant`）；

## 3. 契约漂移与口径注记

1. **票面 authorize 路径与契约不符（已按契约实现）**：dispatch 文称跳转
   `/binflow/api/auth/oidc/authorize?purpose=step_up`；**实际契约**（T-219 服务端
   oidc.go + architecture §14.3 服务端事实）是 `GET /binflow/api/v1/oidc/login?purpose=step_up`
   ——实现与 ADR/architecture 一致，票面路径系笔误，请 conductor 知悉（无需回写
   契约文档，文档本身正确）。
2. **§14.3-2「AppShell 挂载期」的落点上移**：fragment 消费放在 main.tsx 模块作用域
   （早于 React 渲染）而非 AppShell 挂载 effect——React effect 自底向上（子先于父），
   AppShell effect 并不早于路由内容；模块作用域严格满足「早于路由渲染」且消除竞态
   窗口。消费结果的感知（重开续铸视图）仍在 AppShell。语义超集满足，建议 §14.3-2
   措辞回写为「app 引导期（main 模块作用域，早于路由渲染）」。
3. **grant TTL 无查询端点**：§14.3-3 的「TTL 倒计时提示（默认 300s）」只能按默认值
   呈现（实例配置 [60,3600] 不暴露）——已实现为提示性质（M:SS 倒计时 + 服务端 401
   为权威裁决）。若要精确倒计时需服务端在 fragment 或错误体携带 TTL（additive 契约
   变更，未立票不做）。
4. 其余逐项对齐：`bf.pendingMint` 键名、sessionStorage（非 localStorage）、错误体
   ADR-0027 决策 5 逐字（e2e 逐字节断言）、单次消费即焚、admin 豁免臂与 local/LDAP
   腿零回归（m8 spec 双姿态复绿）、`token_id` 如实降级注记（T-242 漂移③维持）。

## 5. 过程记录（坑与修法）

1. **mock IdP form action 整串 encode**：`action="/authenticate?${encodeURIComponent(query)}"`
   把整个 query 编码成单值 → 服务端 `url.searchParams.get('redirect_uri')` 为空 →
   回调链断（页面快照「missing redirect_uri」）。修法：query 原样透传 + HTML 属性
   转义（`&`→`&amp;`）。
2. **armed 探针在 about:blank 上 evaluate**：相对 URL fetch 无法解析（Failed to parse
   URL）。修法：先 `page.goto('/binflow/ui/')` 再探针。
3. **axe color-contrast serious=1**：muted 提示色在 smu-stepup 的 surface-2 底上
   4.5:1 不足——口令腿从未被 axe 扫过（T-242 axe 腿只扫 idle 态），OIDC 引导面板
   长文案首次暴露。修法：§1.5 作用域升 text-2。
4. **默认实例首跑 2 失败（flake）**：冷启动实例 + 4 worker 并发播种时延，test 200/263
   未设宽松超时（默认 30s）。修法：补 `test.setTimeout(60_000)`（88 腿本有 120s），
   此后 4 连跑零 flake。
5. **eslint Node globals**：mock IdP 放 e2e/support 会命中 no-undef（URLSearchParams/
   Buffer/process）；scripts/ 已有 carve-out 但只声明 URL/console/process——按 seed-m8
   先例（显式 `node:` import + globalThis.fetch）放 scripts/ 并显式导入，共享配置零改动。
