### AC ② CE-03~05（W03~W08/W37a）：session 三臂

- **auth 包第三臂**（session.go 新文件，~210 行）：
  - `Service.sessions`（consumer-side `webSessionSource` = metadata.WebSessionStore 子集，直接满足）；`WithSessions()` 克隆缝；**`NewFromStore` 无条件接线**（004 表随 metadata.Open 恒在）——cmd 装配零改动、全部 harness 自动获得；
  - `Authenticate` 臂序：Authorization Basic → X-JFrog-Art-Api → Bearer → **Cookie binflow_session（最后）**；头部凭据优先于 cookie（Bad Basic + 活 cookie 仍拒——头部臂已运行）；**呈交但失效的 cookie = 拒绝凭据（绝不降级匿名）**：未知/过期/已吊销/属主禁用全走 ErrInvalidCredentials 家族 → 401；
  - 每请求重查属主（改 admin 位即时生效、禁用账户杀会话；删户由 FK 级联）；心跳 Touch 复用 token 的 1 分钟节流；
  - **TTL 语义（ADR-0014 决策 2 + 勘误③逐字实现）**：`expires_at = created + TTL` 绝对封顶、last_used 心跳、单键下滑动被封顶数学吞没（注释给出推导：last_used ≥ created ⇒ last_used+TTL ≥ expires_at，续期永远钳到封顶）——**测试固化「封顶胜过滑动」**：TTL 1.2s、中途心跳成功、过点即 401（TestSessionTTLAbsoluteCapWins）；
  - `IssueSession`（32B crypto/rand = 256bit ≥ NFR-S19 128bit 下限；行只存 sha256）+ `RevokeSession`（幂等，not-found 冒泡 metadata.ErrWebSessionNotFound）+ `AuthenticateCredentials`（**就是 authenticateBasic**——argon2id + token 对偶同一实现，控制台不另养密码路径）；
  - `Principal.ViaSession bool`（架构 §3.4 字段位之外的臂标记，供 CSRF 面判定；session 无 TokenID）。
- **httpapi `/api/v1/session` 三动词**（session.go 新文件）：
  - `POST`：JSON/form 双形态（token 面同款首字节嗅探，1MB 上限）；缺字段/坏 JSON/坏 content-type → 400 E-01；错凭据 → **401「invalid credentials」与 router 拒绝凭据分支同文案**（未知用户 vs 错口令 body 逐字节相同，不泄露存在性）；`login.failed`/`login.success` 落审计（复用既有词表动作，actor=尝试用户名，Redact 链盖 password 键）；签发/吊销 info 级结构化日志（user/expires_at，**无 session 值**）；
  - `GET` = whoami：任何臂（cookie/Basic/token）→ 200 `{username,admin}`；匿名 401（路由门 required）；
  - `DELETE` = 204：吊销行 + 清 cookie（Max-Age=-1 + Secure 镜像签发姿态）；重放 401；非 session 臂到达（Basic 登出）= 幂等 no-op 204；
  - **cookie 契约**：`binflow_session; HttpOnly; Path=/binflow; SameSite=Lax; Max-Age=TTL秒`；**Secure 依 `server.base_url` scheme 优先、否则请求 scheme（r.TLS/X-Forwarded-Proto）**——明文 HTTP 不加（TestSessionCookieSecureFlag）；
  - audit Recorder：`audit.BestEffort(audit.New(Deps.Metadata, cfg.Audit.Enabled))` 于 Server.New 内建（架构 §2 边界规则 2 明文允许 httpapi 消费 audit）；session facet 经 **Deps.Auth 类型断言**发现（cmd Deps 清单零改动，fake authenticator → 端点 503）。
- **等价认证**：臂在 `Service.Authenticate` 内 → 经共享 authenticate 中间件覆盖**所有面**——内容路径（PUT/GET/DELETE 全走 cookie，TestSessionCookieEquivalence/content_plane 在 anonymous OFF 实例上证明「非匿名不通过」）、管理面（/api/v1/storage/stats 200）、**docker adapter 面**（ux R10：匿名关时 cookie GET /v2/ 200 vs 无凭据 401——token 流/tags/catalog 同一 authenticator）。
- **重启不掉线（W37a）**：行存储 → 全新 auth.Service + 全新 httpapi.Server 同库复验（go 测试 + curl 真机双证）；**W08 TTL**：`console.session_ttl_seconds=5` 实例登录 → Set-Cookie Max-Age=5 → sleep 6 → whoami 401（curl 真机）。
- **session 值不进日志**：auth 级（TestSessionValueNeverLogged 风暴全失败路径）+ httpapi 级（login/whoami/logout 全程日志 grep 无 id）双断言。

### AC ③ CE-06（W38）：CSRF Origin 防线

- `csrfGuard` 中间件（middleware.go）：链位 **authenticate 之后、dispatch 之前**（需 principal、先于一切路由决策——W39 语义：跨源 DELETE 真路由先见 403 不见 204）；
- 规则：`ViaSession && 非 GET/HEAD && Origin 存在 && 非同源 → 403`；无 Origin/同源放行；Basic/Token/Bearer 天然免疫（**curl+CI 零感知**）；同源判定 = Origin scheme+host 与 `requestScheme(r)`（X-Forwarded-Proto 感知，TLS 终止部署不误杀）+ r.Host 的 EqualFold 比较；Origin `null`/不可解析 → 拒（fail-closed）；
- SPA 习惯层 `X-BinFlow-Console`：服务端**不校验不拒绝**（勘误④撤销强制头），测试固化「带头放行、无头也放行」；
- 矩阵（TestCSRFOriginMatrix）：跨源 403 / 无 Origin 201 / 同源 201 / Origin:null 403 / Basic+跨源 201 / token+跨源 201 / GET 豁免 200 / 守卫先于路由（跨源 DELETE 403 且会话幸存）/ 陈旧 cookie+跨源 = 401（认证先于 CSRF）/ XFP-https 同源 201。

### config console 段

- `ConsoleConfig.SessionTTL`（api.go）+ `DefaultConsoleSessionTTL = 24h`；YAML 双键 `console.session_ttl_hours`（主）/`session_ttl_seconds`（覆盖，**同给 seconds 胜——两键是同一值两种精度，非冲突**，与 anonymous 双键的报错语义区分并注释）；env 键 `BINFLOW_CONSOLE__SESSION_TTL_HOURS/__SESSION_TTL_SECONDS`（走排序遍历，H<S 确定性 seconds 后写胜）；Validate 正数（显式 0 拒——与 storage TTL 零值口径一致）；console_test.go 8 用例（默认/hours/seconds/双键/env×2/未知键拒/零值拒）。

## 决策点（5）

1. **臂在 Service.Authenticate 内（非 httpapi 包装）**：内容/adapter/管理面共享一条认证链，「等价凭据」由结构保证而非逐面接线；cmd 与既有 harness 零改动（NewFromStore 接线）。
2. **失效 cookie = 拒绝凭据不降级匿名**：与 M1「presented-but-rejected 绝不静默成功」姿态同源；过期会话 401 使 SPA 路由守卫可判重登（PRD「到期待遇同未认证」）。
3. **session facet 经 Deps.Auth 类型断言**：cmd Deps 清单不动（area 纪律）；fake authenticator 时端点诚实 503。
4. **TTL 单键塌缩按封顶读法**：见「规格依据」末条；last_used 列留作未来 idle<absolute 拆分的缝。
5. **审计走 audit.BestEffort + 既有词表**（login.success/login.failed 早在 M1 词表，本票首次落 caller）；未发明 logout 动作（词表无、AC 未要求）。
