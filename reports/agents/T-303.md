## 2. 模板体系结论（ADR-0036 分歧门）

**分歧门：关。**

- Artifactory 模板速记 = ①固定注册表展开（非用户可组合原语）+ ②自描述标签（模板名展开后保留为 `BinaryProvidersInfo.template`，原样出现在系统信息 Storage Type / 存储摘要 storageType）+ ③一个上报分支条件（cacheSize 仅在 template==cache-fs / full-db 时上报）。
- **无 `dual` 模板 / dual provider**（反编译全源 0 命中 + 当前官方文档 TOC 无该页，双证）；现行 filestore→S3 迁移 = eventual `_add` 符号链接排水或停机手动拷贝，**不是链内 provider**。ADR-0036 的 `[filestore, s3] + migration.mode` 是 BinFlow 自己的一等拼写，Artifactory 无对应模板速记 → 不存在「少模板层丢模板语义」问题。
- 未定位到「模板 vs 等价显式链」在**数据存取路径**上的行为分叉 → canonical 显式链（ADR-0036 决策 2）不损失行为等价性。
- 遗留登记（非阻塞，转 T-306 设计决策点，已写入 §1.2）：a) BinFlow 等价自描述字段（存储链形态 INFO 行 / 未来 storage info 端点）取值语义；b) cacheSize 类条件上报在无模板层时改按「链上是否存在缓存 provider」判定。
