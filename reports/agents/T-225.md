### 1. 文档命令真实性（本机 scratch：BinFlow 18225/18227/18230 + 自建 Keycloak 26.2.5〔18226，realm binflow/ssouser〕+ OpenLDAP〔13890，jdoe〕，2026-08-23 当前工作树 `make build` 产物）

config 面：

```
TTL=5（开关 on）serve        → exit=1  config: auth.token_step_up_grant_ttl_seconds must be within [60, 3600] seconds, got 5s
TTL=3601（开关 off）serve    → exit=1  同文案 got 1h0m1s（无条件拒启动双态钉死）
纯 env 开关（无 yaml 键）：BINFLOW_AUTH_TOKEN_STEP_UP=true + ..._GRANT_TTL_SECONDS=120
                             → 非 admin session 无凭据铸 401 step_up_required（env 双拼写端到端）
```

本地腿（dev1，session 臂）：

```
POST /api/v1/session → 200；whoami {"username":"dev1","source":"local"}
无凭据铸          → 401 {"error":"step_up_required","error_description":"step-up authentication required to mint a token"}
错口令            → 401 {"error":"step_up_invalid","error_description":"step-up credential rejected, expired, or already used"}
对口令（form）    → 200 {"access_token":<64hex>,"token_type":"Bearer","expires_in":2592000,"scope":"api:*"}
对口令（JSON 体） → 200 同形
```

LDAP 腿（jdoe，session source=ldap）：同三态（required / invalid / 200）逐字同文案。

OIDC 腿（ssouser，session source=oidc，Keycloak 全链）：

```
无 grant 铸                     → 401 step_up_required
错腿（交 step_up_password）     → 401 step_up_required（产品自决②实测）
GET /api/v1/oidc/login?purpose=step_up → authorize URL 含 prompt=login（grep 断言 OK）
未知 purpose=hijack             → 400
重认证 → callback               → 302 Location: /binflow/ui/#step_up_grant=fab28b17...cfcad（64hex）
                                  且 Set-Cookie binflow_session 计数=0（不建新 session）
窗口内携 grant 铸               → 200（expires_in 2592000）
复用同 grant                    → 401 step_up_invalid（单次消费）
TTL=60 实例 + sleep 70 后铸     → 401 step_up_invalid（过期腿）
重启实例后同 grant              → 401 step_up_invalid（台账进程内存，session 仍在——grant 不在）
```

豁免臂（开关开启下）：

```
Bearer 臂（dev1 token 再铸）    → 200
Basic 臂（dev1 口令）           → 200
admin session 自铸              → 200
/v2/token（dev1，docker 协议）  → 200 出 token
匿名                            → 401 {"error":"invalid_request","error_description":"authentication required"}（路由门在前）
readonly_admin session（roa）   → 无凭据 401 step_up_required / 带口令 200（不豁免，实测）
```

护栏与默认 off 回归：

```
step-up 通过后 expires_in=31622401 → 401 invalid_request "The user: 'dev1' can only create user token with
                                     expires in larger than 0 and smaller than 31536000 seconds (requested: 31622401)"
默认 off 实例：dev1 session 无凭据自铸 → 200；为他人铸 → 403 invalid_request "administrator privileges required"；
                                     TTL 帽 → 同文案 401（V25 口径复验）
```
