## 关键裁决（ADR-0012 / ADR-0013 新增）

### ADR-0012 remote 代理基线

1. **缓存 = TTL + 条件再验证**（ETag/Last-Modified，304 刷新零 body）；**artifact 与 metadata 分流**——制品不可变（checksum 命中永不再验，长 TTL），metadata（maven-metadata/packument/simple 页）短 TTL 可再验证。不做纯 TTL 也 不做永久缓存。
2. **降级 = stale-while-error**：上游故障 + 有过期副本 → 回吐 + `Warning: 111`；无副本 → 502。`unreachable_mask` 改名 `blocked_out` 承接手动遮蔽。不做自动熔断。
3. **SSRF 双检（安全底线设计期义务）**：建/改仓时 URL 校验（scheme 白名单 + 全 IP 解析落私网/回环/链路本地/ULA 清单拒绝，`allow_private_upstream` 显式豁免 + 审计）；**连接时 Control 钩子对实际 IP 复查同一清单**（防 DNS rebinding）；重定向不自动跟随（手动 + 每跳重检 + 最多 3 跳）；超时与体量上限（Content-Length 预检 + 流式计数双保险）。
4. **凭据 = AES-256-GCM + env 密钥**（`enc:v1:` 前缀；`BINFLOW_REMOTE_CREDENTIALS_KEY` 注入；存量明文 003 迁移一次性加密；无密钥有存量 → fail-fast）。兑现技术债 #5 的 M3 承诺。
5. **HTTP client = stdlib-only**：自写 transport 装饰（重试仅幂等 GET、指数退避 2 次），不引 retryablehttp/resty（ADR-0005 准入原则）。

### ADR-0013 virtual 解析与写边界

- **解析 = local-first + 同类内 position 序，首命中即返回**（`X-BinFlow-Resolved-From` 头暴露来源）；不做多源归并择优（版本比较器留 M4+ 缝）。priorityResolution 精确语义待 repo-semantics §7.2 逆向补齐后校准。
- **M3 virtual 只读**：写 → 405 + Allow（repo-semantics §1 既有钩子）；local deployment 承接写推迟（PM 联动）。
- **virtual 探索性 miss 不落盘**（防成员扫描污染 remote 缓存）。
