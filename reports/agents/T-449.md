## 1. 做了什么

### 1.1 列集归一（AC1 / B-2.11 断言反转②）

- **共享 ResultsTable**（web/src/pages/search/ResultsTable.tsx 新建）：
  两模式同一张结果网格（「列框架收敛」）——默认列 = **选择列（固定）+
  Artifact（name 链接）| Path | Repository | Modified**；大小/sha256 =
  列选器**可选项不默认呈现**。三源不一致（现行五列 / T-414 注释 /
  console-m8 §6.4）就此归一。
- **useColumnPrefs 扩 defaultHidden 第三参**（lib/columnPrefs.ts——共享层
  增量：缺省 [] = 既有调用方 repos/audit/users/groups 语义零变化；首访/
  腐化/全隐回落默认集）。「全选列」复位翻新为「恢复默认列」（存储落
  `["size","sha256"]` 而非 `[]`——默认档 ≠ 全显）。
- **选择列**：表头全选（作用于快滤后可见行，indeterminate 三态）+ 行选
  checkbox + 「复制路径（N）」批量拷贝（§7.3 一键拷贝家族行集版——
  BinFlow 无批量端点，选择面诚实能力仅此，不伪造批量删除/下载影子入口
  〔E1/零端点纪律〕）。
- 语义副行（maven GAV / property 投影 / virtual 成员）随 name 走（描述
  制品身份非目录）；路径列 = 父目录。

  ——SR-01 全量返回无服务端分页，客户端窄化即全量语义）+ 命中计数 +
  无匹配占位块；分页行同步（「共 c 项（快滤自 d）」）。
