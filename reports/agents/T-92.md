## 做了什么

打开 M1 E-26 的 search 域**恰好两个口**（SR-04：其余族永久 404）：

1. **metadata 层（新文件 search.go，独立于 T-90 的子接口文件面）**
   - `NodeSearcher` 只读扩展接口（`SearchByName` / `SearchByChecksum`），实现在既有 `*nodeStore` 上，`md.Nodes().(NodeSearcher)` 断言取用——不动 api.go 里的 `NodeStore` 接口声明，与并行 T-90 的 `Store`/`AuditStore` 改动零文件交集。
   - name 匹配 = 字面量子串（`LIKE '%frag%' ESCAPE '\'`，DSN `case_sensitive_like=1` 使其二进制大小写敏感；`% _ \` 转义为字面量，K2 暂行语义），`ORDER BY repo_key, path`。
   - checksum 反查：sha256 直连 `idx_nodes_blob`；sha1 走 `idx_blobs_sha1`（T-73 缝）；md5 走 blobs 表扫描（**无 md5 索引**，见遗留）；多摘要各自解析 blob 键后**并集**。
   - folder marker 行（尾斜杠哨兵 blob）一律不返回；repos IN 谓词在 SQL 侧收窄。
2. **repo 层（新文件 search.go + api.go/service.go 接口接线）**
   - `Service` 增 `SearchArtifacts` / `SearchChecksum`（api.go 追加在 docker 段之后的 search 段）；`ChecksumQuery{Sha256,Sha1,Md5}`；sentinels `ErrInvalidSearchQuery`（→400）、`ErrSearchUnavailable`（→500，防御 store 无缝）。
   - 校验：name 非空白；至少一个摘要且各为**裸 hex**（sha256=64/sha1=40/md5=32，大小写归一为小写；`sha256:` 前缀的 docker 拼法按非法 400）；repos csv ≤1000（SQL 占位符防放大）。
   - **ACL 零泄漏（NFR-S24）**：`filterVisible` 逐节点跑与内容面下载**同一个** `Authorizer.Can(read)` 判定；admin 短路全见；零授权已认证用户得空页不报错；匿名走 `anonymous_access` 通道（O4 定界维持），关闭实例匿名 → **403**（rest-api.md §4 的未认证状态码，与 ?list 先例同构，不走 401 挑战）。PRD NFR-S24 明示"谓词下推**或**后置过滤"——本实现 = repos 谓词 SQL 侧收窄 + 路径级 ACL 后置过滤（路径 pattern 无法在 SQL 侧表达，见遗留性能注记）。
3. **httpapi 层（新文件 search.go）**
   - 路由：`GET /binflow/api/search/artifact` 与 `GET /binflow/api/search/checksum`（router.go，`routeAuth{}` 敞开、用例内做匿名通道判定，同 /api/storage read 姿态）；其它方法/路径落 E-26 404。
   - 响应：`{"results":[FileInfo...]}`，E-09 字段集**复用** storage.go 抽出的 `fileInfoOf`（本票把 writeFileInfo 的字段构造提取为共用，storage.go 仅此一处等价重构）；空结果为 `[]` 非 null（W16 的 `jq '.results|length'` 口径）。
   - 错误：查询形状 400 E-01；匿名关闭 403；其余走 writeStorageError。
   - 文件名说明：派单写 `api/search.go`，包内既无 api/ 子目录（storage.go/system.go/security.go 均平铺），故落 `internal/httpapi/search.go`。
4. **断言反转（R5，PRD §5.6）**：routes_test.go E-26 矩阵删除 `/binflow/api/search/artifact` 行（注释注明翻转入 T-92 与去向测试），新增 SR-04 族六行（props/users/artifactory/pattern/badge/gavc）。

## 遗留 / 需上游确认

1. **name 搜索无索引**：`LIKE '%frag%'` 无法用现有索引，10 万 node 全表扫（实测 ~120ms 级）；索引策略（trigram/pattern 前缀）按 NFR-P17 归 architect/004+ 迁移，本票不动 DDL。
2. **blobs.md5 无索引**：md5 反查为 ledger 全扫（内容级行数，量小可接受）；如需索引归 T-90 之后的迁移票。
3. **非 admin 大结果集的 ACL 成本**：逐节点 `Can` = 每节点 2 次权限查询（auth.Service 内部实现）；M4 量级可接受，若 T-105 实测吃紧需在 internal/auth（非本票 area）加批量判定缝。
4. **结果无分页**：Artifactory 同族无强分页，P0 不设 limit（10 万 node 全命中极端场景渲染成本未设门）；若 QA/T-105 认为需要，加 `limit` 参数是窄改动。
5. `repos` csv 非法 key 的 400-vs-空结果口径、多摘要并集语义：现按第"规格依据"节的先例写死，**待逆向扩编票（R3）校准**。
