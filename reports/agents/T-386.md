## 1. 实现要点

- **消费面 = 既有 token REST 两端点，仅此两枚**（AC2）：`POST /api/security/token`（E-17 JSON 投影 + silent401——与 SetMeUpDialog 同源同引擎：同端点、同 wire 形态、同 OAuth 错误体提取、同二次口令态机；引擎函数页内副本，**SetMeUpDialog 是 smu-* 锚冻结载体不为本票改动**）+ `POST /api/security/token/revoke`（E-18 **form 体** token_id——统一请求层 additive 扩 `formBody` 形态，~10 行；revoke 无 JSON 投影是服务端实况）。
- **明文一次性（AC1）**：明文只存活在创建 modal 的 done 面板（React 内存态）；「我已保存，关闭」或 Esc/取消 → modal 卸载即丢弃；重开 = 全新表单；刷新 = 全失。**无任何持久层（localStorage/sessionStorage）持有明文**。spec 断言关面板/重开/重载三面明文不残留 + Bearer 臂证明令牌本身仍活（刷新只清 UI 不吊销）。
- **台账披露（tokens-ledger-note）**：明示「服务端只存指纹、无令牌清单端点（§9-R6），刷新后表格即空」+ 历史令牌吊销走按 id 出口 + 审计日志指纹对账路径。行内指纹 = **Web Crypto sha256 前 8 hex 客户端实算**——与服务端 `auth.TokenFingerprint`/审计 token.issue detail 同 digest（spec 以 node crypto 对账逐字节一致）；非安全上下文 crypto.subtle 缺席 → 空串占位不伪造。
- **吊销双出口**：行内钮（danger ConfirmDialog——取消零副作用〔Bearer 对账 200 维持〕/ 确认翻转 Chip 有效→已吊销 + 行钮禁用 + Bearer 401 服务端终裁）+ **按 token_id 吊销**盒（admin 专属；§9-R6 登记过的历史令牌出口——非数字输入禁用不产请求；"Token not found" 幂等文案如实转译）。
- **角色臂**：admin 全量；**readonly_admin（L06）= 吊销禁用 + 按 id 盒不渲染 + 只读注记**（服务端 CapSecurityWrite 403 兜底——spec 直吊实证 403）；**自铸不受限**（Q11：mint 是 required-only 自助面，与 Set Me Up 同门——readonly 腿真铸 + Bearer 主体对账在案）；普通 user 直链 = L2 无权限卡（导航隐藏；提示语指向 Set Me Up/REST 自助路径）。
- **四态**：无 GET 端点 → **不伪造骨架/错误态**；空态（tokens-empty + CTA）/默认（台账表 + 计数行）/错误（mint 400·500 与吊销错就地内联 + toast——OAuth 形 error_description 优先呈现）。step-up 内联腿 = smu-stepup 同形态（同一 modal 内换内容态，不弹第二层）。
- OIDC 臂降级面板（§0 表末行）无锚——e2e 不可达面不设锚（dead 纪律）。

## 5. 契约漂移

1. **admin 代人签发不存在主体 → 500 非 400**（本票实测发现）：`POST /api/security/token` body `username=<不存在>` 时服务端答 `500 invalid_request "token creation failed"`（日志 `auth: token subject lookup: auth: user "…": metadata: user not found`——`Tokens.Issue` 的 subject 查找错误未被 handler 的 `ErrInvalidCredentials` 分支收编〔该分支只吃自铸臂的等价错误〕）。语义上属 auth-model 3.1「username is required or unknown」的 400 臂。**FE 以能跑通的为准**（错误面就地呈现 500 文案），断言按实况收口；服务端修正（error wrap 链补 Is 判定或 handler 补分支）归后端票——conductor 可据此逼 architect 回写。
2. （文档侧注记，非 API 漂移）console-ux §3.6.2 仍记两端点为「admin（D3，OAuth 错误体）」——as-built 自 M6 T-190 起 mint = required-only（Q11，architecture.md §7.1 族 8 权威）；§9-R6 行「无列表」在本票后会话语境需补「会话台账 + 按 id 吊销」注记。两处均 ux-designer 册内文字，本票只动 §10（锚册），留 conductor 转交。
