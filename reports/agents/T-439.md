## 决策与证据（先于实现）

1. **后端承接核对（票面前置项，活体实证）**：scratch 净实例（127.0.0.1:8080 → 后迁 :18080）`PUT /api/repositories/<k>` 带 8 候选域 → GET 对账：
   - `includesPattern: "**/*.jar"` **回显**（对照组——configJSON 转发链活着）；
   - `blackedOut:true` / `maxUniqueSnapshots:7` / `repoLayoutRef:"maven-2-default"` / `archiveBrowsingEnabled:true` **全部静默丢弃**（PUT 200、GET `configuration` 无此键）——transport **解码层收**（repositories.go L55-62 struct 字段，PRD「已收」证据即止于此）、`configJSON` 三个 rclass 臂**均不转发**（grep internal/ 零读点、零 adapter 消费）→ **decode-only**；
   - `environments` / `notes` / `forceAuthentication` / `suppressPomConsistencyChecks`：notes 有解码位但不转发（decode-only 同类）；其余无解码位（未知键直接丢）；
   - `forceConanAuthentication`：**唯一实字段**——local 臂 configJSON 全收（T-355A）+ conan adapter 行为消费（handler.go auth gate，匿名 401 挑战）；maven local 仓 PUT→GET 回显 `{"forceConanAuthentication":true}` 实证（存储 package-type 无关，语义消费在 conan）。
   - 结论：**Q8「全补」的「API 已收全」前提在 round-trip 层不成立**——八域七域按票面纪律降档为**预留位**（恒禁用、零提交，R3 两档定案先例），一域实字段化；契约漂移见下节。
2. **7.161.20 活体形态复核**（conductor 指令，:8082 admin 只读）：
   - 步进条 = `jf-steps__list` + `jf-steps__item` button ×3，`aria-label="Step N of 3: Basic|Advanced|Replications"`（`data-cy="panel-Advanced"`）——**三段步进条证实，无歧义**；
   - 页脚 = **Cancel（左）+ Create Local Repository（右），无 Reset**（B-3.11 移除裁定佐证）；
   - Basic 字段：Repository Key / **Stage**（7.161 已由 7.84 审计的 Environments 更名——Stages & Lifecycle 域）/ Repository Layout / Public Description / Internal Description + 复选族（Priority Resolution / Disable Artifact Resolution in Repository=blackedOut / Allow Artifact Content Browsing=archiveBrowsingEnabled / Enable Redirect Download / Enable Event Replication）；

## 契约漂移（3 项，conductor 转 architect/PM）

1. **PRD FR-143.2 / 审计 B-1.5「PUT 已收」证据层级错位**：`internal/httpapi/repositories.go` L55-62 的 struct 解码位 ≠ 承接——`configJSON`（同文件 L229-307）三臂均不转发 repoLayoutRef/blackedOut/maxUniqueSnapshots/archiveBrowsingEnabled，PUT 200 后静默丢弃、GET 不回显、零行为联动。**Q8「①全补」的「API 已收全」前提在 round-trip 层不成立**；本票按票面两档纪律落预留位 + API 漂移钉 tripwire（BE 承接票落地日自动翻红提示转正）。**建议 BE 承接票**：configJSON 转发四域 + 行为联动（blackedOut=true 拒写 / maxUniqueSnapshots 清理 / archiveBrowsingEnabled 门 / repoLayoutRef 布局引擎接线或钉协议默认值）。
2. **PRD FR-143.2「Force Authentication（virtual）」范围注不实**：BinFlow 唯一后端承接 = `forceConanAuthentication`（**local** × conan，T-355A）；Artifactory 7.161.20 活体实测 generic local / virtual 表单均无 Force Authentication 标签（conan 域字段）。本票按实态落 local × conan 实字段；virtual 侧无字段不伪造。
3. **7.84 审计 ↔ 7.161 实测字段名漂移**：B-3.12 的「Environments 多选」在 7.161.20 已更名 **Stage**（Stages & Lifecycle 域，导航实测「Stages & Lifecycle」组在场）。预留位标签按双名「环境段（Environments / Stage）」标注；若后续以 7.161 为基准刷新审计材料，请同步该行。
