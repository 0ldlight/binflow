## §任务三 m-holder repo 读位——行为规格草案（docs/reverse/ 风格，转 reverse-engineer 成票候选）

> 当客户端为任意认证非 admin 用户（含仅持非空 manage 覆盖的 plain 用户，及不持任何权限 target 的 plain 用户）GET /api/repositories/{key}（v1 单仓读）：
> 服务端返回 200，体为四键投影 `{key, rclass, packageType, description}`——与权限覆盖无关（覆盖内/覆盖外/无权限三态同形），不返回完整配置面（admin 面 61 键）。
>
> 当客户端为任意认证非 admin 用户 GET /api/repositories（v1 列表）：
> 服务端返回 200 全量仓库清单，无权限过滤；entries 与 admin 面逐字节同（entry 五键 `{key, type, packageType, description, url}`）。
>
> 当客户端为任意认证非 admin 用户 GET /api/v2/repositories/{key}（v2 单仓读）：
> 服务端返回 200 四键 `{key, type, packageType, description}`（local 仓无 url 键——与 contracts/d02-config.yaml#d02-config/v2-read 非 admin 五键注记一致）。
>
> 当客户端为任意认证非 admin 用户（含 m-holder）GET /api/repositories/configurations：
> 服务端返回 403，errors 信封 `Forbidden`（manage 位不开门）。
>
> 置信度：高（holder+noperm 双夹具活体 wire，2026-09-17，7.161.15）。manage 位在读臂全程不参与的结论由「noperm 用户与 holder 逐面同形」支撑。

覆盖内/v2 单仓双臂/configurations）与 A 逐字同。
