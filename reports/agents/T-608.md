## 一、实现模型（对照 T-601 §二 A 模型逐条）

| 面 | A 模型（live 双轮） | 实现 |
|---|---|---|
| CD 恒发·ASCII | `attachment; filename="<n>"; filename*=UTF-8''<n>` 双参数 | repo.SetDownloadDisposition：`path.Base(relPath)`，ASCII 分支双参数 |
| CD·非 ASCII | 仅 `filename*=UTF-8''<pct>` 无 fallback | 非 ASCII 分支 filename*-only，`url.PathEscape`（大写百分号 hex，`-` 字面量，与 gl-get-utf8 腿逐字节同） |
| X-Artifactory-Filename | URL-encoded basename | 同一 encoded 值（ASCII=原名，非 ASCII=pct） |
| 416 裸集 | 仅 CR + CL:0 + infra（F3 裁不仿形→B 无 infra 义务） | repo.WriteRangeNotSatisfiable：撤 9 键（CT/ETag/LM/AR/CD/Filename/三键）+ 设 CR/CL:0 |
| 304 近全集 | 保留 CD/Filename/ETag/LM/三键/AR，撤 CT/CL | 零代码：组装区带上对；net/http suppressedHeaders304 撤 CT/CL/TE（B r2 live 证实） |
| virtual 继承 | 成员头全继承 | 同一渲染出口（serveNode/handleGet 解析后统一组装），零分支 |
| generic sidecar GET | CT/CL/LM infra 集 | writeChecksumEcho GET 臂（吸收 UNKNOWN #2） |
| generic sidecar HEAD | + AR/ETag=源sha1/源三键/CD+Filename（源 basename） | HEAD 臂（吸收 UNKNOWN #1），ETag/三键经 h.digestsOf(node) |

单源纪律：两 handler 的组装区与 416 分支同调 `internal/repo` helper（T-571 mimetable 形态：单源、消费者不落本地副本）；未复用 docker remote.go:1310 单参数 CD 形（docker remote 面自身模型，票面明令勿复用）。
