## 1. 关键发现（对 PRD 暂行值的校准材料）

1. **「36 事件」→ 13 域 66 事件型**：36 是内部统一事件总线枚举（before/after 变体层）；用户可订阅面官方现登记 66 型/13 域（含 2026 新增 xray_scan_status、app_trust）。K48 的「36 事件清单」按官方 66 型全表交付，两层关系在规格 §0 讲清。
2. **订阅面 wire 全量到手**：`/event/api/v1/subscriptions*` 七端点（OpenAPI 3.1 逐字）——list/create(201)/get/update(204, key 不可改, project_key 锁定)/delete(204)/test(吃完整订阅体，非 key 引用)/troubleshooting(流+历史)。key 正则 `^[A-Za-z][A-Za-z0-9_\-]+$`、handlers 恰 1 个、enabled 默认 false、custom 型五方法 + Go 模板 `{{.path}}`。
3. **投递语义参数级锚定**（system.yaml `event:` 段，官方默认值）：timeout 30s（含建连/重定向/读体）；**重试仅发送失败或 HTTP≥500**（4xx 不重试）；**固定间隔 10s、非指数退避**；retryCount 5（首试计入）；限流 1000/s 均速 + 10000 突发 + 50000 并发拒新；headers ≤50 个/5120B、custom secrets ≤50/5120B、payload ≤50KB。无持久死信——出口是排障记录（Redis 10000 条/30s 清老 或 log 文件）。
4. **签名**：`X-JFrog-Event-Auth` 头 + HMAC-SHA256（官方 openssl 验签命令逐字入规格）；`use_secret_for_signing` 双态（false=明文 secret 直传头，官方逐字；true=签载荷——签名态摘要承载头官方未写明，标中置信待活体验证）。
5. **SSRF**：canonical 键 `event.security.blacklist.enabled: true`（默认禁私网：loopback/RFC1918/RFC3927/IPv6 ULA）；预定义页的 `urlStrictPolicy` 键在 system.yaml 模板不存在且语义矛盾——判文档陈旧残留，登记待验证。K50/ADR-0041 旋钮名照 system.yaml。
6. **Q4 终裁建议：维持 pro+/feature-int、不翻转**。功能矩阵逐字：Webhooks 行 Non-commercial ❌ / Pro X ✅ / Enterprise X ✅ / Enterprise+ ✅。社区不含、最低商业档含——与暂行一致。
7. 覆盖界（K48/Q6）：**本体 9 型**（artifact 5 + artifact_property 2 + docker pushed/deleted；织入点：部署链/统一删除 seam/T-339 copy+move/remote 回源/properties PUT+DELETE//v2 push+删除）；**休眠 57 型**（docker promoted〔promotion REST M14+〕、build 3、RB 3、RBv2 3+3、distribution 7、destination 4、curation 4、user locked〔BinFlow 无锁定本体〕、xray 4、app_trust 24）。已核对 BinFlow 代码面：`/api/copy|/api/move`（router.go:776+）与 properties.go 在案、无 promote/lockout 实现——覆盖界与 as-built 一致。
8. artifact 域载荷**无事件时间戳字段**（PRD AC3 提到「时间戳」——规格明示勿发明字段；仅 build/xray/app_trust 域有各自时间字段）。
