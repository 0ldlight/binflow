## 3. QA 测试 harness 声明（透明度，评审重点）

bf-migrate CLI 实际形态 = **单一 `migrate` 命令四阶段串行**（repos→users→tokens→artifacts，无单阶段旗标）——票面「三阶段 + migrate all」对应四阶段报告块。真实源上 users 硬中止（B-1）阻断 tokens/artifacts，故设**直通 shim 代理**（VM 本地 127.0.0.1:8280，python3 stdlib，60 次 shim 全部落日志 `proxy-shim.log`）：

- 仅 shim 3 个 license 门读：`GET /api/security/users{,/{name}}`（**数据实时查源 PG access_users/access_users_groups**，非伪造）与 `GET /api/repositories/{key}`（**由真实 repo 列表合成** key/rclass/packageType/description，includesPattern 缺省 `**/*`）；
- **其余一切请求原样直通真实实例**（repo 列表、FolderInfo 清点、制品下载+校验、token 清点）；
- LEG-1（不走 shim、直连 8181）单独记录 B-1 真实形态——**shim 只用于让迁移主体到达 artifacts 阶段**，等价于 B-1 建议票的 `--skip-users` + repo-config 降级读。
