## 1. 做了什么

1. **migration 018**（双方言两表 + 事件型子表）：`webhook_subscriptions` / `webhook_subscription_events` / `webhook_deliveries`（outbox，status 闭集 + (status,next_attempt_at) 队列索引 + 订阅删除级联）。**对 ADR 草案 DDL 的一处校准**（ADR 自己的「锚点回填位」条款预留）：webhook.md §2 证实订阅是**多事件型**（event_filter.event_types[] 单域多型），故以子表形态落 018（ADR 原文「若 T-358 证实多事件型订阅 → 子表 additive 迁移，机制条款不变」——018 是新迁移，直接落主 schema）。机制条款（outbox 快照 payload、enc:v1 secret 列、(status,next_attempt_at) 谓词、级联）照 ADR 逐字。幂等（CREATE TABLE IF NOT EXISTS，012/015/016 惯例——t212 rewind 测试重放需要）。
2. **internal/webhook 新包**（7 文件）：
   - `eventtypes.go`：66 型 13 域单一事实源，每型 {Name, Domain, Source wired|dormant}；**9 型 wired**（artifact 5 + artifact_property 2 + docker pushed/deleted），57 型 dormant 可订阅零触发。跨域同名型（"deleted"×3 域、"delete_failed"×2 域）按 (domain,event_type) **对**解析。
   - `model.go`：wire DTO（OpenAPI 逐字字段名）+ 校验（key pattern/长度、domain/event_types 闭集、criteria **strict 未知键 400**、handlers 恰 1、两型 handler 判别、url 静态校验：scheme 闭集/host 必填/userinfo/fragment 拒收/≤2048、§5.2 sizeLimits 引擎常量、custom secrets 名 pattern）；secret 三态（omit/哨兵=保持、明文=轮换、""=擦除）与 custom secrets 全量替换。secret 哨兵回显 `********`（ADR 决策 5「脱敏哨兵」；非密文回显）。
   - `criteria.go`：strict 解析 + 匹配（repoKeys 精确 ∪ anyLocal/anyRemote 类族〔按 repo 行 class，懒查〕；include/exclude Ant 两级通配，exclude 优先；**空选择不命中**——订阅必须声明范围）。Ant matcher 为本包独立实现（repo 的 govMatcher 刻意未导出且本包不得 import repo）。
   - `bus.go`：单一 Emit 缝。**首行 gate func**（注入式，不 import license；**nil gate = fail-closed**）；闭集+wired 断言（dormant 到达即 WARN 丢弃，不伪造触发）；匹配 → 逐订阅实例化 envelope（§4 七字段：domain/event_type/data/subscription_key/jpd_origin/source/userContext）→ **单事务批插** delivery 行（同步小事务 fan-out）。recover 盾 + enqueue 失败 WARN + `EnqueueFailures()` 计数（ADR 决策 10；指标族本体归 T-364）。uuid/ULID（26 位 Crockford，§7 事件 id 形态）stdlib 自造。
   - `sign.go`：HMAC-SHA256 hex（openssl `sha256 -hmac` 输出形态，§6 验签命令兼容）+ `X-JFrog-Event-Auth` 头名逐字；双态（use_secret_for_signing=false=secret 明文直传 / true=对线上字节签名）。
   - `sender.go`：单发路径（test 端点用；T-364 dispatcher 复用同 per-attempt 路径）：remote.Guard 全链（scheme/分类清单/连接期 pinning）+ **3xx 不跟随**（ErrUseLastResponse）+ 10s 超时 + 4KB 有界响应读；custom 型 payload 模板（{{.path}}/{{.userContext.id}}/{{.secrets.<name>}}，中置信读法已在注释标注）。
   - `service.go`：Bus 上的 CRUD 应用逻辑（key 不可改、project_key 必须逐字匹配、secret 三态、custom secrets 全量替换+per-name 保持）、Test 同步直发（不入箱不重试；合成 marker 事件；200 + attempt{status_code,elapsed_millis,error}）、troubleshooting 内存环（容量 1000，§7 schema：失败必录、debug:true 成功也录；log/redis 持久形态归 T-364）。
   - `store.go`：Store 接口 + SQLiteStore（replication.SQLiteStore 同姿势：自有 *sql.DB 句柄；key 撞 UNIQUE→ErrDuplicateKey；miss→ErrNotFound）。

## 4. 规格依据（docs/reverse/webhook.md + ADR-0041）

- §1 七端点表（方法/路径/状态码/错误码/鉴权限定）——逐字实现；404 文案 "Subscription not found" 逐字。
- §2 wire schema（key pattern `^[A-Za-z][A-Za-z0-9_\-]+$` ≤500、enabled default false、handlers minItems/maxItems 1、criteria 维度全表、两型 handler、回显/更新语义含 NamedSecretUpdate 三态与 custom 全量替换）。
- §3 66 型全表 + 触发源覆盖界（9 本体/57 休眠）；distribution 用载荷拼写 delete_*（§10.2）；curation 四型按标题拼写登记（§3.10，**中置信**——dormant 不触发出站，不影响 wire，注释标注）。
- §4 envelope 七字段（BinFlow 取文档全集的既定立场）+ userContext 三子字段 + source 实形态 `jfrog/<service>@<node-id>` → BinFlow 拼法 `binflow/binflow@<ULID>`（BinFlow 侧字面量，非官方契约）。artifact 域**无时间戳字段**——测试反向断言「不发明字段」。
- §5.2/5.4：sizeLimits 常量、SSRF 默认拒私网（Guard 复用；测试钉 loopback 默认拒）。5.3 重试节奏归 T-364。
- §6 签名链：头名逐字、openssl 兼容 hex HMAC（独立已知向量 f7bc83f4… 断言）、双态语义；**签名态摘要承载头=同一头（中置信 V1）**——按规格文件本条为准，测试固化。
- §7 排障记录 schema + debug 语义（失败必录/成功需 debug）。
- §8 Q4 终裁：pro+ 解锁（slots.go MinTier=pro）。
- ADR-0041 八轴全 A：单一 Emit 缝/同步小事务入箱/HMAC+enc:v1（复用 remote.Cipher 链，无主密钥拒绝 secret 写）/Guard 默认拒+AllowPrivateTarget 旋钮（BusOptions，config 键归 conductor）/66 型注册-休眠/第 19 槽 KindFeature/权限映射/入箱失败可见（WARN+计数）。

低置信处理：V1（签名头承载）、V2（七字段全集）按规格文件钉死的 BinFlow 立场实现并在测试固化；curation 标题拼写（中）仅登记 dormant；custom 模板上下文顶层平铺 {{.path}}（中，官方示例混用）已在 sender.go 注释标注「规格待验证」。
