## 交付（对应缺陷）

### D7 制品迁移阶段（`internal/migrate/artifacts.go` 新文件 + reader/writer 扩充）

- **文件清单**（reader.go `ListRepoFiles`）：首选 PRD FR-63 流程第 5 步点名的 `GET /api/storage/{repo}?list&deep=1&listFolders=0`（逆向规格 rest-api.md §3 高置信形状，`files[].uri/size/lastModified/folder/sha1/sha2`）；404 → 空仓零文件；**400 → FolderInfo 子代遍历兜底**（规格 400 行「Cannot list files of root.」在仓根一读下的严格解释——BinFlow 自己的 list 面就是这个读法，两条路径都做了单测，工具对两种规格读法都稳）。兜底路径收集的文件不带摘要（FolderInfo 无），复制时自行计算 sha256 校验。
- **下载**（reader.go `OpenFile`）：`GET /{repo}/{path}` 直取面（rest-api.md §1），逐段 percent-escape（空格/非 ASCII 路径可活）。落临时文件同时 sha256+sha1 双哈希；**上传前比对清单承诺的 sha256/sha1**，不一致记 item failure 不上传（H63 的 sha256 一致性在工具内部就有第一道闸）。
- **上传**（writer.go `UploadArtifact`）：经 internal/client 既有 `UploadArtifact`（PUT /binflow/{repo}/{path}），未动 client 一行。
- **分批/限并发**：每仓 worker pool，`--concurrency N`（默认 4，PRD 原名）+ 单 goroutine 折叠结果；进度标记批flush（每 32 条落一次盘，避免大仓 O(n²) 重写；崩溃窗口内重传幂等）。
- **支持度如实标注**：generic 主面 + maven（纯布局文件，目标 maven 适配器收 PUT，H49 实证）；**docker/npm/pypi 仓配置照迁、制品如实留下并计数入报告**，理由各引 T-175 D2/D3/D4 证据（协议化上传面不可由 plain-file 复现）；remote（代理缓存不迁）/virtual（聚合视图无自有存储）各带理由，不发起清单请求。repo 阶段 skip/failed 的仓不尝试制品（目标无仓可写）。
- **单制品失败不中断**（PRD FR-63）：记 failure note、不落进度，--resume 重试；context 取消算一条警告不算 N 条失败，中断文件不入进度可续传。

### D6 空目标守卫（migrate.go `checkTargetGuard`）

- 写前查目标 `GET /binflow/api/repositories`；**非空（≥1 仓，PRD FR-63-AC1 字面「零仓库」）→ 默认拒绝，exit≠0**（ErrTargetNotEmpty 哨兵 + 证据仓键 + override 提示）。
- `--allow-non-empty` 显式覆盖：放行并在 summary+报告记录 **MergeSemanticsNote**（同名仓 create-or-replace 重配、同路径制品覆盖、源未点名的内容不动）。
- **--resume 豁免**：进度文件端点绑定（T-167 先例）且有记录 → 占用是本迁移自己先前写入，照常续跑（不做这条，崩溃恢复会被自己的产出卡死——设计时明确处理了该交互）。
- 检查本身失败（写跑）→ fail-closed 拒绝；dry-run → 软性记录占用不拒绝（无凭据也能 dry-run）。

## 关键设计决策（如实记录）

1. **阶段序 repos → users → tokens → artifacts（制品最后）**：PRD 流程叙述里制品在用户前，但便宜阶段先行能让密码策略缺失/目标拒绝这类 fail-fast 在大规模数据拷贝**之前**暴露；T-167 既有语义（missing password 在 users 阶段中止）原样保留。与 PRD 字面顺序的偏离在此声明（D9 校准家族可一并收口）。
2. **守卫的「非空」口径 = 仓库数 >0**，取 PRD FR-63-AC1 字面（H62 证据同口径：约 10 个既有仓）。目标用户数不参与判定（fresh 实例必有 admin 种子，掺入会造成假拒绝）。
3. **制品进度键 = "repo/path"**（repo key 不含斜杠，无歧义）；progress 文件 version 1→2（v1 文件缺 artifacts 字段按空表载入，向后兼容）。
4. **上传体走临时文件**而非内存流：可复读（client 重试需要）、哈希与校验前置、大文件不撑内存。注意 internal/client 的 doRaw 对带体重试会整读进内存——峰值成本 = 并发数 × 单制品大小，已在 writer 注释声明。
5. **maven 制品复制是我扩展的腿**（票面只要求 generic 主面）：H49 实证目标 maven 面收 plain PUT，故纳入；副作用见下「e2e ④」。
