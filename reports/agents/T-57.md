## 关键产品决策（供 review 聚焦）

1. docker remote 不进 M3（推翻 M2 PRD §2.2 预告）——理由：上游 token 协商+manifest 重写独立工程量、skopeo copy 已覆盖搬运场景；转开放问题 Q4 由用户定夺，不默认扩范围。
2. metadata 跨成员聚合合并（npm packument/maven-metadata/simple union）定为 P1，P0 = 首个命中成员透传——真实客户端（精确版本解析）P0 即可走通，合并仅在同名包跨成员场景需要。
3. remote 缓存删除绝不同步上游 delete；URL 不提供 refresh 参数（强刷走 DELETE 缓存）。
4. SSRF 默认拒绝私网 + `allowPrivateUpstream` 显式放行（内网 Nexus 代理是目标用户真实场景，一刀切会砍掉核心用例）。
5. M3 不做 remote 的 ETag/Last-Modified 回源协商（纯 TTL 制），归档 C4 待逆向校准。
6. npm 重复 publish 取 409（npmjs 为 403，客户端只判非 2xx，无兼容性损失）。
