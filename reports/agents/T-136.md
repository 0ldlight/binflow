### 架构决策

- **单副本硬约束（Q2 定案）**: `values.schema.json` 中 `replicaCount` 和 `hpa.maxReplicas` 均设 `maximum:1`，`--set replicaCount=2` 或 `hpa.maxReplicas=2` 会被 schema 拦截
- **口令分离**: admin password 经 Secret（secret.yaml），不进入 ConfigMap
- **Ingress 无 rewrite**: ingress template 无 `nginx.ingress.kubernetes.io/rewrite-target` 注解（ADR-0010），`/` 与 `/v2/` 均直通
- **镜像默认 distroless**: ghcr.io/lzwzzy/binflow tag 默认 `v1.0.0-distroless`（无 shell 安全面）
