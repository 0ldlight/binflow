### 设计要点

- **G15 静态面**: systemd 单元符合 AC 所有要求（Type=simple, User=binflow, Restart=on-failure, ReadWritePaths, TimeoutStopSec=30, NoNewPrivileges=yes, ProtectSystem=strict, ProtectHome=yes, EnvironmentFile=-/etc/binflow/env）
- **G16 校验和防线**: 脚本先下载 checksums 文件，再下载 tar.gz 归档，执行 `sha256sum -c` 验证通过后才解压。校验失败（exit non-zero）时零文件写入安装路径。临时文件在 `trap EXIT` 中清理
- **G15b 条件腿**: install.sh 支持 --dry-run 打印操作而不执行；支持 --uninstall 停止/禁用/移除服务，--purge 进一步删除用户和数据目录
- **安全基线**: 单元文件添加了 CapabilityBoundingSet=、PrivateTmp=yes、PrivateDevices=yes、RestrictAddressFamilies、SystemCallFilter=@system-service 等多层加固
- **与 goereleaser 对齐**: 归档名模式 `binflow_<VER>_<os>_<arch>.tar.gz` 和校验和文件名 `binflow_<VER>_checksums.txt` 与 `.goreleaser.yaml` 一致
- **版本解析**: `--version latest` 可自动解析最新版（通过 GitHub redirect），失败时要求显式指定版本

## 真实机器测试步骤（G15b 条件腿）

当有 Linux 带 systemd 的环境时，执行以下验证序列：

```bash
# 1. 安装
sudo bash contrib/systemd/install.sh --version v1.0.0

# 2. 检查状态
systemctl status binflow
# → active (running)

# 3. 健康检查
curl -s http://127.0.0.1:8080/readyz
# → 200 OK

# 4. 重启测试
sudo systemctl restart binflow
systemctl is-active binflow
# → active
curl -s http://127.0.0.1:8080/readyz
# → 200 OK

# 5. 开机自启
systemctl is-enabled binflow
# → enabled

# 6. 优雅关闭
sudo systemctl stop binflow
# → 检查日志中是否出现 "shutting down gracefully"
journalctl -u binflow --since "5 min ago"

# 7. 重新安装（幂等性）
sudo bash contrib/systemd/install.sh --version v1.0.0
# → 应跳过已存在的步骤

# 8. 卸载
sudo bash contrib/systemd/install.sh --uninstall
# → 服务停止、禁用、文件删除，数据保留

# 9. 卸载+清除
sudo bash contrib/systemd/install.sh --uninstall --purge
# → 数据目录一并删除

# 10. systemd-analyze verify
systemd-analyze verify contrib/systemd/binflow.service
# → 零告警
```

## 遗留问题

- **systemd-analyze verify**: macOS 无此工具，需在 Linux 环境执行。当前仅通过手动字段验证确认单元文件结构完整
- **真实机器烟测**: 需要 Linux 带 systemd 的机器进行端到端验证（上述测试步骤已文档化）
- **默认配置**: 安装脚本尝试从归档中复制 config.yaml（如果存在），否则警告用户手动创建。归档当前包含 `dist/config.yaml`，但安装脚本解压后的 `binflow_<VER>_<os>_<arch>/` 目录中可能不含 config.yaml — 如果 goreleaser 后续将其加入 archive.files 则自动生效
- **BASE_URL 默认值**: 当前设为 `https://github.com/example/binflow/releases/download` 占位 — GA 发布时需更新为实际仓库 URL
