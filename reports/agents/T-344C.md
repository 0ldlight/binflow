## 3. 实施中修复的回归（根因链）

1. **首焦失效**：ConfirmDialog 挂载期 useEffect 里 ref 恒 null——MUI Modal 内容二段式提交（首 pass 空 render，paper 随后续 commit 进 DOM；MutationObserver 时间线实证 938ms 焦点入 opener、986ms 按钮才落 DOM 且全程无 focusin）。修法：disableAutoFocus + 回调 ref + queueMicrotask（按钮真实落 DOM 的那个 commit 后聚焦）。
2. **Esc 失灵**：MUI useModal 的 Esc 监听挂 modal **root**（非 document）——smu-back 点击后内容切换卸载焦点元素（焦点掉 body），Esc 冒泡不经过 root。修法：三对话框加文档级 keydown 兜底；MUI 已处理路径 stopPropagation 保证不双触发。键盘规格全绿（含 Tab 首尾循环/禁用钮不破口/关闭归焦 session-toggle——MUI FocusTrap restoreFocus 原生达成）。
3. **axe × Fade 入场竞态**：对话框 axe include 扫描落在 225ms 入场动画中途，半透明栈被算进对比度（实测 4.48 < 4.5 假阳性，终态 5.26 达标）。修法：两 spec 扫描前 `toHaveCSS('opacity','1')` 收敛等待（断言语义不变）。**批 C/D 后续给任何 MUI Dialog 加 axe 腿都会踩此坑**。
4. **`.copy-btn` 摘类回归**：首轮全量 repositories.spec:58 超时——`[data-testid="repos-row-*"] .copy-btn` 类钩子被我遗漏（早前 grep 的 `-v data-testid` 把组合定位器过滤掉了）。修法：类名续挂 + CSS 保留（该 CSS 另服务 AppShell/SearchPage 的「清除历史」钮）。
5. **slotProps.paper 字面量 TS 红**：嵌套对象字面量触发 data-* 过剩属性检查（TS 只在 JSX 属性位放行连字符属性）。修法：paperProps 以变量承载传入。

## 4. 差异登记（规范文字 vs 实际落地）

- **D1 `.skeleton` 族 CSS 未删**（规范 §3.2 判 B 波删）：ArtifactsBrowser ×4、SearchPage ×1 的 `skeleton line` 类直连消费（树域/搜索域，批 C area 外）——归波 D 摘页面直连后删。组件侧已换 MUI Skeleton 不再挂类。
- **D2 `.modal`/`.modal-backdrop` 族未删**（§3.2 判 B 波删）：PermissionEditorPage（ResourceDialog）与 RepositoryFormPage（包型网格 modal）两处手作 modal 直连（规范 §3.5 security.css 行把 ResourceDialog 排在 B 波，但该文件在 pages/ = 批 C/D area——**本票 area 纪律让位分区纪律**，未越界）。归波 D。ConfirmDialog paper 续挂 `modal` 类且以 sx 归零泄漏项（p:0/border:none/width），`.modal .server-reason`（pages.css）依赖该类继续生效。
- **D3 `.copy-btn` 未删反留**（§3.2 判删）：spec 类钩子（repositories.spec:104）+ 两处非拷贝语义消费者（AppShell 顶栏/SearchPage 清除历史钮）。建议 architect 回写 §3.2 该行为「类名续挂、规则随页面残面退役」。
- **D4 error-retry 锚**：§4.2 文字「error-card/error-retry 锚不动」与 §10.6 退役表（v1.9 已退役 error-retry）冲突——按册执行（不加回，A4 门）。建议规范勘误。
- **D5 MUI Modal Esc 挂 root 非 document**：规范无此坑记载（§4.2 只说「Esc/焦点陷阱原生」）。焦点掉 body 时需文档级兜底——已写入三对话框；后续批 C/D 页面 modal 换装同样需要。
- **D6 Modal 二段式提交 vs 挂载期首焦**：同上无记载。「打开即聚焦取消」类需求必须回调 ref（或 onEntered）承载。
- **D7 axe × Dialog Fade 竞态**：规范 §5.3 未提。已修 2 处 spec；后续新增对话框 axe 腿需带 opacity 收敛等待（或给 expectA11yClean 加内置 settle，可开小票）。
- **D8 Snackbar 堆叠形态**：§4.2「Snackbar + Alert」落地为 Box(固定右下列容器) + Snackbar(sx position:static) + Alert——MUI 无多 Snackbar 内建堆叠，逐实例 anchorOrigin 会互相覆盖。视觉与语义等价。
- **D9 波 B 的 pages 残面不在本票**：§6 波 B 的「login/NotFound/Placeholder/Profile/Dashboard/SystemInfo + base.css login 段」被 ticket 收窄出 area（批 C 并行占用 pages/ 域）。**这 6 页仍是旧观感，需 conductor 补票**（预计随批 D 或小票收口）。
- **D10 `pages.css` 的 .confirm-input/.modal .server-reason 两行（§3.3 判 B 波删）未动**：文件归批 C/D；类在 DOM 上继续生效，零功能影响。
- **D11 共享树预算口径**：T-344D 同树并行，本票增量按「我波构建时点 vs T-344B 报告值」测量（+1.14%）；合并终态 331,810B（+3.09%/对 344B，+16.76%/对 T-299）——两批合计仍在双门内。
