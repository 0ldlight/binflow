## 1. 三 ADR 一句话决策摘要

- **ADR-0035**：三协议配置段以 DB 描述符（migration 015 新表 `auth_configs`，段粒度整替）为权威，**复用 license Manager 三要素**（immutable snapshot / 验后替换 / 启动回放）实现变更即生效（验后含 OIDC discovery 探测，失败 400 现配置续效——D7 同构）；双源 K31 终裁 = DB 权威 / 文件段首启种子 / 运行期覆盖 WARN（段粒度，无字段合并）；敏感字段 DB 内 `enc:v1:` 密封（复用 `BINFLOW_REMOTE_CREDENTIALS_KEY`，replication 先例，语义升格实例级主密钥）、GET 回固定脱敏哨兵 + write-only PUT 语义；测试连接复用 M3 Guard 机器 + ADR-0025 决策 4 私网默认放行，零新 SSRF 面、零新豁免键。**REST 挂 dispatchAPI 族（ADR-0034 先例），路径/信封/字段字面量全部接口化引 T-302 锚点，机制条款不随锚点翻转。**
- **ADR-0036**：`binstore.yaml` 与已解析主配置文件同目录（默认即 `$BINFLOW_HOME/binstore.yaml`，无新 flag）；canonical schema = 有序 provider 链（type 闭集 filestore|s3，保留名 cache-fs/azure/gs 出现即拒启）+ 链级 `migration.mode` 三态（bypass/dual-write/completed = M6 三模式一等拼写，仅双员链合法且必填）；Q5 终裁三分支 = 无文件照常起+WARN / 有文件+内嵌等价→文件生效+WARN / **语义分歧 fail-fast 指明两处来源**；坏文件拒启指明路径+行号；明文 secret 键拒启（rejectSecrets 全文件生效）；模板速记不进 M11（canonical 链已覆盖三链表达力，模板语义分歧门留给 T-303 复核）。
- **ADR-0038**：GPG keypair 生成/导入/CRUD，新表 `gpg_keypairs`——armored 私钥块与口令**双列均 enc:v1 整封**（S2K 弱口令不作为静态密封等价物）；repo 配置正向引用 keypair id（local debian/rpm 接受、helm 不含〔HL-4〕、virtual/remote 不接受、引用删除 400 护栏）；签名时序解封→签→即弃，私钥永不出库（无导出端点）；生成默认 RSA-4096/不过期为**暂行值**（T-319 mini 规格出处若异 → 按 Q8 先例照 Artifactory 翻转）。

## 2. openpgp 选型结论（ADR-0038 决策 1 / ADR-0005 M11 准入）

**结论：`github.com/ProtonMail/go-crypto`（v1.4.1，2026-03-18 发布）**；keybase/go-crypto 与 x/crypto/openpgp 淘汰。

实测证据（2026-08-26，GOPROXY=goproxy.cn,direct——proxy.golang.org 本环境超时，ADR-0005 既知）：

```
$ go list -m github.com/ProtonMail/go-crypto@latest   → v1.4.1 (Time 2026-03-18)
$ go list -m github.com/keybase/go-crypto@latest      → v0.0.0-20200123153347-de78d2cb44f4 (Time 2020-01-23，六年余零 tag)
$ CGO_ENABLED=0 go build（trivial-import 探针，darwin/arm64 / linux/amd64 / windows/amd64）→ 三平台全过
$ 传递依赖：github.com/cloudflare/circl v1.6.2（纯 Go）+ golang.org/x/crypto + x/sys（已在树）——净新增两模块
```

淘汰理由：keybase fork 2020-01 后冻结（生态迁出证据：terraform-provider-aws#27214、go-git、Helm 迁移轨迹均指向 ProtonMail fork）；x/crypto/openpgp 官方弃用（Go proposal #44226，缺 Ed25519/ECC/v5/v6/AEAD）；自实现 OpenPGP 消息格式正确性面远超收益。零 CGo 硬门与 Makefile `CGO_ENABLED=0` 全构建 + cgo_deps 审计门（Makefile:210）相容。
