## 1. 做了什么

### 1.1 属性编辑解剖翻正（AC1 / FR-144.4 / B-2.9）

- **常显表单**：Property/Value 两输入（placeholder 与 7.161 逐字一致）+
  Add 钮常驻（空态也在场）；隐藏「+ 新增属性」旗标表单与逐行 ✎ 编辑行
  **退役**（node-props-row-new / save / cancel / edit-* 四名入 §10.6）。
- **同名键 Add = 值集整体替换**（§11.40 合并律——行内编辑退役后「改值」
  即同键重 Add；helper 文案 replaceHint 语义可见），兄弟键保留断言钉死。
- **网格搜索**（B-2.9 解剖要素）：键/值子串客户端过滤（大小写不敏感），
  无匹配提示块（node-props-search-empty）+ 清除钮恢复全量；计数行给
  「属性 · N 个键（匹配 M）」。
- **行内删除与 E1 统一**（Q2 出口①）：删除钮保留行内，但走 ConfirmDialog
  危险确认（danger 红、可拒绝）；T-291 期「轻交互无确认」姿态退役
  （m10 L21a 翻新腿：拒绝保留 → 接受移除）。
- **即时校验**维持服务端同口径闭集（键 [A-Za-z][A-Za-z0-9_.-]{0,63}、
  值 ≤1KiB/无控制字节/单键 ≤32 值/节点 ≤64 键）——零坏请求出浏览器。
- **K68 候裁臂**：Property|Property Set 分段**不建不做缺位登记**（Property
  Set 须 BE 属性集小域扩列另立票，裁做时再入册——parity 册 B-2.9 行注记）。
- 四态维持：loading Skeleton / 空（常显表单 + 引导）/ 错误（Alert + 重试 +
  403 信封行内）/ 数据；readonly_admin 预收敛禁用（输入 + Add + 删除全
  disabled）不变，普通用户保留写入口（服务端 403 兜底）。

### 1.2 下载形态（AC2 / FR-144.5 / B-2.12 + Q9）

- **单 24px 图标钮**（`node-download` 锚零改名、载体翻新）：直接下载 =
  浏览器原生落盘锚点（component="a" download）；两带文字按钮「下载并校验/
  直接下载」收敛（t447 spec 反断言钉死）。
- **伴随菜单**（`node-download-menu` 触发 ▾ 24px → Popover role=dialog，
  焦点圈进 + Esc 关闭）承载 Q9 收进来的全部校验域：
  - `node-download-menu-verify` 校验动作（原「下载并校验」能力迁址）；
  - 结果块 `node-download-verify`（锚零改名、载体自 General 页右栏迁址；
    verify 后菜单驻留就地呈现，最终结果另有 toast——关闭菜单不丢反馈）；
  - `node-download-checksums` 区：mimeType 行 + sha256/sha1/md5（截断
    呈现 + §7.3 拷贝不截断 + 「上传时提供：一致」徽标）——**General 页
    平铺退役**（Q9 终裁「校验块收进伴随形态」，t447/artifacts spec 反断言）。
- **下载动作计数联动**（T-438 埋点单源）：校验下载完成（download.phase
  =done）作为 FileStatsRows 的 refreshKey → ?stats 重读 → UI 计数随增
  （spec 断言「动作后 UI > 动作前快照」——探针面计数继承下不断言绝对值）；
  直接下载是原生锚点无 JS 完成回调不触发重读，计数仍由服务端内容面单源
  落库（零 FE 第二通道）。General 页自右栏 verify 块移除后 grid 单列
  （与 RepoGeneral 既有单列形态一致，CSS 零改——tree.css 不在本票 area）。

## 4. 契约漂移（conductor 请过目）

1. **?properties REST 面的分号语法空缺（票内自踩+勘误登记）**：矩阵参数
   分号形 `PUT …;k=v` 仅内容面路径语法；查询串 `?properties=a=1;b=2`
   实测 **404**（分号被当路径段语义），逗号配对 `?properties=a=1,b=2`
   才是 REST 面 grammar（m10 L19 同款、architecture §15.3.3）。两语法
   域在 spec/文案里有明示但易混——已在本票 spec 注释留痕；无需后端动。
2. **T-445 §4-2/4-3 两处 wire 勘误维持登记**（repo url 前缀缺 /binflow、
   downloadUri 语义）：本票下载钮未消费 downloadUri（与 T-445 同构的内容
   面 URL 构造），零阻塞。
3. **无新增漂移**：本票纯 FE，消费面（?properties 读写族 / ConfirmDialog /
   ?stats / usage counts）全为既有契约。
