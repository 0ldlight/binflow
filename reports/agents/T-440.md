## 0. area 映射核对（票面 vs 实际落点）

派单列的落点是 `internal/search`（注册表 + plan）+ `internal/httpapi/search.go`（usage 端点）。
实际改动多了 **internal/metadata/aqlquery.go**（+ 同包测试）：statistics 域的查询要落到 nodes
计数列，而 ADR-0043 pt 3 的管线是 AST→IR→SQL，IR（NodeQuery/QueryField/编译器）住在
metadata——T-438 只落了列与 `CountDownload/Stats`，查询面接列必须扩 IR，绕不开。改动全部
是「已有闭集加成员」（3 个 QueryField、1 个谓词、投影尾列、行结构体 3 字段），零新表零迁移。
httpapi 侧 usage 端点落在 `search_legacy.go`（老搜索门族文件，其头注本就预告 usage 404 族
归 M16）而非票面写的 `search.go`——两文件同包同 area，取族内聚落点，特此留痕。

## 1. 做了什么

### 1.1 statistics 域查询（AC1 前半；aql.md §14.1 字段集照抄）

- **注册表开域**（fields.go）：十字段注册为三档——
  - **列背三字段** `stat.downloaded / stat.downloads / stat.downloaded_by`：全能力
    （criteria + include + sort），映射 nodes 的 `last_downloaded_at / download_count /
    last_downloaded_by`（T-438 单源列）。downloaded 走 date 归一（julianday 双侧，'' →
    NULL → 裸比较天然排除 never 行）；downloads 走整数比较；downloaded_by 走 string 族。
  - **恒零 stub 五字段** `remote_downloaded / remote_downloads / remote_downloaded_by /
    remote_origin / remote_path`：§14.1 映射裁定「BinFlow 无 smart remote 拓扑 → 恒
    null/0，勿造数据」——可查可投影、**不可 sort**（常量无序，登记为 C 层选择），
    planner 常量折叠（`foldStatStub`）：计数 stub 对常量 0 求值各比较符，null 值 stub
    只认 `$eq/$ne null`。
  - **内部 id 两枚** `stat.id / stat.remote_id`：维持诚实拒绝（"internal field, not
    exposed"，与 item 域 id 同款）。
- **null 字面量开禁**（parser.go validateValue）：statistics 域字段接受 `null`，仅
  `$eq/$ne`（顺序比较符配 null 无 Artifactory 注册语义，拒绝并点名——C 层选择，登记）。
  其余域维持既有拒绝文案。
- **IR 扩展**（metadata/aqlquery.go）：`QueryDownloaded/QueryDownloads/QueryDownloadedBy`
  三键；新谓词 **`QueryZero{Field, Negate}`**——null 字面量 = 结构零测试（counter=0、
  date/identity=''），raw 列比较（不走 julianday——'' 是文本不是日期），零值拼写单点
  （`renderZero`/`statsZeroValue`）；投影懒拉三计数列（SELECT 尾列，列数 11/13/14/16 四
  态）；`NodeQueryRow` 增三字段（计数列仅在投影点名时填充）。
- **嵌套输出**（httpapi/search_aql.go）：首个 stat include 位渲染 `"stats" : [ {…} ]`
  （活体 v16 逐形：字段四空格缩进、`} ]` 两空格收口；compact 单行）；include 覆盖域默认
  集——stats 块内容 = 恰好被点名的 stat 字段、echo 序。**criteria-only 的 stat 查询不加
  stats 块**（v16 只验证了 include 路径；登记为按已验证面实现）。
- **§6 脱敏延伸**（engine.go obfuscateRows）：`downloaded_by` 非空值对非 admin 读
  `unknown`；''（从未）保持 ''（渲染 null——unknown 是身份不是 null）。

### 1.2 /api/search/usage（AC1 后半；aql.md §14.2 逐行）

- **路由**：`GET /api/search/usage` 挂 routeAuth{}（匿名门在 handler——非匿名面）。
- **wire**：`notUsedSince` 必填 epoch 毫秒；`createdBefore` 可选（缺省回退 notUsedSince
  值，官方明示）；`repos` 可选 CSV。**勘误落实**：参数名按规格 `notUsedSince`，PRD 的
  `usageSince` 不成为对外参数名（派单防错条执行）。
- **命中语义**：`(downloaded < T OR downloaded IS NULL) AND (remote_downloaded < T OR
  NULL) AND created < createdBefore(缺省=notUsedSince)`，严格小于。实现为 **engine 第二
  入口 `RunUsage`**：手工构造固定模板 AST（下载臂 + remote 臂〔常量折叠为真，保留字面
  与规格登记的内部形态对位〕+ created 臂 + repos 组），走 `runAST`——与手写 AQL **同
  gate/同 deadline/同 cap+1/同 ACL 织入/同 re-check/同脱敏**（K63 零豁免的结构保证）。
  规格自身的单源论断（§14.1「usage REST = statistics 域单源」）即实现形态。
- **行形态**：恰五字段 `{uri, downloadCount, lastDownloaded, remoteDownloadCount,
  remoteLastDownloaded}`（活体 v8m 逐字节定案）；uri = storage API 路径（storageURI 同
  源）；`remoteLastDownloaded` 恒 epoch-0 字面 `"1970-01-01T00:00:00.000Z"`；**never
  行的 lastDownloaded 同为 epoch-0**（从 v8m 的 remote 臂类推：LastDownloadRestResult
  把 null 日期格式化为 epoch-0——推断级，登记待 V-i 对拍）。
- **空/错族**：未命中与缺参 → **404 `No results found.`**（反编译怪癖：缺参不走 400）；
  匿名 → 401 challenge（E5 文案）；非数字/负 epoch → 400（C 层：反编译未登记非数字臂，
  BinFlow 拒绝发明，登记）；非 GET → E-26 404；截断头沿用 `X-BinFlow-Search-Truncated`。
- **消费侧接口**：`usageRunner{RunUsage}` 断言自 s.aql（aqlRunner 的脚本化 fake 不受
  扰动）；指标走 observeLegacySearch（plane="legacy"）。

### 1.3 与 T-438 的单源复核（AC2 第三项）

- 零第二通道：本票**零新写点**——查询面只读 nodes 四列（QueryNodes SELECT 尾列 /
  QueryZero 谓词），usage 与 ?stats 两面同列（`TestT440UsageCountsMatchStatsFace` 引擎层
  + `TestT440UsageEndpointWire` HTTP 层双重复核 count 一致）。
- **T-438 遗留 #3 的裁定落实**：aql.md §14.1 的映射警告执行——AQL/usage 面的
  `remote_downloads/remoteDownloadCount` = 恒 0 stub（smart-remote 回拉维度，BinFlow 无
  源），**不映射** nodes.remote_download_count（那是「remote 仓作为服务点」的 K69 自有
  指标，?stats/Batch③ 面继续用它）——两维度同名不同义、两面并存，规格明文不冲突。需
  conductor 知悉：usage 行 remoteDownloadCount 恒 0，即使 ?stats 面显示非零。

### 1.4 顺手修的真实缺陷（planner 布尔折叠）

Or 的 vacuous-true 臂此前被**丢弃**而非**吸收**：`{"$or":[{"type":"any"},{"repo":"x"}]}`
会丢成只剩 repo=x（错——应命中全部）。本票 usage 模板的常量真 remote 臂立即踩中（整模
板折叠为 QueryFalse → 空集）。修法（plan.go lower）：And 空折叠 → nil（合取单位元），
Or 见 nil 臂 → 整析取 nil（吸收）。旧行为无测试钉过（错误行为未被固化），新快照钉新行为。
