## 2. 裁决落实

- **RP-2 = false（20:55 终裁，推翻 tl-fr91-ac3 表 A 的「true」）**：`calculateYumMetadata` 默认 false——PUT .rpm 仅存储 + `rpm.metadata.*` 九属性登记，不重算 repodata；reindex 端点或仓配置显式开启才触发。断言见 `TestUploadStoresWithoutRepodata`（PUT 201 → 等 150ms → repomd 仍 404）；opt-in 链见 `TestOptInAutoRecompute`（true → 后台重算落盘 + 同步 reindex 409）。
- **TL-5 SHA-256 唯一例外**：索引文件名摘要、repomd `checksum type="sha256"`、primary `pkgid="YES"` 三处一致 sha256（`TestReindexGeneratesRepodata` 断言 type 拼写；`TestClientE2EChecksumReconciliation` 三段对账）。
- **RP-1/DB-1 unsigned**：X-GPG-PASSPHRASE 接受并忽略；无密钥时删旧 `repomd.xml.asc/.key`（`TestStaleSignatureCleanup`）；签名链留 K-1 接口位。

## 7. 差异登记（与 rpm.md / 裁决的差异与留痕）

1. **RP-2 落实为 false**——按 20:55 用户终裁执行（tl-fr91-ac3 表 A 早先裁 true 已被推翻）；409 auto-async 冲突分支照规格保留（opt-in 仓拒绝同步 reindex）。
2. **TL-5 SHA-256**：与 Artifactory 默认 SHA-1 的唯一算法例外；三处（命名/type/pkgid）一致，测试钉死拼写 `sha256`。
3. **reindex 矩阵 virtual 分支未按 §3.2 的 202/200 实现**：BinFlow 尚无 rpm virtual 仓（其票未落）；virtual 行现在回答 400（文案指明 virtual 聚合随其专属票交付）。remote 行为同（本票仅 local）。
4. `.rpmcache` 失效键用 node sha256+size（规格 sha1+mtime）：sha256 严格强于 sha1，size 与 mtime 同答「内容变没变」；记录自管、损坏即弃。
5. **modules.yaml 透传不做**（票面 P2 外）：`repodata/*.yaml` 按普通文件读写（bare 面），reindex 不生成 modules 条目。
6. async 参数缺省按 0（同步）处理——规格未写缺省值；非法值（非 0/1）400。
7. 校验和旁车 GET 仅对 `.rpm` 基路径按 §3.1 精确 404；该面非 GET 动词 405（规格只列 GET）。
8. `repodata/` 下未识别文件（非生成族、非 .xml 组文件，如未来的 modules.yaml）PUT 走 bare 普通存储——规格 PUT 行只定义 .rpm 与组文件，此处取「未保留即放行」；生成族（repomd 三件套、digest 前缀索引、sqlite）一律 403（DB-3 姿态）。
9. `<revision>` 空内容照 S14（代码字面）；真实仓多放时间戳、dnf 容忍——实测 dnf 5 接受。
10. gzip 采用确定性输出（无 name/mtime、BestSpeed）：未变化的仓重算产生相同 digest 文件名，不堆叠相同代——规格未规定，属实现选择（收益：代数保留天然收敛）。
11. **跨区触碰（1 处，T-309 的 helm 测试）**：`internal/adapter/helm/handler_test.go` 的 `waitFor` 原为 100 次无 sleep 忙等，全量并行负载下抢不到调度致 `TestReindexEndpoints` 假红（本包重测试加入 CPU 负载后暴露；隔离与四包并跑均绿）。改为 200×25ms 轮询（上限 5s），断言语义零改动。已在此留痕，请 T-309 复核。
