## 新增 ADR 列表

- **ADR-0005 零 CGo 纯 Go 依赖基线**：modernc.org/sqlite + go.yaml.in/yaml/v3 + stdlib ServeMux；确立依赖准入原则（默认 stdlib、新依赖须 architect 记录、CGo 禁止）、首批白名单。
- **ADR-0006 blob 磁盘布局与上传落盘协议**：`blobs/<sha256[0:2]>/<sha256>` 无 sidecar、session 纯磁盘态、temp→fsync→rename→fsync(dir)→元数据事务的顺序、并发 singleflight 幂等去重、GC=mark-sweep+24h grace 且默认 dry-run。布局即兼容契约。
- **ADR-0007 元数据迁移机制与 SQLite 并发策略**：自写 embedded SQL 迁移器 + schema_migrations 记账、sqlite/postgres 双方言目录同号演进、WAL+busy_timeout+MaxOpenConns=NumCPU、时间戳 RFC3339 文本、禁 SQLite 专有特性入迁移 SQL。

## 关键设计点（供 tech-lead 拆票参考）

- 包边界=area 边界：adapter→repo→{storage,metadata} 单向依赖；storage 不 import metadata；repo.Put 的「先物理后元数据」事务边界（崩溃只产生可 GC 的无引用 blob，不出现元数据悬空）。
- 接口契约精确到签名：storage.Engine/Session、metadata.Store/NodeStore、repo.Service、auth 三件套、audit.Logger、adapter.Handler+Register——各 dev 角色据此并行开发，变更须走 architect。
- SQLite DDL 9 张表定稿（repositories/remote_configs/blobs/nodes/users/tokens/permissions/audit_events/virtual_members + schema_migrations），含索引与首启 admin 引导（无默认弱口令）。
- 配置：单 YAML 全量字段 + `BINFLOW_`/`__` env 覆盖，未知键 fail-fast。
- 部署约定：/healthz /readyz、/etc/binflow/binflow.yaml 挂载点、M1 单副本挂 RWO PVC（多副本由 values 校验拦截）、优雅停机 ≥30s。
