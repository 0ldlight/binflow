## 1. 收敛方案论证（二选一裁定）

**定位**：npm 适配器内的私有 `escapePathSegments`（packument.go，逐段 `url.PathEscape`、分隔 `/` 不动）只有两个消费点：
1. `renderPackument`（packument 整文档渲染，packument.go:481）；
2. `serveVersion`（单版本 manifest 渲染，serve.go:143）。

（`packumentURLPrefix` 只拼前缀不转义；grep 全包核实无第三消费点、无其他逐段转义残留。）

**裁定：直接调 `client.EscapePathSegments`**（方案一），理由：
- **依赖方向无环**：`go list -deps ./internal/client` 确认 client 是叶子包（零 binflow 内部依赖）；adapter→client 单向。先例：`internal/migrate`（服务侧工具）已 import client。

- 两实现逐字节同构（见 §2 探针），收敛即删私有副本、两消费点改调导出函数，无任何行为面。

**行为逐字节零变化的三重证据**：
1. **同构探针（收敛前运行后删除）**：临时测试对比私有实现 vs `client.EscapePathSegments`，语料 = 全部可打印 ASCII 单字符（孤立/嵌入/分段三形态）+ 结构样本（scoped/`~`/`%`/中文/emoji/`'`/`$`/`;`/`,`）= **299 例 0 不匹配**。

## 3. 测试矩阵（escaping_test.go）

- **`TestTarballURLWireSpellingPinned`**：T-231 五字符矩阵（`%`/空格/`#`/`?`/UTF-8 中文）的 npm 面子集 + 结构边界。合法 npm 字符集（`[A-Za-z0-9._~-]`、scoped `@`、semver `+`）**原样透传**（registry.npmjs.org 同拼写）；`'`→`%27` 而 `$` 保留；`;`→`%3B`、`,`→`%2C`；字面 `%2F` 双重编码为 `%252F`；空串/尾斜杠边界。
- **`TestRenderPackumentEscapesTarballRefs`**：renderPackument 三臂——存储字面 rel / 回显绝对 URL（先归约再转义，幂等）/ SLIM（corgi）协商（dist 在白名单，转义 URL 幸存）。
- **`TestServeFacesEscapedTarballRoundtrip`**：真实协作者栈（真实 storage+repo.Service）× 十行矩阵。生产触发形态 = **合法包名 + 特殊字符 rel**（-rev 回显或 remote 中继归约出的字面 rel；npm 自身 publish 字符集门永远产不出）。四面：packument GET 渲染 / 单版本 GET 渲染 / **转义 URL fetch**（Layout 百分号解码回字面节点路径并流出字节）/ npm 10 -rev 回显。
- **`TestSpecialCharNameUnvalidatedFaces`**：特殊字符**包名**直达无校验面（serveVersion/serveTarball 无 charset 门）+ packument GET 面钉住 400 charset 姿态（证明收敛未松动校验）+ 特殊名下 -rev 回显幂等（canonical==rel，两臂殊途同归同一转义 URL）。

## 4. 既有语义发现（本票只登记不改，行为零变化口径的组成部分）

测试编写过程中核实的三点**既有**语义（全部先于收敛存在、收敛前后逐字节不变，测试按现状钉死）：
1. `versionDistTarball` 的归约只认 binflow-mount **URL**；`applyRevDocument`（-rev PUT）把 dist.tarball 归约成**裸 rel** 存储，下一轮渲染不再认得 → 回落后 canonical `<pkg>/-/<pkg>-<ver>.tgz`。对「包名特殊」的包 canonical==rel 故幂等；对「合法包名+特殊 rel」（remote 中继形态）一次回显即塌缩为 canonical——若未来要求中继引用稳定，属语义票。
2. `relativeTarballPath` 对 tail 做**二次** `PathUnescape`：`%25` 先被 `url.Parse` 解成字面 `%`，二次解码见 `%e` 非法转义失败 → canonical 回落。即字面 `%` 的引用经回显必塌缩（上表 `%` 行单独钉死）。
3. remote 引擎上游 URL 构造（`internal/remote/client.go JoinURL`）为裸拼接、不走 `client.EscapePathSegments`——上游路径含字面 `%` 时是 D-1 同类（`url.Parse` invalid escape）潜在点，**area 外**，建议登记候选票。
