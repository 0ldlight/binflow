- **持久定案（AC1 留痕）**：per-page localStorage——键 `binflow-console-cols-repos` / `binflow-console-cols-audit`（ThemeContext `binflow-console-theme` / recent-searches 同款「浏览器本地、无账号面」偏好族）；值 = 隐藏列 id 的 JSON 数组（默认 `[]` = 全显，存储面最小）。读回清洗：未知 id 剔除（列集演进不炸）、「全隐」回落全显；隐私模式 try/catch 双向退化会话内。

- **刷新语义**：仓库页 = `useAsync` reload（列表 403/error 态照常可用；用量批量随 loading→ok 变迁自动重注，T-258 单请求语义不变）；审计页 = `useAuditPages` 加 `tick`（effect 依赖 `[key, tick]`；过滤保持、已加载增量丢弃回第 1 页——与过滤变更同语义；顺手把 effect 内 filters 改经 `JSON.parse(key)` 取用，exhaustive-deps 不再需要豁注释）。
- **「无端点列不伪造」（AC2）**：列选菜单列集 = 既有全部列闭集（仓库 7 / 审计 6）；无「更新时间」列（T-99 契约缺口沿 R 登记）、无 remote 状态列（无端点不伪造）。
