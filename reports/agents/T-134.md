## 修复项

- **`simpleSha256` ESM 兼容**: 原代码使用 `require('crypto')`（CJS），在 ESM 项目（`"type": "module"`）中会失败。改为 `import { createHash } from 'crypto'`。

### e2e 测试修复 (2026-08-21 第二轮)

1. **Docker v2 API 推送流程错误**: 原测试用 `PUT /v2/{repo}/{image}/blobs/sha256:{digest}` 上传 blob，但 `serveBlob` 只接受 GET/HEAD。修复：改用单体上传 `POST /v2/{repo}/{image}/blobs/uploads/?digest=sha256:{hex}`。

2. **认证缺失**: v2 API 路径 `/v2/...` 不在 `/binflow` 下，session cookie 不会发送。`apiV2` 添加 `authUser`/`authPass` 参数支持 Basic auth。

3. **Manifest 引用不存在的 config blob**: `putManifest` 验证所有子引用存在。创建 `pushManifest` helper，先上传 config blob 再构建引用真实 digest 的 manifest。

4. **前端缓存陈旧 bug (TreePage.tsx)**: `isDockerRepo` 在 `repoMeta` 异步加载完成后才变为 true，但 `cacheRef` 已经缓存了无 `?docker_tags` 的数据。修复：添加 `useEffect` 监听 `isDockerRepo` 变化，清空缓存并触发重新加载。

5. **列标题断言 strict mode 违规**: `toContainText` 在多个 `<th>` 上触发 strict mode。改用 `nth(4).toHaveText('摘要')` 和 `nth(1).toHaveText('标签')`。
