## 8. 过程记录（坑与修法）

1. **td 的 `onKeyDown stopPropagation` 吞 Esc**：仓库列表行操作格为防行
   导航加了键盘 stopPropagation——聚焦在行内按钮时按 Esc，keydown 在 React
   根即被截断，document 级对话框监听收不到（对话框关不掉）。修法：键盘
   stopPropagation 移除（行导航只有 click 语义，按钮 Enter 激活按钮自身，
   不冒泡出行）；e2e 入口腿有 Esc 关闭断言钉死。
2. **axe scrollable-region-focusable（serious）两处**：① modal 本体
   `overflow-y:auto`（宽内容实际可滚）→ modal root `tabIndex=-1` + 挂载聚焦
   （顺带承载初始焦点）；② 对话框内 `<pre>` 命令块 `overflow-x:auto` 且
   实际溢出（全宽页面上不溢出所以详情页从未触发）→ `<pre tabIndex={0}>`
   （可滚动区键盘可达，WCAG 2.1 正解）。
3. **显式「部署」步与哈希相序**：入队即 `hashing` 会让「部署」钮在哈希
   完成前恒禁用（inFlight 判定含 hashing），而泵未启动哈希永不完成——
   死锁。修法：入队态改 `queued`，泵内「无 localSha 先算」（queued →
   hashing → queued → uploading），按钮只看 queued/uploading。
4. **generic 的 token 嵌位**：generic 配置侧（下载）不含凭据——token 明文
   在部署侧 `curl -u`；e2e 断言先查配置面占位符退场、切 Tab 后断言部署面
   token 明文（npm 侧则配置面 `_auth` 直接可见）。
5. **armed 实例验证法**：`BINFLOW_AUTH__TOKEN_STEP_UP=true` 起第二实例
   （18089），spec 内探针 sessionApi 铸币判定 armed 与否——默认实例自动
   skip 该腿、armed 实例跑真 401/逐字错误/续铸全链；mock 腿与真实腿互补
   （mock 保证逐字文案断言在任何实例确定性成立）。
6. **`.row-link:hover` 亮色 4.47:1（axe serious，repositories-admin 三 Tab
   腿被本票全量重跑命中）**：过滤空态「清除过滤」点击后指针停在原处，表格
   重渲染时首行 key 链接恰在指针下 → `tr:hover`（surface-2 底）+
   `.row-link:hover`（accent）= 亮色 4.47:1，差 0.03 不过门（T-236 `.on-chain`
   同款病灶）。属共享层潜伏缺陷（与 T-241 badge.warning 4.26:1 同族），非本
   票 diff 引入；但 axe 门挡在全量绿前面。处置 = repositories.css 内 5 行
   修复（hover 行上的链接色回 `--bf-text`，hover 语义由下划线承载）+
   §5 登记共享层对比度家族票——**越界 5 行，conductor 复核可单独 revert**
   （revert 后该腿回到失败态，病灶仍在）。
