### AC ① 004 迁移（sqlite 实装 + postgres 占位）

- **`migrations/sqlite/004_console_governance.sql`**（新文件）：严格照架构 §6 004 定稿块落 DDL——
  - 列级增量两处（PRD R2 登记）：`ALTER TABLE users ADD COLUMN email TEXT NOT NULL DEFAULT ''`（FR-27-AC8）+ `idx_audit_actor(actor,time)` / `idx_audit_action(action,time)`（GE-01/NFR-P17）；
  - 四表：`groups`（id ROWID、name UNIQUE）、`user_groups`（**T-108 勘误名**，非派单摘要里的 `group_members`——AC ①「严格按架构 §6 定稿 DDL」优先；PK (group_id,username)，双 FK ON DELETE CASCADE）、`web_sessions`（id_hash=sha256 主键、expires_at 绝对 TTL、last_used_at、revoked_at；FK→users CASCADE；idx_web_sessions_user）、`repo_usage`（repo_key PK、logical_bytes；FK→repositories CASCADE——本票只建表，计量方法归 T-95）；
  - 文件体内零 BEGIN/COMMIT（TestMigrationsHaveNoTransactionStatements 004 子测绿，T-10 M9 红线）；
  - 语句全部在 SQLite/Postgres 共同子集内（无 AUTOINCREMENT/RETURNING）。
- **`migrations/postgres/README.md`**：版本史补 004 行（postgres 仍占位，FR-3-AC10）。
- **幂等 + 老库升级**：迁移器零改动（T-10 范式直接吃新文件）；`TestConsoleGovernanceMigrationIdempotent`（重复 Open 不重跑）+ `TestConsoleGovernanceUpgradeFromHistoricalShapes`（M1=001 only / M2=001+002 / M3=001+002+003 三形态 table-driven：升到最新版、存量行/口令不动、legacy 用户 email 回填 ''、004 面立即可用）；既有 `TestOpenIdempotentMigration`/`TestDockerMigrationIdempotent`/`TestRemoteVirtualMigrationIdempotent` 经 latestMigrationVersion() 泛化，自动覆盖 004。`TestDockerUpgradeFromM1Database` 的回卷语句表补 004 拆除（DROP 四表二索引 + `ALTER TABLE users DROP COLUMN email`）。

### AC ② 三个子接口

- **`api.go`**：新类型 `Group`/`WebSession`/`AuditQuery`；新哨兵 `ErrGroupNotFound`/`ErrWebSessionNotFound`/`ErrInvalidCursor`（T-93 映射 400 用）；`Store` 增 `Groups() GroupStore`、`WebSessions() WebSessionStore`；`AuditStore` 增 `Query(AuditQuery)`（`List` 原样保留——internal/audit logger 仍消费，零回归）；`User` 增 `Email` 字段 + `UserStore.UpdateEmail`（**给 T-97 SE-05/06 的落盘缝**：T-97 area 是 auth/httpapi，加不了 metadata 方法，故本票一并供出）。
- **`substores_console.go`**（新文件）：
  - `GroupStore`：Create/Update（仅 description，ErrGroupNotFound）/Get/Delete/List（name 序）+ `SetUserGroups`（单事务原子替换：清旧行→按名解析 id→逐行插；未知组返回带组名的 ErrGroupNotFound——SE-06 400 文案源；重名去重；空表清空）+ `GroupsOfUser`（认证时 Principal.Groups 填充源，JOIN user_groups，name 序）；
  - `WebSessionStore`：Create（revoked_at 强制 ''）/GetBySHA256（过期/吊销行也返回——调用方区分「未知 cookie」与「已登出」）/Touch/Revoke（幂等再吊销）/`ListSweepable(now, limit)`（过期或已吊销 = 启动清扫候选，expires_at 序——架构 §11 第 18 条 sessions/ 目录同构模式）/Delete；错误信息里 id_hash 截短（日志最小化）；
  - `AuditStore.Query`：repo/actor/action 等值 + Since/Until **闭开区间**（`time >= since AND time < until`，PRD GE-01）+ keyset cursor；排序 `(time DESC, id DESC)`——正是 (column,time) 复合索引物理序的倒序，索引既供过滤又供排序，免 SORT；cursor 格式 `<RFC3339>|<rowid>`（RFC3339 无 '|'，Cut 无歧义），malformed → ErrInvalidCursor；`auditStore.List` 重构为共用 `scanAuditEvents`（SQL 与语义逐字不变）。
- **`substores_auth.go`**：users 的 Create/Get/GetByPasswordHash/List 全部带上 email 列读写；新增 UpdateEmail；`store.go`：`sqliteStore` 挂 Groups()/WebSessions()。
