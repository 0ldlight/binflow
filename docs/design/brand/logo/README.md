## 0. 设计约束（先于美学）

1. **色板锚定现有主题**：品牌主色**不另起炉灶**，直接采用主题 token `--bf-accent`（亮 `#0b6bcb` / 暗 `#4aa3ff`），结构色用 `--bf-text`（亮 `#1d232c` / 暗 `#e9edf3`）。理由：控制台是产品第一门面，logo 与 UI 同源才成体系；`#0b6bcb` 这档工程蓝本身就是「国际化 + 技术感」的正解，换色收益为负（全站链接/主按钮/焦点环都得跟着动）。
2. **形态约束**：
   - 无文化特定符号、无双关语（不做「中文谐音/生肖/山水」类隐喻）——国际化第一判据；
   - 几何构成、可在网格上重画（技术感第二判据），隐喻限于 bin（容器/仓库）与 flow（流/管道）两个产品自身概念；
   - 16px→512px 单形可缩（favicon 是最苛刻用例）；
   - 深浅底双版本 + 纯 currentColor 单色版（侧栏、按钮内、打印都可用）；
   - 不使用渐变、不做拟物（MUI 原生设计语言的直线系审美）。

## 1. 候选对照表

三稿共用 wordmark 规则：`Bin` 用结构色 + `Flow` 用品牌主色的双色 wordmark（几何无衬线 Bold、字距 -0.5%），暗底自动换 `--bf-accent` 暗色值。规格表内 wordmark 以 `<text>` + 字体族表达，**生产件必须转 path**（见 §3 字体注记）。

| 判据 | 候选 1 容器·双箭流<br>`candidate-1-bin-chevron.svg` | 候选 2 括号·数组流<br>`candidate-2-bracket-stream.svg` | 候选 3 六边容器·折线流<br>`candidate-3-hex-flow.svg` |
|---|---|---|---|
| 概念 | 圆角容器（bin）+ 描边箭→实心箭的加速对（flow），兼读终端提示符 `»` | 方括号（bin=array/仓）+ 三流线其一汇成箭头出仓 | 六边形容器 + 下折流线（pipeline 逐级下泄） |
| 国际性 | 优（`»` 是全球通用的命令行符号） | 优（方括号是代码通用符号） | 良（六边形无语义风险，但辨识度被摊薄） |
| 技术感 | 优（容器 + 终端双隐喻，恰合「制品仓库」） | 优（数组 + 流，程序员味最浓） | 中（六边形偏「区块链/化学」泛技术） |
| 16px 可辨 | **优**（两个箭头的疏密对比在 16px 仍可辨） | 中（水平笔画堆叠，箭头退化为楔形） | 差（内部折线在 16px 糊成一团，需简化派生） |
| 单色可用 | 优（去色后轮廓完整） | 优 | 良（内流线弱化） |
| 深浅底 | 双版本齐 | 双版本齐 | 双版本齐 |
| 与既有 UI 的独特性 | 高（无生态撞形） | 高 | 中（与 helm 图标族、部分协议标共享六边形语言） |
| 备注 | 视觉重量最均衡，mark 在侧栏 224px 窄条内不挤 | 横幅感强，适合 banner，favicon 弱 | 立体感最强，但小尺寸工程量最大 |

## 2. 推荐：候选 1「容器·双箭流」

**推荐理由（三条）：**

1. **favicon 起决定性作用**。产品 logo 的高频曝光位是浏览器标签页（16px）与文档站导航（20~24px），候选 1 是三稿中唯一不需要为小尺寸另做简化形的方案——圆角容器 + 双箭的疏密对比天然抗缩放；候选 3 在 16px 下内部折线必须整条删除，等于两个 logo。
2. **隐喻双关而不歧义**：`»` 读作终端提示符（工程师的肌肉记忆），双箭从细到粗读作「进站—出站/加速的流」，容器读作 bin（仓库/集装箱）。「BinFlow = 制品进仓、按需流出」与产品叙事一一对应，且全部隐喻无文化边界。
3. **系统兼容性最好**：mark 与 MUI 原生视觉（圆角 6 的容器壳、直线条、单色可用）同语言；双色 wordmark（Bin 中性 + Flow 蓝）在侧栏深底与登录页浅底都不需要第三种颜色。

**mark 几何规格（48 网格，便于 FE 复刻）：**

- 容器：`rect(5,5,38,38) rx=9`，描边 3.5（约 7.3% 边长），结构色；
- 描边箭：折线 `(14.5,16.2)→(24.5,24)→(14.5,31.8)`，描边 4、圆帽圆角，品牌主色；
- 实心箭：三角 `(23.5,14.6)(33.5,24)(23.5,33.4)`，品牌主色填充——比描边箭略高（光学补偿：实心形显小）；
- 全部元素水平中心 = 24（容器中心），双箭整体略右置（箭尖视觉留白补偿）。

**色彩规格（与 tokens.css 一一对应，改 token 必须同步）：**

| 元素 | 亮底 | 暗底 |
|---|---|---|
| 容器描边 | `#1d232c`（--bf-text） | `#e9edf3`（--bf-text） |
| 双箭 | `#0b6bcb`（--bf-accent） | `#4aa3ff`（--bf-accent） |
| wordmark `Bin` | `#1d232c` | `#e9edf3` |
| wordmark `Flow` | `#0b6bcb` | `#4aa3ff` |
| 单色版 | 全部 currentColor（继承调用处文字色） | 同左 |

## 3. 字体注记（wordmark）

- 规格表用 `font-family: Inter, 'Helvetica Neue', Helvetica, Arial, sans-serif; weight 700; letter-spacing -0.5%` 表达意图——几何无衬线、中等字面宽、可用 OFL 授权（Inter SIL OFL 1.0，可嵌入）。
- **生产件必须把 wordmark 转 path**（favicon/SVG 独立分发时不携带字体依赖；本仓库 UI 未加载 webfont——`MuiProvider.tsx` 用系统字体栈，见 R6 决策）。转 path 时用 Inter Bold；若用户偏好零外部字体，退路是按 path 手工勾画（工作量 +0.5 天，收益是与文档站字体零耦合）。
- 不建议 wordmark 用等宽字体：mark 已经是「技术形」，wordmark 再 mono 会过度编码味，且与 MUI 默认 sans 的 UI 文字打架。
